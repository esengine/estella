**An agent working in Estella is told how a task is done here and can prove it done: official skills and `verify`.** Any agent connected to the editor's MCP server is told at connect to read `skill_guide { skill: "estella-workflow" }` first; four skills cover the workflow every task follows, screen UI, 2D gameplay and finding why something fails, each with the mistakes agents make in that kind of work (a UI node placed by its Transform, which the layout overwrites; a `UIVisual` that draws nothing until its type is set; a running game read twice without stepping it; a label changed on an object nothing observes) and how to prove the result. They are ordinary `SKILL.md` directories in `skills/`, shipped beside the templates, so an agent that loads skills itself reads the same files. `verify` gives one verdict over whether the work is done: the scripts build, the scene has no empty required field or dead reference, nothing blocks a build, and the game, played deterministically with the inputs given at their frames, meets the expectations given (an entity's field compared, changed or unchanged since play began, present or absent), logs no error while it runs, and draws more than one flat colour. Each failure says where it is and what to do; a task's expectations can be written first, in an acceptance file `verify` reads.
