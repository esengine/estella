**Nothing is compressed unless you tick it.** The Build dialog's single Compression switch, which applied every asset's import settings unless set to Skip all, is replaced by one box per kind of compression the target can do: textures by their import settings (KTX2 and Max Size), packing `.atlas` folders, WAV to MP3, the engine binary on mini-games, and on a playable its images as WebP (off, lossless, quality 90 or 80). Every box is off until ticked, and an export profile can set each one. A playable's size budget is still reported, but it no longer chooses anything: before this, a playable over its budget had its images re-encoded to WebP down to quality 80 and its audio lowered to 96 kbps without being asked. The setting older projects carry (`packaging.assetCompression`) is no longer read, so a project that relied on its default now ships uncompressed until the boxes it wants are ticked.
