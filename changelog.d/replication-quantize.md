**Replicated numbers can be sent as whole numbers of a step, with `quantizeReplicatedFields`, and every state row is smaller.** `quantizeReplicatedFields('Transform', { position: 1, rotation: 0.01 })` (from `esengine/replication`) sends those fields as a count of steps in one to three bytes instead of a four-byte float; the value that arrives is the nearest multiple of the step, and an object field quantizes every number in it. A field moving less than a step is not sent until the movement crosses one, so a client is never more than half a step off. Both ends declare the same steps at startup, and the handshake refuses a client whose steps differ. Every state row's header (entity, component, fields) is now variable-length too, so a row costs a few bytes before its values instead of ten. This is replication protocol 6: clients and servers must be updated together. Measured with `tools/net-sample-microbench.mjs --wasm --quant 1` (800 players, positions to 1 unit), a row went from 22.4 bytes to 9.7, about two thirds fewer rows were sent, and the sample went from about 9 ms to about 6.5 ms. The networking guide's interest examples now import from `esengine/replication`, where they live.
