**UI nodes can be dragged in the viewport and while the game runs.** With Inspect While Playing (F8) on, a UI node had no handle, so nothing on a Canvas could be moved in the running game, and in the scene view a node placed by its layout (Relative) only showed a hint to switch it to Absolute. Now an Absolute node follows the drag in both, its insets moving in their own units so an anchor stays an anchor, and a Relative node dragged inside its row or column takes the place among its siblings the pointer is over, as Unreal's designer and Figma's auto layout do. A drag in the scene is one undo step; an Absolute node moved while playing can be kept at Stop. A game can do the same with `moveUINodeBy` and `moveUINodeToward`.
