## 共同造型规则

- 深枪灰为大面积底色；青色表现动力与反应堆，橙红表现武器，暖白表现驾驶与生活区。
- 方形连接面使用黄黑框，保留清楚的模块接缝和未占用接口。
- 船体、货舱和设备以大形体为主，面板磨损作为表面细节，避免用密集小零件堆叠轮廓。
- 玩家共用模块和接口规则；细长主干、宽货舱架、分支平台和不对称布置由玩家选择。
- 6 / 20 / 50+ 是拼装示例的规模设计目标，尚无对应的装配清单或逐件计数验证，不能作为已验证的模型数量使用。

## 模块目录

COCKPIT、HULL 2x2、HULL 2x4、CORRIDOR、CARGO BAY、ENGINE L、ENGINE S、THRUSTER、TURRET、REACTOR、SOLAR PANEL、DOCKING PORT。

同型号部件应复用同一份网格；引擎喷口形状与结构连接面的方形标准分别处理。生活舱、货舱及方形接口是否允许人员通行，需要单独标记。

## 尺寸与内部空间

本轮将 2x2 / 2x4 解释为网格格数：在 2m 吸附网格下，规划占地分别为 4m × 4m 和 4m × 8m。该解释用于后续白模的尺寸约定，不代表已从图片测得一致的尺寸。

2m 网格约束放置步长，不等于每个舱室仅高 2m，也不等于人员通道的净空。高度、通道净宽净高、地板与顶部设备空间、门框、墙体厚度仍须在白模中确定，再统一到所有模块。

图集中部分视图带轻微俯视或透视；视角之间的装饰面板、开口与接口数量也不是经过同一 3D 网格投影验证的。应先锁定一份尺寸正确的基础舱段，再从统一网格输出生产用正交参考。

外壳、内部通道、门、连接框和封口盖应分别管理。内部空间由规则化白模建立，不能依靠整船图片重建来自动推断。发动机、反应堆等设备可以是封闭模块，不要求每个接口都连通人员通道。

## 后续建模入口

1. 先建立基础舱段和一个通道件的尺寸白模，确定接口中心、朝向、原点及人员净空。
2. 按单件准备无遮挡、无标签的独立参考；不要把整张图集或三艘不同船当成一个物体输入 Tripo。
3. 在 Tripo 使用用户指定的“智能网格”，先验证一个外壳模块；当前包尚未进行这一新风格的建模。
4. 校准输出网格的真实单位、接合平面、壁厚及开口，再制作其他兼容模块。拼装检查应包括转角、纵向串联、并排货舱和不对称布局。
5. 检查拓扑、法线、UV、碰撞、材质、遮挡与细节层级，最终画质和性能以实际目标手机验收。

先前另一风格的试件不属于本包，也不应混入本包的同一物体多视角输入。
