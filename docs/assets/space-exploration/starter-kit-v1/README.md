# 模块化起步舰参考包 v1

用于太空探索建造手游的 3D 舰船建模与 2D 建造界面设计。起步舰是零件库的一种装配示例；玩家可以改变骨架、分支、舱段数量、设备位置和外装。

本包是首轮造型与拆件参考，尚未执行 Tripo 建模、接口尺寸校准或引擎验收。图像不能替代经过验证的网格和装配尺寸。

## 差异化与连续性

- 共用接口标准、尺寸规则和材质规范；布局允许由玩家决定。
- S01 可重复串联，J01 支持分支，G01 与 P01 可通过对应支架改变位置。对称布局可选。
- LONG / WIDE / OFFSET 展示轮廓差异，不是固定职业、强度等级或升级顺序，也不代表三者已经完成数值平衡。
- C01 只是第一种驾驶舱。后续可制作不同形状、共用 U1 接口的驾驶舱和船首族。
- 玩家可以选择保留一到两个外观标志，例如特定驾驶舱、双引擎布局、侧向货舱或识别条纹。连续性属于这位玩家自己的船，不要求所有玩家保留相同外形。
- 船籍、舰名、航行记录和装配历史独立于物理零件保存；更换骨架或驾驶舱不会清除船的历史。

## 接口约定

**U1：结构连接接口。** 概念外形为带倒角的方形连接框，用于驾驶舱、龙骨、连接节点和服务舱。实际可用分支方向、通行空间、锁定键位与承载能力，应在模型的连接点定义中显式标记。

**U2：设备挂点。** 概念外形为较小的带定位键机械座，用于外挂货舱、支架和设备。U2 本身不代表气密人员通道。

U1 与 U2 不直接互换；需要时通过独立转接件连接。当前图像没有批准毫米级尺寸、统一比例或工程公差。建模时先确定基准舱段，再统一接口尺度、轴向、原点和接合面。

同型号 P01 的封闭前端朝舰首，主喷口朝舰尾。爆炸图为了展示零件会使用不同观察角度，最终装配方向以整船正/背/侧参考为准。

## Tripo 使用

1. 首轮整船形体重建使用 tripo-views 中的四张独立图片。按 front / left / back / right 显式对应视角；不要把六视图、爆炸图或三个不同布局当成同一物体的四个角度。
2. 保持模型朝向一致。左右侧参考本来朝向相反，不要为了排版将它们镜像成同一侧。
3. 六视图中的 TOP/BOTTOM 都是舰首朝画面左侧，供人工检查顶面和腹面；本包没有将它们映射为 Tripo 的左右视角。
4. 本轮独立图片基于同一张设计表分别整理，未从统一 3D 网格渲染。轮廓、主要部件与方向已目检；小面板和连接细节仍可能存在差异。首轮网格建立后应统一这些细节，并从统一网格重新输出生产用参考。
5. 要得到可拼装的游戏零件库，按 C01–K01 分别建立单件模型。爆炸图用于指导拆件；整船重建只用于形体验证，不直接代替可编辑模块库。
6. 先校准 U1/U2 接合面与连接点，再检查法线、UV、材质、碰撞、细节层级和模块间遮挡。高质量目标最终以引擎画面与目标手机性能验收。

Tripo 官方输入说明：[Multi-View to 3D](https://www.tripo3d.ai/product-doc/model-generation/multi-view-to-3d)。

## 本轮检查

- 六视图包含全部指定方向；顶/底视图实际排版方向已记录。
- 四张独立视图无文字、无面板分隔，整船未裁切。
- 正/背视图有两个推进器；侧视图中远侧推进器按观察方向被遮挡。
- 八类模块编号与拆件图对应。
- 三种组合在相同配色下具有不同轮廓。
- PNG 可解码，文件尺寸和散列已记录于 manifest.json。
- 未验证真实 3D 配合、可动结构、动力学、Tripo 输出或设备性能。
