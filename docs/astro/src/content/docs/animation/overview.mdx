Estella provides four animation systems. Each has its own asset type, editor and playback component, and all four
apply to both 2D and 3D scenes.

| System | Purpose | Asset | Editor entry point | Played by |
| --- | --- | --- | --- | --- |
| [Timeline](/docs/animation/timeline/overview/) | Time-based sequences of property keys, visibility, audio, camera shots and events across several entities | `.estimeline` | **Add → New Animation** (Sequencer) | **Timeline Player** with **Timeline** assigned and **Playing** ticked |
| [Sprite animation](/docs/animation/sprite-animation/) | Frame-by-frame playback of a sprite sheet or a sequence of images | `.esanim` | Right-click a texture → **Create Sprite Animation** | **Sprite Animator** on an entity with **Sprite** (right-click the clip → **Create Animated Sprite**) |
| [Animator](/docs/animation/animator/) | Parameter-driven state machine that selects, blends and layers clips | `.esanimator` | **Add → New Animation Controller** | **Animator** with **Controller** assigned |
| [Tweens](/docs/animation/tweens/) | Interpolation of a single property from code | — | — | The `Tween` resource, called from a script |

![The Content Browser Add menu with New Animation in the middle and New Animation Controller near the bottom](@/assets/guides/en/animation-create-menu.png)

**New State Machine** in the same menu creates an `.esfsm` for gameplay logic ([AI](/docs/gameplay/ai/overview/)); a
character animation graph is an **Animation Controller**.

## Relationship between the systems

- A timeline is the general clip format. An Animator state can play a timeline clip, which is how a skinned 3D rig
  and any keyed component field are animated by a state machine.
- An Animator state can also play a sprite clip or a [Spine](/docs/animation/spine/) animation, so one controller
  drives a whole character.
- Tweens and timelines both write component fields. A timeline suits many properties or entities animated in
  lockstep; a tween suits a single property changed in response to gameplay.
- Animation events declared on a clip are delivered on the `AnimatorEvent` bus when the clip plays in an Animator
  ([Animation events](/docs/animation/animator-events/)), and on the `TimelineEvent` bus when it plays on a
  `TimelinePlayer` ([Event and marker tracks](/docs/animation/timeline/tracks/#event-and-marker-tracks)).
