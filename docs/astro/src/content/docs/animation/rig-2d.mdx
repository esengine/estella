A 2D rig deforms one image with a bone skeleton. Rigs are authored in the editor from any PNG, with no external
animation tool or third-party format. [Spine](/docs/animation/spine/) and [DragonBones](/docs/animation/dragonbones/)
skeletons can be used alongside rigs.

## Structure

| Element | Description |
|---|---|
| **`.esrig`** | Authoring source: the parts cut from the image, the bones, and the bone weights of each vertex. |
| **`.esmesh`** and **`.esprefab`** | Written beside the `.esrig` on save. Scenes reference these, so builds contain no authoring data. |
| **Bones** | Ordinary entities with a `Transform` and a `Bone2D` component. Clips, the Animator, layer masks and code address them like any other entity. |

| `Bone2D` field | Type | Default | Description |
|---|---|---|---|
| `length` | number | `0` | Reach of the bone along its local +X. An IK chain ending at this bone reaches for its target with this end. |

## Creating a rig

Right-click an image in the Content Browser and choose **Create 2D Rig**. The rig editor's modes, along the top, are
ordered as a character is built:

| Mode | Operations |
|---|---|
| **Parts** | **Split by Transparency** cuts a sheet of limbs into parts. Drag parts to assemble the character. The list on the right sets draw order. |
| **Bones** | With **New**, drag to create a bone; starting on another bone's end continues from it. With **Select**, drag a bone's end to aim it and its body to move it. |
| **Mesh** | Every part starts covered by a grid. Smaller cells deform more smoothly and cost more. Drag a vertex to adjust it. |
| **Weights** | **By Distance** binds each vertex to the nearest bones; then paint corrections: pick a bone on the right and drag. `Shift` inverts, `Ctrl` smooths, `[` and `]` change the brush radius. **Whole Part to Selected Bone** binds a rigid piece to one bone. |
| **Deforms** | **New Shape**, then drag to displace vertices, for shapes such as a breath, a smile or a bulge. |
| Command | Effect |
|---|---|
| **Try Pose** | Rotate bones to test the weights. Does not modify the rig. |
| **Bind Pose** | Returns from Try Pose to the bind pose. |
| **Place in Scene** | Saves the rig and instantiates its prefab. |

Saving again updates every instance in the open scene, keeping per-instance changes made in the scene.

<Aside type="note">
  Single vertices cannot be added or deleted, and a rig draws from one image. Regenerating a part's mesh clears that
  part's weights and deforms; the editor asks for confirmation first.
</Aside>

## Rebinding

A rig's skeleton can be changed after weighting:

| Operation | Behaviour |
|---|---|
| **Move a bone** | In **Bind Pose**, dragging a bone or typing its length or rotation changes the bind pose itself. The image stays in place. |
| **Change parent** | In **Bones**, set **Parent** for the selected bone, or **None (root)**. The bone and its descendants keep their place in the image. |
| **Rename or remove** | Removing a bone hands its children and vertices to its parent. |
| **Recompute weights** | Run **By Distance** or **Whole Part to Selected Bone** again, then paint. |
| **Rebind to another skeleton** | Under **Skeleton**, pick another `.esrig` and **Rebind to This Skeleton**. Bones are matched by name; a vertex on a bone with no match moves to its nearest matched ancestor. Rigs sharing a skeleton have the same bone names and paths, so they play the same clips. |

On save, data that referenced old bone names is updated:

- Clips (`.estimeline`) and Animator layer masks (`.esanimator`) that named a renamed or reparented bone by path are
  rewritten. A clip is treated as belonging to the rig when most of its paths are the rig's bones. A track on a removed
  bone keeps its path; the save reports how many such tracks remain.
- Each bone has a persistent id, which names its prefab entity. Components and children added to a bone in the scene,
  such as an `IK2D` or a sword parented to the hand, stay on that bone through reordering, reparenting and removal of
  other bones.

### Rebinding a skin in the scene

Select an entity with a `MeshSkin` and use **Rebind To** in the Details panel: pick another skeleton in the scene and
**Rebind Joints by Name**. Each joint is matched to the entity of the same name under that skeleton; where a name
occurs more than once (for example `hand` under both arms), the parents' names decide. A joint with no match keeps its
entity and is reported. This also applies to 3D skins, for example a jacket bound to a body.

## Animation

Select the character and key its bones in the [Sequencer](/docs/animation/timeline/sequencer/). A bone is addressed by its path
under the root, such as `hips/spine/arm`. A deform is a weight on the `MeshMorph` component and is keyed the same way.

Blending is done by the [Animator](/docs/animation/animator/): 1D and 2D blends, layers, masks and transitions all
apply to bones.

## IK

Add **`IK2D`** to the last bone of a limb and set `target`. After animation is applied, the end of that bone reaches for
the target, so a hand stays on what it holds whichever clip is playing.

| Field | Type | Default | Description |
|---|---|---|---|
| `target` | entity | none | Entity to reach for. |
| `chainLength` | number | `2` | Number of bones bent, including this one (1–32). Two bones are solved analytically and keep their bend direction; longer chains use an iterative solve. |
| `bend` | number | `1` | Two-bone chains: bend direction of the middle joint, `1` counter-clockwise or `-1` clockwise. |
| `weight` | number | `1` | Blend from the animated pose (0) to the solved pose (1). Animatable. |
| `matchTargetRotation` | boolean | `false` | Also rotates this bone to the target's rotation, for example a foot flat on a slope. |
| `enabled` | boolean | `true` | Enables the solve. |

## Constraints

Add **`BoneConstraint2D`** to a bone. Constraints run after IK, from the root outward.

| `kind` | Behaviour |
|---|---|
| **Limit Rotation** | Keeps the local rotation between `min` and `max`. IK chains through the bone respect the limits. |
| **Copy Rotation** | Takes `source`'s world rotation plus `offset`. |
| **Copy Position** | Takes `source`'s world position. |
| **Look At** | Points the bone's +X at `source`, plus `offset`. |

| Field | Type | Default | Description |
|---|---|---|---|
| `kind` | `BoneConstraintKind` | `LimitRotation` | Constraint type, as above. |
| `source` | entity | none | Entity copied or looked at. Not used by Limit Rotation. |
| `min`, `max` | number | `-45`, `45` | Limit Rotation: local rotation range in degrees. |
| `offset` | number | `0` | Copy Rotation and Look At: degrees added. |
| `weight` | number | `1` | Blend from the unconstrained pose (0) to the constrained pose (1). Animatable. |
| `enabled` | boolean | `true` | Enables the constraint. |

IK and constraints run in play mode. Both handle a character mirrored by a negative scale on its root.

## In code

Rigs are plain data and can be built by game or tool code with the `esengine/rig2d` subpath:

```typescript
import {
  autoWeightPart, bakeRig, coverRigPart, createRig, rigImageFromRGBA, spawnRig, IK2D,
} from 'esengine/rig2d';

const image = rigImageFromRGBA(width, height, rgba);
const rig = createRig('hero.png', width, height);
rig.bones.push(
  { name: 'upper', parent: -1, x: 0, y: 0, rotation: 0, length: 50 },
  { name: 'lower', parent: 0, x: 50, y: 0, rotation: 0, length: 50 },
);
const rect = { x: 0, y: 0, w: width, h: height };
const part = { name: 'arm', rect, x: 0, y: height / 2, ...coverRigPart(image, rect), weights: [] };
rig.parts.push(part);
autoWeightPart(rig, part);

const mesh = assets.createMesh(bakeRig(rig));
const { bones } = spawnRig(world, rig, { mesh, texture });
world.insert(bones[1], IK2D, { target, chainLength: 2, bend: 1, weight: 1, matchTargetRotation: false, enabled: true });
```

| Function | Description |
|---|---|
| `createRig(texture, width, height, unitsPerPixel?)` | Creates an empty `RigSource` for an image. |
| `rigImageFromRGBA(width, height, rgba)` | Wraps RGBA pixels for the mesh functions. |
| `coverRigPart(image, rect, opts?)` | Generates a part's grid mesh (`vertices`, `triangles`) over its opaque pixels. |
| `autoWeightPart(rig, part, opts?)` | Binds a part's vertices to the nearest bones. |
| `bakeRig(rig)` | Produces the skinned mesh data. |
| `spawnRig(world, rig, { mesh, texture, … })` | Spawns the root (with `MeshRenderer`, `MeshSkin` and, when the rig has deforms, `MeshMorph`) and one entity per bone; returns `{ root, bones }`, `bones` in bone-index order. |

## Limits

- A rig is one mesh, drawn in one draw call, with up to 256 bones. A vertex is influenced by at most 4 bones.
- Parts of one rig draw in their set order. Against the rest of the scene, a rig sorts by `MeshRenderer.layer` and then
  by Z, as any mesh does.
- A selected rig's outline shows its bind pose, not its current pose.
