The `Tween` resource interpolates a value from one number to another over a duration. A property tween writes a
component field through the C++ tween system; a value tween delivers each frame's value to a callback.
`to(entity, target, from, to, duration, options?)` starts a property tween and returns a `TweenHandle`. It is called
once, for example on a button press.

```typescript
import { EasingType, LoopMode, TweenTarget, type Entity, type TweenAPI } from 'esengine';

function moveLogo(entity: Entity, tween: TweenAPI) {
  return tween.to(entity, TweenTarget.PositionX, 0, 200, 1, {
    easing: EasingType.EaseInOutQuad,
    delay: 0.2,
    loop: LoopMode.PingPong,
    loopCount: 3,
  });
}
```

The `tween-animation` example project shows the easing curves, `sequence()`, `parallel()` and `.bezier()` running
together.

## Targets

`TweenTarget` selects the property a property tween drives:

| Group | Values |
|---|---|
| Position | `PositionX`, `PositionY`, `PositionZ` |
| Scale | `ScaleX`, `ScaleY` |
| Rotation | `RotationZ` |
| Color | `ColorR`, `ColorG`, `ColorB`, `ColorA` |
| Size | `SizeX`, `SizeY` |
| Camera | `CameraOrthoSize` |

A field outside this list is tweened with `tween.value(...)` and a callback that writes the field, or animated with a
[timeline](/docs/animation/timeline/overview/).

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `easing` | `EasingType` | `Linear` | Easing curve. |
| `delay` | number | `0` | Seconds to wait before starting. |
| `loop` | `LoopMode` | `None` | `None`, `Restart` or `PingPong`. |
| `loopCount` | number | `0` | Number of cycles played before the tween completes when `loop` is not `None`. `0` or a negative value repeats indefinitely. |

## Easing

`EasingType` provides `Linear`; the quad, cubic, quart, quint, sine, expo, circ, back and elastic families
(`EaseIn*`, `EaseOut*`, `EaseInOut*`); the bounce family (`EaseInBounce`, `EaseOutBounce`, `EaseInOutBounce`);
`Smoothstep` and `Smootherstep`; `Step`; and `CubicBezier`. A custom cubic Bézier is set with the handle's
`.bezier(p1x, p1y, p2x, p2y)`.

![Every EasingType plotted as a curve from 0 to 1](@/assets/guides/tween-easings.svg)

*Each easing plotted with progress `t` on the horizontal axis and the eased value on the vertical axis, using the
engine's curves. `Back` and `Elastic` overshoot the 0–1 range; `Step` holds until the end.*

## Sequencing and control

```typescript
// Chain: run one after another (a squash-and-stretch pop).
tween.to(e, TweenTarget.ScaleX, 1, 1.4, 0.15)
  .then(tween.to(e, TweenTarget.ScaleX, 1.4, 1, 0.15))
  .bezier(0.2, 0, 0, 1);

tween.parallel([...]);      // run several at once (a group)
tween.sequence([...]);      // run tween factories in order
tween.delay(0.5);           // a timed gap

tween.cancel(handle);       // stop one
tween.cancelAll(entity);    // stop everything on an entity
```

| `Tween` method | Description |
|---|---|
| `to(entity, target, from, to, duration, opts?)` | Tween a component property; returns a `TweenHandle`. |
| `value(from, to, duration, cb, opts?)` | Tween a plain number, delivered to `cb` each frame; returns a `ValueTweenHandle`. |
| `parallel(tweens)` | Run several tweens together as a group; returns a `TweenGroup`. |
| `sequence(factories)` | Run tween factories one after another; returns a `TweenSequence`. |
| `delay(seconds)` | An empty timed gap for use in sequences; returns a `ValueTweenHandle`. |
| `cancel(handle)` / `cancelAll(entity)` | Stop one tween, or every tween on an entity. |

`TweenHandle` provides `.then(next)`, `.bezier(...)`, `.pause()`, `.resume()` and `.cancel()`.

## Composition handles

`TweenGroup` and `TweenSequence` are handles over their members. Both expose `state` (a `TweenState`),
`pause()` / `resume()` / `cancel()`, which apply to every member, and `onComplete(cb)`.

```typescript
const popX = tween.to(e, TweenTarget.ScaleX, 1, 1.3, 0.2);
const popY = tween.to(e, TweenTarget.ScaleY, 1, 1.3, 0.2);
tween.parallel([popX, popY]).onComplete(() => spawnSparkles());

tween.sequence([
  () => tween.to(e, TweenTarget.PositionY, 0, 60, 0.3),
  () => tween.delay(0.2),
  () => tween.to(e, TweenTarget.PositionY, 60, 0, 0.3),
]).onComplete(() => landDust());
```

<Aside type="caution">
  Groups and sequences must be created through the `Tween` resource. The resource registers them with its internal
  poller (`TweenCompositionManager`), which fires `onComplete` and advances a sequence to its next factory. A group
  constructed directly with `new TweenGroup(...)` is never polled.
</Aside>

`ValueTweenHandle`, returned by `tween.value(...)` and `tween.delay(...)`, has the same controls (`state`,
`.pause()`, `.resume()`, `.cancel()`, `.bezier(...)`) and `.then(next)`, which accepts another value tween or any
pausable composition (a group or a sequence). `TweenHandle.then` also accepts a `ValueTweenHandle`, so property and
value tweens can be mixed in one chain.

The class names `TweenGroup`, `TweenSequence` and `ValueTweenHandle` are needed only to store a handle for later
pausing, cancelling or observation.
