## Screen size and orientation: `ScreenInfo`

`ScreenInfo` is a helper class that is not installed by the runtimes. It is constructed by the game, receives screen
sizes through `update()`, derives the orientation and notifies listeners.

| Member | Type | Default | Description |
|---|---|---|---|
| `width` | number | `0` | Last reported screen width in px. |
| `height` | number | `0` | Last reported screen height in px. |
| `dpr` | number | `1` | Device pixel ratio. |
| `orientation` | `ScreenOrientation` | `Portrait` | `Landscape` when `width > height`, otherwise `Portrait`. |
| `on(event, fn)` | method | — | Subscribes to `'resize'` (every `update()`) or `'orientationchange'` (when the derived orientation changes; not on the first `update()`). Returns an unsubscribe function. |
| `update(width, height, dpr = 1)` | method | — | Supplies the current size; recomputes the orientation and notifies listeners. |

```typescript
import { ScreenInfo, ScreenOrientation } from 'esengine';

const screen = new ScreenInfo();
screen.on('resize', (w, h) => { /* reposition off-canvas HUD */ });
screen.on('orientationchange', (o) => {
  if (o === ScreenOrientation.Portrait) { /* show a "rotate device" hint */ }
});

const feed = () =>
  screen.update(window.innerWidth, window.innerHeight, window.devicePixelRatio);
window.addEventListener('resize', feed);
feed();
```

## Orientation

The orientation of the exported game is a project setting, not runtime state. **Settings → Project → Game → Display →
Orientation** writes one value (`packaging.orientation`) that every export target reads: the WeChat `game.json`, the
web/playable rotate hint and the desktop window aspect. When unset, it is derived from the design resolution's aspect.
See [Project Display settings](/docs/core-concepts/screen/camera-fit/#project-display-settings).

## Safe areas

A `SafeArea` component on an **absolute** `UINode` keeps that node inside the device's safe area: the engine writes the
node's four insets whenever the platform insets or the screen change. The system is part of the standard UI plugin
(`safeAreaPlugin`, built by `uiPlugin`) and needs no installation in a normal app.

![Details of the HUD root in the hud scene of the celestial-heights example: the Safe Area card](@/assets/guides/en/core-safe-area-details.png)
| Property | Type | Default | Description |
|---|---|---|---|
| `applyTop` | boolean | `true` | Moves the node's top inset down by the top safe-area inset. |
| `applyBottom` | boolean | `true` | Same for the bottom inset. |
| `applyLeft` | boolean | `true` | Same for the left inset. |
| `applyRight` | boolean | `true` | Same for the right inset. |
| `avoidHostMenu` | boolean | `false` | Also clears the host's own overlay — WeChat's capsule menu, which lies *inside* the safe area. The top inset becomes the larger of the safe-area inset and the capsule's bottom edge. The whole node moves down, so set it only on a node the capsule overlaps. |

Platform insets are converted from device pixels to UI design pixels before they are written:

| Platform | Source of the insets |
|---|---|
| WeChat | `wx.getSystemInfoSync().safeArea`, read automatically. |
| Native (iOS / Android) | The platform's cached OS insets, read every frame. |
| Web | The `--sat` / `--sab` / `--sal` / `--sar` CSS custom properties on the root element. The host page defines them from `env(safe-area-inset-*)`; undefined properties read as `0`. |

One absolute root node with `SafeArea` protects every HUD element parented under it:

```typescript
import {
  defineSystem, GetWorld, spawnUIEntity, SafeArea, UIPositionType,
} from 'esengine';

const buildHudRoot = defineSystem([GetWorld()], (world) => {
  // Absolute node with auto width/height: the SafeArea system writes the four insets,
  // so the node spans exactly the safe region.
  const hudRoot = spawnUIEntity({
    world,
    node: { position: UIPositionType.Absolute },
  });
  world.insert(hudRoot, SafeArea, {
    applyTop: true, applyBottom: true, applyLeft: true, applyRight: true,
  });
  // Parent all HUD widgets under hudRoot.
});
```
