## Sequencer

Edits keys and curves of a timeline: tracks bound to entities, dope sheet and curve editor. See
[Key a property](/docs/animation/timeline/sequencer/#key-a-property).

![The Sequencer dope sheet with tracks and keys](@/assets/guides/en/seq-dopesheet.png)

## Tilemap mode

Selecting a `TilemapLayer` (or the Tilemap Activity Bar icon) enables tilemap mode: a **Tile Palette** panel and
painting tools in the scene view toolbar.

| Feature | Description |
|---|---|
| Tools | Brush, erase, rectangle, ellipse, line, bucket, select, eyedropper, terrain (autotile) |
| Stamps | Saved multi-tile stamps; flip H / flip V / rotate 90° (`H` / `V` / `R` with a paint tool active); random scatter (`D`) |
| Replace tiles… | Replace one tile id with another across a layer or selection |
| Palette | Arrow keys select; **Shift** extends a multi-tile stamp |
| Grid orientation | Orthogonal, isometric, staggered, hexagonal |

![Tilemap mode: the painting tools in the scene view toolbar and the Tile Palette](@/assets/guides/en/tilemap-tools.png)

## Tileset editor

| Feature | Description |
|---|---|
| Collision | Per-tile box, circle, polygon and slope shapes; one-way, sensor and material modifiers. Direct manipulation on a magnified tile: circle centre and radius, polygon vertices (click to add, drag, click to delete), one-way solid side. |
| Terrain | Autotile sets: edge / corner peering or multi-colour corner Wang. |
| Properties | Per-tile probability weights and custom properties. |
| Animation | Animated tiles: reorder frames by dragging, uniform loop duration, live preview. |

![The tileset editor: per-tile collision shapes edited on a magnified tile](@/assets/guides/en/tileset-collision.png)

## Node graphs

State machines, behaviour trees and script graphs share one node canvas:

| Action | Input |
|---|---|
| Pan | Middle-drag |
| Zoom | Wheel, toward the cursor |
| Connect | Drag from an output handle onto a node |
| Select | Click a node or edge |
| Delete | **Delete** |
| Add node | Right-click the canvas |

![A behaviour tree in the node graph editor](@/assets/guides/en/ai-bt.png)
