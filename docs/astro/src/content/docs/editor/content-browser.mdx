The Content Browser is the project's asset explorer. It is docked at the bottom by default and is also available as an
overlay from anywhere (**Content Drawer**, **Ctrl / ⌘ + Space**).

## Creating assets

The **Add** menu creates assets in the current folder: Scene, Prefab, **Script…**, Animation, Animation Controller,
Input Map, Locale Table, Cube Environment (six images), Material, Material Graph, Material Subgraph, **Shader**,
State Machine, Behavior Tree, Script Graph, Avatar, Sound Event, World Rules, Terrain Layer, Folder, and asset types
contributed by plugins.

![The Content Browser Add menu listing the creatable asset types](@/assets/guides/en/content-new-menu.png)

**New Script…** also registers the module: a module that nothing imports is not bundled and its component never
reaches Add Component, so the dialog adds an import to the appropriate project entry (declaration entry for
components, startup entry for systems). See [Scripting](/docs/scripting/overview/#the-new-script-dialog).

## Context actions

| Asset | Actions |
|---|---|
| Texture | Create Tileset, Create Sprite Animation |
| Tileset | Create Tilemap |
| Animation clip | Create Animated Sprite |
| Material | Create Material Instance |
| Scene | Set as Startup Scene |
| Imported asset | Reimport |
| Any | Rename, Duplicate, Copy Path, Copy Reference, Find Usages, Show in Explorer, Delete |

## Import

Drag files from the file manager onto the Content Browser, or use **Import…**. Each asset receives a `.meta` sidecar
(UUID and import settings) the first time it is seen.

## Rename, move and delete

- Rename, move and duplicate post a notification with **Undo**.
- Rename and move rewrite references in every open document.
- **Delete** first lists every scene, prefab and asset that references the file, then moves it to the OS trash;
  Undo restores it.

## Find Usages

Context menu → **Find Usages**, or the reference count in the asset inspector, lists every reference to a texture,
material, prefab or scene, across the on-disk dependency graph and the unsaved open scene.

## Views

**Settings** (in the Content Browser bar) selects the view — **Tiles**, **List** or **Columns** — and the sort order,
folder visibility and search options. In Columns view, column headers sort by Name, Type, Size or Modified; the edges
between headers can be dragged to resize columns (double-click restores the defaults); a header's context menu hides
the column.

## Keyboard

The folder tree is keyboard-navigable: arrows move and collapse / expand, **Enter** opens a folder, **F2** renames.
