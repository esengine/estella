All three are reachable from the Command Palette (**Ctrl / ⌘ + Shift + P**).

## History

**History** lists the edits of the open scene in order, with **Now** marking the current position. It is the visible
form of the undo stack (**Ctrl / ⌘ + Z**, **Ctrl / ⌘ + Shift + Z**); clicking a row steps back or forward to that state.

Edits by an [agent connected over MCP](/docs/agents/mcp/) are recorded the same way, one row per step, grouped under
the agent run with an **Undo run** action.

![The History panel: an agent run with two set_field steps, the current position marker, and Undo run](@/assets/guides/en/ed-history.png)

## Scatter Brush

The Scatter Brush places copies of an entity by painting in the scene view. Toggle it from the Command Palette
(**Scatter Brush**) or put it away with **Esc**; its panel opens on the left.

![The Scatter Brush panel: Source, Use Selected, and the Brush settings with a preview of one dab](@/assets/guides/en/ed-scatter.png)

1. Select the source entity and press **Use Selected**.
2. Set the brush:

   | Setting | Description |
   |---|---|
   | **Radius** | Radius of one dab. |
   | **Density** | Copies per dab. |
   | **Spacing** | Minimum distance between copies. |
   | **Scale Variation** | Random scale spread per copy. |
   | **Random Turn** | Random orientation per copy. |

   The preview shows one dab: the disc, its sample points and their spacing.
3. Drag in the scene view. Each stroke is one undo step and reports the number of copies placed.

**Scatter Around Selection** fills the area around the current selection without a stroke.

## Project Health

**Project Health** is the pre-build check list; **Build → Package Project…** runs the same checks first, and a blocker
stops the build. Checks include unresolved asset references, empty required component fields, a missing startup scene,
script compilation, unsaved changes that would be excluded from the build, target prerequisites on this machine, and
scene view fallbacks (HDR, MSAA).

![Project Health: one blocker (unsaved changes not in the build) and two checks that could not be run](@/assets/guides/en/ed-health.png)

| Group | Meaning |
|---|---|
| **Blocks the build** | Must be fixed before packaging. |
| **Warnings**, **Notes** | Non-fatal findings. |
| **Could not be checked** | A prerequisite was unavailable (device, toolchain); not a pass. |

Entries with a **Fix** button apply the repair, or state why they cannot. **Re-check** runs the list again; the panel
indicates when the project has changed since the last run. The same list is available to automation as
`get_project_health` in the [editor MCP](/docs/agents/mcp/).
