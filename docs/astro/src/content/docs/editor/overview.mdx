The Estella editor is a desktop application (Electron + React) with a dockable workspace. It provides visual scene
authoring, a component inspector, asset editors (timelines, tilemaps, node graphs, materials) and in-editor play mode,
which runs the game in an isolated runtime realm so that play never modifies the edited scene.

![The Estella editor with a platformer scene: scene view, World Outliner, Details and Content Browser](@/assets/guides/en/editor-overview.png)

*Default workspace: scene view (centre), World Outliner and Details (right), Content Browser, Output Log and Profiler
(bottom), play controls (top).*

## Launcher

With no project open, the editor shows the launcher:

| Page | Function |
|---|---|
| **Recent** | Reopens a recent project; search, grid and list views. |
| **New project** | Creates a project from a template: **Starters** (Blank, 2D Platformer, Top-down, Pixel RPG, UI Game, 3D Starter, Online 3D, Playable Ad, WeChat Mini-game) or **Examples** (the bundled sample projects). |

## Project layout

A project is a folder:

| Path | Content |
|---|---|
| `project.esproject` | Project manifest: name, startup scene, design resolution, enabled features, packaging. Version-controlled. |
| `.esengine/workspace.json` | Editor-local state (last scene, panel layout). Git-ignored. |
| `assets/scenes/*.esscene` | Scenes. |
| `assets/…` | Textures, materials, tilesets and other assets, each with a `.meta` sidecar. |
| `src/components.ts` | **Declaration entry**: the editor evaluates this module and its imports to discover project components. See [Scripting](/docs/scripting/overview/#where-declarations-live). |
| `src/main.ts` | **Startup entry**: registers systems; runs the game. Never evaluated by the editor. |

Assets are referenced by UUID (`@uuid:…`), so moving or renaming files does not break references.

## Workspace

| Region | Content |
|---|---|
| **Activity Bar** (far left) | Editing modes (Tilemap / UI / World / Scene), Panels menu, Content Drawer, Agent, Settings. |
| **Menu Bar** | File, Edit, Entity, View, Build, Window, Help; **Tools** when a plugin contributes to it. |
| **Header** | Play controls (Play, Pause, Restart, play-mode menu), **Scan Preview** (run on a phone), **Compile** (scripts). |
| **Scene view** (centre) | WebGL scene view with its toolbar: transform tools, snapping, 2D / 3D, screen controls, **Show**, **Gizmos**. |
| **World Outliner** (right) | Entity hierarchy of the open scene. |
| **Details** (right) | Inspector for the selection. |
| **Bottom dock** | Content Browser, Output Log, Profiler; other panels (Sequencer, Tile Palette) open on demand. |
| **Status Bar** | Content Drawer toggle, edit mode, save state, loaded modules, FPS, entity count, memory, graphics backend, engine version. |

Panels can be docked, split, floated or rearranged by dragging tabs; the layout is saved per project. The Content
Browser is also available as a slide-up overlay (**Content Drawer**, **Ctrl / ⌘ + Space**).

<Aside type="note">
  Play mode runs in a separate realm from the edited scene. The running game cannot modify the edit-mode world, and
  Stop restores the editor to the scene as it was.
</Aside>
