## Creating entities

| Path | Result |
|---|---|
| **Entity → Add Entity** | An entity with `Transform` only. |
| *World Outliner → Add → Create entity…* | The create popover: built-in presets (Empty, Sprite, Camera, Particles, Light, Tilemap, Spine, Audio, Text, Bitmap Text, Shape, Mesh, Trail, DragonBones, Sound Event, Sun, 3D primitives, Third Person Character, Outdoor Environment), UI primitives and widgets, project components, and every `.esprefab` in the project. |
| *World Outliner → right-click* | Context actions: create, folders, parenting, prefab creation. |
| Drag from the Content Browser | See below. |

All creation paths (menus, drag and drop, automation) share one pipeline; each creation is one undo step.

### Dragging assets into the scene

| Asset | Dropped in the scene view | Dropped in the World Outliner |
|---|---|---|
| Image | `Sprite` at the drop point; a **UI Image** (`UINode` + `UIVisual`) when dropped on a Canvas or UI node | `Sprite` under the row; a UI Image when the row is a Canvas or UI node |
| `.esprefab` | Prefab instance | Prefab instance under the row |
| `.esmesh` | Mesh entity | Mesh entity under the row |
| `.esanim` | Animated sprite | Animated sprite under the row |
| `.estileset` | Tilemap | Tilemap under the row |

Drops on empty Outliner space create the entity at the scene root. See
[Sprite or UI Image](/docs/ui/sprite-or-ui/) for the Sprite / UI Image distinction.

## World Outliner

![The World Outliner with folders and the context menu of the Player entity: Rename, Duplicate, Create Prefab, Delete, Hide, Lock, Disable, New Folder from Selection, Move to Root, Unparent, Add Child, Create Child](@/assets/guides/en/ed-outliner-menu.png)

| Operation | Input |
|---|---|
| Reparent | Drag onto another entity |
| Organise | Folders (context menu → New Folder from Selection) |
| Jump to entity | Type the first letters of a name with the tree focused |
| Rename / Duplicate / Delete | **F2** / **Ctrl/⌘ + D** / **Delete** |
| Hide / Lock | Row toggles; independent of runtime enablement |
| Create Prefab | Context menu on a selection |

- **Hide** removes the entity from the edit scene view (sprites, skeletons, tilemaps, particles, lights) without
  changing the scene the game loads.
- **Lock** keeps the entity visible but not pickable and without transform handles.
- **Prefab instances** offer *Edit Prefab*, *Apply to Prefab*, *Revert to Prefab*, *Create Variant*, *Unpack Prefab*,
  and *Make Virtual (load on demand)* / *Make Whole (load with the scene)*. A virtual instance is edited whole in the
  editor, but the running scene builds only its root. See [Virtual instances](/docs/world/prefabs/#virtual-instances).

## Details

Details inspects the selection. Fields are generated from component reflection metadata, so ranges, units, enums and
tooltips come from the component definition. Edits are written to the scene immediately.

- **Validation** — required fields are flagged when empty; numeric fields are clamped to their declared range; asset
  slots reject assets of the wrong type.
- **Sections** — each component is collapsible; fold state persists across selections and editor restarts.
  Rarely edited components (`Focusable`, `ThemeStyle` on widgets) start folded.
- **Notices** — configurations that have no effect are reported on the component card (for example a `Sprite` on a
  `UINode`, or a positioned Transform on a laid-out UI node).
- **Prefab bar** — on prefab instances, shows the prefab and the **Virtual** toggle.

### Purpose-built controls

| Component | Control |
|---|---|
| `UINode` (absolute) | Anchor picker: 3×3 grid of point anchors plus per-axis Stretch. |
| `FlexContainer` | Direction, 3×3 alignment grid (main and cross axis), main-axis distribution (Packed / Between / Around / Evenly), Wrap and Stretch toggles, four-edge padding. |
| UI nodes with controllers | Inline Controllers strip for page selection and field gears ([UI Controllers](/docs/ui/controllers/)). |
| Material | Shader picker (built-in template or project `.esshader`) ([Materials](/docs/graphics/materials/overview/#shader)). |

## Asset inspector

Selecting an asset in the Content Browser shows its import settings in Details (for materials, its parameters).
Import settings belong to the asset and apply everywhere it is drawn: the edit scene view, play mode (scene view and
Game panel) and packaged builds.

**9-slice border.** For textures, the four slice guides can be dragged on the preview; the numeric fields stay in
sync.
