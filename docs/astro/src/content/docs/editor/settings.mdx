title: Settings
description: Settings window reference — editor preferences stored per machine and project settings stored in project.esproject (display, UI theme, runtime tuning, rendering, physics, build and modules, configuration tables), and the editor language.
---

**Ctrl / ⌘ + ,** or the Activity Bar gear opens Settings. The window has two scopes, **Editor** and **Project**, each
divided into pages; the search field finds settings on any page. Settings changed once per project (screen presets,
solver tuning, theme colours, module switches, AI provider endpoints) are under each page's **Advanced** fold.

![The Settings window on the Editor scope: Editor / Project tabs, page list, search field](@/assets/guides/en/settings-window.png)

## Editor scope

Stored on this machine.

| Page | Content |
|---|---|
| **General** | Appearance (language, accent colour, interface font, UI scale), performance, console, renderer backend. |
| **Viewport** | Grid, snapping, transform gizmos. |
| **Shortcuts** | Rebinding of every shortcut ([Keyboard shortcuts](/docs/editor/shortcuts/)). |
| **Tools and AI** | External script and image editors and browser; whether [AI agents](/docs/agents/mcp/) may connect over MCP and modify the project. |

## Project scope

Stored in `project.esproject` and shared with the project.

| Page | Content |
|---|---|
| **Game** | **Display**: design resolution (seeds new Canvases, drives the device preview), screen orientation (honoured by every export target; derived from the design resolution when unset), camera fit (`None` = off), render resolution (screen size, design resolution, or an integer multiple scaled to the screen). **UI**: widget theme (dark / light) and per-role theme colours, applied identically in editor, play and exports ([Theming](/docs/ui/theming/)). **Audio**, **Spine**, **Runtime** (below). |
| **Rendering** | Up to 32 named sorting layers (populate the layer dropdowns; numeric layers outside the list remain valid) and which of them y-sort; quality tiers; project environment; shader compilation in the background, warm-up behind the loading screen, render on demand ([Quality levels](/docs/performance/quality-levels/runtime/#shader-compilation-and-render-on-demand)). **Render Scheduling**: *Dedicated render thread* (native builds and cross-origin-isolated web builds) and *GPU async compute* (supported native Metal devices); both off by default. |
| **Physics** | Enable, gravity, 16 collision-layer names and the 16×16 collision matrix, solver tuning (fixed timestep, sub-steps, contact Hz / damping / push speed, sleeping, continuous collision). See [Physics](/docs/gameplay/physics-2d/overview/). |
| **Build and modules** | Per-target packaging metadata (WeChat AppID, desktop app id and product name, splash, achievements), included engine modules, and for web builds the **allowed server origins** (e.g. `wss://play.example.com`); without entries the page's Content-Security-Policy allows only its own origin. |
| **Configuration tables** | **Luban** (Excel tables → generated JSON and TypeScript) and **Protobuf** (`.proto` → TypeScript types and binary codec). Off by default; when on, the editor verifies the tool installation (asking before any download) and keeps generated code current. |

## Runtime

**Project → Game → Runtime** exposes engine tuning. The project file stores only values that differ from the engine
defaults, under `features.runtime`; builds ship the same block, and play mode applies it before the first asset loads.
The edit scene view uses engine defaults.

![Project Settings, Game page, Runtime section: Scene Transition, Frame Limits, Cache Budgets and Text groups](@/assets/guides/en/settings-runtime.png)

| Group | Setting | Default | Description |
|---|---|---|---|
| Scene Transition | Duration, Colour | 0.3 s | Fade used by a scene switch that specifies none. |
| Frame Limits | Longest frame step | 0.25 s | Upper bound on the simulated time of one frame (background tabs, stalls). |
| | Most fixed steps per frame *(Advanced)* | 8 | Cap on fixed-rate catch-up steps; beyond it the simulation slows instead of spiralling. |
| Asset Loading | Load timeout *(Advanced)* | 30 s | Time before an asset load fails. |
| | Retry cooldown *(Advanced)* | 5 s | Delay before a failed asset is retried. |
| Cache Budgets | Texture cache | 64 MiB | GPU memory for textures not currently in use; 0 disables. |
| | Audio cache | 32 MiB | Decoded audio clips; 0 disables. |
| | Device-loss copies *(Advanced)* | 16 MiB | CPU copies kept to survive GPU device loss; warns beyond it. |
| Text | Text canvas size *(Advanced)* | 512 | Rasterisation canvas size. |
| | Default font family | — | Font for `Text` components without their own. |

## Editor language

The editor is available in **English** and **简体中文** and follows the system language on first launch. Change it in
**Settings → Editor → General → Appearance → Language**; the change applies after a reload, which the editor prompts
for. Editor strings use the same [localization engine](/docs/assets/localization/) as games at runtime.
