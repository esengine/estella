`mod` is **⌘** on macOS and **Ctrl** elsewhere. All bindings can be changed in **Settings → Editor → Shortcuts**.

| Action | Shortcut |
|---|---|
| New Scene | `mod + N` |
| Open Project | `mod + O` |
| Save Scene / Save Scene As | `mod + S` / `mod + shift + S` |
| Undo / Redo | `mod + Z` / `mod + shift + Z` (or `mod + Y`) |
| Duplicate | `mod + D` |
| Copy / Cut / Paste | `mod + C` / `mod + X` / `mod + V` |
| Delete | `Delete` / `Backspace` |
| Select All | `mod + A` |
| Select / Move / Rotate / Scale / Rect tool | `Q` / `W` / `E` / `R` / `T` |
| Universal Transform tool | `Y` |
| Nudge selection (×10 with Shift) | Arrow keys |
| Frame Selected | `F` |
| Rename | `F2` |
| Play / Stop | `F5` / `Esc` |
| Pause / Resume, Restart | `F6`, `shift + F5` |
| Inspect while playing | `F8` |
| Maximize / restore scene view | `F11` |
| Package Project… | `mod + shift + B` |
| Go to Anything… | `mod + P` |
| Command Palette | `mod + shift + P` |
| Content Drawer | `mod + Space` |
| Settings | `mod + ,` |
| Interface zoom in / out / reset | `mod + =` / `mod + -` / `mod + 0` |

## Command Palette

**Go to Anything** (`mod + P`) searches files, entities, panels, commands and settings; the **Command Palette**
(`mod + shift + P`) opens it on the Command scope. Results show the command's category and shortcut; disabled commands
are listed but greyed out.

![The Command Palette on the Command scope: scope tabs All / Asset / Entity / Panel / Command / Setting, and commands with their category and shortcut](@/assets/guides/en/ed-command-palette.png)

## Keyboard navigation

- Menus and context menus: arrow keys, type-ahead, **Home** / **End**, `→` / `←` for submenus.
- World Outliner: type-ahead to jump to an entity; arrows move, collapse and expand.
- Content Browser folder tree and Tile Palette: arrow-key navigation.
- Keyboard focus is always indicated by a focus ring.
