description: Blackboard reference — each AI agent's key/value store and one-shot triggers, its methods, and access from game code through the AiFsm and AiBt resources.
---

Every state machine and behavior tree agent owns a **`Blackboard`**: a private key/value store plus one-shot triggers.
Actions and conditions reach it through `ctx.blackboard`. Values on it pass state between leaves and supply the values
that transition guards compare.

```typescript
registerAction('takeDamage', (ctx) => {
  const hp = (ctx.blackboard.get<number>('health') ?? 100) - 10;
  ctx.blackboard.set('health', hp);
  if (hp <= 0) ctx.blackboard.fire('died');   // a transition keyed on 'died' fires once
});
```

| Method | Description |
|---|---|
| `get<T>(key)` / `set(key, value)` | Reads / writes a value. |
| `has(key)` / `delete(key)` | Tests / removes a key. |
| `fire(trigger)` | Fires a one-shot trigger; a transition keyed on it is enabled until it is taken. |
| `isFired(trigger)` / `consume(trigger)` | Tests / clears a trigger. |
| `clearTriggers()` | Drops every pending trigger. |

Blackboard values back the `guard` comparisons of FSM transitions. A trigger is an edge event: fired once and consumed
by the transition that takes it.

## Access from game code

Code outside a leaf reaches an agent's blackboard through two resources, which can also seed values or fire a trigger
before the agent's first tick. The blackboard lives as long as the entity and is not serialized.

```typescript
import { AiFsm, AiBt } from 'esengine/ai';

const fsm = app.getResource(AiFsm);
fsm.blackboard(enemy).set('health', 100);
fsm.fire(enemy, 'alarm');          // consumed by the agent's next enabled transition
fsm.state(enemy);                  // active state name, or null before the first tick

const bt = app.getResource(AiBt);
bt.blackboard(enemy);              // a tree agent's blackboard
bt.status(enemy);                  // last root status
```

| Resource | Member | Description |
|---|---|---|
| `AiFsm` | `blackboard(entity)` | The state machine agent's blackboard. |
| | `fire(entity, trigger)` | Fires a trigger on it. |
| | `state(entity)` | Active state name, or `null` before the first tick. |
| `AiBt` | `blackboard(entity)` | The tree agent's blackboard. |
| | `status(entity)` | Last root status, or `null`. |
