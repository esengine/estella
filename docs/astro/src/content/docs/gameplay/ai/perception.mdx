A `Perceiver` senses the nearest visible `PerceptionTarget` each frame and the nearest `Noise` within hearing range, and
writes the result into a `Perception` component on the same entity, adding one if the entity has none. A `Perceiver`
never senses itself. Decisions read `Perception` like any other component.

The perception step runs in `PreUpdate`, in play mode only, so decision systems read a result from the same frame.
Positions are world positions: a perceiver may sit on an eye entity (a head bone, a sensor) and a target on what is looked
at.

![Details of a Perceiver and its Perception: range, field of view, facing axis and line-of-sight layers](@/assets/guides/en/details-perceiver.png)

*A **Perceiver** (above) and the **Perception** it writes (below, filled in during Play).*

```typescript
import { Perceiver, PerceptionTarget, Perception } from 'esengine/ai';

// The hunter senses…
cmds.spawn()
  .insert(Transform, { position: { x: -200, y: 0, z: 0 } })
  .insert(Perceiver, { range: 260, fovDegrees: 120 })
  .insert(Perception, {});          // written every frame by the perception plugin

// …anything tagged as a target.
cmds.spawn()
  .insert(Transform, { position: { x: 100, y: 0, z: 0 } })
  .insert(PerceptionTarget, {});
```

## Components

| Component | Field | Default | Description |
|---|---|---|---|
| **`Perceiver`** | `range` | `220` | Sight range, world units. |
| | `fovDegrees` | `360` | Field-of-view cone, `0`–`360` degrees (`360` = omnidirectional). |
| | `facingAxis` | `'x'` | The entity's own axis the cone points along: `'x'` is screen-right (a flat scene), `'-z'` is the facing of an imported 3D model. |
| | `losLayers` | `0` | 3D only: physics layers the line-of-sight ray may hit (`0` = every layer). |
| | `hearingRange` | `0` | Distance at which a noise of loudness 1 is heard, through walls; `0` = deaf. |
| **`Perception`** | `visible` | `false` | A target is currently seen. |
| | `distance` | `0` | Distance to the seen target. |
| | `targetX`, `targetY`, `targetZ` | `0` | Position of the seen target, world units. |
| | `dirX`, `dirY`, `dirZ` | `0` | Unit direction from observer to target. |
| | `heard` | `false` | A noise was heard this step. |
| | `noiseX`, `noiseY`, `noiseZ` | `0` | Where the last noise heard came from. |
| | `sinceHeard` | `-1` | Seconds since that noise; `-1` = nothing heard yet. |
| **`PerceptionTarget`** | *(tag)* | — | Marks an entity as sensable by perceivers. |

`Perception` is a transient, runtime-only component: the plugin rewrites it every frame and its values are not authored.

## Sight

Sensing is three-dimensional; a flat scene is the case where `z` is constant. The cone is oriented by the perceiver's
world rotation along `facingAxis`. A target is visible when it is within `range`, inside the cone and not occluded; of
the visible targets the nearest is reported.

When a physics world is present, the sight ray is cast against it and walls block sight. The 3D world is used if the
scene has one, otherwise the 2D world; with neither, sensing is range and cone only. Hits on the observer's own body and
on the target's body do not count as occlusion. In 3D, `losLayers` restricts the ray to the layers that block sight.

## Hearing

A `Noise` event announces a sound perceivers may hear: a gunshot, a door, a footstep.

| `NoisePayload` field | Default | Description |
|---|---|---|
| `x`, `y`, `z` | `0` | Where the noise was made. |
| `loudness` | `1` | Multiplier on each perceiver's `hearingRange`: a noise is heard within `hearingRange * loudness`. |
| `source` | `0` | The entity that made it; it does not hear itself. `0` = no particular entity. |

```typescript
import { defineSystem, EventWriter } from 'esengine';
import { Noise } from 'esengine/ai';

const gunshot = defineSystem([EventWriter(Noise)], (noises) => {
  noises.send({ x: muzzle.x, y: muzzle.y, z: muzzle.z, loudness: 2, source: shooter });
});
```

The perception step reads noises the frame after they are sent, as with every event. Each perceiver records the nearest
noise within reach (`heard`, `noiseX/Y/Z`, `sinceHeard = 0`); on steps without a new noise, `sinceHeard` increases by the
frame time and the last position is kept. Hearing is not blocked by geometry.
