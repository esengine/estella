<Tabs>
  <TabItem label="Editor">
    <Steps>

    1. Download the editor from the [download page](https://estellaengine.com/#download) (Windows; macOS on Apple
       silicon). All releases, with release notes and checksums, are also on the
       [releases page](https://github.com/esengine/estella/releases).

    2. Install and start the editor, then select **New project**.

    3. Select a template, enter a project name and location, and select **Create project**. The **Blank** template
       opens a scene containing a single Camera entity.

    </Steps>

    ![The launcher's New project page: starter templates (2D Platformer, 3D Starter, Blank, Online 3D, Pixel RPG, Playable Ad, Top-down, UI Game, WeChat Mini-game), each with a description](@/assets/guides/en/gs-new-project.png)

    *Launcher → New project. Starter templates are listed first, followed by the bundled examples.*

    <Aside type="tip">
      **Help → Check for Updates…** downloads and installs updates on restart, from the same mirror as the installer
      (`dl.estella.games`), with GitHub as fallback when the mirror is unavailable or behind. Builds that cannot
      self-update show a download link instead.
    </Aside>

    <Aside type="note">
      Installers are currently unsigned. On first launch, Windows SmartScreen or macOS Gatekeeper may report an
      unknown developer; allow the application via **Run anyway** or **System Settings → Privacy & Security**.
    </Aside>
  </TabItem>

  <TabItem label="Source build">
    Requirements:

    - **Node.js** ≥ 18 and **pnpm** ≥ 8
    - **Emscripten** 5.0.0 (exact version, matching CI)

    <Steps>

    1. Clone with submodules and install dependencies:

       ```bash
       git clone --recursive https://github.com/esengine/estella.git
       cd estella
       pnpm install
       pnpm emsdk:setup   # one-time: installs Emscripten 5.0.0 into tools/emsdk
       ```

    2. Build the engine and SDK and sync them to the editor:

       ```bash
       node build-tools/cli.js build -t all
       ```

    3. Start the editor:

       ```bash
       cd desktop && pnpm dev
       ```

    </Steps>

    Full build reference: [CONTRIBUTING.md](https://github.com/esengine/estella/blob/master/CONTRIBUTING.md).
  </TabItem>
</Tabs>

## Command-line project creation

The command line uses the same templates as the editor's New project page, for scripted and headless setups:

```bash
node pipeline/bin/estella.mjs templates                          # list templates and examples
node pipeline/bin/estella.mjs create 3d-starter ./my-game --name "My Game"
node pipeline/bin/estella.mjs export ./my-game                   # web build without the editor
```

`create` copies the template, sets the project name, and adds `package.json` and `.gitignore`. Opening the project once
in the editor stages the SDK type declarations referenced by its `tsconfig.json`; exporting does not require this.
