Estella is a **2D and 3D game engine**. Game code is written against a TypeScript SDK; the engine core (ECS storage,
renderer, resources, physics, particles, tilemaps, text) is C++ compiled to WebAssembly, or to native arm64 on
mobile. A visual editor covers scene authoring, asset management and builds. One project exports to **the web,
desktop, WeChat and other mini-game platforms, single-file playable ads, and native Android / iOS applications**.

## Characteristics

| Area | Description |
|---|---|
| Runtime | C++ core compiled to WebAssembly (web) or arm64 with an embedded WebGPU implementation (Android / iOS; no WebView). |
| Programming model | Entity-Component-System. TypeScript API: `defineComponent`, `defineSystem`, `defineBehavior`, `Query`. |
| Editor | Scene hierarchy, inspector, content browser, asset editors, play mode, build pipeline. Scenes are edited visually, not as JSON. |
| Targets | Web, desktop, WeChat and other mini-game platforms, playable ads, Android, iOS. |
| Feature set | 2D and 3D physics, glTF/FBX models with PBR materials, lighting, terrain and water, tilemaps, particles, 2D lighting, skeletal and 2D animation, Spine, audio, UI, gameplay AI. |

## Architecture

| Layer | Responsibility |
|---|---|
| **TypeScript SDK** (`esengine`) | Authoring surface: `App`, `World`, systems, components, queries, plugins. |
| **WasmBridge** | The single boundary between SDK and engine, with a generated, hash-checked memory layout. |
| **C++ core** | ECS storage, renderer (`GfxDevice`), resources, particles, tilemaps, text. Compiled to WebAssembly, or to arm64 on [mobile](/docs/publishing/android-ios/). |

Full architecture: [`ARCHITECTURE.md`](https://github.com/esengine/estella/blob/master/docs/ARCHITECTURE.md).
