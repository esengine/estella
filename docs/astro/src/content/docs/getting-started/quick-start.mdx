import { Steps, Aside } from '@astrojs/starlight/components';

This walkthrough produces a project with one entity moved by the arrow keys. It uses the **Blank** template (a scene
with a Camera) and a `ShapeRenderer`, so no art assets are required.

## Steps

<Steps>

1. **Create the project.** Launcher → **New project** → **Blank** → **Create project**. The editor opens
   `assets/scenes/main.esscene`, which contains one `Camera` entity.

2. **Add an entity.** *World Outliner → Add → Create entity… → Rendering → Shape*. The new entity carries `Transform`
   and `ShapeRenderer` (a white 100 × 100 circle at the origin). Rename it `Player` (**F2**).

   ![The editor after creating the Shape: a white circle at the origin, Player in the World Outliner, Transform and Shape Renderer in Details](@/assets/guides/en/gs-shape.png)

3. **Declare the behaviour.** Replace the contents of `src/components.ts` (the Blank template's declaration entry):

   ```typescript title="src/components.ts"
   import { defineBehavior, Transform } from 'esengine';

   export const Player = defineBehavior('Player', {
     state: { speed: 300 },
     update(ctx, dt) {
       const x = (ctx.input.isKeyDown('ArrowRight') ? 1 : 0) - (ctx.input.isKeyDown('ArrowLeft') ? 1 : 0);
       const y = (ctx.input.isKeyDown('ArrowUp') ? 1 : 0) - (ctx.input.isKeyDown('ArrowDown') ? 1 : 0);
       if (x === 0 && y === 0) return;

       const t = ctx.get(Transform);           // a copy: Transform is stored in the engine
       t.position.x += x * ctx.self.speed * dt;
       t.position.y += y * ctx.self.speed * dt;
       ctx.set(Transform, t);                  // write the copy back
     },
   });
   ```

   On save, the editor re-extracts component schemas from this module and registers `Player`.

4. **Attach the component.** Select `Player`, then *Details → Add Component → Player*. The `state` fields appear as
   editable properties.

   ![Details for Player: Transform, Shape Renderer and the Player card with its Speed field set to 300](@/assets/guides/en/gs-player-component.png)

5. **Run.** **F5** starts play mode; the arrow keys move the entity. **Esc** stops. Play mode runs in a separate world
   and does not modify the edited scene.

   ![Play mode: the scene view outlined in green, the running world in the Outliner and Details](@/assets/guides/en/gs-play.png)

</Steps>

## Explanation

- **`defineBehavior` registers a component and a system.** The `update` hook is scheduled as a system over every
  entity carrying the component, which is why `Player` is available in Add Component with no further declaration.
- **`state` is the component's data.** Values edited in Details are the values the system reads; code and inspector
  address the same field.
- **`ctx` is the per-entity view of the frame.** `ctx.self` is the entity's component state, `ctx.input` the input
  state, `dt` the frame time in seconds. Multiplying by `dt` makes `speed` a rate in units per second.

<Aside type="caution">
  `ctx.get` returns the stored object for components declared in TypeScript, but engine components (`Transform`,
  `Sprite`, `RigidBody2D`, …) are decoded from the WebAssembly heap on each read. Modifying the returned value without
  `ctx.set` has no effect. See [Scripting](/docs/scripting/overview/#your-first-behavior).
</Aside>
