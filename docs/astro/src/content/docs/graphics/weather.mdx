A weather is expressed as **multipliers of what the scene already authors** — the sun at a quarter of its strength, fog
five times as dense, the image slightly greyer — plus a few absolute levels with the same meaning in every project, such
as rain intensity and ground wetness. The same preset therefore fits any project regardless of its fog units or sun
brightness.

## Outdoor environment

The parts of an outdoor scene depend on one another: the clock moves the sun, the sky draws clouds that cast shadows, the
fog reads those clouds so gaps become light shafts, and the weather scales all of it. **Create → Rendering → Outdoor
Environment** creates this arrangement under one root: a sun, a sky light, a `TimeOfDay`, a `Weather`, and a global
Post Process Volume with sky, height fog and a neutral grade, set for the engine's reference scale of 100 units per
metre. The result is an ordinary set of entities; edit or delete any part.

## Component

Add `Weather` to one entity.

| Field | Description |
|---|---|
| `preset` | Current weather: Clear, Mist, Overcast, Rain, Storm, Snow. Default Clear. |
| `target` | Weather being transitioned to; None (default) for no transition. |
| `progress` | Transition progress, 0–1 (default 0). Advanced by the system during play; set in the editor to preview a partial transition. |
| `duration` | Transition time in seconds (default 6). |
| `sequence` | Presets to cycle through automatically, comma separated, e.g. `clear,mist,rain,clear`. Empty (default) holds the current weather. |
| `hold` | Seconds each weather in the sequence holds before the next transition (default 20). |
| `drive` | What the weather drives: Lights, Fog, Rain, Grade, Exposure, Reflections, Sound, Wind. All by default. |
| `soundSource` | An entity with a looping `AudioSource` for rain sound. The weather raises its `playing` while it rains and sets its volume to the authored volume × rain intensity. |

Transitions are eased in and out. A finished transition sets `preset` to the target and clears `target`.

## In the editor

Details shows the built-in weathers as buttons (a project's own preset id still works and shows as **Custom**), the
transition progress as a draggable value, the cycle and the drive flags, and a live readout of the current effect on the
image: key-light scale, fog scale, wetness and rain. Rain and fog reach the image through a Post Process Volume, which
the panel indicates.

## What a weather drives

| Drive | Effect |
|---|---|
| **Lights** | Directional lights are scaled and tinted and the ambient light is scaled, from their authored values (the weather always scales the authored number, never its own previous result). They are restored when the weather is removed or `Lights` is switched off. Applied only during play; in the editor lights are left alone, so previewing a weather never changes the saved scene. As the sky clouds over, directional shadows become softer (the `shadowSoftness` multiplier widens the sun's source) and lighter (`shadowStrength` × the authored darkness). |
| **Fog** | Height Fog density, sun glow and carried volumetric light are scaled, sky haze is raised, and the fog colour moves toward the weather's. |
| **Rain** | The Rain effect is added (if the scene has none) at the preset's intensity, and Rain and Screen Space Reflections receive the resulting wetness and puddles. Where the scene authors its own rain, the weather can only increase it. **Snow** uses the same drive: the [Snow Cover](/docs/graphics/terrain/overview/#snow-and-wet-surfaces) effect is added (if the scene has none) and lies on sky-facing surfaces, and the Rain effect's `snowfall` draws falling flakes. |
| **Reflections** | A baked reflection probe shows the sky it was baked under, so a rainy street would reflect a sunny one. The ambient light's `reflectionScale` and `reflectionSaturation` multiply and desaturate what baked probes show, and the weather lowers both. |
| **Wind** | The preset's `wind` scales Sky Atmosphere cloud drift and plant sway (a Foliage material's `u_windStrength`, a Sway sprite's `u_swayWind`); `waves` scales wave height on every water body, both drawn and as returned by surface queries. |
| **Grade**, **Exposure** | Colour Grade saturation and contrast are scaled, and Auto Exposure compensation is raised. |
| **Sound** | The `soundSource` volume and playback follow rain intensity. |

A Sky Atmosphere effect also takes the preset's `overcast` as cloud coverage and haze: clouds thicken and join, and the
sun, moon and stars behind them are hidden by the same transmittance.

Effects are applied after the scene's volumes have blended, so a scene with thin fog remains thinner than one with thick
fog under the same rain.

## Custom presets

```ts
import { registerWeatherPreset } from 'esengine';

// A preset names only what it changes; everything else stays neutral.
const sandstorm = registerWeatherPreset('sandstorm', {
  sun: 0.5, fogDensity: 10, fogTint: [0.82, 0.62, 0.38], fogTintAmount: 0.85,
  saturation: 0.8, exposure: 0.4,
});
```

`registerWeatherPreset(name, preset)` returns the preset's id. A custom preset is referenced by name in `sequence`, and
by the returned id in `preset` and `target`. Registering a built-in name again retunes that preset.

## Transitions from code

The component is data: write `target` and `progress: 0`, and the system performs the transition.

```ts
import { Weather, WEATHER_RAIN } from 'esengine';

world.insert(weatherEntity, Weather, { target: WEATHER_RAIN, progress: 0, duration: 10 });
```

## Scene clock

A weather's state derives from when its run began and how long it has run, measured on the scene clock: the game's own
seconds of play (a paused game stands still; a slowed game slows). Any moment can be computed without playing up to it,
the same `t` gives the same weather on every machine, and a cutscene or replay can move the clock freely.

```ts
import { seekSceneClock, sceneClock, weatherAt, WEATHER_CLEAR, WEATHER_NONE } from 'esengine';

seekSceneClock(240);   // weather, hour and clouds as at four minutes, from the next frame
sceneClock();          // seconds of play the clock has run

// Query without moving anything: a Weather that began as `start`, 90 s later.
weatherAt({ preset: WEATHER_CLEAR, target: WEATHER_NONE, progress: 0, duration: 10, sequence: 'clear,mist,rain', hold: 8 }, 90);
```

| Function | Description |
|---|---|
| `seekSceneClock(t)` | Moves the scene clock to `t` seconds, effective from the next frame. |
| `sceneClock()` | Seconds of play the clock has run. |
| `weatherAt(start, t)` | `{ preset, target, progress }` of a weather that began as `start`, `t` seconds later. |

Writing the component directly (as in [Transitions from code](#transitions-from-code)) starts a new run from the written
values, so a script's transition and the clock agree. Clouds are placed where the sky's wind, integrated over the
weather's changes of strength, would have carried them.
