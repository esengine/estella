  <Card title="Fast" icon="rocket">

  </Card>
  <Card title="Type-safe SDK" icon="seti:typescript">
    A first-class TypeScript API: `defineComponent`, `defineSystem`, `Query`,
    `Commands`, `Res`.
  </Card>
  <Card title="Data-oriented" icon="puzzle">
    An Entity-Component-System core with a single cache-friendly storage layer.
  </Card>
  <Card title="Visual editor" icon="pencil">
    A UE5-style editor — scene viewport, inspector, tilemap painter, Sequencer, and
    node-graph editors for materials and AI.
  </Card>
  <Card title="Batteries included" icon="star">
    Physics, tilemaps, particles, materials & 2D lighting, animation, Spine, audio,
    UI, and a gameplay AI layer.
  </Card>
  <Card title="Cross-platform" icon="laptop">
    One project, exported to the web, desktop, WeChat MiniGames, single-file
    playable ads, and native Android / iOS apps.
