The **Frame Debugger** captures a single frame, lists every draw call in order and states for each one **why it started
a new batch** (a different shader, blend mode, material, texture, scissor rectangle and so on). It is the editor view of
the [Frame Capture API](/docs/performance/profiling/frame-capture/).

Open it with **Window → Frame Debugger**, or search **Frame Debugger** in the Command Palette. It docks next to the
Profiler.
## Capturing a frame

1. Select the **realm**: **Viewport** (the editor's view), **Running game** (during Play) or **Device** (a connected
   device preview).
2. Click **Capture frame**. The frame is listed as one or more **passes**, a camera pass per camera plus a screen-overlay
   pass for UI drawn on top, each with its draw count.

A capture is a snapshot. When the scene changes afterwards the panel indicates it; capture again to inspect the new
frame.

## Draw list

Each row is one draw call:

| Column | Content |
|---|---|
| **Type** | Kind of draw: sprites, text, a mesh, a tilemap chunk, an effect… |
| **Break reason** | Why this draw could not join the previous one. |
| **Drew** | Material, shader and texture. |
| **Triangles** | Triangle count. |

The **Break reason** chips above the list filter the rows by cause:

| Break reason | Cause | Remedy |
|---|---|---|
| **First draw of its pass** | Every pass starts a batch. | — |
| **Shader / Material / Blend mode** | The neighbouring draw uses a different one. | Order entities so like draws are adjacent, or share a material. |
| **Texture slots** | The previous draw used every texture slot. | Pack sprites into fewer atlases. |
| **Scissor / Stencil** | A UI mask or clip region changed between the two draws. | — |
| **Depth / Culling / Render state** | Different depth test, face culling or custom state. | — |
| **Vertex layout / Index gap** | Different kinds of geometry that cannot share a buffer run. | — |

A UI pass with many **Blend** and **Material** breaks indicates interleaved widgets of different kinds; reorder siblings
or merge materials.

## Inspecting a draw

Clicking a row, or stepping with **Previous draw** / **Next draw**, shows its details: material, shader, texture,
triangles, instances, layer, scissor and stencil, and the **entities** it drew (**Select in the Outliner** selects one).
A draw without an entity (a glyph run, a gizmo, an effect) is marked as such.

The viewport can **replay** the frame up to the selected draw, showing what had been drawn at that point. A draw that
cannot be replayed is reported instead of showing an incorrect image.
