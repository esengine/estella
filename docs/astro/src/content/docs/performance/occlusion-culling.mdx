Frustum culling removes what is outside the camera's view. **`Occluder`** declares boxes that sight does not pass
through; the renderer then does not collect objects entirely hidden behind one.

```typescript
world.insert(wall, Occluder, { halfExtents: { x: 400, y: 300, z: 20 } });
```

Occlusion culling changes the cost of a frame, never its image: a frame with occluders and the same frame without them
produce the same pixels.

## Fields

| Field | Type | Default | Description |
|---|---|---|---|
| `halfExtents` | Vec3 | `{50, 50, 50}` | Half size of the box in world units, centred on the entity's position and rotated by its rotation. Scale is not applied. |
| `enabled` | boolean | `true` | Off: the box is not used. |

## Placing the box

An occluder box is authored, not derived from geometry. A mesh's bounds enclose the mesh, so bounds around a pillar, an
arch or a rock include empty space at their corners, and objects standing in that space would be culled while visible.

<Aside type="caution">
**The box must lie inside the solid part of the geometry.** A box that is too small only culls less. A box that is too
large culls visible objects, which no counter reports.
</Aside>

- The editor draws the box in the viewport, so it can be sized against the wall it sits in.
- The box can be on the wall's own entity or on a separate empty entity. A building made of many meshes usually needs one
  large box rather than one per mesh.

## What is culled

Only draws a depth test would have hidden. An object that ignores depth paints over the wall in front of it, so sprites,
UI, text and any surface whose material disables the depth test are never culled by an occluder.

Occlusion is evaluated per camera:

- Each camera in a frame tests its own occluders.
- **Shadows are not occlusion-culled.** An object hidden from the camera still casts its shadow.
- An occluder that contains the camera is ignored.

## Occlusion grid

Occluders are rasterized on the CPU into a grid, whose side is the **Occlusion grid** setting of the quality level (64
at every level by default; [View Distance & Draws](/docs/performance/quality-levels/settings/#view-distance--draws)).
Each object's bounds are then tested against it. A box hides only grid cells it covers **completely**, so:

- An occluder narrower than one grid cell (1/64 of the view at the default size) hides nothing. Large shapes such as
  walls, floors between storeys, buildings and cliffs are effective.
- An object hidden only by the combination of two boxes with a gap between them is still drawn; each box is tested on
  its own.

## Counters

| Counter | Meaning |
|---|---|
| `render.cull.occluders` | Occluder boxes this view used. |
| `render.cull.occluded` | Renderables an occluder culled. |
| `render.culled` | All culled renderables, frustum included. |

Zero occluders means the boxes were not used (rotated past the near plane, or of zero size). Occluders used with nothing
occluded means they are not in front of anything.

## Related systems

`Occluder` decides which objects are collected. [World streaming](/docs/world/streaming/) decides which objects exist,
and [`LODGroup`](/docs/performance/level-of-detail/) decides how much geometry the remaining objects cost. The three
combine.
