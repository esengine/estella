A packaged native app can link SDKs of its own — ads, store, sign-in, analytics — written in Java, Kotlin,
Objective-C or Swift. The engine links none of them. **`NativeChannel`** connects scripts to that code: the native
side registers a method name, the script calls the name, and values cross as JSON.

```typescript title="src/shop.ts"
import { NativeChannel } from 'esengine';

if (NativeChannel.has('store.buy')) {
    const receipt = await NativeChannel.call<{ token: string }>('store.buy', { sku: 'gems_100' });
}
const off = NativeChannel.on<{ sku: string }>('store.restored', (p) => grant(p.sku));
```

## API

| Member | Description |
|---|---|
| `NativeChannel.available` | Whether the platform has native code to reach. `false` on the web, in mini-games and in the editor. |
| `NativeChannel.has(method)` | Whether a call to `method` would be answered. |
| `NativeChannel.call(method, args?)` | Runs the handler and resolves with its answer. Rejects when no handler is registered for the name, or with the reason the handler gave. |
| `NativeChannel.on(event, handler)` | Subscribes to events the native side raises. Returns the unsubscribe function. |

Code that checks `has` before calling runs unchanged on every platform: where there is no native code, `has` returns
`false` and nothing is called.

Every native build answers `app.info`: `{ os, osVersion, device, id, version, build }` on Android and iOS (the package
id and version, which scripts cannot otherwise read), and `{ device }` on desktop.

## Android

Native code must be compiled into the app, so export with **Package as: Android Studio project**. Put classes under
`app/src/game/java`, which a re-export does not touch, and register handlers from a plugin:

```java title="app/src/game/java/com/example/game/GamePlugin.java"
package com.example.game;

import android.app.Activity;
import com.estella.host.NativeChannel;

public final class GamePlugin implements NativeChannel.Plugin {
    @Override public void register(Activity activity) {
        NativeChannel.register("store.buy", (args, reply) -> {
            // args is JSON text. Call your SDK, then answer once, from any thread:
            reply.resolve("{\"token\":\"abc\"}");   // or reply.reject("cancelled")
        });
    }
}
```

List the plugin class in `app/src/game/resources/META-INF/services/com.estella.host.NativeChannel$Plugin`, one class
name per line. Plugins are discovered through Java's `ServiceLoader` before the first frame, so a library can provide
its own and nothing in the manifest names it.

- Handlers run on the UI thread.
- `NativeChannel.emit("store.restored", json)` raises an event from any thread.
- `NativeChannel.activity()` returns the game's activity for SDKs that need one.

A project exported before the `src/game` source set existed has no entry for it in `app/build.gradle.kts`, which a
re-export does not rewrite. Add it manually:

```kotlin title="app/build.gradle.kts"
android {
    sourceSets {
        getByName("main") {
            java.srcDir("src/game/java")
            resources.srcDir("src/game/resources")
        }
    }
}
```

## iOS

The exported Xcode project contains `App/EstellaNativeChannel.h`. Add a source file to the app target outside `App/`
(which a re-export rewrites) and register from `+load`, which runs before the game starts:

```objc title="GamePlugin.m"
#import "App/EstellaNativeChannel.h"

@interface GamePlugin : NSObject
@end

@implementation GamePlugin
+ (void)load {
    [EstellaNativeChannel registerMethod:@"store.buy"
                                 handler:^(NSString* args, EstellaNativeReply reply) {
        // Call your SDK, then answer once, from any thread:
        reply(@"{\"token\":\"abc\"}", nil);   // or reply(nil, @"cancelled")
    }];
}
@end
```

`[EstellaNativeChannel emitEvent:@"store.restored" json:json]` raises an event. Handlers run on the main thread.

## Ads

The [`Ads` service](/docs/publishing/ads-sharing/#rewarded-ads) works on a device once native code answers the
following methods. `Ads.available` then returns `true`, and `showRewarded` pauses the game and suspends audio around
the ad as on a mini-game host.

| Method | Args | Answer |
| --- | --- | --- |
| `ads.show` | `{ kind: "rewarded" \| "interstitial", unitId }` | Answer when the ad has **closed**. For a rewarded ad, `{ "completed": true }` when the reward was earned; any other answer grants nothing. Reject when no ad can be shown. |
| `ads.preload` | Same | Optional. Answer when the ad is loaded. |

The ad SDK (an ad network SDK or a mediation layer) is chosen by the project.
