Estella 可播放 [DragonBones](https://docs.egret.com/dragonbones) 骨架：骨骼、网格、插槽与动画，由与场景其余部分相同的渲染器绘制。骨架由
**`DragonBonesAnimation`** 组件（主包 `esengine`）放置，运行时通过 **`DragonBones`** 资源控制，该资源从 `esengine/dragonbones` 子路径导出。

DragonBones 在引擎支持的所有目标上运行：编辑器视口、Play、Web、试玩广告、小游戏，以及 iOS 与 Android 宿主。

<Aside type="note">
  DragonBones 运行时采用 **MIT 许可**。发布使用它的游戏无需单独许可。
</Aside>

## 导入项目

DragonBones 导出包含三个文件，作为一种资源类型一并导入：

| 文件 | 内容 |
|---|---|
| `<name>_ske.json` 或 `<name>.dbbin` | 骨骼：骨骼、插槽、动画。 |
| `<name>_tex.json` | 图集：每个部件在图像中的位置。 |
| `<name>_tex.png` | 图集图像。 |

图集图像使用自身的过滤、环绕、sRGB 和 mipmap 导入设置。通过 `loadDragonBonesAssets` 单独加载时，效果与场景加载一致。

将文件夹复制到项目中。骨骼与图集两个 JSON 文件**通过 `_ske` / `_tex` 名称后缀**区分，而非扩展名。

PNG 只在图集内部通过其 `imagePath` 字段引用。打包时会沿该引用收集，因此图像无需被场景引用也会包含在构建中。

## `DragonBonesAnimation` 组件

通过 **+ Add → Create entity… → DragonBones** 创建，或将该组件添加到已有实体上。

![细节面板里的 DragonBonesAnimation 组件——骨骼与图集的资源槽，以及从文件读取并填充的骨架和动画下拉框](@/assets/guides/zh/dragonbones-inspector.png)

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `skeletonPath` | 资源 | `''` | 骨骼文件（`_ske.json` 或 `.dbbin`）。 |
| `atlasPath` | 资源 | `''` | 图集文件（`_tex.json`）。 |
| `armature` | string | `''` | 文件中的骨架。为空时使用第一个。 |
| `animation` | string | `''` | 生成时播放的动画。 |
| `loop` | boolean | `true` | 初始动画是否循环。 |
| `playing` | boolean | `true` | 播放是否推进。 |
| `fadeInTime` | number | `0` | 动画切换时的交叉淡入时长（秒），包括首次播放。 |
| `timeScale` | number | `1` | 单个实体的播放速度（≥ 0）。 |
| `skeletonScale` | number | `1` | 骨架的统一缩放（≥ 0）。 |
| `flipX` / `flipY` | boolean | `false` | 水平 / 垂直镜像。 |
| `color` | Color | `{1,1,1,1}` | 着色（RGBA，0–1），与每个插槽的原始颜色相乘。 |
| `layer` | number | `0` | 排序层；值越大越靠上绘制。 |
| `material` | 资源 | 无 | 自定义材质。为空时使用默认批处理着色器。 |
| `enabled` | boolean | `true` | 关闭后骨架冻结并隐藏。 |

### 编辑器行为

- **资源槽。** `skeletonPath` 与 `atlasPath` 是资源槽：可从弹出列表选择、从内容浏览器拖入文件，或使用槽上的定位 / 清除操作。场景以
  `@uuid:` 引用保存它们，移动或重命名文件不会断开引用。
- **实时预览。** 编辑模式下骨架在视口中摆出姿势；修改动画、缩放或翻转无需进入 Play 即可看到。
- **着色。** 由于 `color` 与插槽原始颜色相乘，不透明白色（默认值）不改变颜色，清空该字段即恢复原始颜色。

## 骨架选择

一个 DragonBones 文件是一个项目，可包含多个骨架；`armature` 选择其中之一。

设置 `skeletonPath` 后，**Armature** 与 **Animation** 变为从文件读取并填充的下拉框。动画列表随所选骨架变化，因为同一文件中的不同骨架各有自己的动画列表。`armature`
为空时使用文件中的第一个骨架。

<Aside type="note">
  `.dbbin` 骨骼不会填充下拉框，这些字段保持为文本框。手动输入的名称在运行时仍然有效。
</Aside>

## 播放与交叉淡入

DragonBones 不在骨骼上保存混合表。交叉淡入在动画开始时指定，作为 `fadeIn` 的参数：

```typescript
import { defineSystem, Query, Res, DragonBonesAnimation } from 'esengine';
import { DragonBones } from 'esengine/dragonbones';

const control = defineSystem(
  [Query(DragonBonesAnimation), Res(DragonBones)],
  (q, dragonBones) => {
    // 运行时加载前为 null；首次使用时获取。
    if (!dragonBones) return;

    for (const [entity] of q) {
      dragonBones.fadeIn(entity, 'walk', 0.25, true);  // 0.25 秒交叉淡入
      dragonBones.setTimeScale(entity, 1.5);           // 1.5 倍速
    }
  },
);
```

| 方法 | 说明 |
|---|---|
| `play(entity, name, loop?)` | 立即开始动画，不混合。 |
| `fadeIn(entity, name, seconds, loop?)` | 交叉淡入到一段动画。 |
| `stop(entity, name?)` | 停止一段动画；省略 `name` 时停止全部。 |
| `setTimeScale(entity, scale)` | 单个实体的播放速度。 |
| `setColor(entity, r, g, b, a)` | 为骨架着色（0–1），与插槽颜色相乘。 |
| `setEnabled(entity, on)` | 将骨架移出帧（冻结并隐藏）或恢复。 |
| `setEntityProps(entity, props)` | 一次设置 `{ skeletonScale?, flipX?, flipY?, layer?, playing?, timeScale?, color? }`。 |

`play` 与 `fadeIn` 的 `loop` 默认为 `true`。

### `playing` 与 `enabled`

| 设置 | 姿势 | 是否绘制 |
|---|---|---|
| `playing: false` | 冻结 | 是 |
| `enabled: false` / `setEnabled(entity, false)` | 冻结 | 否 |

`setEnabled` 与组件的 `enabled` 字段控制同一个开关。写入该字段（在检查器中或通过 `world.set`）在写入时生效；`setEnabled`
保持有效，直到下一次这样的写入。大纲视图的可见性开关使用同一通道，因此在大纲视图中隐藏实体不会改变其编写的 `enabled` 值。

## 查询骨架

```typescript
const anims  = dragonBones.getAnimations(entity);  // string[]
const bounds = dragonBones.getBounds(entity);      // { x, y, width, height } | null
```

`getBounds` 由骨架**摆好姿势后**的几何体计算，而非编辑工具记录的包围盒，因此会随当前姿势变化。

## 共享骨骼

引用同一对骨骼与图集的实体共享**一份解析后的骨骼和一张图集纹理**。最后一个引用它们的实体移除时数据被卸载。无需任何设置。

单个实体的属性仍各自独立，因此共享骨骼的实例可以分别缩放、翻转和着色：

## 构建产物

只有当打包的场景使用 DragonBones 时才会包含其运行时。编辑器通过扫描要打包的场景来判断，没有对应设置。

| 目标 | 运行时的交付方式 |
|---|---|
| Web / 桌面 | 引擎旁的 `dragonbones.wasm`，首次使用时获取。 |
| 试玩广告 | 内联进单个 HTML 文件。 |
| 小游戏 | 复制进包内。 |
| iOS / Android | 编译进应用二进制。 |

## 最佳实践

- **过渡使用交叉淡入**：`fadeIn`（0.15–0.3 秒）；`play` 不混合直接切换。在组件上设置 `fadeInTime`，使首次播放也混合。
- **在实体之间共享骨骼与图集**：一组相同角色只需一次解析和一张图集。
- **从下拉框选择骨架**而非手动输入；文件中不存在的名称不会绘制任何内容。
- **用 `playing: false`** 而非禁用来保持可见的静止姿势。
