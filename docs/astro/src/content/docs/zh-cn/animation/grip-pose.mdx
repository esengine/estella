**`GripPose`** 让骨架的手保持一个命名姿势，例如 `pistol`、`handle` 或 `cup`。姿势只规定每根手指弯曲多少、手指张开多少以及拇指够向何处；它不指名任何骨骼，因此一个姿势适用于任何带手指骨骼的骨架。弯曲轴在骨架第一次被握持时根据其手部推算。

`GripPose` 只负责手的形状。把手放到物体上由 **`GripHolder`** 与 **`GripProfile`** 完成（[握持物体](#握持物体)），或者用手部关节下的实体加手臂的
two-bone IK 实现。

所有握持组件与函数都从 `esengine` 导出，并标记为实验性。

## `GripPose` 组件

在骨架的根实体上添加 `GripPose`，并为任一只手指定姿势名：

```ts
import { GripPose } from 'esengine';

world.insert(hero, GripPose, { rightPose: 'pistol', leftPose: 'support' });

// 扣动：食指从搭放移到按下，其余不动。
world.update(hero, GripPose, (grip) => { grip.rightTrigger = 1; });
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `rightPose`、`leftPose` | string | `''` | 每只手的姿势名。为空时该手淡出，交由其他动画控制。 |
| `rightWeight`、`leftWeight` | number | `1` | 姿势相对手指片段动画的权重（0–1）。 |
| `rightTrigger`、`leftTrigger` | number | `0` | 食指从搭放（0）到按下（1）的位置，仅对定义了扳机的姿势有效。 |
| `blendSeconds` | number | `0.15` | 姿势切换的大致时长。过渡从静止开始、在静止结束，没有跳变。 |
| `rightHand`、`leftHand` | string | `''` | 手部关节，以相对此实体的路径表示。为空时按名称查找。高级字段。 |

### 执行

- `GripPose` 在 Animator 之后运行，因此片段动画继续驱动手臂，姿势保持手指。没有 Animator 时也能工作。
- 它在游戏运行时生效，编辑模式下不运行。

## 内置姿势

| 名称 | 手形 |
|---|---|
| `open` | 平展，与骨架静止时相同。 |
| `relaxed` | 自然下垂。 |
| `fist` | 握拳，拇指压在其他手指上。 |
| `pistol` | 手枪握把，食指沿枪身伸直。定义了 `trigger`。 |
| `support` | 托在步枪前握把下。 |
| `handle` | 锤子、剑或工具的手柄。 |
| `pinch` | 拇指与食指捏合。 |
| `cup` | 环握杯子或球，手指张开。 |

`gripPoseNames()` 列出已注册的名称；`gripPose(name)` 返回一个定义。

## 自定义姿势

`registerGripPose(name, def)` 添加一个姿势，或替换同名姿势：

```ts
import { registerGripPose } from 'esengine';

registerGripPose('claw', {
    thumb: { opposition: 1, gap: 0.2 },
    index: { curl: 0.9, base: 0.2 },
    middle: { curl: 0.9, base: 0.2 },
    ring: { curl: 0.9, base: 0.2 },
    pinky: { curl: 0.9, base: 0.2 },
});
```

`GripPoseDef` 包含 `thumb`、`index`、`middle`、`ring`、`pinky`，以及可选的 `trigger`（`trigger` 为 1 时的食指；缺省时 `trigger` 不起作用）。

### 手指数值（`GripFinger`）

| 数值 | 说明 |
|---|---|
| `curl` | 手指的弯曲，从 0（静止姿势）到 1（合拢）。必填。 |
| `base` | 第一节关节的弯曲，用于与手指其余部分不同的情况，例如沿枪身伸直或勾起的手指。默认等于 `curl`。 |
| `spread` | 手指张开程度，−1 到 1。 |
| `bend` | 逐关节的弯曲角度（度），相对静止姿势，从指根关节起，例如 `[30, 45, 20]`。覆盖 `curl` 与 `base`。由编辑器写入。 |
| `fan` | 该手指偏离手掌中线的角度（度）：食指与中指偏向拇指，无名指与小指偏离拇指。覆盖 `spread`。 |

### 拇指数值（`GripThumb`）

| 数值 | 说明 |
|---|---|
| `opposition` | 拇指从静止位置移向够取目标的程度，0 到 1。必填。 |
| `to` | 够取目标：`fingers`（中指中部，如握拳或握柄；默认）或 `index`（食指指尖，如捏合）。 |
| `gap` | 拇指在目标前停下的距离，以食指长度为单位：即被握物体所占的空间。默认 0。 |

拇指没有逐关节的弯曲数值。其指尖被放到其他手指当帧姿势下掌侧的一个点上，两个关节共同弯曲以够到该点，因此握拳时拇指压在手指上，握柄时环绕握把。该点够不到时（例如手指平展），拇指指向该点。

`gripPoseByJoint(pose)` 把一个姿势换算为逐关节的 `bend` 与 `fan` 数值，得到完全相同的手形，可作为编辑单个关节的起点。`bend` 与 `fan`
以手部自身的轴而非某根骨骼的轴测量，因此逐关节的姿势仍适用于任何骨架和任意一只手。

## 骨架要求

- **手部关节。** 按名称查找：名为 `RightHand`、`hand_r` 之类的关节。名称不匹配时，将 `rightHand` / `leftHand` 设为关节路径。
- **手指。** 手部关节下名为 `thumb`、`index`、`middle`、`ring` 以及 `pinky` 或 `little` 的关节。`index_metacarpal_r` 这类掌骨会被跳过。手指未按此命名的手无法摆姿势。
- **缺少手指。** 手指较少的骨架只为已有手指摆姿势，并在日志中列出缺少的手指。

`gripPoseStatus(app, entity)` 按手报告：找到的关节、手指关节数、缺少的手指、当前姿势与权重，以及正在接触表面的手指。

## 握持物体

握持由三部分组成：

| 部分 | 职责 |
|---|---|
| `GripProfile`（在物体上） | 每只手的掌心在物体上的位置（主手与副手各一个锚点实体），以及各自的手指姿势。 |
| 手臂 | 把掌心送到锚点：肩、肘、腕的 two-bone IK，手肘保持片段弯向的一侧，手腕转到锚点朝向。 |
| 手指 | 每根手指的姿势：截取的手指姿势或按名称的握持姿势，以 `slerp(clip, grip, weight)` 叠加在片段上。 |

**锚点**是物体下的任意实体，用移动与旋转 gizmo 摆放。其原点为掌心中心（手部关节到中指指根的中点），+Z 为手指指向，+Y 为掌心朝向。

```ts
import { GripHolder, GripPlacement, GripProfile } from 'esengine';

world.insert(rifle, GripProfile, { mainAnchor: gripAnchor, supportAnchor: foregripAnchor, mainPose: 'pistol', supportPose: 'support' });
world.insert(hero, GripHolder, { held: rifle, placement: GripPlacement.Object });
```
### `GripHolder`

放在骨架的根实体上。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `held` | 实体 | 无 | 被握的物体，一个带 `GripProfile` 的实体。为空时松手。 |
| `mainHand` | `GripHand` | `Right` | 主手：`Right` 或 `Left`。 |
| `placement` | `GripPlacement` | `Hand` | `Hand`：物体随片段动画中的主手移动。`Object`：由游戏代码放置物体（例如瞄准时），主手手臂被带到物体上。 |
| `weight` | number | `1` | 握持相对片段的权重（0–1）。 |
| `supportWeight` | number | `1` | 副手握持的权重，在 `weight` 之下应用（0–1）。 |
| `blendSeconds` | number | `0.2` | 握住、松开或更换被握物体的大致时长。每个关节从之前的姿势平滑过渡，从静止开始、在静止结束。 |
| `rightHand`、`leftHand` | string | `''` | 手部关节，以相对此实体的路径表示。为空时按名称查找。高级字段。 |

### `GripProfile`

放在被握的物体上。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `mainAnchor` | 实体 | 无 | 主手掌心的锚点。 |
| `supportAnchor` | 实体 | 无 | 副手掌心的锚点。为空时单手握持。 |
| `mainPose`、`supportPose` | string | `'handle'`、`'support'` | 每只手的手指姿势：按名称的握持姿势，或已注册的手指姿势。 |
| `mainFingers`、`supportFingers` | string | `''` | 逐关节的手指姿势，`GripPoseDef` 的 JSON，由编辑器写入。设置后覆盖按名称的姿势。高级字段。 |
| `hand` | number | `0`（Right） | 锚点按哪只手摆放。另一只手为主手时，两个锚点都会镜像。 |
| `mirror` | `GripMirror` | `X` | 物体的镜像平面：垂直于其 X（YZ 平面）、Y（XZ）或 Z（XY）。 |
| `wrap` | boolean | `true` | 使手指合拢到物体的 `GripSurface` 形状上。没有表面时不起作用。 |

### 求值顺序

握持在 Animator 之后运行，每帧按固定顺序：

1. 片段的姿势；
2. 物体：随主手（`Hand`），或位于游戏放置的位置并把主手手臂带过去（`Object`）；
3. 副手锚点，从物体当前位置读取；
4. 副手手臂；
5. 双手的手指。

物体从不读取副手，因此没有步骤依赖自身的输出。每帧都从片段姿势求解，而非从上一帧的结果继续，且只读取游戏时钟：相同的输入与步进产生逐位相同的骨骼。

### 手指姿势

`captureFingerPose(world, handJoint)` 将手部下每个具名关节的旋转记录为纯 JSON；`registerFingerPose(name, pose)` 以一个名称注册它，供
`GripProfile` 引用。用 `GripPose`、片段或手动摆好手形，截取后将 JSON 随游戏保存。截取的姿势指名了骨架的骨骼，因此只适用于该骨架；按名称的握持姿势适用于任何骨架。

### 贴合物体

姿势规定手指最多合拢多少；**`GripSurface`** 形状规定手指合拢到什么上。为手要环握的每个部分，在物体或其下任意实体上添加一个：手柄或枪管用圆柱或胶囊，也可用球体，块状握把用盒体。尺寸以实体自身单位表示，与碰撞体相同。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `shape` | `GripSurfaceShape` | `Cylinder` | `Cylinder`、`Capsule`、`Sphere` 或 `Box`。 |
| `direction` | number | `1`（Y） | 圆柱或胶囊的轴：实体的 X、Y 或 Z。 |
| `center` | vec3 | `(0, 0, 0)` | 形状中心，以实体单位表示。 |
| `radius` | number | `0.5` | 圆柱、胶囊或球体的半径。 |
| `height` | number | `1` | 圆柱或胶囊的全长，包括两端。 |
| `size` | vec3 | `(1, 1, 1)` | 盒体尺寸。 |

`wrap` 打开时：

- 每根手指从张开状态向姿势角度合拢，所有关节同时运动。首先碰到表面的骨骼连同其之前的所有关节停下；其后的关节继续合拢。
- 拇指沿其够取方向靠近，在其某根骨骼碰到表面时停下。
- 手指在形状外约一个手指粗细处停下（食指长度的 8%），且绝不超过姿势；姿势中张开的手指保持张开。
- 起始时位于表面内部的骨骼（压入掌心的手柄）可以继续运动，但不会更深。
- 接触计算为点到形状的距离，每只手数百次。不使用物理，也不使用网格，结果是确定的。

因此打开 `wrap` 的 `fist` 无论手柄粗细都会让每根手指贴合手柄，而 `pistol` 保持食指沿枪身伸直。

### 另一只手的镜像

锚点只按 `hand` 指定的手摆放一次。另一只手为主手时，两个锚点在物体的 `mirror` 平面中镜像：位置被反射，旋转换算为另一只手的掌心。按名称的姿势与逐关节姿势描述的是手形而非骨骼，因此同样镜像。截取的姿势不镜像，因为它指名的是一只手的骨骼。

### 不同的身体比例

锚点定位的是掌心而非手部关节，手臂每帧根据其所在身体求解，因此手臂更长或更短的身体同样能把掌心放到锚点上。超出够取范围时，手臂直指锚点，手腕仍转向锚点；掌心在锚点前停下，结果是确定的。

### 编辑器

选中带 `GripProfile` 的物体。细节面板中的对应区块用于编辑握持，握着该物体的角色会在编辑时于视口中显示握持效果，无需进入 Play。

| 控件 | 行为 |
|---|---|
| **Preview** | 选择角色。没有 `GripHolder` 的角色会获得一个，以 `Object` 放置方式握持此物体，从而在场景中所站的位置伸手够取物体。主手开关设置握持者的 `mainHand`，用于查看镜像后的握持。掌心够不到锚点时显示剩余距离。 |
| **Anchors** | 选择锚点实体，或在物体下创建一个。Select 将选择切换到锚点，以便使用移动与旋转 gizmo。视口绘制每个掌心目标，另一只手为主手时绘制镜像：掌心的坐标框、表示手指方向的箭头、表示掌心朝向的虚线，以及拇指一侧的短线；主手为琥珀色，副手为蓝色。 |
| **Clip** | 选择一条时间轴；拖动时间或播放时，角色在视口中按其摆姿势，并在其上叠加握持，与 Play 中相同。只有视口被摆姿势；移除片段、关闭预览或离开该区块都会恢复姿势。 |
| **Fingers** | 从一个握持姿势开始；可按角度修改每个关节的弯曲与每根手指的偏斜。第一次修改会把逐关节姿势写入 `mainFingers` 或 `supportFingers`；Reset 回到按名称的姿势。视口中，预览角色的每个手指关节都有一个手柄（主手琥珀色，副手蓝色）；拖动即弯曲该关节，每次拖动为一个撤销步骤。 |
| **Close onto surfaces** | `wrap` 开关、当前接触表面的手指，以及物体的表面。Create 在主手锚点下添加一个横穿主手掌心的圆柱，按角色掌心大小设定尺寸，再用 gizmo 和字段调整以贴合手柄。视口以绿色绘制表面，并同时绘制掌心。 |

预览由 **View → Preview FX** 控制，与弹簧骨骼使用同一开关。它只移动视口中的骨骼和被握物体，从不修改场景；关闭后两者恢复为场景中保存的状态。

## 限制

- **单独的 `GripPose` 不产生接触。** 姿势只是手形：手指可能陷入较粗的握把，或在较细的握把前停下。用 `GripHolder` 握持并添加 `GripSurface` 形状后，手指才会贴合物体。
- **手部的轴只计算一次**，取自骨架首次被握持时的姿势。若此时手正处于动画中，轴取自该姿势；实际差异很小。
- **不支持手臂上的负缩放。** 镜像的骨骼会转向错误方向。
- **手指贴合的是表面形状，而非网格。** 不规则的握把用多个形状近似。
- **拇指在视口中没有手柄。** 拇指是够取而非弯曲，由其数值设定。截取的姿势不能在该区块中编辑。
- **编辑器在握持之下播放时间轴，而非 Animator 状态机**；状态机在 Play 中运行。
- **手臂求解有限。** `Hand` 放置方式下只弯曲副手手臂；`Object` 放置方式下先弯曲主手手臂，再弯曲副手手臂。肩部与脊柱不会倾斜以扩大够取范围。
- **每个握持者只能握一个物体。**
- **验证范围。** 姿势在一个 Mixamo 命名的角色上调校。以其他骨骼朝向和名称搭建的同一只手得到相同的指尖位置，但尚未在第二个真实骨架上测试。
- **未在设备上测量。** 开销为每帧最多 30 个关节、每个关节若干次四元数运算；在没有片段驱动的骨架上手部稳定后不再有开销。
