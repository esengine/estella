2D 骨骼用一套骨骼使一张图像变形。骨骼在编辑器中由任意 PNG 制作，无需外部动画工具或第三方格式。[Spine](/docs/zh-cn/animation/spine/) 与
[DragonBones](/docs/zh-cn/animation/dragonbones/) 骨骼可与之并用。

## 结构

| 组成 | 说明 |
|---|---|
| **`.esrig`** | 编辑源文件：从图像切出的部件、骨骼，以及每个顶点的骨骼权重。 |
| **`.esmesh`** 与 **`.esprefab`** | 保存时写在 `.esrig` 旁边。场景引用的是它们，因此构建中不包含编辑数据。 |
| **骨骼** | 带 `Transform` 与 `Bone2D` 组件的普通实体。片段、Animator、层遮罩与代码都像访问其他实体一样访问它们。 |

| `Bone2D` 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `length` | number | `0` | 骨骼沿其局部 +X 的长度。以此骨骼结尾的 IK 链用这一端够取目标。 |

## 创建骨骼

在内容浏览器中右键一张图像，选择 **创建 2D 骨骼**。骨骼编辑器顶部的模式按制作角色的顺序排列：

| 模式 | 操作 |
|---|---|
| **部件** | **按透明区域切分** 把一张肢体拼图切成部件。拖动部件组装角色。右侧列表设定绘制顺序。 |
| **骨骼** | 选 **新建** 后拖动创建骨骼；从另一根骨骼的末端开始则接续该骨骼。选 **选择** 时，拖动末端调整方向，拖动骨骼本体移动它。 |
| **网格** | 每个部件初始覆盖一层网格。格子越小变形越平滑，开销也越大。拖动顶点可调整。 |
| **权重** | **按距离** 把每个顶点绑定到最近的骨骼；然后刷绘修正：在右侧选择一根骨骼并拖动。`Shift` 反向，`Ctrl` 平滑，`[` 与 `]` 调整笔刷半径。**整个部件跟选中骨骼** 把刚性部件绑定到一根骨骼。 |
| **变形** | **新建形状**，然后拖动以位移顶点，用于呼吸、微笑、鼓起等形状。 |

| 命令 | 作用 |
|---|---|
| **试摆** | 转动骨骼以检查权重。不修改骨骼文件。 |
| **绑定姿势** | 从试摆返回绑定姿势。 |
| **放入场景** | 保存骨骼并实例化其 prefab。 |

再次保存会更新已打开场景中的所有实例，并保留场景中对单个实例的修改。

<Aside type="note">
  不能单独添加或删除顶点，一个 2D 骨骼只使用一张图像。重新生成部件网格会清除该部件的权重与变形；编辑器会先请求确认。
</Aside>

## 重新绑定

骨骼在刷好权重之后仍可修改：

| 操作 | 行为 |
|---|---|
| **移动骨骼** | 在 **绑定姿势** 下拖动骨骼或输入其长度、旋转，修改的是绑定姿势本身。图像保持不动。 |
| **更换父骨骼** | 在 **骨骼** 模式中为选中骨骼设置 **父骨骼**，或 **无（根骨骼）**。该骨骼及其后代在图像上的位置不变。 |
| **重命名或删除** | 删除骨骼时，其子骨骼与顶点交给其父骨骼。 |
| **重算权重** | 再次执行 **按距离** 或 **整个部件跟选中骨骼**，然后刷绘。 |
| **换绑到另一套骨架** | 在 **骨架** 下选择另一个 `.esrig`，点击 **换绑到这套骨架**。骨骼按名称匹配；所在骨骼无匹配的顶点移到最近的已匹配祖先骨骼。共享同一骨架的骨骼文件具有相同的骨骼名称与路径，因此可播放相同的片段。 |

保存时，引用旧骨骼名称的数据会被更新：

- 以路径引用了被重命名或更换父骨骼的骨骼的片段（`.estimeline`）与 Animator 层遮罩（`.esanimator`）会被改写。片段中大部分路径属于该骨骼文件的骨骼时，才视为属于该骨骼文件。指向已删除骨骼的轨道保留原路径；保存时报告此类轨道的数量。
- 每根骨骼有一个固定 id，用于命名其 prefab 实体。在场景中添加到某根骨骼上的组件与子实体（例如 `IK2D`，或挂在手上的剑），在其他骨骼被重排、更换父骨骼或删除后仍保留在该骨骼上。

### 在场景中重新绑定蒙皮

选中带 `MeshSkin` 的实体，在细节面板中使用 **换绑到**：选择场景中的另一套骨架，点击 **按名字换绑关节**。每个关节匹配该骨架下同名的实体；同一名称出现多次时（例如两条手臂下都有
`hand`），由父级名称区分。无匹配的关节保留原实体并被列出。这同样适用于 3D 蒙皮，例如绑定到身体上的外套。

## 动画

选中角色，在 [Sequencer](/docs/zh-cn/animation/timeline/sequencer/) 中为其骨骼设置关键帧。骨骼以其在根下的路径寻址，例如 `hips/spine/arm`。变形是 `MeshMorph`
组件上的一个权重，以相同方式设置关键帧。

混合由 [Animator](/docs/zh-cn/animation/animator/) 完成：1D 与 2D 混合、层、遮罩与过渡均适用于骨骼。

## IK

在肢体的最后一根骨骼上添加 **`IK2D`** 并设置 `target`。动画应用之后，该骨骼的末端够向目标，因此无论播放哪个片段，手都能停留在所握之物上。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `target` | 实体 | 无 | 要够取的实体。 |
| `chainLength` | number | `2` | 弯曲的骨骼数，包括本骨骼（1–32）。两根骨骼用解析解，并保持弯曲方向；更长的链使用迭代求解。 |
| `bend` | number | `1` | 两骨链：中间关节的弯曲方向，`1` 为逆时针，`-1` 为顺时针。 |
| `weight` | number | `1` | 从动画姿势（0）到求解姿势（1）的混合。可做动画。 |
| `matchTargetRotation` | boolean | `false` | 同时把本骨骼旋转到目标的旋转，例如让脚贴合斜坡。 |
| `enabled` | boolean | `true` | 启用求解。 |

## 约束

在骨骼上添加 **`BoneConstraint2D`**。约束在 IK 之后运行，从根部向外。

| `kind` | 行为 |
|---|---|
| **Limit Rotation** | 将局部旋转限制在 `min` 与 `max` 之间。经过该骨骼的 IK 链也遵守此限制。 |
| **Copy Rotation** | 取 `source` 的世界旋转加上 `offset`。 |
| **Copy Position** | 取 `source` 的世界位置。 |
| **Look At** | 使骨骼的 +X 指向 `source`，再加上 `offset`。 |

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `kind` | `BoneConstraintKind` | `LimitRotation` | 约束类型，见上表。 |
| `source` | 实体 | 无 | 被复制或注视的实体。Limit Rotation 不使用。 |
| `min`、`max` | number | `-45`、`45` | Limit Rotation：局部旋转范围（度）。 |
| `offset` | number | `0` | Copy Rotation 与 Look At：附加的角度（度）。 |
| `weight` | number | `1` | 从未约束姿势（0）到约束姿势（1）的混合。可做动画。 |
| `enabled` | boolean | `true` | 启用约束。 |

IK 与约束在运行模式下生效。两者都能处理根部负缩放造成的镜像角色。

## 代码

骨骼是纯数据，游戏或工具代码可通过 `esengine/rig2d` 子路径构建：

```typescript
import {
  autoWeightPart, bakeRig, coverRigPart, createRig, rigImageFromRGBA, spawnRig, IK2D,
} from 'esengine/rig2d';

const image = rigImageFromRGBA(width, height, rgba);
const rig = createRig('hero.png', width, height);
rig.bones.push(
  { name: 'upper', parent: -1, x: 0, y: 0, rotation: 0, length: 50 },
  { name: 'lower', parent: 0, x: 50, y: 0, rotation: 0, length: 50 },
);
const rect = { x: 0, y: 0, w: width, h: height };
const part = { name: 'arm', rect, x: 0, y: height / 2, ...coverRigPart(image, rect), weights: [] };
rig.parts.push(part);
autoWeightPart(rig, part);

const mesh = assets.createMesh(bakeRig(rig));
const { bones } = spawnRig(world, rig, { mesh, texture });
world.insert(bones[1], IK2D, { target, chainLength: 2, bend: 1, weight: 1, matchTargetRotation: false, enabled: true });
```

| 函数 | 说明 |
|---|---|
| `createRig(texture, width, height, unitsPerPixel?)` | 为一张图像创建空的 `RigSource`。 |
| `rigImageFromRGBA(width, height, rgba)` | 包装 RGBA 像素，供网格函数使用。 |
| `coverRigPart(image, rect, opts?)` | 在部件的不透明像素上生成网格（`vertices`、`triangles`）。 |
| `autoWeightPart(rig, part, opts?)` | 把部件的顶点绑定到最近的骨骼。 |
| `bakeRig(rig)` | 生成蒙皮网格数据。 |
| `spawnRig(world, rig, { mesh, texture, … })` | 生成根实体（带 `MeshRenderer`、`MeshSkin`，有变形时还带 `MeshMorph`）以及每根骨骼一个实体；返回 `{ root, bones }`，`bones` 按骨骼索引排序。 |

## 限制

- 一个 2D 骨骼是一个网格，一次绘制调用，最多 256 根骨骼。每个顶点最多受 4 根骨骼影响。
- 同一骨骼的部件按设定顺序绘制。与场景其余部分之间，骨骼先按 `MeshRenderer.layer` 再按 Z 排序，与普通网格相同。
- 选中 2D 骨骼的轮廓显示其绑定姿势，而非当前姿势。
