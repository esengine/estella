**弹簧骨骼**为骨架添加次级运动：头发、尾巴、围巾与绳索滞后于身体、摆动并静止下来，无需编写动画。骨骼链**根部**上的 `SpringBone`
使其下的每个实体都成为弹簧：动画仍决定每根骨骼本应所在的位置，骨骼链因惯性滞后于该姿势、受重力下落，并被拉回该姿势。根骨骼本身不参与模拟；它由动画或身体驱动。

弹簧骨骼属于引擎核心，以 C++ 运行，在所有目标上开销相同，包括没有 JIT 的目标。

## `SpringBone` 组件

将 `SpringBone` 添加到骨骼链最上方的骨骼，例如一缕头发的第一根骨骼（其父骨骼是身体，其子骨骼是发束）。其下沿所有分支的每个实体都参与模拟。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | boolean | `true` | 关闭时骨骼链完全保持动画给出的姿势。 |
| `stiffness` | number | `0.1` | 以 60 Hz 计每帧把骨骼拉回动画姿势的力度，0 到 1。0 为自由悬垂；1 完全跟随动画。 |
| `drag` | number | `0.5` | 骨骼每帧损失的速度比例，0 到 1。值越大静止越快；默认值的阻尼足以避免振荡。 |
| `gravity` | vec3 | `(0, -980, 0)` | 单位为世界单位每二次方秒；世界 Y 轴向上。默认值假定 1 米为 100 个单位。 |
| `wind` | vec3 | `(0, 0, 0)` | 作用于骨骼链的恒定风加速度，世界单位每二次方秒。为零表示无风。 |
| `windGust` | number | `0` | 阵风幅度，0 到 1。0 为恒定风；1 使风力在无风与两倍强度之间变化。每根骨骼比上一根稍晚遇到阵风，因此发束呈波浪状摆动。 |
| `windFrequency` | number | `0.5` | 每秒阵风次数。 |
| `endLength` | number | `0` | 在每根末端骨骼之后添加的尖端长度（世界单位）；末端骨骼没有可指向的子骨骼。为 0 时末端骨骼不参与模拟。 |
| `radius` | number | `0` | 发束的粗细（世界单位），与碰撞体保持该距离。 |
| `weight` | number | `1` | 从仅动画（0）到完整模拟（1）的混合。 |
| `colliders` | 实体列表 | 空 | 骨骼链需避开的、带 `SpringBoneCollider` 的实体。 |

### `SpringBoneCollider`

列出它的骨骼链需避开的球体或胶囊体，由其实体的变换定位。将碰撞体放在头部与肩部骨骼上，使头发不会穿过身体。

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `shape` | `SpringBoneShape` | `Sphere` | `Sphere`，或沿实体局部 Y 轴的 `Capsule`。 |
| `radius` | number | `10` | 半径，世界单位，未计实体缩放。 |
| `height` | number | `20` | 仅胶囊体：两端球心之间的距离，世界单位，未计缩放。 |
| `offset` | vec3 | `(0, 0, 0)` | 形状中心在实体局部空间中的位置。 |

## 从模型生成骨骼链

将模型的 **Spring Bones** 导入设置设为 **From File Data and Names** 后，导入器根据文件中的数据构建骨骼链与碰撞体。按以下顺序读取：

1. **`VRMC_springBone`**（VRM 1.0 扩展）：弹簧、碰撞体与碰撞体组及其数值。一个弹簧在其第一个关节上生成 `SpringBone`（该骨骼固定，其下的骨骼运动）。其刚度（VRM
   中以每秒计）与重力强度被换算为引擎的每帧单位与加速度单位。指名关节少于两个的弹簧，或会移动未指名骨骼的弹簧，会在导入警告中报告。
2. **节点属性**：链根上的 `extras.estella.springBone`（`stiffness`、`drag`、`gravity`、`radius`、`endLength`），以及碰撞体节点上的
   `extras.estella.springCollider`（`shape`、`radius`、`height`、`offset`）。Blender 自定义属性通过这种方式以精确数值传入引擎。同一节点上它们优先于 VRM 数据。
3. **名称**，用于以上未规定的部分：

| 名称 | 结果 |
| --- | --- |
| `Hair_<region>_<chain>_00`（其下有骨骼） | 该骨骼上的 `SpringBone`；发束为其下的骨骼。 |
| `SBC_Sphere_<name>_r<cm>` | 球形 `SpringBoneCollider`；半径以厘米计。 |
| `SBC_Capsule_<name>_r<cm>_h<cm>` | 沿节点局部 +Y 的胶囊体；半径与两端球心距离以厘米计。 |

- 区域名（`Ponytail`、`Temple_L`、`Fringe`、`Crest`、`Crown`）决定初始刚度与阻尼：刘海贴近头部，马尾摆动。
- 每条骨骼链都避开模型中的所有碰撞体。
- 尺寸以模型的米为单位并随导入缩放变化；重力为以该单位表示的地球重力。
- 长度为零的胶囊体，或其下没有骨骼的链根，会被跳过。
- 基于名称的骨骼链只是约定；应在细节面板中检查结果并在那里调整。

## 编辑器

### 细节面板

`SpringBone` 的字段分为 **Motion**（stiffness、drag、gravity）、**Wind**（wind、gust、frequency）、**Chain**（end length、radius、weight）与
**Collision**（colliders）几组。第一行报告实体下的骨骼数与末端尖端数；若实体没有子骨骼、不模拟任何内容，则以警告色提示。

### 视口 gizmo

仅为选中对象绘制，归于 Gizmo 菜单中的 **Spring bones** 项：

| 选中对象 | 绘制内容 |
|---|---|
| 链根 | 以琥珀色线条绘制动画姿势下的骨骼；每个关节处绘制宽度为 `radius` 的圆环（为 0 时为圆点）；`endLength` 添加的尖端；以碰撞体绿色绘制每个列出的碰撞体的线框球体或胶囊体。 |
| `SpringBoneCollider` | 其形状及六个方形尺寸手柄。球体上六个手柄都设置半径；胶囊体上围绕中部的四个设置半径，两端的两个设置高度。远侧的手柄淡化显示。 |

拖动手柄为一个撤销步骤，并在指针旁显示数值；Preview FX 打开时骨骼链实时跟随。手柄只调整碰撞体尺寸，不改变其位置；`offset` 在细节面板中输入，或通过移动实体设置。

### 预览

**View → Preview FX**（新编辑器中默认打开；与粒子和拖尾使用同一开关）在编辑视口中运行骨骼链：移动头部或修改字段会使头发摆动。打开时，模拟的骨骼链以实线绘制在以虚线绘制的动画姿势之上。关闭后模拟结束，骨骼恢复为场景中保存的状态。编辑器的模拟从不写入场景文件。

## 逐帧求解

动画先运行并写入骨骼的局部旋转。然后对每条骨骼链：

1. 从根部沿链向下，用动画的旋转计算动画姿势。上一帧被本系统旋转、本帧没有动画写入的骨骼，按动画给出的值读取，而非按系统留下的值读取，因此骨骼链不会朝自己上一帧的结果回弹。
2. 骨骼链朝该姿势推进一步。每根骨骼保留扣除阻尼后的速度、受重力下落、被拉向其姿势、恢复到与父骨骼的长度（先处理父骨骼，因此骨骼不会被拉长），并被推出碰撞体。时间步被细分为最长一个 60 Hz 帧的子步。
3. 每根骨骼旋转以指向其子骨骼的新位置。**只写入旋转**；骨骼位置从不改变，因此骨骼不会脱离父骨骼，蒙皮也无需其他数据。

### 重置

| 条件 | 结果 |
|---|---|
| 根部在一帧内移动超过骨骼链长度的数倍 | 骨骼链重置为其姿势。 |
| 停顿半秒或更久 | 骨骼链重置为其姿势。 |
| 组件被禁用或移除 | 骨骼恢复为动画姿势。 |
| `SpringBoneRes.reset(root)` | 显式重置，例如瞬移之后。 |

通过 `app.getResource(SpringBoneRes)` 读取 `SpringBoneRes`。

## 开销

求解器对每根骨骼只需若干次算术运算。在编辑器的运行环境中以 WebAssembly 引擎测量：**300 条六骨骼的骨骼链（2100 个节点）每次更新耗时 0.28 ms。**
该测量为编辑器检查 `springbone`；`test_springbone` 是求解器与系统的 C++ 单元测试。

## 限制

- 有多个子骨骼的骨骼指向其第一个子骨骼；其他子骨骼作为子节点跟随，并各自指向自己的子骨骼。
- 缩放取自骨骼的组合缩放；不模拟链上的非均匀缩放。
- 碰撞仅为骨骼对球体或胶囊体：没有发束间碰撞、自碰撞，也不与物理形状碰撞。
- 风是每条骨骼链上的字段，而非场景中的力；没有供所有骨骼链共享的场景级风源。
- 导入器根据名称与文件数据构建骨骼链，而非根据网格形状；没有 `Hair_` 骨骼（也没有 VRM 或 `extras` 数据）的发束不会获得运动。
