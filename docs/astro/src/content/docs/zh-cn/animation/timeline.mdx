时间轴是一段 **Sequencer 动画**——随时间排布的关键帧轨道,可以移动 Transform、切换精灵、
触发音频、开关实体或驱动 Spine。你在编辑器的 Sequencer 里编辑它,用 `TimelinePlayer` 组件
附加,并通过 `Timeline` 资源控制播放。因为一条时间轴能同时驱动很多东西,它是过场与脚本化
序列的工具。

## 附加时间轴

`TimelinePlayer` 组件把实体指向一个时间轴资源。通常在编辑器里设;用代码则以 `Commands` 插入:

```typescript
import { defineSystem, Commands, TimelinePlayer } from 'esengine';

const attach = defineSystem([Commands()], (cmds) => {
  cmds.spawn().insert(TimelinePlayer, {
    timeline: 'assets/timelines/intro.estimeline',
    playing: true,
    speed: 1.0,
    wrapMode: 'once',
  });
});
```

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `timeline` | asset | `''` | 时间轴资源(`.estimeline`)。 |
| `playing` | boolean | `false` | 播放旗标——拉起播放,放下暂停。对已播完的片段拉起 = 从头重播。 |
| `speed` | number | `1` | 播放速率倍率。 |
| `wrapMode` | string | `''` | 覆盖片段自带的循环模式:`'once'`、`'loop'` 或 `'pingPong'`(驼峰写法)。留空——以及任何其它字符串,那算笔误——则沿用片段自己声明的模式。 |
| `finished` | boolean | `false` | `'once'` 片段播完时闩为 true;下次播放时清除。运行时只读。 |

组件旗标**就是**播放控制本身:引擎每帧把它们调和进内部时钟,所以任何翻动
`playing` 的一方——你的代码、检视器、[AI 动作](/docs/zh-cn/gameplay/ai/overview/#内建名字)——
都经同一条通道驱动片段。

## 控制播放

读 `Timeline` 资源来驱动某个实体的时间轴:

```typescript
import { defineSystem, Query, Res, TimelinePlayer, Timeline } from 'esengine';

const control = defineSystem([Query(TimelinePlayer), Res(Timeline)], (q, timeline) => {
  for (const [entity] of q) {
    timeline.play(entity);
    timeline.pause(entity);
    timeline.stop(entity);
    timeline.setTime(entity, 1.5);                  // seek to 1.5s
    const t = timeline.getCurrentTime(entity);
    const playing = timeline.isPlaying(entity);
  }
});
```

| 方法 | 说明 |
|---|---|
| `play(entity)` | 开始或恢复播放(已播完的片段从头重播)。 |
| `pause(entity)` | 暂停,保留当前时间。 |
| `stop(entity)` | 停止、重置到开头并清除 `finished` 闩。 |
| `setTime(entity, seconds)` | 定位到某时间(scrub 所有轨道)。 |
| `getCurrentTime(entity)` | 当前播放头时间(秒)。 |
| `isPlaying(entity)` | 是否正在播放。 |

这些方法写穿到 `TimelinePlayer` 的旗标——`timeline.play(e)` 和 `player.playing = true`
是同一条通道上的同一个操作。

<Aside type="tip">
  想做**零代码过场**,把组件和状态机配对:内建的 `timeline.play` 动作 +
  `timeline.finished` 条件就是一个"进入即播放、播完即转出"的 FSM 状态。见
  [AI——内建名字](/docs/zh-cn/gameplay/ai/overview/#内建名字)。
</Aside>

### 播放范围、真实时间与播放事件

`TimelinePlayer` 可以只播放时间轴的一段,对应 UE 的播放范围:从 `rangeStart` 秒到 `rangeEnd` 秒(`0` 表示时间轴结尾)。它从
范围开头开始播放,单次播放的时间轴在范围结尾结束,循环的时间轴在范围内循环。`unscaledTime` 让播放器按真实时间运行,
所以游戏用 `Time.scale` 为 0 暂停时,过场或菜单动画仍会继续播放(对应 Unity 的 Unscaled Game Time)。

播放器的动作作为 `TimelinePlayback` 事件发出,下一帧读到,对应 Unity PlayableDirector 的 played、paused、stopped 事件和
UE 的 OnPlay、OnPause、OnStop、OnFinished:

```typescript
import { defineSystem, EventReader, TimelinePlayback } from 'esengine';

const onCutscene = defineSystem([EventReader(TimelinePlayback)], (events) => {
  for (const e of events) if (e.kind === 'finished') giveControlBack(e.player);
});
```

| `kind` | 时机 |
|---|---|
| `played` | 播放器开始播放,或从暂停恢复。 |
| `paused` | 停在原处(`Timeline.pause`,或把 `playing` 关掉)。 |
| `stopped` | 停止并回到开头(`Timeline.stop`)。 |
| `finished` | 单次播放的时间轴到达结尾(或范围结尾)。 |
| `looped` | 循环或往返的时间轴转回一圈。 |

## 轨道类型

时间轴是一组每帧一起求值的轨道:

| 轨道 | `TrackType` | 驱动 |
|---|---|---|
| 属性 | `Property` | 组件字段关键帧——位置 / 旋转 / 缩放及任意数值点路径。 |
| 精灵帧 | `AnimFrames` | 随时间切换精灵表帧。 |
| 精灵剪辑 | `SpriteAnim` | 在某时刻启动一个命名 `anim-clip`。 |
| 音频 | `Audio` | 声音:瞬间条目触发一次完整声音;有长度的片段在其区间内播放([见下文](#音频片段))。 |
| 激活 | `Activation` | 按区间开关实体,连同其子对象;UI 节点写 `UINode.display`([见下文](#激活区间))。 |
| Spine | `Spine` | 把 Spine 动画作为片段播放。 |
| 标记 | `Marker` | 命名时间标记,播放头经过时作为 `TimelineEvent` 发给游戏。 |
| 自定义事件 | `CustomEvent` | 带 payload(及可选持续窗口)的命名事件,作为 `TimelineEvent` 发出([见下文](#事件与标记))。 |
| 相机 | `Camera` | 逐镜头决定哪台相机是当前视图([见下文](#相机与子序列))。 |
| 子序列 | `Sequence` | 在本时间轴的一个时间窗里播放另一条时间轴。 |
| 动画 | `Animation` | 在角色骨骼上播放骨骼动画片段,带淡入淡出并与其自身动画交叉混合([见下文](#动画轨道))。 |

### 淡入淡出与时间缩放

UE 的 Fade 和 Time Dilation 轨道在这里是两个组件,由时间轴用普通属性轨道打关键帧,所以脚本也可以直接使用。Sequencer 的
**Track → 淡入淡出** 和 **Track → 时间缩放** 会在根实体上添加对应组件(没有时),并新建一条在播放头处带关键帧的轨道。

| 组件 | 字段 | 说明 |
|---|---|---|
| `ScreenFade` | `amount` | 屏幕淡出的程度,0(清晰)到 1(完全是该颜色)。取最强的一个绘制在所有内容之上(2D 和 3D 都一样),用一个位于游戏 UI 之上的独立 UI 画布,且不会拦截指针。 |
| | `color` | 淡出到的颜色。 |
| `TimeDilation` | `scale` | 生效期间游戏运行的快慢:0.25 为慢动作。多个会相乘,并且与游戏自己的 `Time.scale` 相乘,所以游戏暂停(0)时仍保持暂停,时间缩放结束后恢复游戏原本的速度。 |

两者都在运行时生效;Sequencer 预览只显示关键帧的数值,不显示淡出效果和变慢的时钟。

### 音频片段

音频轨道的条目在没有长度时是一个**瞬间**:播放头经过它的时刻时,把整段声音播放一次。给它设置 `duration` 就成了**片段**,
和 Unity Timeline、UE Sequencer 一样:只在播放头处于片段内时发声,从声音的 `clipIn` 秒处开始,在 `fadeIn` 内渐强、在 `fadeOut`
内渐弱,`loop` 时重复以填满片段。时间轴暂停时它也暂停;播放头跳进片段中间(跳转、循环回头)时从播放头所在位置开始播放,
所以听到的是一句台词剩下的部分而不是从头开始;到片段结束时停止。Sequencer 把片段画成条,渐强渐弱画成两端的斜坡,播放时
会播放这些片段,拖动播放头时也会播放所在位置的一小段。

```json
{ "type": "audio", "childPath": "", "events": [
  { "time": 1, "clip": "@uuid:…", "volume": 0.8, "duration": 4, "clipIn": 0.5, "fadeIn": 0.5, "fadeOut": 1 }
] }
```

### 动画轨道

动画轨道在一个角色骨骼上播放骨骼动画,对应 Unity 的 Animation Track 和 UE 的 Skeletal Animation 轨道。每个片段在轨道
对应的实体上播放一段动画(一个由关节曲线组成的 `.estimeline`,导入模型时就会写出这种文件):

| 片段字段 | 默认值 | 说明 |
|---|---|---|
| `clip` | `''` | 播放的动画(资源引用)。 |
| `start` / `duration` | | 在轨道上的位置(秒)。 |
| `clipIn` | `0` | 从动画的第几秒开始播放。 |
| `speed` | `1` | 播放速度。 |
| `loop` | `false` | 重复动画来填满片段,而不是停在最后一帧。 |
| `easeIn` / `easeOut` | `0` | 从角色自身动画混合进来、以及混合回去所需秒数。 |

两个片段重叠时,重叠部分就是交叉淡化:前一个淡出、后一个淡入。片段淡入淡出时,与角色自身的姿势混合:有 `Animator` 时是
它这一帧给出的姿势(时间轴在 Animator 之后运行,所以满权重时由轨道决定姿势),否则是角色的静止姿势。片段之间角色交还给
它自己;把轨道的 `hold` 打开,最后一个片段结束后会保持它的最终姿势。Sequencer 在条的两端用斜坡画出淡入淡出,用斜线
标出重叠的交叉淡化,预览也会播放混合效果。

### 激活区间

激活轨道说的是*这个子对象在这些区间里是开着的*——宝箱就是这么开的(关着的图在某一刻
交给开着的图,连同它的辉光一起),徽章就是这么在一段华彩末尾冒出来的,任何双态控件的
动画都是这么做的。

它写什么,取决于目标是什么:

- **实体**被整个开关,和 Unity 的 Activation Track 设置 GameObject active 一样:它下面的一切
  一起开关(角色和它的剑、灯和它的光),关掉的实体退出所有查询,而不只是不画。渲染器自己的
  `enabled` 保持作者设的值。
- **UI 节点**写的是 `UINode.display`。UI 节点的显示/隐藏是 `display`,它同样**会把整棵子树
  一起带走**。

两种情况下都只在状态真的翻转时才写,所以一条不动的轨道不会每帧把变更检测弄脏。

### 绑定

轨道按播放该时间轴的实体之下的路径找到目标。以 `@Name` 开头的路径改为经过一个**绑定**:正在播放的 `TimelinePlayer`
把 `Name` 绑定到的实体(可以是场景里的任意实体),路径的其余部分在它之下(`@Hero/Arm`)。这对应 Unity 的
PlayableDirector 绑定和 UE 的 possessable:过场可以移动不是它子对象的东西,同一条时间轴由两个播放器播放时可以驱动两个
不同的角色。

| `TimelinePlayer` 字段 | 说明 |
|---|---|
| `bindingNames` | 播放器各个绑定的名字。 |
| `bindings` | 每个名字绑定到的实体,顺序相同;和其他实体引用一样会映射到加载后的实体。 |

在 Sequencer 里,**Track → (类型) → 绑定的实体…** 列出根实体之外的场景实体,选中一个就新建一条绑定到它的轨道:播放器
增加这个绑定(该实体已有绑定则复用),轨道路径变成 `@Name`,整个操作是一步撤销。播放器的 Details 按名字列出各个绑定,
可以逐个改绑实体。每种轨道都可以绑定,绑定路径在预览、运行和子序列里都有效;播放器没有的绑定解析为空,对应轨道不起作用。

### 事件与标记

事件轨道和标记轨道告诉游戏时间轴正在做什么,对应 Unity 的 Signal 和 UE 的事件轨道。播放头经过的每一个
都作为 `TimelineEvent` 发出,并带上它所在轨道对应的实体;系统在下一帧读到:

```typescript
import { defineSystem, EventReader, TimelineEvent } from 'esengine';

const onCue = defineSystem([EventReader(TimelineEvent)], (events) => {
  for (const e of events) {
    if (e.name === 'door-open') openDoor(e.target);
    if (e.kind === 'event') console.log(e.payload);   // 标记的 payload 为空
  }
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `kind` | `'event'` \| `'marker'` | 事件轨道的条目,或标记。 |
| `name` | string | 作者写的名字。 |
| `payload` | object | 事件的数据;标记为空。 |
| `time` | number | 在时间轴里的位置(秒)。 |
| `player` | Entity | 播放这条时间轴的实体。 |
| `target` | Entity | 轨道对应的实体(根上的轨道为播放者本身)。 |

每趟只发一次;循环时下一圈再发。带持续窗口(`duration`)的事件,还会在这段时间里对播放该时间轴的
Animator 状态报告为打开。

## 在 Sequencer 里创作

双击一个 `.estimeline`(或打开选中实体的时间轴),就在 **Sequencer**(关键帧动画编辑器)里
创作它。**摊开表(dope sheet)**把每条轨道及其关键帧沿一条共享、可拖动的播放头排开;加轨道、
拖关键帧,然后 **Save**。

![Sequencer 摊开表——一段过场时间轴的轨道与关键帧](@/assets/guides/zh/seq-dopesheet.png)

*摊开表:一轨一行(这里是某 Transform 的 `position.x` / `position.y`,加两条黑边激活轨道),关键帧是菱形,播放头可拖动,顶部是走带控制。*

切到 **Curves** 标签可塑形关键帧之间的插值——拖动值曲线及其切线手柄,做出摊开表表达不了的缓动:

![Sequencer 曲线编辑器——带切线手柄的值曲线](@/assets/guides/zh/seq-curves.png)

*曲线编辑器:每个关键帧通道变成一条可编辑曲线(这里 `position.x` 缓入、`position.y` 起伏),每个关键帧带切线手柄。*

### 实体上的轨道

Sequencer 头部的 **Track** 可以添加运行时能播的任何轨道:先选类型(激活、Spine 动画、序列帧动画、
音频、粒子、标记、事件),再选它对应的根下实体,或根本身。轨道放在该实体那一行下面,第一个条目在
播放头处。区间(激活区间、Spine 动画、带窗口的事件)是条,拖动主体移动、拖动边缘改长度;瞬间
(声音、粒子动作、标记、事件)是图钉,拖动改时间。行上的 **+** 在播放头处再加一个,选中的条目在
Details 里编辑:声音资源和音量、粒子动作、Spine 动画名/循环/速度、事件名/窗口/附带数据。Delete 删除;
每次编辑都是一步撤销。

### 静音、锁定与分组

每条轨道行都有**静音**(眼睛图标)和**锁定**,和 Unity Timeline、UE Sequencer 一样,都随时间轴保存。静音的轨道或
静音的属性通道,在时间轴播放的任何地方都被跳过:游戏里、播放它的 Animator 状态里、子序列里,以及 Sequencer 的预览里。
锁定的轨道在解锁前不能编辑;它的条目仍可选中查看,也仍可静音。右键轨道打开菜单:静音、锁定、**移到分组**(放进已有分组
或新建一个)、重命名、删除。分组(Unity 的 Track Group)可以像其他行一样折叠;双击分组名或轨道名可重命名。文件里它们是
轨道上的 `muted`、`locked`、`group` 和通道上的 `muted`,只在设置时写入。

### 相机与子序列

**相机轨道(镜头轨道)**存放镜头:每根条就是一台相机,在它的区间内充当视图。首尾相接的条是硬切;
把一根条拖到与前一根重叠,重叠部分就成了混合,由后一个镜头的混合曲线塑形。没有镜头的区间会把视图
还给场景自己的相机。每条时间轴只有一条相机轨道,它的相机必须位于时间轴根之下(每条轨道都是从该根
出发按名字路径找到目标的)。

**子序列轨道**在本时间轴的一个时间窗里,用它自己的时钟播放另一个 `.estimeline`:`speed` 缩放它,
`loop` 让它重复以填满整根条,而不是停在最后一帧。**绑定到**用来选嵌套时间轴的名字路径从哪个节点
开始,所以同一段问候序列可以在不同角色身上播放。一条时间轴不能播放自己,无论直接还是经由另一条;
嵌套最多四层;编辑器会拒绝这些选择,已加载的游戏则跳过它们并给出警告。

拖动预览时,切换画面显示在视口的相机预览窗里。拖动、跳转或倒放都是安全的:当前显示哪个镜头、
嵌套时间轴的哪一帧,只取决于时间本身。嵌套时间轴里的事件和其他事件一样,只在正向播放时触发。

### 预览动的是什么

在 Sequencer 里拖播放头或按播放,动的是**活的视口**,不是另开一个预览窗——采样出的姿态写进当前
打开的文档,一旦解绑、关闭或进入 Play 就立刻还原,所以它永远不会漏进存下来的场景。

它只动一个实体:**预览根**,名字就写在 Sequencer 头部那个链接按钮上。这个根是**推导出来的、不用你
指定**——谁的 `TimelinePlayer` 在播这条时间轴,它就是根,所以从内容浏览器双击一个 clip 就会绑到真正
播它的那个东西上。选中特效**内部**的某个节点也照样预览整个特效(会往上找根);同一条时间轴被多个实体
播时,头部会写明有几个、预览的是所选那个。要是哪儿都没有播它的实体、又没选中任何东西,那就没什么可动
的:按钮显示 **未绑定**,点它会绑到你当前的选择——这正是给一个还没播它的实体新建 clip 的做法。

## 用代码构建时间轴

`.estimeline` 文档就是普通数据——用 `TimelineAsset` 类型加上 `TrackType` /
`InterpType` / `WrapMode` 常量,可以完全在代码里构建。注册到 `Timeline` 资源上之后,
任何 `timeline` 指向该名字的 `TimelinePlayer` 都会像播放编辑器资产一样播放它——
代码注册的名字优先于同名的 `.estimeline` 资产:

```typescript
import {
  defineSystem, Commands, Res, Timeline, TimelinePlayer,
  TrackType, InterpType, WrapMode, type TimelineAsset,
} from 'esengine';

const slideIn: TimelineAsset = {
  version: '1.3',
  type: 'timeline',
  duration: 2,
  wrapMode: WrapMode.Once,
  tracks: [{
    type: TrackType.Property,
    name: 'Slide in',
    childPath: '',                       // '' = the player entity itself
    component: 'Transform',
    channels: [{
      property: 'position.x',
      keyframes: [
        { time: 0, value: -200, inTangent: 0, outTangent: 0, interpolation: InterpType.EaseOut },
        { time: 2, value: 0, inTangent: 0, outTangent: 0 },
      ],
    }],
  }],
};

const attach = defineSystem([Commands(), Res(Timeline)], (cmds, timeline) => {
  timeline.registerAsset('code/slide-in', slideIn);
  cmds.spawn().insert(TimelinePlayer, {
    timeline: 'code/slide-in',
    playing: true,
    wrapMode: 'once',
  });
});
```

`Keyframe` 是 `{ time, value, inTangent, outTangent, interpolation? }`。以某
关键帧*起始*的分段用该关键帧的 `interpolation`:`Hermite`(默认——切线驱动曲线)、
`Linear`、`Step`、`EaseIn`、`EaseOut` 或 `EaseInOut`。属性轨道按 `childPath`
解析目标实体(子实体名以 `/` 分隔;空 = 播放器实体本身),把通道的点路径字段写到
命名组件上。

### 循环模式

片段自己声明数值型 `WrapMode`(在资产和纯求值 API 里);**播放器组件**的 `wrapMode` 字符串只要指了名,
就覆盖它。映射与行为:

| `WrapMode` | 播放器字符串 | 越过终点后的行为 |
|---|---|---|
| `WrapMode.Once`(`0`) | `'once'` | 停在 `duration`,停止,闩上 `finished`。 |
| `WrapMode.Loop`(`1`) | `'loop'` | 回绕(`time % duration`)。 |
| `WrapMode.PingPong`(`2`) | `'pingPong'` | 每周期先正放再倒放。 |

`applyWrapMode(time, duration, mode)` 就是这个纯映射——对绝对时钟时间返回
`{ time, stopped }`。

### 采样与序列化

求值器是纯 TypeScript,播放与编辑器 scrub 共用——你也可以自己调用:

| 函数 | 说明 |
|---|---|
| `sampleTimelineInWorld(asset, time, world, rootEntity, opts?)` | 在 `time` 求值所有属性轨道并把结果写进 world(即 scrub 操作)。 |
| `sampleTimeline(asset, time, rootEntity, deps, opts?)` | 同上,但注入 `SampleDeps`(world / 组件查找 / 子实体解析)——用于测试和工具。 |
| `evaluateChannel(channel, time)` | 单个属性通道在 `time` 的值;端点截断。 |
| `serializeTimelineAsset(asset)` | 资产转为可 JSON 化对象(`.estimeline` 文档形状)。 |
| `serializeTimelineToJson(asset, indent?)` | 美化打印的 `.estimeline` JSON 字符串(indent 默认 `2`)。 |

采样只覆盖属性轨道;事件型轨道(音频、标记、自定义事件)在播放中按边沿检测触发,
采样不会触发它们。

## 在包里

时间轴是可选模块:场景里有 `TimelinePlayer`、内容里有 `.estimeline`,或脚本导入了 `esengine/timeline`,包里才会带上运行时和加载器;三者都没有的游戏两样都不带。

## 最佳实践

- **在 Sequencer 里编辑**——时间轴资源持有轨道,代码只负责播放与定位。
- 过场用 **`wrapMode: 'once'`**,环境/待机序列用 `'loop'`。
- **用 `setTime` scrub** 来预览,或把过场与玩法状态同步。
- 当很多属性/实体需要同步动画时**用时间轴(而非补间)**;一次性的单属性手感用
  [补间](/docs/zh-cn/animation/overview/)。

<Aside type="note">
  时间轴播放属于玩法——它在播放模式和独立运行时里推进,在编辑器编辑模式下冻结。
</Aside>
