**序列器（Sequencer）**用于编辑 `.estimeline` 资源。用**添加 → 新建动画**创建时间轴、双击 `.estimeline`，或从左侧工具栏的**面板 → 序列器**均可打开序列器。

## 为属性设置关键帧

以下步骤使 `Hero` 等精灵沿 X 轴在一秒内从当前位置移动到 120。同样的步骤适用于 3D 物体。

<Steps>

1. **新建时间轴。** 在内容浏览器中进入目标文件夹，选择**添加 → 新建动画**。编辑器创建 `NewAnimation.estimeline` 并在序列器中打开。空白序列器面板中的**新建动画**按钮作用相同。

   ![空白序列器中的“新建动画”按钮](@/assets/guides/zh/seq-first-new.png)

2. **绑定实体并添加通道。** 在**世界大纲**中选中实体。序列器左上角的链接按钮显示其名称；若显示**未绑定**，点击该按钮。点击**跳到开头**，将播放头置于第 0 帧。打开 **＋ 轨道**，滚动到**属性（来自绑定的实体）**，选择 `Transform` 下的 `position.x`。摄影表添加该通道，并在实体当前 X 坐标处放置第一个关键帧。

   ![轨道菜单的属性区，已指向 Transform 的 position.x](@/assets/guides/zh/seq-first-track.png)

3. **添加结束关键帧。** 点击标尺上的 **1.00 s**（默认 12 fps 下为第 12 帧）。将鼠标移到 `position.x` 行，点击其菱形按钮**在播放头处打关键帧**。点击轨道上的新关键帧，在**细节 → 值**中输入 `120` 并按回车。摄影表底部显示 **2 个关键帧**。

   ![第 12 帧选中了第二个关键帧，细节面板的值为 120，左下角显示 2 个关键帧](@/assets/guides/zh/seq-first-keys.png)

4. **预览并保存。** 在第 0 帧与第 12 帧之间拖动播放头，或点击播放三角按钮，在视口中查看实体移动。点击序列器右上角的**保存**写入 `.estimeline`。

</Steps>

要在游戏中播放该时间轴，在同一实体上添加 **Timeline Player**（**细节 → 添加组件**，搜索 `TimelinePlayer`），将保存的 `.estimeline` 指定给 **Timeline**，勾选 **Playing**，保存场景并点击播放。若剪辑在序列器中可以预览而游戏中不播放，检查播放器所在的实体及其引用的文件。

### 录制

绑定实体后，将播放头移到某一时间，点击链接按钮旁的红色录制按钮。此时用移动工具移动实体，或在**细节**中编辑其字段，会在播放头处为**绑定实体已有的属性通道**设置关键帧。再次点击录制按钮停止。录制同时会修改实体的场景值；在**细节**中编辑关键帧的值则不改变场景值。

## 音频条目

1. 将播放头置于声音开始的位置。
2. 选择 **＋ 轨道 → 音频**，选择**（时间轴根实体）**或其子孙实体。序列器在播放头处创建并选中一个音频条目；**未选声音**表示尚未指定文件。若细节显示的是轨道设置，点击轨道上该条目的菱形。
3. 在**细节 → 音频 → 声音**中点击 **None ▾**，选择音频文件。点击**保存**。

   ![声音选择器，声音栏下方列出了项目中的 Bell.wav 和 Intro.mp3](@/assets/guides/zh/seq-sound-picker.png)

**时长**为 `0` 的条目是一次性音效：正在播放的时间轴经过它时完整播放一次，运行场景时可听到。**时长**为正数的条目是剪辑，显示为一段条，在序列器播放时可听到（[音频轨道](/docs/zh-cn/animation/timeline/tracks/#音频轨道)）。

**＋ 轨道**的目标子菜单可用键盘操作：↑ 和 ↓ 选择条目，→ 展开，回车选定实体。

## 摄影表与曲线

`cutscene` 示例中的 `assets/timelines/intro.estimeline` 可同时展示两种视图。**摄影表**左侧列出轨道和当前值，右侧为帧标尺；沿标尺拖动播放头即可逐帧查看。关键帧的形状表示插值方式（`Hero` 位置通道上的圆点和菱形）。激活区间显示为条（下方两条黑边区间）。

![过场示例的摄影表，Hero 的位置关键帧与两条持续三秒的黑边激活区间](@/assets/guides/zh/seq-dopesheet.png)

**曲线**将每个通道显示为曲线。选中关键帧后显示两侧的切线手柄。拖动关键帧可修改其时间和值；拖动手柄可修改该关键帧处的斜率。

![选中角色高度曲线上的关键帧，显示帧号、数值和两侧的切线手柄](@/assets/guides/zh/seq-curves.png)

## 缩放与标记

在轨道区域按 **Ctrl+滚轮**以指针为中心缩放时间轴，指针下的时间保持不变；缩放时标尺显示更细的刻度。缩放后轨道可横向滚动，播放时视图跟随播放头。**适应**显示整条时间轴。标记轨道上的每个标记按名称显示在标尺上；点击标记即可将播放头移到该处。

## 多选与批量编辑

在轨道空白处拖动会绘制选框，选中框内触及的关键帧和片段。按住 **Shift** 或 **Ctrl** 可追加选择，点击单个条目时同样适用。拖动任一选中项会将所有选中的关键帧和片段跨轨道一起移动，记为一步撤销；锁定轨道上的条目不移动。点击选择中的某一项会只选中该项。

| 按键 | 作用 |
| --- | --- |
| **Ctrl+C** / **Ctrl+X** | 复制 / 剪切所选内容。 |
| **Ctrl+V** | 在播放头处粘贴，保持布局，粘贴回原来的轨道和通道。 |
| **Ctrl+D** | 在所选内容之后紧接着复制一份。 |
| **S** | 拆分每个包含播放头的选中片段。后半段从前半段停止处继续（动画或声音的起始偏移按切去的时长后移）；切口为硬边，没有缓入缓出或淡入淡出。 |
| **Delete** | 删除所选内容。 |
| **Ctrl+A** | 选中所有关键帧和片段。 |

片段的右键菜单同样提供拆分、复制和粘贴。

## 实体轨道

打开 **＋ 轨道**，选择实体轨道类型，例如音频、激活、动画、生成或相机震动，再选择**（时间轴根实体）**或其子孙实体。第一个条目放在播放头处。拖动片段主体可移动片段，拖动边缘可修改时长；单一时刻的粒子动作、标记或事件可沿轨道拖动。对可容纳多个条目的轨道，行上的 **＋** 在播放头处追加条目。条目字段（声音资源、音量、动画、事件数据）在**细节**中编辑。

**＋ 轨道 → 淡入淡出**与 **＋ 轨道 → 时间缩放**会在根实体没有对应组件时添加 `ScreenFade` 或 `TimeDilation`，并添加一条在播放头处带关键帧的轨道。

## 静音、锁定与分组

每条轨道行都有**静音**开关（眼睛图标）和**锁定**，两者均随时间轴保存。

- 静音的轨道或静音的属性通道，在时间轴播放的任何地方都被排除：游戏中、播放它的动画控制器状态中、子序列中以及序列器预览中。
- 锁定的轨道在解锁前不能编辑；其条目仍可选中，轨道仍可静音。
- 轨道的右键菜单提供静音、锁定、**移到分组**（移入已有分组或新建分组）、重命名和删除。分组可像其他行一样折叠。双击分组名或轨道名可重命名。

在文件中，它们是轨道上的 `muted`、`locked`、`group` 和通道上的 `muted`，仅在设置时写入。

## 预览根实体

链接按钮显示**预览根实体**：轨道名称路径据以解析的实体。轨道可以驱动根实体本身、其子孙实体，以及通过播放器绑定的其他场景实体（[绑定](/docs/zh-cn/animation/timeline/tracks/#绑定)）。

打开时间轴时，序列器先在选中实体或其祖先上查找播放该文件的 `TimelinePlayer`，其次查找场景中第一个匹配的播放器；没有匹配的播放器时使用当前选择。按钮显示**未绑定**时，在世界大纲中选中目标，再点击链接按钮。

拖动播放头时，场景视口显示属性通道的值，视口的相机预览显示镜头，场景视图上显示淡入淡出，同时预览相机震动、动画轨道的混合以及生成的实例。预览不改变场景自身的值。激活区间、精灵剪辑的启动和一次性音效需运行场景检查；时间缩放造成的时钟变慢只在运行时可见。

## 渲染为图片序列或视频

序列器标题栏中的**渲染**将时间轴渲染为图像。对话框设置帧率（24、30 或 60）、格式（**MP4**、**WebM** 或 **PNG 序列**）以及范围（**从**、**到**）。

点击**渲染**时会捕获当前剪辑，包括尚未保存的关键帧。预览根实体的 `TimelinePlayer` 需要绑定到该剪辑。导出使用独立的游戏实例，先截取起始时间的画面，再按所选帧率逐帧推进。试玩运行或暂停时都可以导出。

每次渲染都会在项目的 `renders/` 下创建独立文件夹，图片从 `frame_00000.png` 开始编号。选择视频格式时，编辑器自带的 ffmpeg 会在文件夹旁生成 MP4 或 WebM。点击**取消**会保留已经写入的图片。
## 通过代理编辑

通过 [MCP](/docs/zh-cn/agents/mcp/) 操作编辑器的代理，使用序列器自身的命令编辑时间轴，这些命令位于 `timeline` 工具组：

| 工具 | 作用 |
|---|---|
| `timeline_add_track` | 在实体上添加任意类型的轨道；实体按 id 或其在播放器下的名称路径指定。 |
| `timeline_add_items` | 添加镜头、片段、声音、生成、标记和事件，字段名与文件中保存的一致。 |
| `timeline_set_keys` | 为可动画字段设置关键帧，并创建其属性轨道。 |
| `save_asset_document` | 写入文件。 |

每次调用记为一步撤销。无效名称（轨道没有的字段、不在播放器之下的实体、不可动画的字段）会被拒绝，并给出有效名称。
