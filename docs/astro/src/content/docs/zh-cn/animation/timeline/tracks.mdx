每条轨道用 `childPath` 指定目标实体，即播放该时间轴的实体之下的名称路径（子实体名以 `/` 分隔；为空表示播放器实体本身）。以 `@` 开头的路径经由[绑定](#绑定)解析。轨道的通用字段为 `name`、`childPath`，以及编辑器标志 `muted`、`locked` 与 `group`（[静音、锁定与分组](/docs/zh-cn/animation/timeline/sequencer/#静音锁定与分组)）。

## 属性轨道

属性轨道指定一个 `component` 并包含 `channels`。每个通道按点路径（`position.x`、`color.a`）为一个数值字段设置关键帧，并包含 `keyframes`。可设置关键帧的字段是组件的 `animatableFields`（[组件](/docs/zh-cn/core-concepts/components/)）。

`Keyframe` 为 `{ time, value, inTangent, outTangent, interpolation? }`，切线单位为每秒的数值变化量。以某关键帧起始的分段使用该关键帧的 `interpolation`：

| `InterpType` | 分段形状 |
|---|---|
| `Hermite`（默认） | 由切线决定的曲线。 |
| `Linear` | 到下一关键帧的直线。 |
| `Step` | 保持当前值直到下一关键帧。 |
| `EaseIn` / `EaseOut` / `EaseInOut` | 到下一关键帧的缓动过渡。 |

## 淡入淡出与时间缩放

淡入淡出与时间缩放是两个组件，由时间轴在普通属性轨道上设置关键帧；脚本也可直接设置。**＋ 轨道 → 淡入淡出**与 **＋ 轨道 → 时间缩放**会在根实体没有对应组件时添加组件，并添加一条在播放头处带关键帧的轨道。

| 组件 | 字段 | 说明 |
|---|---|---|
| `ScreenFade` | `amount` | 屏幕淡出程度，从 `0`（清晰）到 `1`（完全为该颜色）。取最强的淡出绘制在所有内容之上（2D 与 3D 均然），使用位于游戏 UI 之上的独立 UI 画布，且不接收指针输入。 |
| | `color` | 淡出到的颜色。 |
| `TimeDilation` | `scale` | 生效期间的游戏速度；`0.25` 为慢动作。多个时间缩放相乘，并与游戏自身的 `Time.scale` 相乘，因此游戏暂停（`0`）时保持暂停，时间缩放结束后恢复游戏自身的速度。 |

两者在运行时生效。序列器预览时间轴时，播放头处的淡出会绘制在场景视图和相机预览上，不改变场景自身的值；时钟变慢只在运行时可见。

## 音频轨道

音频轨道的条目在没有长度时是**瞬间**：播放头经过其时间时完整播放一次声音。设置 `duration` 后成为**片段**，仅在播放头处于其中时发声。

| 条目字段 | 说明 |
|---|---|
| `time` | 开始时间（秒）。 |
| `clip` | 音频资源。 |
| `volume` | 播放音量。 |
| `duration` | 片段长度；缺省或 `0` 为瞬间。 |
| `clipIn` | 片段从声音的第几秒开始。 |
| `fadeIn` / `fadeOut` | 片段开头和结尾的淡入、淡出秒数。 |
| `loop` | 重复声音以填满片段。 |

时间轴暂停时其音频片段也暂停。播放头落入片段中间（跳转或循环）时，从对应位置开始播放，因此听到的是一句台词的剩余部分而不是开头。片段在结束处停止。序列器将片段绘制为条，两端的淡入淡出绘制为斜坡；播放时播放片段，拖动播放头时播放所在位置的一小段。

```json
{ "type": "audio", "childPath": "", "events": [
  { "time": 1, "clip": "@uuid:…", "volume": 0.8, "duration": 4, "clipIn": 0.5, "fadeIn": 0.5, "fadeOut": 1 }
] }
```
## 动画轨道

动画轨道在骨架上播放骨骼动画。每个片段在轨道对应的实体上播放一段动画（由关节曲线组成的 `.estimeline`，导入模型时写出）。

| 片段字段 | 默认值 | 说明 |
|---|---|---|
| `clip` | `''` | 播放的动画，资源引用。 |
| `start` / `duration` | | 在轨道上的位置（秒）。 |
| `clipIn` | `0` | 片段从动画的第几秒开始。 |
| `speed` | `1` | 播放速度。 |
| `loop` | `false` | 重复动画以填满片段，而不是停在最后一帧。 |
| `easeIn` / `easeOut` | `0` | 从骨架自身动画混合进入、以及混合回去的秒数。 |
| `preExtrapolation` / `postExtrapolation` | 无 | 片段之前（为第一个片段时）及之后直到下一片段之间播放的内容：`hold`、`loop`、`pingPong` 或 `continue`。 |

重叠的片段交叉淡化：前一个淡出，后一个淡入。片段缓入或缓出时，与骨架自身的姿势混合：骨架有 `Animator` 时为该帧 `Animator` 给出的姿势，否则为静止姿势。时间轴在 `Animator` 之后运行，因此满权重时由轨道决定姿势。片段之间骨架回到自身动画；轨道的 `hold` 使最后一个片段结束后保持其最终姿势。序列器将缓入缓出绘制为条末端的斜坡，将交叉淡化绘制为重叠部分的斜线，预览会播放混合效果。

**外推。** `hold` 保持片段的端点帧；`loop` 与 `pingPong` 正向重复或往返重复其区间；`continue` 使其动画继续播放。后外推填充片段之后到下一片段开始之间的时间；前外推填充轨道第一个片段之前的时间。被外推的一端不做缓入缓出，片段保持满权重。序列器将外推区间绘制为淡色虚线带；片段的细节中分别为**之前**和**之后**。未设置外推的片段使用轨道的 `hold`。

**分层。** 同一骨架上的多条动画轨道构成图层，按轨道顺序应用。第一条与骨架自身姿势结合；之后的每条轨道设置：

| 轨道字段 | 默认值 | 说明 |
|---|---|---|
| `blend` | `override` | `override` 使上方轨道的姿势趋向本轨道的姿势。`additive` 叠加其片段相对自身首帧（片段在动画中的起点）的变化，因此倾身或受击在任何姿势上表现一致。 |
| `weight` | `1` | 轨道强度，`0` 到 `1`。 |
| `mask` | 全部 | 可移动的关节：骨架之下的路径，每条包含其下所有内容。 |
| `rootMotion` | `false` | 用片段的根运动移动骨架。 |
| `hold` | `false` | 最后一个片段结束后保持其最终姿势。 |

在行走之上让上半身挥手，即为第二条遮罩到 `Spine` 的轨道；呼吸为一条低权重的叠加轨道。这些字段属于轨道：选中轨道行后，细节在**混合**分组中显示它们，旁边是轨道名称、静音和锁定。**遮罩**是一个数组；每个元素是从骨架上选取的关节，包含其分支。片段的细节分为**分段**（播放时间）、**动画**、**缓动**和**外推**几组。

**根运动。** 片段的根轨道（动画自身根节点上的 `Transform` 位置和旋转）默认像普通关节一样摆放骨架，因此行走动画原地播放。打开轨道的 `rootMotion`（细节中的**根运动**）后，根轨道被排除在姿势之外，骨架从原来所在位置出发，按片段开始以来根节点移动的距离移动。

- 移动量为各片段按权重缩放后的运动。连续的片段首尾相接，因此连续两段行走移动两倍距离；循环片段每一圈持续前进。
- 缓入的片段使骨架逐渐起步，缓出的片段使其逐渐停下；交叉淡化混合两个片段的步伐；最后一个片段结束后，骨架停在到达的位置。
- 后外推延续运动：`loop` 继续行走，`pingPong` 来回行走，`continue` 按动画继续播放，`hold` 原地站立。
- 位移随骨架朝向旋转，朝向其他方向的角色向该方向行走。
- 位置在每个时间点由片段直接计算，而非逐帧累加，因此拖动、跳转和循环得到的位置一致。场景自身的位置保持不变。
## 相机轨道

相机轨道保存镜头；每根条是一台相机，在其区间内用作视图。首尾相接的条为硬切。将一根条拖到与前一根重叠，重叠部分成为混合，由后一个镜头的混合曲线决定形状。没有镜头的区间将视图交还给场景自身的相机。每条时间轴只有一条相机轨道，其相机必须位于时间轴根实体之下。

拖动播放头时，视口的相机预览显示当前镜头。显示哪个镜头只取决于时间，因此拖动、跳转和倒放的结果一致。

## 子序列轨道

子序列轨道在本时间轴的一个时间窗内，以其自身时钟播放另一个 `.estimeline`。`speed` 缩放其速度，`loop` 使其重复以填满整根条，而不是停在最后一帧。**绑定到**选择嵌套时间轴名称路径的解析起点，因此同一序列可在不同角色上播放。

时间轴不能直接或经由其他时间轴播放自身，嵌套最多四层（`MAX_SEQUENCE_DEPTH`）。编辑器拒绝此类选择；已加载的游戏跳过它们并给出警告。显示嵌套时间轴的哪一帧只取决于时间。嵌套时间轴中的事件仅在正向播放时触发。

## 相机震动轨道

相机震动轨道在指定时间触发震动。每个条目为一个 `time` 和一个 `force`（`1` 为原始强度）。效果取决于轨道对应的实体：

- **带有 `CameraImpulseSource`**（[冲击](/docs/zh-cn/graphics/camera/shake/#冲击来自某处的震动)）时，条目从该实体的位置发出冲击，强度为源强度的 `force` 倍。每台带 `CameraImpulseListener` 的相机按距离衰减接收冲击。
- **没有该组件**（例如根实体上的轨道）时，就地震动当前使用的视图，强度为默认震动的 `force` 倍。

运行时，震动只移动渲染的视图，从不改动相机的 `Transform`。序列器预览在拖动时显示震动：当前镜头的相机（或场景的活动相机）按播放头处震动所产生的偏移移动，偏移由之前的震动以与运行时相同的噪声计算，因此同一时间总是产生相同的震动。震动结束后相机复位；场景中保存的相机从不被修改。

## 生成轨道

生成轨道使实体在一段时间内出现于场景中，因此只在过场中出现的实体不必在其余时间存在于关卡里。

| 片段字段 | 说明 |
|---|---|
| `start` / `duration` | 实例存在的时间：播放头进入片段时创建，离开时移除。 |
| `prefab` | 实例化的预制体，资源引用。 |
| `name` | 实例的名称。 |

实例创建在轨道对应的实体之下（根实体上的轨道则在根实体之下），因此其他轨道可以像引用普通子实体一样按名称引用它：路径为 `Dragon` 的属性、动画或相机轨道在生成的 `Dragon` 存在时作用于它，不存在时不起作用。停止时间轴或移除其播放器时，所有实例都被移除。

加载时间轴文件时，引擎会按场景的纹理导入设置准备生成轨道引用的预制体。两个叠加场景可以播放同一份时间轴，让生成的精灵和网格分别使用各自的过滤与平铺设置。片段开始的那一帧，播放器先创建实例，再让其他轨道对它采样。某个预制体缺失时，其他片段仍可播放。

对于在代码中注册的时间轴，播放器一获得时间轴便开始加载预制体。若播放头在加载期间进入片段，预制体就绪时只要片段仍在播放，实例就会出现。在序列器中拖动播放头会创建临时预览实例，世界大纲和保存后的场景均不包含这些实例。

## 激活轨道

激活轨道在指定区间内开启其目标，例如由关闭的图片切换为打开的图片及其光晕，或在动画结尾出现的徽章。写入内容取决于目标：

- **实体**整体激活或停用，连同其下所有内容。停用的实体被排除在所有查询之外，而不只是不渲染。渲染组件自身的 `enabled` 保持编辑时设置的值。
- **UI 节点**设置其 `UINode.display`，该属性同样会显示或隐藏节点的子树。

轨道仅在状态变化时写入，因此不变的轨道不会每帧将组件标记为已变更。

## 事件与标记轨道

事件与标记轨道向游戏报告时间轴的进度。播放头经过的每个条目都作为 `TimelineEvent` 发出，并附带其轨道的目标实体；系统在下一帧读取。

```typescript
import { defineSystem, EventReader, TimelineEvent } from 'esengine';

const onCue = defineSystem([EventReader(TimelineEvent)], (events) => {
  for (const e of events) {
    if (e.name === 'door-open') openDoor(e.target);
    if (e.kind === 'event') console.log(e.payload);   // a marker's payload is empty
  }
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `kind` | `'event'` \| `'marker'` | 事件轨道的条目或标记。 |
| `name` | string | 编辑时设置的名称。 |
| `payload` | object | 事件的数据；标记为空。 |
| `time` | number | 在剪辑中的位置（秒）。 |
| `player` | Entity | 播放该时间轴的实体。 |
| `target` | Entity | 轨道的目标实体（根实体上的轨道为播放器）。 |

每个条目每趟发出一次；循环时下一圈再次发出。带 `duration` 的事件（窗口）还会在该时长内对播放该时间轴的动画控制器状态报告为打开（[窗口](/docs/zh-cn/animation/animator-events/#窗口)）。

### 可视化脚本与事件绑定

每个命名事件或标记还会作为实体事件 `timeline:<名称>` 发出（名为 `boom` 的标记为 `timeline:boom`），先发给轨道的目标实体，再发给播放器。可视化脚本中该类型的**监听事件**节点响应此事件；节点的 `target` 为轨道实体，`other` 为播放器。节点声明为**输入**的负载字段（在细节中，每项一个名称和一个类型）成为带类型的输出引脚；事件自身的 `time` 与 `name` 也可以同样声明。实体上的脚本图接收以该实体为目标的轨道事件；播放时间轴的实体上的脚本图接收全部事件。这些实体上的事件绑定与状态机同样接收这些事件。代码中用 `timelineSignalType(name)` 获取事件类型。

## 绑定

以 `@Name` 开头的轨道路径经由绑定解析：正在播放的 `TimelinePlayer` 将 `Name` 绑定到的实体（可位于场景中任何位置），路径其余部分位于其下（`@Hero/Arm`）。绑定使时间轴可以驱动播放器层级之外的实体，并使同一条时间轴由两个播放器播放时驱动两个不同的角色。

| `TimelinePlayer` 字段 | 说明 |
|---|---|
| `bindingNames` | 播放器各绑定的名称。 |
| `bindings` | 每个名称绑定的实体，顺序相同；与其他实体引用一样随场景重映射。 |

假设播放器位于 `Stage` 上，`Hero` 是 `Stage` 的子实体，`Spotlight` 位于场景其他位置，且链接按钮显示的预览根实体为 `Stage`：

- **子实体。** **＋ 轨道 → 激活 → Hero** 创建一条按 `Stage` 之下的路径找到 `Hero` 的轨道。
- **其他位置的实体。** **＋ 轨道 → 激活 → 绑定的实体… → Spotlight** 在 `Stage` 的 **Timeline Player** 上创建或复用名为 `Spotlight` 的绑定，并将轨道目标设为 `@Spotlight`。若子菜单提示根实体没有播放器，先在 `Stage` 上添加 **Timeline Player**。
- **更换绑定目标。** 选中 `Stage`，打开**细节 → Timeline Player → Bindings**。每行左侧为绑定名，右侧为实体下拉框；行由序列器创建，不能在此列表中新增。
