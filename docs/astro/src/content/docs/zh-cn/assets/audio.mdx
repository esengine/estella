Estella 的音频通过 `Audio` 资源播放一次性音效和循环音乐,用句柄控制单个声音,用总线层级
平衡混音,并用空间音频把声音定位到世界里。它在浏览器上跑 Web Audio 后端,在微信等小游戏宿主上每个声音一个播放器,在 iOS 和 Android 应用里用宿主的原生音频引擎(miniaudio)。

## 工作原理

`Audio` 是逐 App 的资源,默认已注册。音频文件会被解码成**缓冲区**并在首次使用时缓存,然后
在某个**总线**(命名的音量分组)上播放。每次播放返回一个 `AudioHandle`,你可以留着它来调节
或停止这一个声音。对于绑定到某个位置或物体的声音,`AudioSource` 组件声明式地播放,并在
(`spatial`)开启时按与 `AudioListener` 的距离衰减。

解码后的缓冲区放在一个**按字节预算的热缓存**里(默认 32 MB,
`RuntimeConfig.audioCacheBudget`,构建配置里为 `audioCacheBudget`)——纹理预算的音频镜像:
被资源生命周期释放的缓冲区仍可即时播放,再次加载时原地复活而不用重新下载和解码;超出预算时
最旧的未使用缓冲区被丢弃。收到系统内存警告时引擎会自动清空整个热缓存——正在播放的声音不受
影响。

<Aside type="note">
  音频自动注册——无需加插件。浏览器要求先有用户手势才能开始播放,所以第一次播放要从点击或
  按键触发。
</Aside>

## 音效与音乐

```typescript
import { defineSystem, Res, Audio } from 'esengine';

const play = defineSystem([Res(Audio)], (audio) => {
  const sfx = audio.playSFX('assets/hit.wav', { volume: 1, pitch: 1, pan: 0 });
  audio.playBGM('assets/theme.ogg', { fadeIn: 0.5, crossFade: 1.0 });
});
```

`playSFX` 触发一次性播放并返回一个句柄;`playBGM` 循环并替换当前曲目,可选交叉淡入。两者都会
自动预加载未缓存的片段并在就绪后播放。

## 音效事件定义（beta）

`.esaudioevent` 是带有 `version: 1` 的 JSON 资源，`clips` 保存音频引用和相对 `weight`。
使用 `assets.load<SoundEventAsset>('sound-event', ref)` 加载并校验定义，不会解码所有候选声音。
候选的 UUID 引用会进入导出依赖，权重为零的槽位也保留依赖。

```typescript
import { parseSoundEvent, SoundEventSelector } from 'esengine';

const event = parseSoundEvent({
  version: 1,
  mode: 'no-repeat',
  clips: [{ clip: 'assets/step-a.wav', weight: 1 }, { clip: 'assets/step-b.wav', weight: 3 }],
  volume: [0.8, 1],
  playbackRate: [0.9, 1.1],
});
const selector = new SoundEventSelector(event, 42);
const result = selector.next();
if (result.selection) {
  const { clip, volume, playbackRate } = result.selection;
  audio.playSFX(clip, { volume, pitch: playbackRate });
}
```

`random` 按权重选择，`sequence` 按作者排列的顺序循环启用槽位，`no-repeat` 在存在其他正权重声音时排除上次的音频标识。
随机模式会合并相同音频标识的权重并返回其首个槽位。所有模式均跳过零权重槽位；空池和全零权重池分别返回
`empty`、`zero-weight` 原因。只有一个启用声音时允许重复。

固定种子可重现片段及参数选择，不承诺后端采样同步；修改参数范围不会改变片段顺序。
播放速率同时影响音高和时长，不是保时长变调。

选择器只负责选择片段和参数。使用托管播放资源，可以同时应用事件设置并管理加载和声音生命周期。

### 托管事件播放

```typescript
import { SoundEvents } from 'esengine';

const events = app.getResource(SoundEvents);
const emitter = await events.load('assets/steps.esaudioevent', { owner: entity, seed: 42 });
const voice = emitter?.trigger(); // 空间事件也可传入世界坐标。
if (voice) {
  await voice.ready;
  console.log(voice.status, voice.reason, voice.selection);
}
```

重复触发时保留发射器。它持有事件定义租约及独立选择序列，固定种子重现该发射器的序列。
同一资源的发射器共享事件并发与冷却，热更新前后的定义也共享名额。先检查事件准入，再加载选中的音频，
最后由现有 Audio 声音池应用全局优先级和声音上限。加载中和暂停的请求均占名额。
冷却从准入时开始，后续加载失败或全局池拒绝也不撤销冷却；停止不重置冷却。Audio 插件按模拟时间推进事件时钟。

`ready` 在加载完成或取消时返回状态；`reason` 区分事件上限、冷却、空池、全零权重、全局上限、缺少位置和加载失败。
加载错误包含事件路径及选中的槽位。加载期间也可修改音量/速率、暂停或停止。
自然结束、停止、全局 `Audio.stopAll()`、对象销毁和 App 清理均归还音频租约。
没有 owner 的发射器由调用者显式 `emitter.dispose()`；绑定对象的发射器在注册表断开时也会释放。
`events.getStats()` 记录准入、实际声音创建、结束、停止和拒绝数量，不保留触发历史。

空间事件复用 AudioSource 的衰减和声像计算，owner 需有世界变换，或在 `trigger()` 传入位置。
没有监听器时以原点为监听位置。小游戏宿主不支持立体声声像时会报告该限制，但仍应用软件距离衰减。
组件与图动作见[音效事件源](#音效事件源)。

### 制作音效事件

![声音事件编辑器:三个带波形和权重的变体,以及播放、音量与音高、并发设置](@/assets/guides/zh/sound-event.png)

*一个有三个变体的声音事件。每行有波形和权重(占比＝权重除以权重之和),**触发试听**按该事件自己的规则在监听器位置播放。*



在内容浏览器选择 **新建 → 创建音效事件**，或选中音频资源后从右键菜单创建。
双击 `.esaudioevent` 打开专用编辑器。将音频拖到空事件面板，会在第一条音频旁创建
事件；拖到已打开的事件则添加变体。

用音频选择器添加或替换片段；拖动行或点击上下箭头排序。删除仅移除槽位，保留音频文件。
权重 `0` 禁用槽位。选择模式、音量/速率范围、总线、优先级、并发上限、冷却和可选空间
参数使用与运行时相同的校验格式。修改参与撤销/重做、脏标签、保存、自动保存快照和外部
文件变更处理。无效文件不会替换当前文档。

**触发试听**选择下一个变体；**连续试听**在片段完成后继续，并遵守事件冷却与声音预算。
试听复用现有混音器和全局声音池，显示最后选中的槽位、片段及采样音量/速率，并用共享
波形跟随该声部。空间试听把音源放在监听器位置；距离衰减请在场景中验证。
试听种子是编辑器状态，不写入资源；停止或修改会重置试听流。运行时请配置
`SoundEventSource.seed`。

修改定义、关闭面板、切换项目或全局 Stop All 会取消试听。波形缓存最多保存 64 组峰值
（约 200 KiB），其中不缓存 PCM。磁盘变化和项目切换使峰值失效。软件试听验证不能替代
目标设备及实际输出验收。

## `Audio` API 参考

| 方法 | 说明 |
|---|---|
| `playSFX(url, config?)` | 播放一次性;返回 `AudioHandle`。config:`volume`、`pitch`、`pan`、`priority`。 |
| `playBGM(url, config?)` | 循环音乐,替换当前曲目。config:`volume`、`fadeIn`、`crossFade`。 |
| `stopBGM(fadeOut?)` | 停止音乐,可在 `fadeOut` 秒内淡出。 |
| `stopAll()` | 停止所有正在播放的声音。 |
| `setMasterVolume(v)` | 设置 master 总线音量(0..1)。 |
| `setMusicVolume(v)` | 设置 `music` 总线音量。 |
| `setSFXVolume(v)` | 设置 `sfx` 总线音量。 |
| `setUIVolume(v)` | 设置 `ui` 总线音量。 |
| `muteBus(name, muted)` | 按名字静音/取消静音一个总线。 |
| `preload(url)` | 提前解码并缓存一个片段(异步)。 |
| `preloadAll(urls)` | 预加载一组片段(异步)。 |
| `getBufferHandle(url)` | `url` 的已缓存缓冲区,或 `undefined`。 |
| `getSpectrum(out)` | 用主输出的频谱填充一个 `Uint8Array`(每个频段 0–255,从低频到高频),供可视化用。在没有分析能力的后端(微信)上返回 `false`——按静音处理。 |
| `setBufferBudget(bytes)` | 覆盖热缓存字节预算(`null` 回到 RuntimeConfig 的值;`0` 关闭缓存)。 |
| `getBufferStats()` | 驻留计数:`bufferCount`、`bufferBytes`、`bufferBudget`、`evictableCount`。 |
| `trimBufferCache()` | 立即释放所有未使用的缓存缓冲区(引擎在系统内存警告时会自动调用)。 |

## 控制正在播放的声音

`playSFX` 返回一个 `AudioHandle`——留着它驱动这个特定的声音:

```typescript
const shot = audio.playSFX('assets/laser.wav');
shot.setVolume(0.6);
shot.setPan(-0.5);            // -1 left … +1 right
shot.setPlaybackRate(1.2);   // pitch / speed
shot.setLoop(true);
shot.pause(); shot.resume(); shot.stop();
shot.onEnd = () => { /* the sound finished */ };
```

| 成员 | 类型 | 说明 |
|---|---|---|
| `setVolume(v)` | 方法 | 音量,0..1。 |
| `setPan(p)` | 方法 | 立体声声像,`-1`(左)…`+1`(右)。 |
| `setPlaybackRate(r)` | 方法 | 播放速度 / 音调(`1` = 正常)。 |
| `setLoop(l)` | 方法 | 循环该声音。 |
| `pause()` / `resume()` / `stop()` | 方法 | 传输控制。 |
| `onEnd` | 回调 | 声音结束时调用一次。 |
| `isPlaying` | 只读 | 是否正在播放。 |
| `currentTime` | 只读 | 播放位置(秒)。 |
| `duration` | 只读 | 总时长(秒)。 |

## 声明式播放 —— `AudioSource`

给实体加一个 `AudioSource` 即可不写代码播放——非常适合环境音、循环的机器声,或锚定到物体的
声音。配 `playOnAwake` + `enabled`,音频系统会自动开始播放。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `clip` | asset | `''` | 要播放的音频资源。 |
| `bus` | string | `'sfx'` | 路由经过的混音总线。 |
| `volume` | number | `1` | 音量,0..1。 |
| `pitch` | number | `1` | 播放速度 / 音调。 |
| `loop` | boolean | `false` | 循环片段。 |
| `playing` | boolean | `false` | 播放标志:升起即播放,放下即停止。非循环片段播完时引擎会把它放下。 |
| `finished` | boolean | `false` | 运行时只读:片段已播完;再次升起 `playing` 会重新播放。 |
| `playOnAwake` | boolean | `false` | 实体启用时自动开始。 |
| `spatial` | boolean | `false` | 按与监听器的距离衰减。 |
| `minDistance` | number | `100` | 在此距离内音量为满。 |
| `maxDistance` | number | `1000` | 超过此距离即静音。 |
| `attenuationModel` | `AttenuationModel` | `Inverse` | 衰减曲线——`Linear` / `Inverse` / `Exponential`。 |
| `rolloff` | number | `1` | 衰减陡峭度的倍率。 |
| `priority` | number | `0` | 池满时的声部优先级(高者胜)。 |
| `enabled` | boolean | `true` | 关掉即停止并静音,而不移除组件。 |

## 混音总线

混音器是层级的——`master → { music, sfx, ui, voice }`。设置某个总线的音量会缩放路由到它下面
的一切:

```typescript
audio.setMasterVolume(0.8);
audio.setMusicVolume(0.6);
audio.setSFXVolume(1.0);
audio.setUIVolume(0.9);
audio.muteBus('music', true);
```

用 `AudioSource.bus` 字段把声音路由到某个总线,或让 `playSFX` 默认走 `sfx`。音量设置器有
`setMasterVolume`(全局滑条)和 `setMusicVolume` / `setSFXVolume` / `setUIVolume`。`voice`
总线能路由声音,但没有专门命名的设置器:用 `setBusVolume('voice', v)`(它能按名字指到任何总线)设音量,或用 `muteBus('voice', …)` 开关它。

### 总线效果与自动闪避(ducking)

每条总线携带一条 DSP 插入链,以数据声明:

```typescript
audio.setBusEffects('music', [
  { type: 'filter', filter: 'lowpass', frequency: 800, q: 1 },   // 闷化(暂停菜单)
  { type: 'reverb', seconds: 1.5, wet: 0.3 },                     // 程序化房间混响
  { type: 'compressor', thresholdDb: -24, ratio: 4 },
]);
audio.setBusEffects('music', []);   // 清空
```

旁链闪避是一条规则,不是代码——语音播放时自动压低音乐:

```typescript
audio.setBusDucking('music', { trigger: 'voice', amount: 0.3, attack: 0.05, release: 0.4 });
audio.setBusDucking('music', null);  // 移除
```

`attack`(默认 0.05 秒)和 `release`(默认 0.4 秒)是时间常数,`threshold`(默认 0.003,0 到 1 的 RMS 电平)是触发总线响到多大才算有信号。`trigger` 总线有信号时,目标总线的闪避级压到 `amount`;静默后按 `release` 恢复到 1。
闪避是独立的增益级,不会与用户音量设置打架。无 WebAudio 图的后端(微信)上,
两个 API 与音量调用一样优雅降级为空操作。

### 音频混音器面板与项目配置

底部停靠的**音频混音器**面板可视化编辑以上一切——每总线一条 strip:音量推子、
静音、效果链、闪避规则、自定义总线。编辑持久化到 `project.esproject`
(`features.audio`)并在编辑器中即时生效;Play 与所有导出以同一套混音启动。

### 导入设置与打包音频

选中音频资产会显示解码波形(可播放/点击跳转)和**导入设置**:`Compress`(默认开)与
`Bitrate`(96、128 或 192 kbps,默认 128)控制打包时的 WAV → MP3 转码(在打包对话框勾选**压缩音频**)。
已压缩格式原样通过。MP3 有少量编码器延迟——需要无缝循环的素材请关闭 `Compress`。

**加载方式(Load Type)** 决定这个片段在 Web 上怎么持有:*自动*把 30 秒及以上的片段按压缩文件流式播放、较短的则解码,
*加载时解压*总是解码(起播即时,三分钟的曲子约占 69 MB),*流式*总是流式播放。流式片段几乎不占内存,走同样的总线、音量与淡入淡出,
但放弃了采样精确的循环点,以及同一片段的第二个并发声音。这个选择会写进导出游戏的音频设置,所以编辑器 Play、导出和试玩广告流式播放的是同一批片段。

## 门面之下

`Audio` 是一个门面,其后是 Web Audio 后端组装的三个导出类——`AudioMixer`、`AudioBus`、
`AudioPool`。游戏里很少直接构造它们(微信和原生后端上它们根本不存在,这正是总线 API 在那里
降级为空操作的原因),但它们公开导出是为了两件实事:**内建四条之外的自定义总线**,以及
**独立音频管线**——试听工具、自定义 `PlatformAudioBackend`、测试——建在你自己的
`AudioContext` 上。

自定义总线完全不需要类——门面就够:

```typescript
audio.ensureBus('ambience');                 // create under master (idempotent)
audio.ensureBus('footsteps', 'sfx');         // or under an existing bus
audio.setBusVolume('ambience', 0.5);
// playSFX 始终走 'sfx' 总线;playTrack(或实体的 AudioSource.bus)才能选总线。
audio.playTrack('assets/wind.ogg', { bus: 'ambience' });
```

`ensureBus(name, parent?)` 在总线缺失时创建它(挂在 `parent` 下,默认 `master`),
无混音图的后端上返回 `false`;之后所有按名字的门面调用(`setBusVolume`、`muteBus`、
`setBusEffects`、`setBusDucking`)都能触达它。

### `AudioBus`

一条混音 strip:`input → [效果插入…] → duck → gain(volume) → parent`。声源和子总线
连到 `input`;`node` 是**输出**增益——音量/静音作用在这里,父总线(或做 VU 表的
`AnalyserNode`)也从这里取信号。闪避级是独立的增益,所以旁链闪避永远不会与用户音量设置
打架。用 `AudioBusConfig` 构造:

| `AudioBusConfig` | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | string | – | 总线名。 |
| `volume` | number | `1` | 初始音量,钳制到 0..1。 |
| `muted` | boolean | `false` | 以静音启动。 |
| `parent` | string | `'master'` | 父总线名(由 `AudioMixer.createBus` 消费)。 |

| 成员 | 说明 |
|---|---|
| `input` / `node` | 入口 `GainNode` / 输出 `GainNode`(analyser 从 `node` 取信号)。 |
| `volume` | 0..1;变化在约 15 ms 内平滑,永不爆音。 |
| `muted` | 把输出渐变到 0 再回来,不丢失 `volume`。 |
| `effects` / `setEffects(defs)` | 读取 / 幂等替换 DSP 插入链(`BusEffectDef[]`)。 |
| `duckTo(level, timeConstant)` | 把闪避级向 `level` 渐变(混音器的闪避驱动它)。 |
| `connect(dest)` / `addChild(bus)` | 把输出接进父总线或裸 `AudioNode`。 |

### `AudioMixer`

拥有总线树。构造一个就建好接到 `context.destination` 的
`master → { music, sfx, ui, voice }`,音量来自 `AudioMixerConfig`
(`masterVolume` / `musicVolume` / `sfxVolume` / `uiVolume` / `voiceVolume`——
music 默认 `0.8`,其余 `1`):

```typescript
import { AudioMixer } from 'esengine';

const mixer = new AudioMixer(new AudioContext(), { musicVolume: 0.6 });
const ambience = mixer.createBus({ name: 'ambience' });   // under master
```

| 方法 | 说明 |
|---|---|
| `master` / `music` / `sfx` / `ui` / `voice` | 内建总线,作为只读字段。 |
| `getBus(name)` / `busNames()` | 查找总线 / 列出所有名字(创建顺序,`master` 在先)。 |
| `createBus(config)` | 创建总线并接到 `config.parent` 下(默认 `master`)。 |
| `setDucking(target, rule \| null)` / `getDucking(target)` | 安装或清除旁链 `BusDuckRule`(`trigger`、`amount`、`attack`、`release`、`threshold`)。 |
| `updateDucking()` | 每帧:测量各触发总线的 RMS,渐变其目标的闪避级(引擎的混音器由音频系统调用)。 |

### `AudioPool`

一次性播放背后的声部池:预建的 `gain → panner` 节点对(`PooledAudioNode`),每次播放
`acquire()`、声音结束时 `release()`,超过初始 16 个时按需增长;`activeCount` 与
`capacity` 报告用量。当你在自己的 `AudioContext` 上做自定义播放、想避免每次播放的节点
开销时可以用它。

## 空间音频

设 `AudioSource.spatial = true`,并给监听实体(通常是相机或玩家)加一个启用的 `AudioListener`。
声源便按距离衰减:

```typescript
import { defineSystem, Commands, Transform, AudioSource, AudioListener,
         AttenuationModel } from 'esengine';

const setupSpatial = defineSystem([Commands()], (cmds) => {
  // A positioned, looping ambience that fades with distance.
  cmds.spawn()
    .insert(Transform, { position: { x: 600, y: 0, z: 0 } })
    .insert(AudioSource, {
      clip: 'assets/campfire.ogg', loop: true, playOnAwake: true,
      spatial: true, minDistance: 80, maxDistance: 900,
      attenuationModel: AttenuationModel.Inverse,
    });

  // The listener (attach to the camera/player).
  cmds.entity(cameraEntity).insert(AudioListener, { enabled: true });
});
```

| `AttenuationModel` | 衰减 |
|---|---|
| `Linear` | 从 `minDistance` 到 `maxDistance` 的直线。 |
| `Inverse`(默认) | 自然的反距离衰减。 |
| `Exponential` | 更陡的指数衰减。 |

`AudioListener` 只有一个字段 `enabled`(默认 `true`)——场景里保持恰好一个启用的监听器。

空间音频是三维的:每帧,音频系统取声源和监听器的世界位置,按三个轴算出距离,用
`volume × 衰减` 加上**沿监听器自己右方向的立体声声像**(`dot(source − listener, right) / maxDistance`,
钳制到 ±1;没转过的监听器的右方向就是世界 +X,监听器转向后听到的世界也跟着转)驱动正在播放的句柄。没有 HRTF、多普勒或遮挡。空间声源在没有启用监听器时播放,
会警告一次并从世界原点量距离。

曲线数学以纯函数导出,供工具和测试使用——`calculateAttenuation(distance, config)`
配 `SpatialAudioConfig`(`model`、`refDistance`、`maxDistance`、`rolloff`——系统用
`AudioSource.minDistance`/`maxDistance`/`rolloff` 填充它),以及
`calculatePanning(source, listener, right, maxDistance)`(前三个是 `{ x, y, z }`):

```typescript
import { calculateAttenuation, calculatePanning, AttenuationModel } from 'esengine';

const gain = calculateAttenuation(250, {
  model: AttenuationModel.Inverse, refDistance: 100, maxDistance: 1000, rolloff: 1,
});                                                  // 0.4 — refDistance / distance
const pan = calculatePanning(
  { x: 600, y: 0, z: 0 }, { x: 0, y: 0, z: 0 }, { x: 1, y: 0, z: 0 }, 1000,
);                                                   // 0.6 — to the right
```

### 音效事件源

为实体添加 `SoundEventSource`，选择 `.esaudioevent` 资源。场景预加载只持有定义，
不会解码全部候选。`seed` 默认 `0`，固定此源的选择流；`playOnAwake` 在每个启用的
组件生命周期播放一次。修改事件或种子会建立新的选择流。

```typescript
import { SoundEventSource, triggerSoundEventSource, stopSoundEventSource } from 'esengine';

app.world.insert(entity, SoundEventSource, { event: 'assets/steps.esaudioevent', seed: 42 });
const voice = await triggerSoundEventSource(app.world, entity);
if (voice) {
  await voice.ready;
  console.log(voice.status, voice.reason, voice.selection);
}
stopSoundEventSource(app.world, entity);
```

可视化脚本、FSM 钩子和 BT 动作使用 `soundEvent.trigger` / `soundEvent.stop`，
与代码触发同一个组件。同一帧多次触发各自保留；图动作立即继续，不等待加载或播放完成。

冷定义按顺序最多保留每个源 256 次触发。超额、源不可用或禁用、定义加载失败、取消的请求
返回 `null`；返回的句柄再提供片段加载状态及事件/全局声音预算拒绝原因。冷却从定义加载
完成后的准入开始，因此多次冷触发可能共享同一个准入时刻。

停止仅取消此组件的队列和声音，不影响调用者在同一实体上创建的其他发射器。之后再触发
会从固定种子的起点开始。禁用、移除、修改事件或种子、层级失活、销毁、注册表断开都会
使旧生命周期失效；异步加载完成时再次检查，防止下一帧更新前出现迟到播放。
全局 `Audio.stopAll()` 取消待播意图并保留准备好的定义。局部停止不会在下一帧重新触发
`playOnAwake`。

## 最佳实践

- 对在关键时刻要播放的片段**预加载**(`preload` / `preloadAll`),第一次播放就不会因解码而静音。
- **在手势上开始**——浏览器在第一次用户输入前会屏蔽音频。
- **分开总线**(`music` / `sfx` / `ui` / `voice`)让玩家能各自调节,并统一由 `master` 驱动。
- 用 `AudioSource` 上的 `priority` **限制同时播放的声音数**,声部池满时重要的声音才胜出。
  上限默认 32 个声部,可用 `project.esproject` 的 `features.audio.maxVoices` 自己定(0 = 不限)。
  池满时最不值钱的那个被让位给更重要的,同优先级让位给更早的;比场上任何一个都不值钱的新声音,
  则根本不会开始。
- 世界/物体声音**用 `AudioSource`(声明式)**,一次性的 UI/玩法音效用 `playSFX`。
