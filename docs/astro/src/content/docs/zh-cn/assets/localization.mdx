`Localization` 资源为每个语言区域保存一份翻译目录，记录当前与回退语言区域，并用 `t()` 解析字符串。它不使用 `Intl`，因此在 Web 与微信上结果一致。

## 安装

`Localization` 需要显式启用。在任何系统读取 `Res(Localization)` 之前安装其插件：

```typescript
import { localizationPlugin, LocalizationPlugin } from 'esengine';

app.addPlugin(localizationPlugin);
// 或带选项：
app.addPlugin(new LocalizationPlugin({
  locale: 'en',
  fallback: 'en',
  catalogs: { en: { play: 'Play' }, 'zh-CN': { play: '开始' } },
}));
```

| `LocalizationOptions` | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `locale` | string | `'en'` | 当前语言区域。 |
| `fallback` | string | `'en'` | 当前语言区域缺少某个键时使用的语言区域。 |
| `catalogs` | `Record<string, LocaleCatalog>` | — | 启动时注册的目录，按语言区域分组。 |
| `tables` | string[] | — | 启动时通过 `Assets` 加载的 `.eslocale` 资源（路径或 `@uuid:` 引用）。需要资源插件。 |

把 `Text` 绑定到键的场景会自动安装该插件（[把 Text 绑定到键](#把-text-绑定到键)）。

## 目录与查找

```typescript
import { defineSystem, Res, Localization } from 'esengine';

const setupI18n = defineSystem([Res(Localization)], (i18n) => {
  i18n.addCatalog('en',    { play: 'Play', score: 'Score: {n}' });
  i18n.addCatalog('zh-CN', { play: '开始', score: '得分:{n}' });

  i18n.setLocale('zh-CN');
  const label = i18n.t('score', { n: 42 });   // "得分:42"
});
```

- `addCatalog(locale, entries)` 把键合并进某个语言区域；后调用的覆盖先前的同名键。
- `t(key, params?)` 替换 `{placeholder}` 占位符。当前语言区域缺少的键在回退语言区域中查找，仍找不到则原样返回键名。

## 复数

条目可使用 `zero`、`one`、`two`、`few`、`many`、`other` 六种 CLDR 复数形式。`t` 根据 `count` 选择形式。如果条目提供了 `zero`，数量为零时优先使用它。默认选择器采用英语规则（`one` / `other`）。其他语言可用 `setPluralSelector(locale, (count) => category)` 注册选择器，返回六种类别之一。如果译文取自回退语言，复数形式也按该语言的规则选择。

```typescript
i18n.addCatalog('en', { apples: { one: '{count} apple', other: '{count} apples' } });
i18n.t('apples', { count: 3 });   // "3 apples"
```

## `Localization` API

| 成员 | 说明 |
|---|---|
| `addCatalog(locale, entries)` | 把键合并进某个语言区域。 |
| `t(key, params?)` | 查找并插值字符串。 |
| `setLocale(locale)` / `locale` | 设置 / 读取当前语言区域。 |
| `setFallbackLocale(locale)` / `fallbackLocale` | 设置 / 读取回退语言区域。 |
| `setPluralSelector(locale, selector)` | 为某个语言区域注册复数规则。 |
| `setPseudoLocalization(options \| null)` | 启用伪本地化（`expansion`、`accents`）；`null` 恢复正常查找。`@experimental`。 |
| `availableLocales()` | 已注册的语言区域。 |
| `has(key)` | 当前或回退语言区域中是否存在该键。 |

### 伪本地化

`setPseudoLocalization({ expansion: 0.35, accents: true })` 拉长每个已翻译字符串并加上重音符号，同时保持占位符、富文本标签与换行不变，用于检验布局能否容纳更长的语言。`setPseudoLocalization(null)` 恢复真实文本。

## 字符串表（`.eslocale`）

`.eslocale` 资源只保存**一个**语言区域的目录，因此游戏只加载需要的语言：

```json
// assets/i18n/zh-CN.eslocale
{
  "version": 1,
  "locale": "zh-CN",
  "entries": {
    "ui.title": "UI 控件",
    "apples": { "other": "{count} 个苹果" }
  }
}
```

字符串表可通过三种方式加载：

- `assets.loadLocaleTable(path)`：需要本地化插件，否则失败；
- `new LocalizationPlugin({ tables: ['assets/i18n/zh-CN.eslocale'] })`；
- 由含键绑定 `Text` 的场景自动加载（[见下文](#把-text-绑定到键)）。

烘焙始终发布 `.eslocale` 文件，因为它们按键寻址，没有场景会引用它们。

同一语言的多张表定义同一个键时，靠后的表生效。场景自动发现的表按项目逻辑路径排序。在 `LocalizationPlugin({ tables })` 中显式列出的表优先级更高，按你列出的顺序覆盖。切换场景会复用已加载的表，通过路径和 UUID 引用同一张表也只占一份。

热更新成功后，新表替换旧表。删除一个键会露出前一张表或回退语言中的译文。若更新的表加载失败，界面继续显示上一次成功加载的译文。
编辑器预览也会保留上次有效的译文。字符串表会列出无法读取的文件，并在部分导出前说明将略过哪些文件。修复文件后即可恢复编辑和导入。

### 检视器

用 **内容浏览器 → 右键 → New Locale Table** 创建字符串表。选中字符串表时，Details 面板变为其编辑器：键与文本行（含复数形式）、以暗色显示的项目其他字符串表中的对应文本作为参考，以及可一键补充的缺失键列表。每次编辑立即保存。

### String Table 编辑器

双击 `.eslocale` 打开 **String Table** 编辑器，并排显示项目的所有语言：每个键一行，每张字符串表一列，未翻译的单元格有标记，并提供筛选及添加、删除键的命令。每次编辑立即写入对应语言的文件。复数条目在检视器中编辑。
- **Import** 读取 Excel（`.xlsx`）、CSV 或 XLIFF（`.xlf`）文件，并按键合并到字符串表。
- **Export** 把所有语言写成一张 Excel 或 CSV 表，或 XLIFF 1.2，并先列出发现的问题。

## 把 Text 绑定到键

设置 `Text.i18nKey`（Details 面板中的 **I18n Key** 字段，列出项目所有字符串表中的键并带翻译预览）后，`content` 成为派生值：**每帧**重新解析，因此 `setLocale` 或稍后加载完成的字符串表会更新所有绑定的标签，无需代码。

绑定了任意键的场景：

- 加载时若游戏尚未安装本地化插件，则自动安装；
- 加载所有已发布的字符串表；
- 若发布了与**玩家系统语言**匹配的字符串表，则以该语言启动。自行安装插件或调用 `setLocale` 的游戏不会被覆盖。

调用 `SceneManager.prepare(name)` 时，候选场景会在后台解码字符串表。当前场景继续显示原有语言的译文，直到目标场景接管资源。如果游戏在此期间配置了插件，或玩家手动选择了语言，目标场景会沿用该设置。

动态标签（`Score: 42`）由代码驱动：内容由代码改写的标签不能再绑定键。应在负责该标签的系统中调用 `t('score', { n })`。

<Aside type="tip">
  `examples/ui-controls` 用 `i18nKey` 把五个标签绑定到 `en` 与 `zh-CN` 字符串表，不含任何本地化代码。
</Aside>

## 使用建议

- 所有面向用户的字符串都通过 `t()` 或 `i18nKey` 解析。
- 使用插值（`'Score: {n}'`）而非拼接，使不同语言可以有不同的语序。
- 设置回退语言区域，使缺失的翻译回退到另一种语言而不是键名。
- 每种语言一个 `.eslocale`，放在同一文件夹（`assets/i18n/`）中，键保持一致。
