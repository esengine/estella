在世界中拥有位置的每个实体都带有 `Transform`：位置、旋转与缩放。本页定义 Transform 的各字段、单位制（世界单位即设计像素；
物理使用米）、坐标约定，以及变换如何沿父子层级复合。

![platformer 示例中玩家的细节面板：含 Position、Rotation 与 Scale 的 Transform 卡片](@/assets/guides/zh/core-transform-details.png)
## `Transform` 组件

`Transform` 保存创作的**局部**值，以及由引擎计算的**世界**值。局部字段相对于父实体；没有父实体时相对于世界原点。
变换系统每帧沿层级向下复合局部值，并将结果写入世界字段。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `position` | Vec3 | `{0, 0, 0}` | 局部位置，单位为世界单位，相对于父实体。2D 场景中 `z` 用于在同一排序层内区分绘制顺序。 |
| `rotation` | Quat | `{w: 1, x: 0, y: 0, z: 0}` | 以四元数表示的局部旋转；单位四元数表示无旋转。2D 旋转绕 Z 轴进行（[2D 旋转](#2d-旋转)）。 |
| `scale` | Vec3 | `{1, 1, 1}` | 各轴的局部缩放。`1` 为原始尺寸；负值产生镜像。 |
| `worldPosition` | Vec3 | `{0, 0, 0}` | **只读。**由引擎复合得到的世界空间位置。 |
| `worldRotation` | Quat | 单位四元数 | **只读。**世界空间旋转。 |
| `worldScale` | Vec3 | `{1, 1, 1}` | **只读。**世界空间缩放。 |

系统写入局部字段、读取世界字段。对世界字段的写入不会保留：变换系统会根据局部字段与父链重新计算世界字段。
对根实体而言，世界值等于局部值。

```typescript
import { defineSystem, Query, Mut, Transform } from 'esengine';

const drift = defineSystem([Query(Mut(Transform))], (q) => {
  for (const [entity, t] of q) {
    t.position = { x: t.position.x + 1, y: t.position.y, z: t.position.z }; // write local
    console.log(t.worldPosition.x);                                        // read world
  }
});
```

| 能力 | 字段 |
|---|---|
| 可由 [Sequencer](/docs/zh-cn/animation/timeline/sequencer/) 与[补间](/docs/zh-cn/animation/tweens/)驱动动画 | `position.x/y/z`、`rotation.x/y/z/w`、`rotation.angle`（以弧度表示的 Z 旋转；另外两个轴保持不变）、`scale.x/y/z` |
| 由[状态复制](/docs/zh-cn/scripting/networking/replication/)同步 | `position`、`rotation`、`scale` |

细节面板将旋转显示为**以度为单位的 X / Y / Z 欧拉角**，按先 X、再 Y、后 Z 的顺序应用；2D 内容仅绕 Z 轴旋转。
存储的值始终是四元数。

<Aside type="note">
  `LocalTransform` 与 `WorldTransform` 作为同一组件的别名导出：`Transform === LocalTransform === WorldTransform`。
  一个组件同时保存局部数据与世界数据。
</Aside>

## 坐标系

| 空间 | 约定 |
|---|---|
| 世界 | **Y 轴向上。**`+X` 向右，`+Y` 向上。角度 `0` 指向 `+X`；正角度逆时针旋转，因此 `Math.atan2(dy, dx)` 给出指向目标的角度。 |
| 3D | 坐标轴相同。`z` 是空间轴；相机与灯光朝向 `-Z`，地面为 XZ 平面。适用于网格、透视相机与 [3D 物理](/docs/zh-cn/gameplay/physics-3d/overview/)。 |
| 2D | `position.z` 用于区分绘制顺序。渲染器先按排序 `layer` 排序，再在层内按 `z` 排序，或在 [Y 排序层](/docs/zh-cn/graphics/sprites/sorting/#y-排序层)中按 Y 排序。`z` 不会缩放精灵，也不产生透视缩短。 |
| 屏幕 | **Y 轴向下。**指针坐标（`Input.mouseX` / `mouseY`、UI 命中测试）是距画布**左上角**的像素。 |

`CameraView` 资源在屏幕坐标与世界坐标之间转换（完整 API 见
[相机](/docs/zh-cn/graphics/camera/overview/#屏幕--世界坐标)）：

```typescript
import { defineSystem, Res, CameraView, Input } from 'esengine';

const pick = defineSystem([Res(CameraView), Res(Input)], (view, input) => {
  // Screen px (Y-down, top-left origin) -> world units (Y-up). null without a camera.
  const world = view.screenToWorld(input.mouseX, input.mouseY);
  if (world) { /* world.x, world.y */ }
});
```

## 单位

创作使用一种空间单位，即设计像素。物理使用一种派生单位，即米。

```text
screen px (Y-down)  ── CameraView.screenToWorld ──▶  world units = design px (Y-up)
world / design px   ── ÷ Canvas.pixelsPerUnit (100) ──▶  physics metres (Box2D)
```

### 设计像素

**1 世界单位 = 1 设计像素。**默认设计分辨率为 1920×1080（`Canvas.designResolution`），编辑器场景相机以
`orthoSize = designResolution.y / 2 = 540` 创作，因此相机恰好显示一个设计分辨率大小的世界范围。由此：

- 拖入场景的纹理按纹理的**像素尺寸**创建精灵；在默认缩放下，128×128 的图片即 128×128 世界单位。
- 在场景相机下，`UINode` 的像素尺寸与设计像素 1:1 对应。
- 玩法中的距离、偏移与速度以设计像素计（px、px/s）。

设计分辨率如何适配到实际屏幕，见[屏幕与设计分辨率](/docs/zh-cn/core-concepts/screen/overview/)。

### 物理米制

`Canvas.pixelsPerUnit`（默认 `100`）是每物理**米**对应的世界像素数。它缩放 Box2D 世界与瓦片碰撞体，并不是精灵的显示缩放。

| 物理接口 | 单位 |
|---|---|
| 碰撞体尺寸（`halfExtents`、`radius` 等） | **米**（像素 ÷ `pixelsPerUnit`） |
| 求解器方法——力、冲量、速度、`setGravity` | **米** |
| 空间查询——`raycast`、`shapeCast*`、`overlapCircle`、`overlapAABB` | **世界像素**（自动换算） |
| `CharacterController2D.velocity` / `moveCharacter` | 每秒**世界像素** |

默认值以常量形式导出，读取自引擎的 Canvas 默认值：

```typescript
import { DEFAULT_DESIGN_WIDTH, DEFAULT_DESIGN_HEIGHT, DEFAULT_PIXELS_PER_UNIT } from 'esengine';

DEFAULT_DESIGN_WIDTH;    // 1920
DEFAULT_DESIGN_HEIGHT;   // 1080
DEFAULT_PIXELS_PER_UNIT; // 100

const radiusMeters = 24 / DEFAULT_PIXELS_PER_UNIT; // a 24 px circle collider
```

## 2D 旋转

`Transform.rotation` 是四元数 `{w, x, y, z}`。2D 旋转是绕 Z 轴的旋转，只使用 `z` 与 `w` 分量：

```text
angle a (radians)  ->  { w: cos(a/2), x: 0, y: 0, z: sin(a/2) }
```

`quat()` 工厂函数构造四元数。其参数顺序为 **`w` 在前**：`quat(w = 1, x = 0, y = 0, z = 0)`。

```typescript
import { quat } from 'esengine';

const angle = Math.PI / 4;                                   // 45° counter-clockwise
const rot = quat(Math.cos(angle / 2), 0, 0, Math.sin(angle / 2));
```

| 辅助函数 | 签名 | 说明 |
|---|---|---|
| `quaternionToAngle2D` | `(rz, rw) => number` | 由四元数的 `z` / `w` 求出以弧度表示的 Z 角度（`2 * atan2(z, w)`）。来自 `esengine`。 |
| `normalizeAngle` | `(a) => number` | 将角度规整到 `(-π, π]`，用于求最短转向差值。来自 `esengine/ai`。 |

跟随光标的炮塔：

```typescript
import { defineSystem, defineTag, Query, Mut, Res, Transform, CameraView, quat, quaternionToAngle2D } from 'esengine';
import { normalizeAngle } from 'esengine/ai';

const Turret = defineTag('Turret');

const aim = defineSystem([Query(Mut(Transform)).with(Turret), Res(CameraView)], (q, view) => {
  const target = view.getWorldMousePosition();
  if (!target) return;
  for (const [entity, t] of q) {
    const angle = Math.atan2(
      target.y - t.worldPosition.y,
      target.x - t.worldPosition.x,
    );
    t.rotation = quat(Math.cos(angle / 2), 0, 0, Math.sin(angle / 2));

    // Gradual turning: read the current facing and step toward the target.
    const facing = quaternionToAngle2D(t.rotation.z, t.rotation.w);
    const delta = normalizeAngle(angle - facing); // shortest signed turn
  }
});
```

`TweenTarget.RotationZ` 以**弧度**为单位驱动 Z 角度动画，并在每一步重建四元数；Sequencer 以相同方式为 `rotation.angle`
打关键帧（[补间](/docs/zh-cn/animation/tweens/)）。不需要旋转的方向向量由 `v2.fromAngle(angle, len)` 与 `v2.rotate(v, angle)`
生成（[数学辅助](/docs/zh-cn/scripting/math/)）。

## 父子层级

实体通过 `Parent` 与 `Children` 组件构成树。层级通过 world API 编辑：

```typescript
import { defineSystem, addStartupSystem, GetWorld, Transform } from 'esengine';

const build = defineSystem([GetWorld()], (world) => {
  const ship = world.spawn('Ship');
  world.insert(ship, Transform, { position: { x: 400, y: 300, z: 0 } });

  const turret = world.spawn('Turret');
  world.insert(turret, Transform, { position: { x: 0, y: 24, z: 0 } }); // 24 px above the ship
  world.setParent(turret, ship);
});
addStartupSystem(build);
```

| 方法 | 行为 |
|---|---|
| `world.setParent(child, parent)` | 将 `child` 挂接或重新挂接到 `parent` 下，同时更新子实体的 `Parent` 与父实体的 `Children`。子实体追加在新的兄弟节点之后。将实体设为自身或其后代的子实体会被拒绝，且不做任何更改。 |
| `world.removeParent(entity)` | 解除实体的父级，使其成为根实体。其自身的子实体仍挂接在它下面。 |
| `world.despawn(entity)` | 销毁**整棵子树**，先销毁子实体。 |

直接添加或设置 `Parent` 或 `Children` 会经过同一操作，因此链接两侧保持一致；`world.setParent` 是显式写法。

`Parent` 保存 `{ entity }`（父实体），`Children` 保存 `{ entities }`（一个 `Entity[]`）。它们可以像其他组件一样被查询：

```typescript
import { defineSystem, Query, Parent, Children, Transform } from 'esengine';

const followers = defineSystem([Query(Transform, Parent)], (q) => {
  for (const [entity, t, parent] of q) { /* parent.entity */ }
});
```

### 世界变换复合

变换系统每帧从根实体开始深度优先遍历树。对每个实体，它按 **平移 × 旋转 × 缩放**（TRS）构建局部矩阵，并与父实体的世界矩阵相乘：

```text
world = parentWorld × T(position) × R(rotation) × S(scale)
```

因此子实体的 `position` 在父实体经过旋转与缩放的坐标系中度量：父实体旋转 90° 时，局部坐标为 `{x: 24, y: 0}` 的子实体
在世界空间中位于父实体*上方* 24 px。分解后的结果写入 `worldPosition`、`worldRotation` 与 `worldScale`。

### 层级行为

- **重新设置父级时保留局部值。**`setParent` 不会为保持世界姿态而调整局部字段；局部坐标为 `{0, 0}` 的子实体会移动到新父实体的位置。
  如需保持实体位置不变，应在重新设置父级前将其世界位置转换到新父实体的坐标系中。
- **`Children` 的顺序有意义。**UI 布局与 UI 绘制顺序遵循该顺序，层级顺序层（`Renderer.setTreeSortLayers`）也按它堆叠。
  解除某个子实体的父级时，其余兄弟节点保持原有顺序；重新挂接时追加到末尾。兄弟顺序在世界大纲中设置。
  普通的 2D 绘制顺序应使用 `position.z` 或排序层。

## 缩放

`scale` 按轴设置。`{2, 2, 1}` 将实体均匀放大一倍，`{2, 1, 1}` 将其水平拉伸，负值产生镜像：`{-1, 1, 1}` 水平翻转。
对精灵而言，`Sprite.flipX` 可在不改变变换的情况下翻转。

缩放通过 `worldScale` 沿层级向下复合。位于 `{2, 2, 1}` 父实体下的子实体以其自身缩放的两倍渲染，其局部 `position`
也会被父实体缩放：局部坐标 `{x: 10, y: 0}` 在世界空间中位于 20 px 处。

<Aside type="caution">
  父实体的非均匀缩放与子实体的旋转组合会产生错切：复合后的矩阵不再是纯旋转，物理碰撞体（以米为单位、未缩放的形状）也不再与渲染结果一致。
  父实体应使用均匀缩放（x 与 y 相等）。相机通过 `Camera.orthoSize` 缩放视野，而不是缩放其 Transform。
</Aside>
