在内容浏览器中双击资源，会在场景视图旁以文档标签打开其编辑器。

| 资源 | 编辑器 | 章节 |
|---|---|---|
| `.estimeline` | 序列器 | [序列器](/docs/zh-cn/animation/timeline/sequencer/) |
| `.estileset` | 瓦片集编辑器 | [瓦片集](/docs/zh-cn/world/tilemaps/tilesets/) |
| `TilemapLayer`（选中） | 瓦片地图模式 + 瓦片调色板 | [绘制瓦片](/docs/zh-cn/world/tilemaps/painting/) |
| `.esfsm` / `.esbt` | 状态机 / 行为树图 | [玩法 AI](/docs/zh-cn/gameplay/ai/overview/) |
| `.esgraph` | 脚本图 | [脚本图](/docs/zh-cn/gameplay/script-graphs/) |
| `.esmatgraph` | 材质图 | [材质与着色器](/docs/zh-cn/graphics/materials/code/#代码中的材质图) |

## 序列器

编辑时间轴的关键帧与曲线：绑定到实体的轨道、关键帧表与曲线编辑器。见[序列器](/docs/zh-cn/animation/timeline/sequencer/)。

## 瓦片地图模式

选中 `TilemapLayer`（或单击活动栏中的瓦片地图图标）进入瓦片地图模式：出现**瓦片调色板**面板，场景视图工具栏中出现绘制工具。

| 功能 | 说明 |
|---|---|
| 工具 | 画笔、橡皮、矩形、椭圆、直线、填充、选择、吸管、地形（自动瓦片） |
| 图章 | 保存的多瓦片图章；水平翻转 / 垂直翻转 / 旋转 90°（绘制工具激活时按 `H` / `V` / `R`）；随机散布（`D`） |
| 替换瓦片… | 在图层或选区内把一个瓦片 id 替换为另一个 |
| 调色板 | 方向键选择；**Shift** 扩展多瓦片图章 |
| 网格方向 | 正交、等距、交错、六边形 |

![瓦片地图模式：场景视图工具栏中的绘制工具与瓦片调色板](@/assets/guides/zh/tilemap-tools.png)

## 瓦片集编辑器

| 功能 | 说明 |
|---|---|
| 碰撞 | 每个瓦片的矩形、圆形、多边形与斜坡形状；单向、触发器与物理材质修饰。在放大的瓦片上直接操作：圆的中心与半径、多边形顶点（单击添加、拖动、单击删除）、单向平台的实心边。 |
| 地形 | 自动瓦片集：边 / 角邻接，或多色角 Wang。 |
| 属性 | 每个瓦片的概率权重与自定义属性。 |
| 动画 | 动画瓦片：拖动重排帧、统一循环时长、实时预览。 |

![瓦片集编辑器：在放大的瓦片上编辑碰撞形状](@/assets/guides/zh/tileset-collision.png)

## 节点图

状态机、行为树与脚本图共用同一节点画布：

| 操作 | 输入 |
|---|---|
| 平移 | 中键拖动 |
| 缩放 | 滚轮，朝向光标 |
| 连接 | 从输出端口拖到节点上 |
| 选择 | 单击节点或连线 |
| 删除 | **Delete** |
| 添加节点 | 在画布上右键 |

![节点图编辑器中的行为树](@/assets/guides/zh/ai-bt.png)
