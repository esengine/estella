内容浏览器是项目的资源管理器。默认停靠在底部，也可以随时以覆盖层形式打开（**内容抽屉**，**Ctrl / ⌘ + Space**）。

## 创建资源

**添加**菜单在当前文件夹中创建资源：场景、预制体、**脚本…**、动画、动画控制器、输入映射、本地化表、立方体环境（六张图片）、材质、材质图、材质子图、**着色器**、状态机、行为树、脚本图、Avatar、声音事件、世界规则、地形层、文件夹，以及插件贡献的资源类型。

![内容浏览器的添加菜单，列出可创建的资源类型](@/assets/guides/zh/content-new-menu.png)

**新建脚本…** 同时注册模块：未被任何模块导入的模块不会被打包，其组件也不会出现在添加组件列表中，因此该对话框会在相应的项目入口中添加导入（组件写入声明入口，系统写入启动入口）。见[脚本](/docs/zh-cn/scripting/overview/)。

## 上下文操作

| 资源 | 操作 |
|---|---|
| 纹理 | 创建瓦片集、创建精灵动画 |
| 瓦片集 | 创建瓦片地图 |
| 动画片段 | 创建动画精灵 |
| 材质 | 创建材质实例 |
| 场景 | 设为启动场景 |
| 导入的资源 | 重新导入 |
| 任意 | 重命名、复制、复制路径、复制引用、查找引用、在资源管理器中显示、删除 |

## 导入

将文件从文件管理器拖到内容浏览器，或使用**导入…**。每个资源首次被发现时生成一个 `.meta` 附属文件（UUID 与导入设置）。

## 重命名、移动与删除

- 重命名、移动与复制会给出带**撤销**的通知。
- 重命名与移动会改写所有已打开文档中的引用。
- **删除**先列出引用该文件的所有场景、预制体与资源，再将其移入系统回收站；撤销可恢复。

## 查找引用

右键 → **查找引用**，或资源检视器中的引用计数，会列出纹理、材质、预制体或场景的所有引用位置，范围包括磁盘上的依赖图与未保存的已打开场景。

## 视图

内容浏览器工具栏中的**设置**选择视图——**平铺**、**列表**或**分栏**——以及排序方式、是否显示文件夹与搜索选项。分栏视图中，列标题按名称、类型、大小或修改时间排序；拖动列标题之间的边线可调整列宽（双击恢复默认）；列标题的右键菜单可隐藏该列。

## 键盘

文件夹树支持键盘导航：方向键移动与折叠 / 展开，**Enter** 打开文件夹，**F2** 重命名。
