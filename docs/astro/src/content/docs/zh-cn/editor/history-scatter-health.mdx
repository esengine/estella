三个较小的编辑器工具,其他指南默认你已经知道它们。都可以在命令面板里搜到。

## 历史

**历史**按顺序列出你在当前场景里做过的每一次编辑,**当前状态**标出你现在的位置。它是撤销 / 重做
(`Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`)的可视化形式:点一个更早的行就回到那个状态。

[通过 MCP 连接的代理](/docs/zh-cn/agents/mcp/)做的编辑也和你自己的一样记在这里,每步一行,同样可以退回。

## 散布笔刷

**散布笔刷**用在视口里拖动的方式装饰场景——石头、树、草丛——而不是一个个手动摆放。
从命令面板(**散布笔刷**)启用,它的面板在左侧打开;再次启用或按 `Esc` 收起。

1. 选中要散布的实体,点**用当前选中**(**散布源**显示当前装填的对象)。没有散布源时面板会提示*先选中要散布的实体*。
2. 设置**笔刷**:

   | 设置 | 作用 |
   |---|---|
   | **半径** | 一笔点出的圆盘有多大。 |
   | **密度** | 圆盘里落下多少个副本。 |
   | **最小间距** | 副本之间的最小距离,避免堆叠。 |
   | **大小变化** | 每个副本的随机缩放幅度。 |
   | **随机朝向** | 每个副本的随机朝向。 |

   预览显示一次采样:笔刷圆、会落下的副本,以及每个副本留出的间距。
3. 在视口里拖动。每一笔是**一个撤销步骤**,并提示*散布了 N 个*。

**围绕选中散布**命令不用拖动,直接在选中对象所在的位置补一批——"这里再来点这个"。

## 项目健康

**项目健康**是编辑器在构建前对项目运行的检查清单,**构建 → 打包项目…** 开始前也会先跑同一份——有阻塞项就不会构建。
它检查的内容包括:指向空的资产引用、组件必填字段为空、缺少入口场景、脚本无法编译、
不会进入构建的未保存改动、本机无法构建的目标平台,以及视口回退(HDR、MSAA)。它停靠在底部,并把结果分组:

- **阻塞构建**——打包前必须修。
- **警告**与**提示**——值得看一眼,但不致命。
- **无法检查**——编辑器缺少所需条件(已连接的设备、工具链);这不等于通过。

有些条目带**修复**按钮,直接替你应用修复;做不到时面板会说明原因。**重新检查**再跑一遍,
自上次检查后项目有改动时面板也会提醒。结果干净时显示*没有任何东西阻碍构建。*
同一份清单在[编辑器 MCP](/docs/zh-cn/agents/mcp/)里以 `get_project_health` 提供给自动化。
