三者均可通过命令面板（**Ctrl / ⌘ + Shift + P**）打开。

## 历史

**历史**按顺序列出当前场景的编辑，**当前状态**标记当前位置。它是撤销栈（**Ctrl / ⌘ + Z**、**Ctrl / ⌘ + Shift + Z**）的可视形式；单击某一行即后退或前进到该状态。

[通过 MCP 连接的智能体](/docs/zh-cn/agents/mcp/)所做的编辑以相同方式记录，每步一行，归入该智能体运行，并提供**撤销这次运行**操作。

![历史面板：一次智能体运行及其两个 set_field 步骤、当前状态标记与“撤销这次运行”](@/assets/guides/zh/ed-history.png)

## 散布笔刷

散布笔刷通过在场景视图中绘制来放置某个实体的副本。从命令面板（**散布笔刷**）切换，或按 **Esc** 关闭；其面板在左侧打开。

![散布笔刷面板：来源、使用选中对象，以及带单次笔触预览的笔刷设置](@/assets/guides/zh/ed-scatter.png)

1. 选中来源实体，按**使用选中对象**。
2. 设置笔刷：

   | 设置 | 说明 |
   |---|---|
   | **Radius** | 单次笔触的半径。 |
   | **Density** | 每次笔触的副本数。 |
   | **Spacing** | 副本之间的最小距离。 |
   | **Scale Variation** | 每个副本的随机缩放范围。 |
   | **Random Turn** | 每个副本的随机朝向。 |

   预览显示一次笔触：圆盘、采样点及其间距。
3. 在场景视图中拖动。每一笔为一个撤销步骤，并报告放置的副本数。

**围绕选择散布**无需绘制，直接填充当前选择周围的区域。

## 项目健康

**项目健康**是构建前检查列表；**构建 → 打包项目…** 会先运行同一组检查，存在阻塞项时停止构建。检查内容包括无法解析的资源引用、组件的必填字段为空、缺少启动场景、脚本编译、未保存的修改不会进入构建、本机的目标平台前置条件，以及场景视图回退（HDR、MSAA）。

![项目健康：一个阻塞项（未保存的修改不会进入构建）与两项无法检查的项](@/assets/guides/zh/ed-health.png)

| 分组 | 含义 |
|---|---|
| **阻塞构建** | 打包前必须修复。 |
| **警告**、**提示** | 非致命问题。 |
| **无法检查** | 缺少前置条件（设备、工具链）；不等于通过。 |

带**修复**按钮的条目可直接应用修复，或说明无法修复的原因。**重新检查**再次运行列表；项目自上次检查后有变化时面板会提示。自动化可通过[编辑器 MCP](/docs/zh-cn/agents/mcp/) 中的 `get_project_health` 获取同一列表。
