Estella 编辑器是一个桌面应用（Electron + React），采用可停靠的工作区。它提供可视化场景编辑、组件检视器、资源编辑器（时间轴、瓦片地图、节点图、材质）以及编辑器内运行模式；运行模式在隔离的运行时领域中执行游戏，不会修改正在编辑的场景。

![Estella 编辑器与一个平台跳跃场景：场景视图、世界大纲、细节与内容浏览器](@/assets/guides/zh/editor-overview.png)

*默认工作区：场景视图（中）、世界大纲与细节（右）、内容浏览器、输出日志与性能分析器（下）、运行控制（上）。*

## 启动器

未打开项目时，编辑器显示启动器：

| 页面 | 功能 |
|---|---|
| **最近** | 重新打开最近的项目；支持搜索、网格与列表视图。 |
| **新建项目** | 由模板创建项目：**起步模板**（空白、2D 平台跳跃、俯视角、像素 RPG、UI 游戏、3D 入门、联网 3D、试玩广告、微信小游戏）或**示例**（内置示例项目）。 |

## 项目目录结构

项目即一个文件夹：

| 路径 | 内容 |
|---|---|
| `project.esproject` | 项目清单：名称、启动场景、设计分辨率、启用的功能、打包配置。纳入版本控制。 |
| `.esengine/workspace.json` | 编辑器本地状态（上次打开的场景、面板布局）。被 Git 忽略。 |
| `assets/scenes/*.esscene` | 场景。 |
| `assets/…` | 纹理、材质、瓦片集等资源，各带一个 `.meta` 附属文件。 |
| `src/components.ts` | **声明入口**：编辑器执行该模块及其导入，以发现项目组件。见[脚本](/docs/zh-cn/scripting/overview/)。 |
| `src/main.ts` | **启动入口**：注册系统并运行游戏。编辑器不会执行它。 |

资源以 UUID（`@uuid:…`）引用，移动或重命名文件不会破坏引用。

## 工作区

| 区域 | 内容 |
|---|---|
| **活动栏**（最左） | 编辑模式（瓦片地图 / UI / 世界 / 场景）、面板菜单、内容抽屉、智能体、设置。 |
| **菜单栏** | 文件、编辑、实体、视图、构建、窗口、帮助；插件贡献命令时出现**工具**菜单。 |
| **标题栏** | 运行控制（运行、暂停、重启、运行模式菜单）、**扫码预览**（在手机上运行）、**编译**（脚本）。 |
| **场景视图**（中） | WebGL 场景视图及其工具栏：变换工具、吸附、2D / 3D、屏幕控制、**显示**、**Gizmo**。 |
| **世界大纲**（右） | 当前场景的实体层级。 |
| **细节**（右） | 选中对象的检视器。 |
| **底部停靠区** | 内容浏览器、输出日志、性能分析器；其他面板（序列器、瓦片调色板）按需打开。 |
| **状态栏** | 内容抽屉开关、编辑模式、保存状态、已加载模块、FPS、实体数、内存、图形后端、引擎版本。 |

拖动标签可停靠、拆分、浮动或重新排列面板；布局按项目保存。内容浏览器也可以作为上滑覆盖层随时打开（**内容抽屉**，**Ctrl / ⌘ + Space**）。

<Aside type="note">
  运行模式在独立于编辑场景的领域中执行。运行中的游戏无法修改编辑模式的世界，停止后编辑器恢复到运行前的场景。
</Aside>
