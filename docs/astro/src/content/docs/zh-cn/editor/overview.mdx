Estella 编辑器是一个桌面应用(Electron + React),带 UE5 风格的**可停靠工作区**。你可视化地搭
场景、在检视器里调组件、绘制瓦片地图、连节点图,并**直接在编辑器里运行游戏**——在一个隔离的
运行时 realm 里,所以运行永远不会弄脏你的场景。

## 启动项目

没有项目打开时,编辑器显示 **启动器(Launcher)**:

- **最近** — 重新打开你做过的项目,带搜索和网格/列表视图。
- **新建项目** — 选一个模板,起名字、选位置,创建。模板分两组:**Starters**
  (**Blank**——只有一个相机的空场景——以及可直接运行的起步项目,如 2D 平台跳跃、
  俯视角、像素 RPG、UI 游戏、3D 起步、在线 3D 世界、试玩广告和微信小游戏)和
  **Examples**(随附的示例项目,可直接探索和修改)。

一个项目就是磁盘上的一个文件夹。编辑器关心的几块:

| 路径 | 是什么 |
|---|---|
| `project.esproject` | 项目清单——名字、默认场景、设计分辨率、启用的特性(物理、渲染)、打包。纳入版本控制。 |
| `.esengine/workspace.json` | 编辑器本地状态(上次打开的场景、面板布局)。被 gitignore。 |
| `assets/scenes/*.esscene` | 你的场景。 |
| `assets/…` | 纹理、材质、瓦片集等资产,每个带一个 `.meta` 边车文件。 |
| `src/components.ts` | **声明入口**——编辑器会求值这个模块以及它 import 到的一切,以此认识你的组件。组件定义在哪都行,从这里 re-export 出来即可。见[脚本](/docs/zh-cn/scripting/overview/#声明放在哪里)。 |
| `src/main.ts` | **启动入口**——注册系统的地方。跑游戏的是它;编辑器从不求值它。 |

资产按 UUID(`@uuid:…`)可移植地引用,而不是按路径,所以移动或重命名文件不会断掉引用。

## 工作区

![Estella 编辑器与一个平台跳跃场景——视口、世界大纲、细节、内容浏览器](@/assets/guides/zh/editor-overview.png)

*默认工作区:视口居中,世界大纲与细节在右侧,内容浏览器在底部,运行控制在顶部。*

从外到内的默认布局:

- **活动栏(Activity Bar)** — 最左侧的图标竖条:四种**编辑模式**(瓦片地图 / UI / 世界 / 场景)、**面板**菜单(显示或隐藏任何停靠面板)、内容抽屉、Agent 和设置。
- **菜单栏** — 文件 · 编辑 · 实体 · 视图 · 构建 · 窗口 · 帮助;插件往“工具”菜单里加了命令后,会多出一个**工具**菜单。保存在“文件”里,撤销和重做在“编辑”里。
- **顶栏** — **运行**控制(运行、暂停、重新运行,以及选择游戏在哪里运行的菜单)、**扫码预览**(在手机上运行游戏)、**编译**(编译脚本)。
- **视口**(中央) — 实时 WebGL 场景视图,自带工具栏:变换工具、吸附、2D / 3D、屏幕控制、**显示**和 **Gizmo**。
- **World Outliner**(右) — 场景的实体层级。
- **Details**(右) — 当前选中项的检视器。
- **内容浏览器**、**输出日志**和**性能分析器**(底部标签)。其他面板 —— 序列器、瓦片调色板 —— 在需要时打开:从“面板”菜单,或由拥有它的模式打开。
- **状态栏** — 内容抽屉开关、编辑模式、场景是否已保存、已加载的模块、FPS、实体数、内存、图形后端和引擎版本。每个读数都保持单行;窗口太窄时,状态栏会先去掉较长的消息和最不重要的读数,而不是换行。

面板可停靠——拖动标签即可重排、拆分或浮动,布局会自动保存。你也能用 **Ctrl / ⌘ + Space** 从任
何地方把内容浏览器唤成上滑浮层(*内容抽屉*)。

<Aside type="note">
  运行发生在与你正在编辑的场景**分离的 realm** 里,所以运行中的游戏无法改动你的编辑态世界。
  停止后回到你原本那个场景,分毫不差。
</Aside>
