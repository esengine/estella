运行模式在隔离的领域中执行游戏，使用与发布构建相同的运行时。

## 控制

| 控件 | 功能 | 快捷键 |
|---|---|---|
| 运行 / 停止 | 开始；运行中则停止 | **F5** / **Esc** |
| 暂停 / 继续 | | **F6** |
| 重启 | | **Shift + F5** |
| 最大化 | 最大化或恢复场景视图 | **F11** |
| 检查 | 由编辑器接管运行中游戏上的指针 | **F8** |

运行按钮旁的运行方式菜单可选择：

| 选项 | 取值 |
|---|---|
| 宿主 | **在视口中运行**会覆盖场景视图，**在新窗口中运行**会打开游戏标签页，**独立进程运行**会在单独的进程中打开游戏窗口。 |
| 运行时最大化视口 | 将编辑器内的游戏画面扩大到整个工作区，停止时恢复布局。 |
| 玩家数 | **单人**，或 **2 / 3 / 4 人（监听服务器）**：第一个领域作为监听服务器，其余玩家各为一个通过编辑器内复制连接的客户端领域 |

![运行方式菜单：在视口中 / 新窗口中运行、运行时最大化视口、单人或带监听服务器的 2–4 人](@/assets/guides/zh/play-mode-menu.png)

运行中的游戏以场景视图周围的强调色边框表示（暂停时为琥珀色，画面变暗）。

嵌入编辑器的游戏加载完成后会接管键盘。如果你在加载期间切换了控件，焦点会留在新位置。
在检查器里输入时，脚本热重载后可以接着输入。多人预览重载后，键盘也会留给刚才操作的玩家。
从游戏中停止预览时，如果上次使用的编辑器控件仍然可用，焦点会回到那里。

## 大纲中的运行世界

运行期间大纲显示运行中的世界。来自场景的实体保留其身份，因此展开状态、选择与细节面板保持不变。游戏生成的实体显示在**运行时**分组下，停止时移除。

结构性编辑需等到停止：运行期间可以选择、搜索、折叠和隐藏行，但不能重命名、修改父级、创建或删除。字段编辑作用于运行中的世界，除非保留（见下文），否则在停止时结束。

## 检查模式

开启**检查**（游戏上方的按钮，或 **F8**）后，指针归编辑器使用：单击选择光标下的对象，并用变换工具（**W / E / R**，显示在画面旁）移动、旋转或缩放。拾取与拖动由运行中的世界和游戏自身的相机解析，因此移动后的实体落在游戏绘制它的位置。检查模式默认关闭；关闭时游戏画面上不绘制任何内容。

## 保留运行时修改

运行期间修改过字段时，停止会询问是否**保留**；输出日志在决定前列出每项修改及其值。保留会将每个被修改字段在停止时于运行世界中的值写回场景（包括由脚本驱动的轴），作为一个撤销步骤。游戏生成的实体无法保留，日志中会给出其数量。

## 手机预览

**扫码预览**保存场景、构建 Web 预览，并通过局域网提供服务和二维码。手机浏览器以相同的运行时运行项目，2D 与 3D 均可。

- 弹出框显示地址、已连接设备与停止按钮。**更多设置**可选择场景与网络接口、重新构建，并报告连接与重新加载错误。
- 每次会话生成新的访问令牌；不提供公网隧道。停止、切换项目或关闭编辑器会使链接失效。
- 保存场景或资源会重新构建并刷新已连接的浏览器。脚本保存在结构兼容时热替换；结构性变化会重新加载页面并报告原因。构建失败时保留上一次完成的预览。
- 预览构建跳过 AOT 与资源压缩。浏览器来源不支持 WebGPU 时预览回退到 WebGL2；项目的发布后端设置不变。
- 页面可连接与运行模式相同的服务器。Web 导出仅可连接 **项目设置 → 允许的服务器来源** 中列出的服务器。

## 自动保存与恢复

编辑器会定期将未保存的文档快照写入项目的工作区文件夹（仅在存在未保存修改且没有运行会话时）。快照不等于保存。下次打开项目时，若快照比磁盘上的文件更新，编辑器会提供**恢复**；保存文档会取代其快照。这与崩溃转储以及 GPU 进程丢失后的自动重新加载互为补充。
