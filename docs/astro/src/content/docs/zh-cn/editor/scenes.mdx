## 创建实体

| 途径 | 结果 |
|---|---|
| **实体 → 添加实体** | 只带 `Transform` 的实体。 |
| *世界大纲 → 添加 → 创建实体…* | 创建弹窗：内置预设（Empty、Sprite、Camera、Particles、Light、Tilemap、Spine、Audio、Text、Bitmap Text、Shape、Mesh、Trail、DragonBones、Sound Event、Sun、3D 基本体、第三人称角色、户外环境）、UI 基础元素与控件、项目组件，以及项目中的每个 `.esprefab`。 |
| *世界大纲 → 右键* | 上下文操作：创建、文件夹、父子关系、创建预制体。 |
| 从内容浏览器拖放 | 见下文。 |

所有创建途径（菜单、拖放、自动化）共用同一流程；每次创建为一个撤销步骤。

### 将资源拖入场景

| 资源 | 拖放到场景视图 | 拖放到世界大纲 |
|---|---|---|
| 图片 | 在释放点创建 `Sprite`；拖放到画布或 UI 节点上时创建 **UI 图片**（`UINode` + `UIVisual`） | 在该行下创建 `Sprite`；该行为画布或 UI 节点时创建 UI 图片 |
| `.esprefab` | 预制体实例 | 该行下的预制体实例 |
| `.esmesh` | 网格实体 | 该行下的网格实体 |
| `.esanim` | 动画精灵 | 该行下的动画精灵 |
| `.estileset` | 瓦片地图 | 该行下的瓦片地图 |

拖放到大纲空白处时在场景根下创建。精灵与 UI 图片的区别见[精灵还是 UI 图片](/docs/zh-cn/ui/sprite-or-ui/)。

## 世界大纲

![带文件夹的世界大纲与 Player 实体的右键菜单：重命名、复制、创建预制体、删除、隐藏、锁定、禁用、由选择新建文件夹、移到根、解除父级、添加子级、创建子级](@/assets/guides/zh/ed-outliner-menu.png)

| 操作 | 输入 |
|---|---|
| 修改父级 | 拖放到另一个实体上 |
| 组织 | 文件夹（右键 → 由选择新建文件夹） |
| 跳转到实体 | 树获得焦点时输入名称开头的字母 |
| 重命名 / 复制 / 删除 | **F2** / **Ctrl/⌘ + D** / **Delete** |
| 隐藏 / 锁定 | 行上的开关；与运行时启用状态无关 |
| 创建预制体 | 选中对象的右键菜单 |

- **隐藏**将实体从编辑场景视图中移除（精灵、骨骼、瓦片地图、粒子、灯光），不改变游戏加载的场景。
- **锁定**使实体保持可见，但不可拾取且没有变换手柄。
- **预制体实例**提供 *编辑预制体*、*应用到预制体*、*还原为预制体*、*创建变体*、*解包预制体*，以及 *设为虚拟（按需加载）* / *设为完整（随场景加载）*。虚拟实例在编辑器中完整编辑，但运行中的场景只构建其根节点。见[虚拟实例](/docs/zh-cn/world/prefabs/)。

## 细节

细节面板检视当前选择。字段由组件反射元数据生成，范围、单位、枚举与提示均来自组件定义。编辑立即写入场景。

- **校验**——必填字段为空时标出；数值字段被限制在声明的范围内；资源槽拒绝类型不符的资源。
- **分节**——每个组件可折叠；折叠状态跨选择与编辑器重启保留。不常编辑的组件（控件上的 `Focusable`、`ThemeStyle`）默认折叠。
- **提示**——不起作用的配置会在组件卡片上提示（例如 `UINode` 上的 `Sprite`，或已布局 UI 节点上设定了位置的 Transform）。
- **预制体栏**——在预制体实例上显示所属预制体与**虚拟**开关。

### 专用控件

| 组件 | 控件 |
|---|---|
| `UINode`（绝对定位） | 锚点选择器：3×3 点锚点网格，外加各轴的拉伸。 |
| `FlexContainer` | 方向、3×3 对齐网格（主轴与交叉轴）、主轴分布（Packed / Between / Around / Evenly）、换行与拉伸开关、四边内边距。 |
| 带控制器的 UI 节点 | 内联控制器条：选择页面并为字段设置齿轮（[UI 控制器](/docs/zh-cn/ui/controllers/)）。 |
| 材质 | 着色器选择器（内置模板或项目 `.esshader`）（[材质](/docs/zh-cn/graphics/materials/overview/#着色器)）。 |

## 资源检视器

在内容浏览器中选中资源时，细节面板显示其导入设置（材质则显示其参数）。导入设置属于资源本身，作用于其所有绘制位置：编辑场景视图、运行模式（场景视图与游戏面板）以及打包构建。

**九宫格边界。** 对纹理，可以在预览上直接拖动四条切片参考线；数值字段同步更新。
