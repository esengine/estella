**Ctrl / ⌘ + ,** 或活动栏的齿轮图标打开设置。窗口分为**编辑器**与**项目**两个范围，各分若干页面；搜索框可查找任意页面上的设置。每个项目只需设置一次的项（屏幕预设、求解器参数、主题颜色、模块开关、AI 提供方端点）位于各页面的**高级**折叠区。

![设置窗口的编辑器范围：编辑器 / 项目标签、页面列表、搜索框](@/assets/guides/zh/settings-window.png)

## 编辑器范围

保存在本机。

| 页面 | 内容 |
|---|---|
| **通用** | 外观（语言、强调色、界面字体、界面缩放）、性能、控制台、渲染后端。 |
| **视口** | 网格、吸附、变换 Gizmo。 |
| **快捷键** | 重新绑定所有快捷键（[键盘快捷键](/docs/zh-cn/editor/shortcuts/)）。 |
| **工具与 AI** | 外部脚本与图片编辑器、浏览器；是否允许 [AI 智能体](/docs/zh-cn/agents/mcp/) 通过 MCP 连接并修改项目。 |

## 项目范围

保存在 `project.esproject` 中，随项目共享。

| 页面 | 内容 |
|---|---|
| **游戏** | **显示**：设计分辨率（作为新画布的初始值，驱动设备预览）、屏幕方向（所有导出目标遵循；未设置时由设计分辨率推导）、相机适配（`None` 为关闭）、渲染分辨率（屏幕尺寸、设计分辨率或其整数倍后缩放到屏幕）。**UI**：控件主题（暗色 / 亮色）与按角色的主题颜色，在编辑器、运行模式与导出中一致生效（[主题](/docs/zh-cn/ui/theming/)）。**音频**、**Spine**、**运行时**（见下文）。 |
| **渲染** | 最多 32 个命名排序层（填充层下拉菜单；列表外的数值层仍然有效）及其中哪些按 Y 排序；质量档位；项目环境；后台编译着色器、在加载画面后预热、按需渲染（[质量等级](/docs/zh-cn/performance/quality-levels/runtime/#着色器编译与按需渲染)）。**渲染调度**：*独立渲染线程*（原生构建与跨源隔离的 Web 构建）与 *GPU 异步计算*（支持的原生 Metal 设备）；默认均关闭。 |
| **物理** | 启用、重力、16 个碰撞层名称与 16×16 碰撞矩阵、求解器参数（固定步长、子步数、接触频率 / 阻尼 / 推出速度、休眠、连续碰撞）。见[物理](/docs/zh-cn/gameplay/physics-2d/overview/)。 |
| **构建与模块** | 各目标的打包元数据（微信 AppID、桌面应用 id 与产品名、启动画面、成就）、包含的引擎模块，以及 Web 构建的**允许的服务器来源**（例如 `wss://play.example.com`）；未配置时页面的内容安全策略只允许其自身来源。 |
| **配置表** | **Luban**（Excel 表 → 生成 JSON 与 TypeScript）与 **Protobuf**（`.proto` → TypeScript 类型与二进制编解码）。默认关闭；开启后编辑器检查工具是否已安装（下载前会询问），并保持生成代码最新。 |

## 运行时

**项目 → 游戏 → 运行时**提供引擎参数。项目文件只在 `features.runtime` 中保存与引擎默认值不同的项；构建包含同一配置块，运行模式在第一个资源加载前应用它。编辑场景视图使用引擎默认值。

![项目设置游戏页的运行时一节：场景切换、帧限制、缓存预算与文本分组](@/assets/guides/zh/settings-runtime.png)

| 分组 | 设置 | 默认值 | 说明 |
|---|---|---|---|
| 场景切换 | 时长、颜色 | 0.3 s | 未指定过渡时场景切换使用的淡入淡出。 |
| 帧限制 | 最长帧步长 | 0.25 s | 单帧模拟时间的上限（后台标签页、卡顿）。 |
| | 每帧最多固定步数 *（高级）* | 8 | 固定频率追帧步数的上限；超出后模拟减速而不是持续堆积。 |
| 资源加载 | 加载超时 *（高级）* | 30 s | 资源加载失败前的等待时间。 |
| | 重试冷却 *（高级）* | 5 s | 失败资源再次尝试前的间隔。 |
| 缓存预算 | 纹理缓存 | 64 MiB | 当前未使用纹理占用的 GPU 内存；0 为关闭。 |
| | 音频缓存 | 32 MiB | 已解码的音频片段；0 为关闭。 |
| | 设备丢失副本 *（高级）* | 16 MiB | 为在 GPU 设备丢失后恢复而保留的 CPU 副本；超出时发出警告。 |
| 文本 | 文本画布尺寸 *（高级）* | 512 | 光栅化画布尺寸。 |
| | 默认字体族 | — | 未指定字体的 `Text` 组件使用的字体。 |

## 编辑器语言

编辑器提供 **English** 与**简体中文**，首次启动时跟随系统语言。在 **设置 → 编辑器 → 通用 → 外观 → 语言** 中切换；更改在重新加载后生效，编辑器会提示重新加载。编辑器界面文本使用与游戏运行时相同的[本地化引擎](/docs/zh-cn/assets/localization/)。
