`mod` 在 macOS 上为 **⌘**，其他平台为 **Ctrl**。所有绑定均可在 **设置 → 编辑器 → 快捷键** 中修改。

| 操作 | 快捷键 |
|---|---|
| 新建场景 | `mod + N` |
| 打开项目 | `mod + O` |
| 保存场景 / 场景另存为 | `mod + S` / `mod + shift + S` |
| 撤销 / 重做 | `mod + Z` / `mod + shift + Z`（或 `mod + Y`） |
| 复制实体 | `mod + D` |
| 复制 / 剪切 / 粘贴 | `mod + C` / `mod + X` / `mod + V` |
| 删除 | `Delete` / `Backspace` |
| 全选 | `mod + A` |
| 选择 / 移动 / 旋转 / 缩放 / 矩形工具 | `Q` / `W` / `E` / `R` / `T` |
| 通用变换工具 | `Y` |
| 微移选择（Shift 为 ×10） | 方向键 |
| 框选当前选择 | `F` |
| 重命名 | `F2` |
| 运行 / 停止 | `F5` / `Esc` |
| 暂停 / 继续、重启 | `F6`、`shift + F5` |
| 运行时检查 | `F8` |
| 最大化 / 恢复场景视图 | `F11` |
| 打包项目… | `mod + shift + B` |
| 前往任意位置… | `mod + P` |
| 命令面板 | `mod + shift + P` |
| 内容抽屉 | `mod + Space` |
| 设置 | `mod + ,` |
| 界面放大 / 缩小 / 重置 | `mod + =` / `mod + -` / `mod + 0` |

## 命令面板

**前往任意位置**（`mod + P`）搜索文件、实体、面板、命令与设置；**命令面板**（`mod + shift + P`）在命令范围内打开它。结果显示命令的分类与快捷键；不可用的命令也会列出，但呈灰色。

## 键盘导航

- 菜单与右键菜单：方向键、按字母跳转、**Home** / **End**、`→` / `←` 进入或退出子菜单。
- 世界大纲：输入字母跳转到实体；方向键移动、折叠与展开。
- 内容浏览器文件夹树与瓦片调色板：方向键导航。
- 键盘焦点始终以焦点环显示。
