![场景视图中选中玩家时的通用变换工具：移动箭头、缩放方块与旋转环](@/assets/guides/zh/ed-gizmo.png)

*选中实体上的通用变换（**Y**）：移动箭头与中心平面、位于箭头末端外侧的缩放方块、旋转环。*

## 导航

| 操作 | 输入 |
|---|---|
| 平移 | 中键拖动，或 **Space** + 拖动 |
| 环绕 | 空间视图（透视或已旋转）中右键拖动，或任意视图中 **Alt** + 拖动。平面 2D 视图中右键拖动为平移。 |
| 缩放 | 鼠标滚轮，朝向光标 |
| 框选当前选择 | **F** |

## 选择

| 操作 | 输入 |
|---|---|
| 选择 | 单击 |
| 切换是否在选择中 | **Shift** + 单击 |
| 框选 | 在空白处拖动 |
| 取消拖动 / 清除选择 | **Esc** |

## 变换工具

| 工具 | 按键 | 手柄 |
|---|---|---|
| 选择 | `Q` | 仅拾取与框选。 |
| 移动 | `W` | 轴向箭头。空间视图另有 XY / YZ / ZX 平面手柄和屏幕平面中心；正视 2D 显示 X / Y 与中心平面。 |
| 旋转 | `E` | 轴向环；空间视图另有外圈屏幕轴环。正视 2D 显示 Z 环。 |
| 缩放 | `R` | 轴向方块；空间视图另有平面手柄与等比中心。正视 2D 显示双轴中心缩放。 |
| 矩形 | `T` | 选中精灵或 UI 节点自身的矩形手柄。 |
| 通用 | `Y` | 同时显示移动、缩放与旋转手柄。 |

Gizmo 行为：

- **通用工具的优先级。** 移动手柄优先于缩放方块，缩放方块优先于旋转环。缩放方块位于箭头末端外侧；拖动一个方块臂长使该轴缩放加倍。按下时确定的操作在整个拖动中保持不变。
- **平面手柄**朝向相机所在象限；侧对相机的平面被隐藏。世界空间平面拖动只改变其两个分量；局部空间使用旋转后的平面法线。空间视图的移动中心在按下时确定的、经过轴心且平行于相机的平面上拖动。
- **旋转。** 外圈绕按下时相机的前向轴旋转，与局部 / 世界设置无关。内圈使用绘制出的局部或世界轴。旋转经过各目标父坐标系换算。外圈吸附按主对象绕视线轴的扭转角取整。
- **悬停**高亮按下时将抓取的手柄并设置光标；不修改变换，也不开启撤销步骤。
- **设置 → 编辑器 → 视口 → Gizmo**：**变换手柄大小**（0.5–2，默认 1）缩放手柄及其命中区域；**淡化被遮挡的变换手柄**使几何体后方的空间手柄段变暗。两项均跨会话保存。

## 轴心模式

轴心按钮在 **中心 → 轴心 → 各自原点** 之间循环（也可通过**视图**菜单与命令面板选择）：

| 模式 | 旋转 / 缩放的基准 |
|---|---|
| 中心 | 选择集的几何中心。 |
| 轴心 | 活动对象的位置。 |
| 各自原点 | 每个目标自身的位置（在选择中心绘制一个手柄）。 |

各模式下平移相同。同时选中父子实体时，由父实体带动子树，子实体不会被重复变换。锁定的实体被排除。模式在拖动开始时确定。

## 复制与微移

- 每次拖动为一个撤销步骤；**Esc** 取消。
- 在选中对象的手柄上 **Alt** + 拖动会复制选择集并拖动副本。
- 方向键按一个网格步长微移；**Shift** 乘以 10。

## 对齐与分布

选中两个或以上实体时，场景视图工具栏中出现对齐按钮：左 / 中 / 右边缘与上 / 中 / 下边缘对齐。选中三个或以上时，另有两个分布按钮用于均分水平或垂直间距。每次操作为一个撤销步骤，适用于精灵、UI 节点和仅有 Gizmo 的实体。

![选中三个平台：场景视图工具栏中的对齐与分布按钮，选择中心的移动 Gizmo](@/assets/guides/zh/ed-align.png)

## 吸附

吸附下拉菜单用于启用吸附，并设置网格步长、旋转增量与缩放增量。

## 显示选项与 Gizmo

**显示**下拉菜单切换网格、Gizmo、物理形状与性能覆盖层，并设置世界 / 局部朝向与轴心模式。不渲染的实体——相机、灯光、碰撞体、关节、粒子发射器——在编辑模式下以 Gizmo 绘制（图标、视野矩形、灯光范围与锥角、碰撞体轮廓、关节锚点）。许多 Gizmo 带有可直接编辑组件字段的手柄（灯光半径、碰撞体尺寸、发射器形状、关节锚点）。

## 编辑模式

活动栏前四个图标选择编辑模式：**瓦片地图**、**UI**、**世界**、**场景**。模式跟随选择——选中 `Canvas` 或 `UINode` 时建议 UI 模式，选中 `TilemapLayer` 时建议瓦片地图模式——并切换工具与场景视图辅助，而不改变面板布局。单击模式图标或场景视图中的模式标签会打开其配套面板（UI 控件、瓦片调色板），并**固定**该模式，使选择变化不会离开它；再次单击取消固定。

## 设计分辨率与设备预览

场景以**设计分辨率**为参照创作（例如横屏 `1920 × 1080` 或竖屏 `750 × 1334`）。它是项目设置（**设置 → 项目 → 游戏 → 显示**），适用于所有编辑模式，无论有无 UI 画布。存在画布时，UI 还会按其缩放模式在框内布局。

| 控件 | 功能 |
|---|---|
| **设计分辨率**（工具栏，例如 `800×600`） | 设置设计分辨率并重新框选。存在画布时编辑画布，否则编辑项目值。可撤销。 |
| **设备**（未模拟设备时显示为 `Design`） | 选择目标屏幕（iPhone、iPad、1080p 等）。编辑模式下以黑边与安全区内边距绘制该屏幕的宽高比；运行模式下游戏在场景视图与游戏面板中按相同形状加黑边。不改变设计分辨率。 |
| **方向**（设备下拉菜单） | 交换设备的宽和高。选择 `Design` 时不可用。 |
| **相机适配**（设置 → 项目 → 游戏 → 显示） | 主相机如何缩放设计分辨率，与画布无关。`None`（默认）保持相机自身的 `orthoSize`；其他模式在所有设备上以相同方式加黑边，设备预览显示实际取景。 |

`Design` 表示不模拟：游戏填满面板的可用区域。选择设备后，编辑覆盖层与运行中的游戏都采用该设备的形状。

![在场景视图中运行的场景，按所选目标屏幕而非面板形状取景](@/assets/guides/zh/game-target-screen.png)

### 项目屏幕预设

**设置 → 项目 → 游戏 → 高级 → 屏幕预设**为打开该项目的所有人扩展或覆盖内置设备列表：

- **Id** —— 保存的选择通过它解析，应保持稳定。复用内置 id（`iphone`、`ipad`、`1080p`、`720p`）会替换该内置项。
- **尺寸** —— 与内置项一样以竖屏方向存储（宽 ≤ 高）。
- **安全区**（行展开项）—— 刘海与主屏指示条的内边距，以设备像素计。为零的内边距不写入项目文件。

![项目设置 → 游戏 → 显示 → 高级：Steam Deck 与 iPhone 15 Pro 两条屏幕预设](@/assets/guides/zh/settings-screen-presets.png)

预设存储在 `project.esproject` 中：

```json title="project.esproject"
{
  "screenPresets": [
    { "id": "steam-deck", "label": "Steam Deck", "width": 800, "height": 1280 },
    {
      "id": "iphone", "label": "iPhone 15 Pro", "width": 1179, "height": 2556,
      "safe": { "top": 59, "bottom": 34, "left": 0, "right": 0 }
    }
  ]
}
```
