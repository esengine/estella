---
title: 在编辑器中创作
description: AI 图的创作流程——创建 .esfsm 与 .esbt 资源，用已注册的名字填写叶子，并把资源指定给 StateMachineAgent 或 BehaviorTreeAgent。
---

状态机与行为树是数据：叶子逻辑在代码中注册一次（[动作与条件](/docs/zh-cn/gameplay/ai/actions/)），状态机与行为树作为资源在编辑器中构建与调整。

1. 在**内容浏览器**中，通过创建菜单的 **New State Machine** / **New Behavior Tree** 创建 `.esfsm` 或 `.esbt` 资源。双击即可打开节点图编辑器。
2. 添加状态或节点，拖动以连接，并用已注册的名字填写每个叶子的**动作**或**条件**。转移条件、触发器与黑板守卫在 Inspector 中设置。名字字段在输入时提示所有已注册的名字。
3. 在代理实体上，将 `StateMachineAgent.fsm` 或 `BehaviorTreeAgent.bt` 设为该资源的路径。

资源按路径引用并**随场景预加载**，因此图在代理首次 tick 前即已注册，无需调用 `registerFsm` / `registerBt`。由于两种形式都从同一注册表解析叶子，以状态机原型实现的敌人日后可以改用行为树（或两者并用），而无需修改动作与条件代码。
