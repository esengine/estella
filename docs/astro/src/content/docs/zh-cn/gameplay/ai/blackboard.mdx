每个状态机与行为树代理都拥有一个 **`Blackboard`**：私有的键值存储加上一次性触发器。动作与条件通过 `ctx.blackboard` 访问它。黑板上的值在叶子之间传递状态，并为转移守卫提供比较用的值。

```typescript
registerAction('takeDamage', (ctx) => {
  const hp = (ctx.blackboard.get<number>('health') ?? 100) - 10;
  ctx.blackboard.set('health', hp);
  if (hp <= 0) ctx.blackboard.fire('died');   // a transition keyed on 'died' fires once
});
```

| 方法 | 说明 |
|---|---|
| `get<T>(key)` / `set(key, value)` | 读取 / 写入值。 |
| `has(key)` / `delete(key)` | 检测 / 移除键。 |
| `fire(trigger)` | 触发一次性触发器；以其为键的转移在被执行前保持可用。 |
| `isFired(trigger)` / `consume(trigger)` | 检测 / 清除触发器。 |
| `clearTriggers()` | 清除所有待处理的触发器。 |

黑板的值支撑 FSM 转移的 `guard` 比较。触发器是边沿事件：触发一次，由执行它的转移消费。

## 从游戏代码访问

叶子之外的代码通过两个资源访问代理的黑板，也可在代理首次 tick 前预设值或触发触发器。黑板与实体同生命周期，且不会被序列化。

```typescript
import { AiFsm, AiBt } from 'esengine/ai';

const fsm = app.getResource(AiFsm);
fsm.blackboard(enemy).set('health', 100);
fsm.fire(enemy, 'alarm');          // consumed by the agent's next enabled transition
fsm.state(enemy);                  // active state name, or null before the first tick

const bt = app.getResource(AiBt);
bt.blackboard(enemy);              // a tree agent's blackboard
bt.status(enemy);                  // last root status
```

| 资源 | 成员 | 说明 |
|---|---|---|
| `AiFsm` | `blackboard(entity)` | 状态机代理的黑板。 |
| | `fire(entity, trigger)` | 在其上触发一个触发器。 |
| | `state(entity)` | 当前激活的状态名；首次 tick 前为 `null`。 |
| `AiBt` | `blackboard(entity)` | 行为树代理的黑板。 |
| | `status(entity)` | 最近一次根节点状态，或 `null`。 |
