游戏 AI 层使实体能够感知、决策与移动。它由四个部分组成，共享同一份具名动作与条件注册表：

| 部分 | 组件 | 说明 |
|---|---|---|
| [感知](/docs/zh-cn/gameplay/ai/perception/) | `Perceiver`、`PerceptionTarget`、`Perception` | 感知视野锥内最近的可见目标以及听觉范围内的声音，并把结果写入组件。 |
| [导航](/docs/zh-cn/gameplay/ai/navigation/overview/) | `NavAgent`、`NavVolume`、`NavLink`、`NavArea`、`NavObstacle` | 在格子网格或由几何烘焙的导航网格上把代理移动到世界坐标点，并随目标移动重新规划。 |
| [状态机](/docs/zh-cn/gameplay/ai/state-machines/) | `StateMachineAgent` | 运行 `.esfsm` 图：带进入/更新/退出钩子的状态与带守卫的转移。 |
| [行为树](/docs/zh-cn/gameplay/ai/behavior-trees/) | `BehaviorTreeAgent` | 运行 `.esbt` 图：选择器、序列、装饰器与叶子。 |

状态机与行为树是同一组构件之上的两种创作形式。动作与条件在代码中按名称注册一次（[动作与条件](/docs/zh-cn/gameplay/ai/actions/)）；使用它们的图是在编辑器中创作的资源（[在编辑器中创作](/docs/zh-cn/gameplay/ai/authoring/)）。感知为决策提供输入，决策设置导航目标。

## 安装

AI 层是 `esengine/ai` 子路径中的 TypeScript 代码，没有 WebAssembly 侧模块。导入 `esengine/ai` 即注册感知、状态机、行为树与导航插件；编辑器与 Web 运行时会把它们加入应用。从裸 `new App()` 构建的应用需显式添加（[自定义应用](/docs/zh-cn/gameplay/ai/advanced/#自定义应用)）。

注册函数（`registerAction`、`registerCondition`、`registerValue`、`aiRegistry`）也从主 `esengine` 入口导出。

## 示例

[`enemy-ai` 示例](https://github.com/esengine/estella/tree/master/examples/enemy-ai)中有两个共享同一套感知与叶子的敌人；一个由状态机驱动，另一个由行为树驱动：

```typescript
import { defineSystem, Res, registerAction, registerCondition } from 'esengine';
import { Nav, NavGrid, setNavDestination, Perception } from 'esengine/ai';

// Shared leaves — the same names serve BOTH the .esfsm and the .esbt.
registerCondition('seesPlayer', (ctx) => ctx.has(Perception) && ctx.get(Perception).visible);
registerCondition('lostPlayer', (ctx) => !ctx.has(Perception) || !ctx.get(Perception).visible);

registerAction('chase', (ctx) => {
  if (!ctx.has(Perception)) return;
  const per = ctx.get(Perception);
  if (per.visible) setNavDestination(ctx.world, ctx.entity, { x: per.targetX, y: per.targetY });
});
registerAction('patrol', () => { /* hold position until the player is seen */ });

// One open nav grid over the arena.
export const setupNavGrid = defineSystem([Res(Nav)], (nav) => {
  nav.setSurface(new NavGrid({ width: 60, height: 44, cellSize: 20, origin: { x: -600, y: -440 } }));
}, { name: 'SetupNavGrid' });
```

两个敌人的 `StateMachineAgent.fsm` 与 `BehaviorTreeAgent.bt` 分别指向 `enemy.esfsm` 与 `enemy.esbt`，它们在编辑器中创作并随场景加载。感知、FSM 与 BT 的 tick 以及路径跟随都是内建的；游戏代码只包括共享的叶子与网格设置。

<Aside type="note">
  [`Hunter`](/docs/zh-cn/gameplay/ai/hunter/) 是现成的 3D 近战敌人，无需状态机或行为树即可组合感知、导航与 `MeleeAttack`。
</Aside>
