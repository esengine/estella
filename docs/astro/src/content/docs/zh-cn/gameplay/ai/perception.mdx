---
title: 感知
description: "Perceiver 在视锥内感知附近目标,并把看到的写进 Perception 组件。"
---

`Perceiver` 每帧扫描最近的、可见的 `PerceptionTarget`,把结果写进同一实体上的 `Perception`
组件(实体上没有时会自动加一个)。`Perceiver` 不会感知自己。决策读 `Perception`;感知只是 ECS 数据,
而不是一条旁路。这一步在 `PreUpdate` 里运行、只在运行模式下执行,所以决策系统同一帧就能读到新结果。

![Perceiver 及其 Perception 的 Details:范围、视野、朝向轴和视线层](@/assets/guides/zh/details-perceiver.png)

***Perceiver**(上)和它写入的 **Perception**(下,运行前是关闭的)。*

```typescript
import { Perceiver, PerceptionTarget, Perception } from 'esengine/ai';

// 猎手负责感知……
cmds.spawn()
  .insert(Transform, { position: { x: -200, y: 0, z: 0 } })
  .insert(Perceiver, { range: 260, fovDegrees: 120 })
  .insert(Perception, {});          // 由感知插件每帧写入

// ……任何被标记为目标的实体。
cmds.spawn()
  .insert(Transform, { position: { x: 100, y: 0, z: 0 } })
  .insert(PerceptionTarget, {});
```

| 组件 | 字段 | 默认 | 说明 |
|---|---|---|---|
| **`Perceiver`** | `range` | `220` | 视野范围(世界像素)。 |
| | `fovDegrees` | `360` | 视野锥角度,范围 `0`–`360`(`360` = 全向)。 |
| | `facingAxis` | `'x'` | 视野锥沿实体自身哪根轴指向:`'x'` 是屏幕右方(平面场景),`'-z'` 是导入 3D 模型的朝向。 |
| | `losLayers` | `0` | 仅 3D:视线射线可命中的物理层(`0` = 所有层)。 |
| **`Perception`** | `visible` | `false` | 当前是否看见一个目标。 |
| | `distance` | `0` | 到所见目标的距离。 |
| | `targetX`、`targetY`、`targetZ` | `0` | 所见目标位置(世界像素)。 |
| | `dirX`、`dirY`、`dirZ` | `0` | 从观察者指向目标的单位方向。 |
| **`PerceptionTarget`** | *(标签)* | — | 把实体标记为可被 `Perceiver` 感知。 |

感知是三维的(平面场景只是 `z` 恒定的特例),所以视野锥和距离在 3D 场景里同样适用。
视野锥的朝向由感知者的 `Transform` 旋转沿 `facingAxis` 决定。场景里有物理世界时,
视线射线会对它投射,墙体因此能挡住视线:有 3D 求解器就用 3D 的,否则用 2D 的;两者都没有时,
感知只做距离 + 视野锥。`Perception` 是一个瞬态、仅运行时的组件——
插件每帧重写它,所以你从不需要手写它的值。
