蒙皮角色上的 `Ragdoll` 在 `active` 置位期间把骨骼变为由关节连接的刚体，清除后把姿态交还给动画。它读取角色已有的骨架（蒙皮网格引用的关节），无需其他创作。

```typescript
world.insert(enemy, Ragdoll, { active: false });
// When it is knocked down:
world.insert(enemy, Ragdoll, { ...world.get(enemy, Ragdoll), active: true });
```

## 行为

- 每根足够长的骨骼沿骨骼方向获得一个盒体，并以摆动/扭转关节连接到最近的、带刚体的祖先骨骼。刚体从该帧动画的姿态开始。动画在下层继续运行；刚体的姿态每帧覆盖其上。
- **限位。** 使用 `Humanoid` 配置时，每个关节按其在身体中的部位获得相应比例的 `swing` 与 `twist`，部位由骨骼名称判断：脊柱较僵硬，肩部较松，小腿接近铰链。膝盖与手肘是单向铰链，最大弯曲 `bend` 度：小腿向后折，前臂向前折，方向由 `facing` 确定。`Uniform` 配置给所有关节相同的限位。
- **恢复。** 清除 `active` 后，在 `recoverTime` 秒内从刚体的最后姿态混合到动画姿态。
- **编辑器预览。** 在编辑器中选中布娃娃，会依据骨架当前姿态显示将生成的盒体与关节限位。

布娃娃是被动的：没有任何东西驱动肢体。

## `Ragdoll`

| 属性 | 默认值 | 说明 |
|---|---|---|
| `active` | `false` | 角色是否瘫软。角色被击倒时置位；清除以使其站起。 |
| `skin` | `0` | 持有蒙皮网格的实体；`0` 先在本实体、再在其下查找。 |
| `profile` | `Humanoid` | `Uniform` 或 `Humanoid`（`RagdollProfile`）。 |
| `swing` | `100` | 肢体可偏离骨骼方向摆动的角度，度。使用 `Humanoid` 时为松弛关节（肩、髋）可获得的最大值。 |
| `twist` | `60` | 肢体可绕自身方向扭转的角度，度。使用 `Humanoid` 时为松弛关节可获得的最大值。 |
| `bend` | `130` | 膝盖或手肘单向弯曲的最大角度，度。`0` 表示将其视为普通摆动/扭转关节。仅 `Humanoid`。 |
| `facing` | `+Z` | 角色朝向所沿的自身轴（`RagdollFacing`：`+Z`、`-Z`、`+X`、`-X`）；用于区分弯曲的膝盖与过伸的膝盖。 |
| `thickness` | `0.25` | 肢体厚度占其长度的比例。 |
| `minBoneLength` | `0.05` | 短于该长度的骨骼（手指、脚趾）不获得自己的刚体，由父骨骼承载。 |
| `friction` | `0.5` | 肢体刚体的摩擦。 |
| `recoverTime` | `0.4` | 从瘫软姿态混合回动画的秒数。 |

## `RagdollJoint`

骨骼实体上的 `RagdollJoint` 覆盖该骨骼的设置。

| 属性 | 默认值 | 说明 |
|---|---|---|
| `body` | `true` | 该骨骼是否获得自己的刚体。`false` 时由上方骨骼承载。 |
| `custom` | `false` | 使用下列限位而非配置给出的限位。 |
| `swing` | `70` | 摆动限位，两个方向各若干度。 |
| `twist` | `40` | 扭转限位，两个方向各若干度。 |
| `bend` | `0` | 单向弯曲限位，度；`0` 为普通摆动/扭转关节。 |
| `fold` | `0` | 骨骼名称未指明时的弯曲方向：`0` 按名称判断，`1` 朝向角色朝向，`-1` 背离角色朝向。 |
