**脚本图**是以节点与连线创作在 `.esgraph` 资源中的玩法逻辑，由实体上的 `ScriptGraphAgent` 运行。它的叶子与[状态机和行为树](/docs/zh-cn/gameplay/ai/actions/)所用的已注册**动作**与**条件**相同。它适合简短的事件驱动逻辑：开始时生成一个物体；按键时按条件分支。

`.esgraph` 文件即运行时定义。它不会预先编译，因此编辑器运行的图与包中发布的图是同一份数据。

## 创建与运行脚本图

1. 在**内容浏览器**中选择 **New → New Script Graph**。资源在文档标签页中打开；双击 `.esgraph` 可重新打开。
2. 右键单击画布添加一个事件，然后连接它所触发的节点。
3. 在运行该图的实体上添加 **`ScriptGraphAgent`** 组件，并将其 `graph` 字段设为该资源。

资源按路径引用并随场景预加载，因此在代理首次 tick 之前即已就绪。脚本图在 **Play** 与导出的游戏中运行，位于 `Update` 调度，与状态机解释器并列。

## 连线

| 连线 | 携带 | 方向 |
|---|---|---|
| **Exec**（控制） | “执行下一个” | 推送：事件激活其入口节点，沿连线深度优先执行。 |
| **Data**（number、boolean、string、entity、any） | 一个值 | 拉取：节点运行时沿连线向后求值其输入。 |

连线只连接兼容的类型。没有连线接入的输入持有在节点上输入的**字面量**。

执行顺序遵循图的结构：**Sequence** 节点先完成引脚 0 的整条链，再开始引脚 1。为同一节点的两个引脚提供数据的纯节点（无 exec 引脚）在每次激活中只求值**一次**，因此两个引脚看到相同的值；下一次激活会重新求值，这使 **While** 的条件可以变为假。

## 节点

工具栏中的 **Node** 按钮或右键单击画布会按分组列出节点：

| 分组 | 节点 |
|---|---|
| **Events** | **Start**、**Every frame**、**Destroy**、**On event**（具名实体事件）。每个都是入口点；一个图可以有多个。 |
| **Flow** | **Branch**、**Sequence**（引脚数量可配置）、**While**、**Delay**。 |
| **Variables** | **Get variable**、**Set variable**。 |
| **Values** | **Number**、**Boolean**、**String** 字面量。 |
| **Actions** | 带 exec 引脚的节点：`timeline.play` / `timeline.pause`、`spriteAnim.play` / `restart` / `stop`、`audio.play` / `stop`、`soundEvent.trigger` / `stop`、`property.set`、`entity.spawn`（在 x / y 处生成指定预制体，可选父级，并输出新实体）、`entity.despawn`、`debug.log`、`scene.load` / `reload`、`ui.setVisible`、`ui.setPage`、`fsm.fire`、`blackboard.set`，以及代码中注册的所有动作。 |
| **Queries** | 仅输出值的节点（无 exec 引脚）：`math.*`（add、subtract、multiply、divide、min、max、abs、clamp、lerp、random）、`compare.*`（equal、less、greater）、`logic.*`（and、or、not）、`string.concat`、`property.get`、`entity.self`、`entity.byName`、`input.down` / `pressed` / `axis` / `pointer`，以及所有已注册的条件。 |
| **Graphs** | 项目中所有其他可调用的图，通过 **Call graph** 节点调用（在有图声明输入之前为空）。 |

节点细节：

- **Every frame** 输出 `dt`，即帧间隔（秒）。
- **On event** 按类型监听实体事件（例如[触发区](/docs/zh-cn/gameplay/markers/#触发区)的 `trigger_enter`，或按钮的 `click`），并输出 `target`（事件发送到的实体）与 `other`（事件提及的另一个实体，例如接触的另一方；没有时为 `0`）。选中该节点后，Details 显示其 **Type** 与 **Inputs**：每个输入是一个名称与类型（`number`、`bool`、`string`、`entity` 或 `any`），并成为一个引脚，携带事件或其 `payload`（如时间轴事件）中的对应字段，转换为该类型；事件没有该字段时为该类型的零值。图文件把这些输入存为节点的 `payload` 字面量，即以逗号分隔的 `name:type` 对。
- **Sequence** 有 1–16 个引脚（默认 2 个）。**While** 有 `body` 与 `done` 引脚。
- **Delay** 等待 `seconds` 后继续。进入已在计时的 Delay 不产生任何效果，因此频繁的调用者无法使其重新开始。被其他图调用的图不能包含 Delay（一次调用在一步内完成）；图会将其报告为问题。

菜单按注册名称列出动作与条件；放置后的节点显示可读标题（**Find entity by name**、**Key pressed**、**Set property** 等），注册名称显示在其下方。

用 `registerAction` / `registerCondition` 注册的动作或条件会以其声明给出的端口出现。文件只存储名称，因此已有的图会按当前声明重绘，不会保留声明中已不存在的端口。

**Arrange** 按数据流从左到右排列节点。节点位置仅用于编辑器，运行时忽略。

## 变量

画布旁的面板分为 **Inputs**、**Outputs** 与 **Variables** 三部分，各有计数、**Add** 按钮与搜索，每一项都显示其被读取与写入的次数（或 *unused*）。

- 在 **Variables** 下 **Add** 声明一个带默认值的类型化变量。变量由资源声明、按实体取值：运行同一图的两个实体各自保有自己的值。
- 将变量拖到画布上会询问创建 **Get** 还是 **Set**；按住 `Ctrl/⌘` 创建 Get，按住 `Alt` 创建 Set。
- 在变量所在行重命名或修改其类型。删除仍被节点使用的变量会先请求确认，并把这些节点留在画布上、不再关联变量。

## 可调用图

图在 **Inputs** 下声明一项（输入引脚）或在 **Outputs** 下声明一项（输出引脚）后即成为**可调用**图。其他图通过 **Call graph** 节点运行它，传入值并读回结果。签名属于被调用方；修改签名会重绘所有调用方。

调用在调用方的一步之内**同步执行至完成**。每个调用点为被调用方保留独立的帧，被调用方消耗调用方的步数预算，嵌套深度有上限。

## 执行限制

| 限制 | 值 | 行为 |
|---|---|---|
| 每次 tick 的步数 | 4096（`DEFAULT_STEP_BUDGET`） | 每次节点激活消耗一步。超出预算的图（例如永不为假的 **While**）会停止，指出耗尽预算的节点，并保持停止状态。 |
| 调用深度 | 16（`MAX_CALL_DEPTH`） | 更深的调用（包括通过循环调用自身的图）会停止并报告问题。 |

对不存在的图、预制体或动作的引用只报告一次，而不是每帧报告。

## 在代码中注册

图也可以不经资源直接注册：

```typescript
import { registerScriptGraph, ScriptGraphAgent } from 'esengine/logic';

registerScriptGraph('door-open', graphData); // a ScriptGraph object

cmds.spawn().insert(ScriptGraphAgent, { graph: 'door-open' });
```

`ScriptGraphAgent.graph` 接受注册名称或 `.esgraph` 路径。
