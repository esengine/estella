import { Tabs, TabItem, Steps, Aside } from '@astrojs/starlight/components';

<Tabs>
  <TabItem label="使用编辑器">
    <Steps>

    1. 从[下载页](https://estellaengine.com/#download)获取最新版编辑器——Windows 与
       macOS（Apple 芯片），走项目自己的镜像。每个版本的发布说明与校验和也都在
       [发布页](https://github.com/esengine/estella/releases)。

    2. 安装并打开，点击 **New project**（新建项目）。

    3. 选一个模板——**Blank** 起始模板，或随附的 **Examples** 示例项目——填写项目
       名称与位置，点击 **Create project**（创建项目）。选 Blank 时，编辑器会打开
       一个带有相机实体的默认场景。

    </Steps>

    <Aside type="tip">
      **帮助 → 检查更新…** 会在编辑器内下载更新，并在重启时安装；下载源与上面的安装包
      同为镜像（`dl.estella.games`），镜像没答案或答案更旧时回落 GitHub —— 「有没有
      新版本」始终以源站为准。无法自行安装更新的版本，则仍旧只给出下载链接。
    </Aside>

    <Aside type="note">
      安装包目前尚未签名，因此首次启动时 Windows SmartScreen 或 macOS Gatekeeper
      可能提示「未知开发者」——请选择**仍要运行**，或在**系统设置 → 隐私与安全性**中
      放行。
    </Aside>
  </TabItem>

  <TabItem label="从源码构建">
    环境要求：

    - **Node.js** ≥ 18 与 **pnpm** ≥ 8
    - **Emscripten** 5.0.0（需精确版本，与 CI 对齐）

    <Steps>

    1. 克隆（带子模块）并安装依赖：

       ```bash
       git clone --recursive https://github.com/esengine/estella.git
       cd estella
       pnpm install
       pnpm emsdk:setup   # 一次性：把 Emscripten 5.0.0 装进 tools/emsdk
       ```

    2. 构建引擎、SDK 并同步到编辑器：

       ```bash
       node build-tools/cli.js build -t all
       ```

    3. 运行编辑器：

       ```bash
       cd desktop && pnpm dev
       ```

    </Steps>

    完整构建说明见
    [CONTRIBUTING.md](https://github.com/esengine/estella/blob/master/CONTRIBUTING.md)。
  </TabItem>
</Tabs>
