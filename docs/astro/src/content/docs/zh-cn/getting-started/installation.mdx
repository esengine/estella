  <TabItem label="编辑器">
    <Steps>

    1. 从[下载页](https://estellaengine.com/#download)下载编辑器（Windows；macOS 仅支持 Apple 芯片）。所有版本及其发布说明和校验和也可在[发布页](https://github.com/esengine/estella/releases)获取。

    2. 安装并启动编辑器，选择 **新建项目**。

    3. 选择模板，填写项目名称与位置，选择 **创建项目**。**空白（Blank）** 模板打开的场景只包含一个 Camera 实体。

    </Steps>

    *启动器 → 新建项目。起步模板在前，随后是内置示例。*

    <Aside type="tip">
      **帮助 → 检查更新…** 在编辑器内下载更新并在重启时安装，下载源与安装包相同（`dl.estella.games`）；镜像不可用或版本落后时回退到 GitHub。无法自更新的构建会改为提供下载链接。
    </Aside>

    <Aside type="note">
      安装包目前未签名。首次启动时 Windows SmartScreen 或 macOS Gatekeeper 可能提示开发者未知，可通过 **仍要运行** 或 **系统设置 → 隐私与安全性** 放行。
    </Aside>
  </TabItem>

  <TabItem label="源码构建">
    环境要求：

    - **Node.js** ≥ 18 与 **pnpm** ≥ 8
    - **Emscripten** 5.0.0（精确版本，与 CI 一致）

    <Steps>

    1. 连同子模块克隆并安装依赖：

       ```bash
       git clone --recursive https://github.com/esengine/estella.git
       cd estella
       pnpm install
       pnpm emsdk:setup   # 一次性：把 Emscripten 5.0.0 安装到 tools/emsdk
       ```

    2. 构建引擎与 SDK，并同步到编辑器：

       ```bash
       node build-tools/cli.js build -t all
       ```

    3. 启动编辑器：

       ```bash
       cd desktop && pnpm dev
       ```

    </Steps>

    完整构建说明：[CONTRIBUTING.md](https://github.com/esengine/estella/blob/master/CONTRIBUTING.md)。
  </TabItem>
</Tabs>

## 命令行创建项目

命令行使用与编辑器新建项目页相同的模板，适用于脚本化与无界面环境：

```bash
node pipeline/bin/estella.mjs templates                          # 列出模板与示例
node pipeline/bin/estella.mjs create 3d-starter ./my-game --name "My Game"
node pipeline/bin/estella.mjs export ./my-game                   # 不经编辑器的 Web 构建
```

`create` 复制模板、设置项目名称，并添加 `package.json` 与 `.gitignore`。在编辑器中打开一次项目会生成其 `tsconfig.json` 引用的 SDK 类型声明；导出不需要这一步。
