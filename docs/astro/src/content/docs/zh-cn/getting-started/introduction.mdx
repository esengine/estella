Estella 是一款 **2D 与 3D 游戏引擎**。游戏代码基于 TypeScript SDK 编写；引擎内核（ECS 存储、渲染器、资源、物理、粒子、瓦片地图、文本）以 C++ 实现，编译为 WebAssembly，移动端编译为原生 arm64。可视化编辑器负责场景创作、资源管理与构建。同一项目可导出到 **Web、桌面、微信及其他小游戏平台、单文件试玩广告，以及原生 Android / iOS 应用**。

## 特性

| 方面 | 说明 |
|---|---|
| 运行时 | C++ 内核编译为 WebAssembly（Web），或编译为 arm64 并内嵌 WebGPU 实现（Android / iOS，不使用 WebView）。 |
| 编程模型 | 实体-组件-系统（ECS）。TypeScript API：`defineComponent`、`defineSystem`、`defineBehavior`、`Query`。 |
| 编辑器 | 场景层级、检视器、内容浏览器、资源编辑器、运行模式、构建流程。场景以可视化方式编辑，而非编辑 JSON。 |
| 目标平台 | Web、桌面、微信及其他小游戏平台、试玩广告、Android、iOS。 |
| 功能 | 2D 与 3D 物理、带 PBR 材质的 glTF/FBX 模型、光照、地形与水体、瓦片地图、粒子、2D 光照、骨骼与 2D 动画、Spine、音频、UI、玩法 AI。 |

## 架构

| 层 | 职责 |
|---|---|
| **TypeScript SDK**（`esengine`） | 创作接口：`App`、`World`、系统、组件、查询、插件。 |
| **WasmBridge** | SDK 与引擎之间唯一的边界，内存布局由生成代码定义并经哈希校验。 |
| **C++ 内核** | ECS 存储、渲染器（`GfxDevice`）、资源、粒子、瓦片地图、文本。编译为 WebAssembly，[移动端](/docs/zh-cn/publishing/android-ios/)编译为 arm64。 |

完整架构说明：[`ARCHITECTURE.md`](https://github.com/esengine/estella/blob/master/docs/ARCHITECTURE.md)。
