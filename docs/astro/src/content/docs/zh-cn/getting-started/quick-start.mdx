import { Steps, Aside } from '@astrojs/starlight/components';

本流程创建一个包含单个实体、可用方向键移动的项目。使用 **空白（Blank）** 模板（只含一个 Camera 的场景）与 `ShapeRenderer`，无需任何美术资源。

## 步骤

<Steps>

1. **创建项目。** 启动器 → **新建项目** → **空白** → **创建项目**。编辑器打开 `assets/scenes/main.esscene`，其中只有一个 `Camera` 实体。

2. **添加实体。** *世界大纲 → 添加 → 创建实体… → Rendering → Shape*。新实体带有 `Transform` 与 `ShapeRenderer`（原点处 100 × 100 的白色圆形）。将其重命名为 `Player`（**F2**）。

   ![创建 Shape 后的编辑器：原点处的白色圆形，世界大纲中的 Player，细节面板中的 Transform 与 Shape Renderer](@/assets/guides/zh/gs-shape.png)

3. **声明行为。** 将 `src/components.ts`（空白模板的声明入口）的内容替换为：

   ```typescript title="src/components.ts"
   import { defineBehavior, Transform } from 'esengine';

   export const Player = defineBehavior('Player', {
     state: { speed: 300 },
     update(ctx, dt) {
       const x = (ctx.input.isKeyDown('ArrowRight') ? 1 : 0) - (ctx.input.isKeyDown('ArrowLeft') ? 1 : 0);
       const y = (ctx.input.isKeyDown('ArrowUp') ? 1 : 0) - (ctx.input.isKeyDown('ArrowDown') ? 1 : 0);
       if (x === 0 && y === 0) return;

       const t = ctx.get(Transform);           // 副本：Transform 存储在引擎中
       t.position.x += x * ctx.self.speed * dt;
       t.position.y += y * ctx.self.speed * dt;
       ctx.set(Transform, t);                  // 写回副本
     },
   });
   ```

   保存后，编辑器从该模块重新提取组件结构并注册 `Player`。

4. **挂载组件。** 选中 `Player`，*细节 → 添加组件 → Player*。`state` 中的字段显示为可编辑属性。

   ![Player 的细节面板：Transform、Shape Renderer，以及 Speed 为 300 的 Player 卡片](@/assets/guides/zh/gs-player-component.png)

5. **运行。** **F5** 进入运行模式，方向键移动实体；**Esc** 停止。运行模式在独立的世界中执行，不会修改正在编辑的场景。

   ![运行模式：场景视图带绿色边框，大纲与细节显示运行中的世界](@/assets/guides/zh/gs-play.png)

</Steps>

## 说明

- **`defineBehavior` 同时注册组件与系统。** `update` 钩子作为系统，作用于所有带该组件的实体；因此 `Player` 无需额外声明即可出现在添加组件列表中。
- **`state` 即组件数据。** 在细节面板中编辑的值就是系统读取的值；代码与检视器访问的是同一字段。
- **`ctx` 是实体在当前帧的视图。** `ctx.self` 为实体的组件状态，`ctx.input` 为输入状态，`dt` 为以秒计的帧时长。乘以 `dt` 使 `speed` 成为以单位/秒计的速率。

<Aside type="caution">
  对 TypeScript 中声明的组件，`ctx.get` 返回存储的对象本身；但引擎组件（`Transform`、`Sprite`、`RigidBody2D` 等）每次读取都从 WebAssembly 堆解码，修改返回值而不调用 `ctx.set` 不会生效。见[脚本](/docs/zh-cn/scripting/overview/)。
</Aside>
