三个 API 都生成普通的纹理句柄，可用作 `Sprite.texture`、用于 `Draw.texture`，或作为材质的纹理参数。

| API | 内容 |
|---|---|
| `RenderTexture` | 在 `begin` / `end` 之间绘制的内容，或某台相机看到的场景。 |
| `TextureAtlas` | 自动打包到一张画布上的多张纹理。 |
| `TextureCanvas` | 按调用方给定位置贴入的纹理。 |

## 离屏目标：`RenderTexture`

`RenderTexture.create` 分配一个离屏渲染目标。在 `begin` 与 `end` 之间发出的绘制命令渲染到其中，使用调用方提供的 view-projection 矩阵。

```typescript
import { RenderTexture, Draw } from 'esengine';

const rt = RenderTexture.create({ width: 256, height: 256, filter: 'linear' });

RenderTexture.begin(rt, viewProjection);   // 正交 view-projection
Draw.circle({ x: 0, y: 0 }, 80, { r: 1, g: 0.5, b: 0, a: 1 });
RenderTexture.end();

sprite.texture = rt.texture;
```

`begin` / `end` 只重定向绘制，不渲染场景。

### 把相机渲染到目标

把 `Camera.renderTarget` 设为目标的渲染目标句柄（`rt._handle`，而不是 `rt.texture`）后，该相机渲染到目标而不是屏幕。

- 目标相机在屏幕相机之前渲染，不参与主视图的竞争。
- `Camera.cullingMask` 选择相机可见的排序层，因此小地图相机与玩家相机可以显示同一世界的不同部分。
- 渲染目标在两个后端上都可显示在 `Sprite` 上。该路径的像素验证仅在 WebGL2 上运行；在 WebGPU 上，一帧同时包含离屏通道与屏幕通道时，帧回读返回空。

### `RenderTextureOptions`

| 字段 | 默认值 | 说明 |
|---|---|---|
| `width` / `height` | — | 目标像素尺寸（必填）。 |
| `depth` | `true` | 附加深度缓冲。纯 2D 合成可关闭以节省内存。 |
| `filter` | `'nearest'` | 结果的采样过滤：`'nearest'` 或 `'linear'`。 |
| `floatColor` | `false` | 请求可混合的半精度浮点颜色目标，用于线性辐射度或数据。 |

### 方法

| 方法 | 作用 |
|---|---|
| `create(options)` | 分配目标。返回的句柄含 `texture`（供组件使用的资源表句柄）、`textureId`（底层路径使用的设备 id）、`width`、`height`。 |
| `begin(rt, viewProjection, { data? })` | 把后续绘制重定向到目标。`data: true` 把绘制内容作为数据存储，跳过项目的后期链（线性捕获、输出变换、曝光）。 |
| `end()` | 结束离屏渲染。 |
| `resize(rt, width, height)` | 释放并重建目标。返回新句柄；`texture` 句柄会改变。 |
| `getDepthTexture(rt)` | 以可采样纹理句柄返回深度附件。 |
| `contentLost(rt)` / `contentDrawn(rt)` | 自目标上次绘制以来设备是否重建（存储被清零）；重绘后用 `contentDrawn` 清除该标志。适用于只绘制一次的目标，例如烘焙遮罩。 |
| `release(rt)` | 释放目标及其纹理。 |

## 图集打包：`TextureAtlas`

共用同一纹理的精灵在一个批次中绘制。`TextureAtlas.pack` 在运行时把分别获得的纹理——来自服务器的图标、角色部件、玩家选择的图片——绘制到一张画布上，并给出每张的位置。

![底部四张彩色卡片是四个独立精灵，旁边画着它们被合进的那张画布（缩小）](@/assets/guides/zh/texture-atlas.png)

*每张卡片都是从同一画布切出的精灵（右侧小图为画布本身）。卡片左上角的白色方块与底边的深色条用于确认方向。*

```typescript
import { TextureAtlas } from 'esengine';

// 在 Schedule.Update 系统中调用：画布在独立的通道中绘制。
const atlas = TextureAtlas.pack([iconA, iconB, iconC], { padding: 2 });
if (!atlas) return;                      // 渲染器尚未就绪；下一帧重试

world.insert(entity, Sprite, { ...atlas.sprite(iconB), size: { x: 64, y: 64 } });
```

`sources` 是纹理句柄（即 `Sprite.texture` 中存放的值）。

| 成员 | 返回值 / 作用 |
|---|---|
| `atlas.sprite(source)` | 供 `Sprite` 使用的 `{ texture, uvOffset, uvScale }`。 |
| `atlas.get(source)` | 条目：像素矩形（`x`、自顶边起算的 `y`、`width`、`height`）及其 UV 窗口，或 `undefined`。 |
| `atlas.texture`、`atlas.width`、`atlas.height` | 画布纹理句柄与尺寸。 |
| `atlas.repaint()` | 从源纹理重绘画布（源纹理变化后）。 |
| `atlas.release()` | 释放画布。不影响源纹理。 |

| 选项 | 默认值 | 说明 |
|---|---|---|
| `maxSize` | `2048` | 尝试的最大画布边长（像素）。放不下时 `pack` 抛出异常。 |
| `padding` | `2` | 图片之间的透明像素，避免过滤时边缘采样到相邻图片。 |
| `filter` | `'linear'` | 画布采样方式：`'linear'` 或 `'nearest'`（像素画）。 |

行为：

- 画布取能容纳全部源纹理的最小 2 的幂尺寸，先加宽再加高。图片不经混合直接复制，透明度完整保留。
- 同一句柄传入两次只打包一次。
- 图集使用期间源纹理必须保持存活；图形设备丢失后，画布会自动由其重绘。
- 渲染器未就绪时 `pack` 返回 `null`；句柄没有尺寸时抛出异常。请在 `Schedule.Update` 系统中调用，而不是在绘制回调中。
- 与 `RenderTexture` 相同，在 `Sprite` 上显示画布的像素验证仅在 WebGL2 上运行。

[Render Texture 示例](https://github.com/esengine/estella/tree/master/examples/render-texture)构建了四张卡片并将其打包（`src/systems/atlas.ts`）。

## 按指定位置拼合：`TextureCanvas`

`TextureCanvas` 创建一张空白画布，把纹理贴到给定位置，例如由部件拼成的角色，或带图标与边框的卡片。结果显示在 `Sprite` 上。

```typescript
import { TextureCanvas } from 'esengine';

// 在 Schedule.Update 系统中调用：每次贴图都是一个独立的通道。
const canvas = TextureCanvas.create(256, 256);       // 空白、透明
if (!canvas) return;                                 // 渲染器尚未就绪；下一帧重试
canvas.draw(body, 96, 100);                          // (x, y) = 图片左上角
canvas.draw(head, 104, 46);
canvas.draw(head, 190, 20, 24, 24);                  // 可选的 width 与 height 用于缩放
world.insert(entity, Sprite, { texture: canvas.texture, size: { x: 512, y: 512 } });
```

| 成员 | 作用 |
|---|---|
| `TextureCanvas.create(width, height, { filter? })` | 透明画布；`filter` 为 `'linear'`（默认）或 `'nearest'`。渲染器未就绪时为 `null`。请在 `Schedule.Update` 系统中调用，而不是在绘制回调中。 |
| `canvas.draw(source, x, y, width?, height?)` | 以左上角位于 (`x`, `y`) 贴入 `source`，坐标以像素计、原点为画布左上角、y 向下。未给出 `width` 与 `height` 时按其自身尺寸绘制。后贴的按顺序混合在先贴的之上。 |
| `canvas.clear()` | 恢复透明并丢弃全部贴图记录。 |
| `canvas.release()` | 释放画布。不影响贴入的纹理。 |
| `canvas.texture`、`canvas.width`、`canvas.height` | 纹理句柄与尺寸。 |

- 贴入的纹理必须保持存活；图形设备丢失后，画布按原顺序由其重绘。
- 画布是普通纹理，显示时不加 `flipY`。
- 没有预定位置的图片，使用 `TextureAtlas.pack`。

[Texture Canvas 示例](https://github.com/esengine/estella/tree/master/examples/texture-canvas)用七次贴图拼出一个人物。

<Aside type="note">
  `TextureAtlas` 与 `TextureCanvas` 基于 `RenderTexture` 构建；每次绘制都在独立的通道中进行，因此二者都在 `Schedule.Update` 系统中调用，而不是在绘制回调中。
</Aside>
