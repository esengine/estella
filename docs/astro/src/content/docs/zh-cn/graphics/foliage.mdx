---
title: 植被
description: 一个 Foliage 组件,把草或网格散布到一片区域或地形上,按格子绘制,在风里摆动,并随距离变稀。
---

一片草地是几万根草叶,一片森林是几千棵树,没有哪个引擎会一个实体一个实体地画它们。`Foliage` 组件把它们按**格子**长出来:区域被切成方块,每个方块是一个包含全部植物的网格,所以一片草地是几百次绘制,剔除可以整块丢掉,每个格子又按它的距离该有的细节来构建。

## 组件

给某个实体加一个 `Foliage` 组件。区域以它为中心,它的子实体就是这些格子。格子是[程序化区块](/docs/zh-cn/world/streaming/#程序化区块):围绕流送源(没有流送源的游戏里是视点,编辑器场景视图里也是视点)生长到 `drawDistance`,由近及远,超出后连同网格一起释放,所以大片区域只保留看着它的东西附近的格子。字段、地面或水变化时重新生长,每个旧格子保留到新格子替换它为止。没有任何东西被烘焙。

| 字段 | 作用 |
|---|---|
| `mesh` | 要散布的植物。为空则长草,草叶在这里生成。 |
| `material` | 用 **Foliage** 着色器的材质,它负责风(见下)。为空则植物静止,用自己的颜色绘制。 |
| `sizeX`、`sizeZ`、`cellSize` | 区域,以及它被切成的格子的边长。 |
| `count`、`seed` | 每格的植物数,以及种子:换一个种子就在别处长出同样的植物。 |
| `minScale`、`maxScale` | 每棵植物的大小在这两者之间。 |
| `minUp`、`heightMin`、`heightMax` | 植物在哪里生长:一个地方最少要朝上多少(调低能让植物长上斜坡),以及一段世界高度范围。 |
| `waterDepth` | 植物能站在水下多深:`0`(默认)让它们只长在干地上,芦苇则站在浅水里。 |
| `bladeHeight`、`bladeWidth` | 只对草:缩放为 1 时一根草叶的大小。 |
| `lodDistance`、`drawDistance` | 超过前者,格子用它的远景版本绘制;超过后者就不画。 |
| `cardU0`、`cardV0`、`cardU1`、`cardV1` | 网格的远景版本是两张交叉的卡片,显示它纹理的这个矩形(`cardTent` 为 `1` 时卡片裁成帐篷形,即针叶树的轮廓,而不是矩形)。 |

如果场景里有 [Terrain](/docs/zh-cn/graphics/terrain/),植物就站在它上面,避开太陡的地方,并等它构建完;没有地形时,区域是实体所在高度的平地。

## 风

**Foliage** 着色器(`builtin:foliage`)按顶点颜色里画好的权重弯曲每个顶点(红色是它在植物上多高,所以根不动、尖端动;绿色是植物自己的相位,所以一片草地不会整体一起摆),再加一阵在世界上传播的阵风和叠在上面的颤动。参数在材质里:`u_windStrength`、`u_windSpeed`、`u_windDirection`(度)、`u_gustScale`(越小阵风越长)和 `u_flutter`。植物是双面的,并且让光透过(`u_translucency`);带 alpha 通道的叶子纹理(`u_albedo`、`u_useTexture`、`u_alphaCutoff`)能从一张卡片里抠出叶子的轮廓。

你自己的着色器也能读到同样的权重:顶点钩子(`#pragma vertexoffset`)里,顶点颜色是 `es_vertexColor`。

## 细节层级

每个格子构建两次。近处,草是每棵植物一根弯曲、渐细的草叶;远处,是三分之一的草叶,更宽而且更平。网格近处是完整的拷贝,远处是每棵植物两张交叉的卡片。引擎自己的[细节层级](/docs/zh-cn/performance/level-of-detail/)按格子覆盖多少屏幕在它们之间选择,超过 `drawDistance` 就把格子丢掉。

## 手摆植物

`Foliage` 按规则撒植物。美术搭好的场景里，每一棵都在美术放的位置，常常有几万棵，做成实体就是每棵一个变换、一个渲染器、一次绘制。**`PlacedFoliage`** 把它们当作数据存在一个实体里：一张 `kinds` 种类表和一份 `records` 记录。

| 字段 | 作用 |
|---|---|
| `sizeX`、`sizeZ`、`cellSize` | 区域（以实体为中心）和切成的格子边长。 |
| `kinds` | 每种植物由什么组成：`parts` 部件（`mesh` 网格、更省的 `lod1Mesh`、`material` 材质、`texture` 贴图、`tint` 色调、是否 `opaque`）；超过 `lodDistance` 换成更省的网格，超过 `drawDistance` 不再绘制；以及远景版本 `far` 部件，从 `drawDistance` 一直画到 `farDistance`。 |
| `records` | 每棵植物的位置：每棵六个数，种类序号、x、y、z（在实体空间里）、绕竖直轴的转角（弧度）、缩放。 |

镜头（或流式加载源）周围的格子会被生长出来，离开距离就释放。格子会立刻出现，之后的几帧里逐步填满：每个种类的每个部件占帧预算里很小一块，由近到远。每个部件是一个实体，画的是该部件的网格（所有格子共用这一份），摆在每棵植物所在的位置：**`MeshInstances`** 组件存着这些位置（每棵 64 字节），引擎逐棵按视野剔除，超过 `lodDistance` 的用更省的网格，超过 `drawDistance` 的不画。几何体不论多少棵都只有一份，网格和材质相同的绘制合成一次。网格保留美术做的所有通道（法线贴图、第二套 uv、顶点色），不会被覆盖，所以植物用普通材质绘制，而不是带风的材质。

远景版本就是层级细节（HLOD）：树的交叉卡片烘到自己的图集上，和植物本身一样是一组摆放位置，从 `drawDistance` 起画到离镜头 `farDistance`。它便宜到整个区域可以一次全部长出。没有远景版本的种类，超过 `drawDistance` 就不画。

没有自己卡片的种类可以拿更省的网格当远景版本,并设置 `farKeep`:远景版本画多少比例的植物(大于 0 到 1)。每 n 棵保留一棵,n 取最接近 1 / `farKeep` 的整数,保留下来的放大到原来的 n 的平方根倍(最多两倍),覆盖的地面面积不变。这样远处的地被只花近处一个比例的代价,其余由地面自己的纹理承担。

植物是直立、等比缩放的，记录里没有倾斜。`kinds` 里的路径是项目路径，列出来是为了让包带上它们。

## 在包里

植被和地形一样是可选模块:场景里有 `Foliage` 或 `PlacedFoliage` 组件,或脚本导入了 `esengine/foliage`,包里才会带上它。场景里有 `Terrain` 时植被立在地形上;平地上不需要地形模块。

## 限制

- **只有位置。** 区域被当作不旋转、不缩放;地形的位置和均匀缩放会被跟随,旋转不会。
- **没有碰撞,也没有交互。** 植物不会被角色压弯;风是唯一能让它们动的东西。
- **网格的远景版本是卡片,不是 impostor。** 它显示你指定的那个纹理矩形,从各个方向看都一样;纹理里没有这样一张图的树,卡片上就是它的纹理。
- **格子在每帧预算内生长**,由近及远,所以远处会在一小会儿内填满。
