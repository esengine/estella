植被按**格子**绘制：区域被划分为方块，每个方块是一个包含其全部植物的网格。一片草地只需几百次绘制调用，剔除可以整块丢弃，
每个格子按其距离所需的细节构建。

| 组件 | 作用 |
|---|---|
| `Foliage` | 按规则在区域内散布草或网格。 |
| `PlacedFoliage` | 将手工摆放的植物作为数据保存在一个实体中，以实例方式绘制。 |
| `FoliageContact` | 使植物对实体作出反应：草被分开，手摆植物倾斜、成为实体、可被砍伐或采集。 |
| `WindWake`、`WindBurst` | 用运动物体的尾流或扩散的压力前沿推动植物。 |

植被是可选模块（`esengine/foliage`）。场景包含 `Foliage` 或 `PlacedFoliage`，或脚本导入该模块时，包中才会带上它。场景中有
`Terrain` 时植物立于其上；立于平坦地面时不需要地形模块。

## 组件

为实体添加 `Foliage`。区域以实体为中心，其子实体为格子。格子是[程序化区块](/docs/zh-cn/world/streaming/#程序化区块)：围绕流送源
（没有流送源的游戏中为视点，编辑器场景视图中同样为视点）生长到 `drawDistance`，由近及远，超出后连同网格一起释放，因此大片
区域只保留观察者附近的格子。字段、地面或水变化时格子重新生长；每个旧格子保留到替代它的新格子就绪。不烘焙任何内容。

场景中有[地形](/docs/zh-cn/graphics/terrain/overview/)时，植物立于地形上，避开过陡的地面，并等待地形构建完成。没有地形时，区域为实体
高度处的平面。

### 植物

| 字段 | 说明 |
|---|---|
| `mesh` | 要散布的植物。留空则生成草叶。 |
| `material` | **Foliage** 着色器上的材质，提供风效。留空时植物静止，以自身颜色绘制。 |
| `minScale`、`maxScale` | 每株植物的缩放范围。 |
| `colorMap`、`colorMapStrength`、`colorMapFrom` | 覆盖区域、按位置为植物着色的纹理，按其 alpha 混入：同一网格和材质在不同位置可呈粉色或黄色。`colorMapFrom` 为植物上开始着色的高度（0 为整株；0.8 只着色顶点红色升至花瓣的网格顶部）。需要材质。每帧读取，修改不触发重新生长。 |
| `palette` | 一条颜色带，每株植物按自身编号取其顶部颜色：每种颜色在色带中的占比即其在植物中的占比。顶部从材质的 `u_tipFrom` 开始。需要材质。 |

### 放置

| 字段 | 说明 |
|---|---|
| `densityMap` | 红色通道表示植物密度的纹理：黑色为无，白色为全部 `count`。导入**用途**：数据。留空则处处生长。 |
| `scaleMap` | 红色通道表示植物尺寸的纹理：白色为完整尺寸，越黑越小，黑色为无。导入**用途**：数据。仅用密度图时边缘是参差的全高草丛；尺寸图使草在稀疏处逐渐变矮，边缘柔和。 |
| `minUp` | 地面法线向上分量的最小值。越低越允许植物长在斜坡上。 |
| `heightMin`、`heightMax` | 植物生长的世界高度范围。 |
| `waterDepth` | 植物可立于其中的最大水深。0（默认）只长在干地上；芦苇需调高。 |
| `zoneWorld`、`zoneTags`、`zonePadding` | 区域排除，见[预算与禁植区域](#预算与禁植区域)。 |

### 区域

| 字段 | 说明 |
|---|---|
| `sizeX`、`sizeZ` | 以实体为中心的区域尺寸。 |
| `cellSize` | 格子边长。每个格子是一个网格，整块剔除。 |
| `count` | **每个格子**的植物数。 |
| `seed` | 不同种子在不同位置长出同样的植物。 |

### 草

| 字段 | 说明 |
|---|---|
| `bladeHeight`、`bladeWidth` | 缩放为 1 时草叶的高度和底部宽度。 |
| `bladeLean` | 草叶尖端倾倒的程度，以其高度的比例表示，每片各朝一个方向（默认 0.12）。直立的草叶之间露出地面；倾倒的草叶将其覆盖。 |

### 距离与远景版本

| 字段 | 说明 |
|---|---|
| `lodDistance` | 格子切换到第一个远景版本的距离。 |
| `drawDistance` | 超过此距离格子不再绘制。植物在此之前逐株稀疏，因此草地没有边缘。 |
| `castShadows` | 格子是否投射阴影（默认开启）。密集矮草应关闭，避免每个格子在每级阴影级联中重绘；光照和接收阴影不受影响。 |
| `farLevels` | 远景版本数（1–3）。 |
| `farKeep` | 每个远景版本相对上一版本保留的植物比例（默认 0.34）。 |
| `farStep` | 每个远景版本接替距离相对上一版本的倍数（默认 2）。 |
| `farGrow` | 保留植物为覆盖被省略植物的地面而放大的上限（默认 2）。 |
| `farGrowUp` | 0–1。网格植物高度所取的放大比例（默认 0）。为 0 时保留植物只在地面方向变大（一簇花不比一朵花高）；为 1 时等比放大。草只变宽，不变高。 |
| `farTilt` | 远景版本中网格植物顶部十分之一（茎上的花头）倾斜的角度，每株方向各异（默认 0）。低视点看一片朝天的花是侧面；倾斜后半片花田露出花面。茎保持直立。 |
| `faceEyeNear`、`faceEye` | 0–1。网格植物头部（顶部十分之一）转向视点的程度：`faceEyeNear` 为近处，`faceEye` 为绘制距离一半以外，中间插值。大于 0 时，第二组 UV 携带每个头部顶点相对植物轴线的偏移，Foliage 着色器使头部绕其旋转。需要材质。 |
| `farCards` | 网格的远景版本为其纹理的交叉面片（开：树），或植物本身、数量更少尺寸更大（关：花、蕨类）。 |
| `cardU0`、`cardV0`、`cardU1`、`cardV1` | 交叉面片显示的纹理矩形（左、下、右、上）。 |
| `cardTent` | 面片轮廓：0 为矩形，1 为帐篷形（针叶树）。 |

每株植物都有自己的编号；植物随距离按编号稀疏，远景版本恰好保留其接替处仍在绘制的植物，因此切换时没有跳变。有材质时，每个
远景版本是单独一层格子，只生长到其绘制距离：完整的草甸只存在于视点附近，远处只有其中一部分。没有材质时，每个格子包含其所有
版本，由 `LODGroup` 选择其一，距离换算为其比较的屏幕尺寸。画质档位的 **细节距离** 缩放 `lodDistance` 和 `drawDistance`
（高 1、中 0.8、低 0.5）。

近处草为每株一片弯曲、渐细的草叶；远景版本使用更少、更宽的扁平草叶。网格在近处完整复制；开启 `farCards` 时，其远景版本为
每株两片交叉面片。

远处的草叶可能窄于一个像素，画面采样只落在其一部分上，远处草甸会断成虚线。Foliage 着色器以至少 `u_strandMinPx` 像素的宽度
绘制每片草叶（默认 1.2），并将其覆盖率降至实际宽度所占比例，因此开启多重采样时远处草叶逐渐淡出。0 保持草叶真实宽度。

## 预算与禁植区域

`count` 为**每个格子**的数量。在距离与地形剔除之前，700 × 700 的草地、35 单位格子、每格 750 株，共 400 个格子、至多 300 000
株植物。应同时评估密度（`count / cellSize²`）、格子数、近远距离和阴影通道。更大的格子减少提交次数，但剔除更粗。矮草可设置
`castShadows: false`。

存在 `WorldGen` 时，Foliage 遵循其排除区域：

| 字段 | 说明 |
|---|---|
| `zoneWorld` | 遵循其建筑和道路区域的 WorldGen 世界。留空使用第一个世界。 |
| `zoneTags` | 区域排除使用的额外标签，逗号分隔。自动包含 `foliage` 和 `grass`（网格为 `tree`）。 |
| `zonePadding` | 与区域之间的额外间距，世界单位。 |

用 `WorldZone` 盒体预留建筑地面、台阶和入口，用 `esengine/worldgen` 中 `roadZones` / `setRoad` 生成的区域预留道路。移动或删除
区域会使草地重新生长。没有 WorldGen 时草地忽略区域。

编辑器 MCP 工具 `audit_vegetation` 报告编写的上限和实时计数。测量前用 `step` 预热生成。`gpuDraws` 包含阴影及其他通道，
`drawCalls` 统计场景列表。后台窗口的空闲时间不能作为前台帧率测量。大型森林使用 `WorldRules.plants` 和 `PlacedFoliage`，
它们共享几何体并支持逐实例 LOD。

## 风

**Foliage** 着色器（`builtin:foliage`）按顶点颜色中绘制的权重弯曲每个顶点：红色为在植物上的高度（根部不动，尖端摆动），绿色为
每株植物的相位（使草甸不会整齐摆动）。一阵在世界中传播的阵风，再叠加颤动。

| 参数 | 说明 |
|---|---|
| `u_windStrength`、`u_windSpeed` | 弯曲量和风速。带 Wind 驱动的 `Weather` 会缩放 `u_windStrength`。 |
| `u_windDirection` | 风向，度。 |
| `u_gustScale` | 阵风尺度；越低阵风越长。 |
| `u_flutter` | 高频颤动。 |
| `u_translucency`、`u_translucencyColor` | 透过双面植物的光量及其颜色（叶片背光时比正面看起来更黄）。 |
| `u_specular` | 对阳光和天空的反射。 |
| `u_bladeFaceEye` | 草叶将其平面转向视点的程度，使其在侧视时不成为一条线。 |
| `u_albedo`、`u_useTexture`、`u_alphaCutoff` | 带 alpha 的叶片纹理，在面片上镂空出叶形。 |
| `u_rootOcclusion` | 到达植物根部的环境光比例，向尖端升至全部（默认 1：不减弱）。只减弱环境光和天光；太阳和其他光源不受影响。 |
| `u_tipFrom` | `palette` 颜色在植物上开始的高度。 |
| `u_strandMinPx` | 草叶最小像素宽度，见上文。 |

自定义着色器可读取相同权重：顶点钩子（`#pragma vertexoffset`）以 `es_vertexColor` 读取顶点颜色，以 `es_vertexUv1` 读取网格的
第二组 UV（没有时为零）；`faceEye` 请求时，后者携带每个头部顶点相对植物轴线的偏移。

## 手摆植物

`Foliage` 按规则散布植物。经过编排的场景中，每株植物都在美术放置的位置上，常常多达数万株；作为实体，每株都需要一个变换、一个
渲染器和一次绘制。**`PlacedFoliage`** 将它们作为数据保存在一个实体中：一张种类表 `kinds` 和一个记录列表 `records`。

| 字段 | 说明 |
|---|---|
| `sizeX`、`sizeZ`、`cellSize` | 以实体为中心的区域，以及格子边长。 |
| `kinds` | 植物种类，见下表。 |
| `records` | 每株六个数：种类索引，实体空间中的 x、y、z，绕竖直轴的旋转（弧度），以及缩放。 |
| `stateKey` | 存档保存这些植物状态时使用的名称。留空使用实体名。 |

| 种类属性 | 说明 |
|---|---|
| `parts` | 植物的部件：`mesh`、更省的 `lod1Mesh`、可选的更省的 `lod2Mesh`、`material`、`texture`、`tint`、`opaque`（混合部件为 false，在实体部件之后绘制）、可选的 `soft`（0–1，使法线朝上，让代表树冠的面片按圆形物体受光）和 `castShadows`（默认 true）。 |
| `lodDistance` | 超过此距离绘制 `lod1Mesh`。 |
| `lod2Distance` | 超过此距离绘制 `lod2Mesh`（默认 0：无）。 |
| `drawDistance` | 超过此距离不再以自身绘制该种类。 |
| `far`、`farDistance` | 远景部件（层级 LOD），从 `drawDistance` 绘制到 `farDistance`。 |
| `farKeep` | 远景版本绘制的植物比例，大于 0 至 1（默认 1）。 |
| `interaction` | 有物体接近时该种类的行为，见[触碰植物](#触碰植物)。 |

流送源（或视点）周围的格子随距离生长和释放。格子立即出现，在之后几帧内填满，每个种类和部件占用帧预算中的几微秒，由近及远。
每个部件是一个实体，在每株植物的位置绘制该部件的网格，所有格子共享：**`MeshInstances`** 组件保存位置（每株 64 字节），引擎对
每株植物做视锥剔除，超过各自距离时选择更省的网格，超过 `drawDistance` 时不绘制。无论植物多少，几何只存在一份，共享网格和材质
的绘制合为一次。网格保留所有编写的通道（法线贴图、第二组 UV、顶点颜色），不覆盖任何内容，因此植物使用普通材质而非 Foliage
风效着色器绘制。

远景版本即层级 LOD：树的交叉面片，烘焙到自己的图集，作为一组放置，从 `drawDistance` 绘制到 `farDistance`。它足够廉价，可以
同时绘制整个区域。没有远景版本的种类在 `drawDistance` 之外不绘制。

没有自己面片的种类可将更省的网格作为远景版本并设置 `farKeep`：每 n 株保留一株，n 为最接近 1 / `farKeep` 的整数，每株放大
√n 倍（最多两倍），使覆盖的地面不变。远处地被的开销因此只占近处的一部分，其余由地面纹理承担。

植物直立且等比缩放；记录不含倾斜。`kinds` 中的路径是项目路径，列出它们是为了让包包含这些资源。

## 触碰植物

只有靠近某物的植物才能被触碰，因此植物不必是实体。为角色（或任何应让植物作出反应的物体）添加 **`FoliageContact`**。

| 字段 | 说明 |
|---|---|
| `radius` | 植物向外倾斜的范围，世界单位。 |
| `strength` | 倾斜程度（0–2）：1 为完全倾斜，0 为无。 |
| `recovery` | 接触离开后草重新立起所需的秒数。 |
| `enabled` | 关闭时既不弯曲植物也不激活植物。 |

**草。** `Foliage` 格子是一个网格，因此弯曲在顶点中计算：Foliage 着色器接收四个位置（`u_contact0`–`u_contact3`），按草叶上的
高度将每片草叶推离这些位置，草叶越高于或低于它们推力越小。这四个位置是离流送源最近的接触，然后是它们刚离开的位置，后者在
`recovery` 内闭合，因此角色身后留下的分开痕迹会逐渐合拢。`u_contactBend` 为草叶分开的程度，以接触作用范围的比例表示。超出四个
的接触不会分开任何草。除添加组件外无需其他设置。

**手摆植物。** `PlacedFoliage` 或 `WorldRules.plants` 中的种类通过 `interaction` 启用交互。植物仍是其 `MeshInstances` 集合中的
放置；在接触的 `activationDistance` 内，它还会获得一个实体 **`PlantProxy`**，接触离开后移除。渲染从不交接，因此没有跳变。代理
实体是射线或碰撞找到的对象，游戏可在其上添加自己的组件。

| `interaction` 字段 | 说明 |
|---|---|
| `activationDistance` | 植物成为实体时与接触的距离，世界单位。0 保持为数据（不可触碰）。 |
| `radius`、`height` | 立于植物根部的物理胶囊，单位为网格单位 × 植物缩放。任一为 0：无胶囊。 |
| `bend` | 远离接触的倾斜角度（弧度）：对放置施加带弹簧的剪切，任何材质都随之弯曲，松开时会晃动。 |
| `health` | 砍倒所需的伤害。0：不能通过伤害砍倒。 |
| `fallSeconds`、`fallAngle`、`lieSeconds` | 倒下所需时间（默认 1.8）、倒下角度（默认 85 度），以及倒地后沉没前的时间（默认 30）。 |
| `felledKind`、`harvestedKind` | 砍倒后留下的种类（树桩），或采尽后变成的种类（光秃的灌木）：`kinds` 中的索引或 `WorldRules.plants` 中的植物名。缺省时不留下任何东西。 |
| `yields` | `harvest` 可采集的次数。 |
| `regrowSeconds` | 砍倒或最后一次采集后、从小重新长出前的秒数。0：永不。 |

通过 `PlantInteractionRes` 访问植物：

```ts
import { PlantInteractionRes } from 'esengine/foliage';

const plants = app.getResource(PlantInteractionRes);

// 挥砍可及范围内的植物，由近及远。
const [tree] = plants.near(player.x, player.z, 2);
if (tree) plants.damage(tree, 25, { x: player.x, z: player.z });   // 生命值归零时背离打击方向倒下

// 射线命中的植物。
const hit = physics.raycast(eye, forward);
const plant = hit && plants.of(hit.entity);
if (plant) inventory.berries += plants.harvest(plant, 1);

plants.on((event) => { if (event.type === 'landed') spawnDust(event.plant); });
```

| 方法 | 说明 |
|---|---|
| `near(x, z, radius)` | 半径内的植物，由近及远。 |
| `of(entity)` | `PlantProxy` 实体所代表的植物，或 `null`。 |
| `damage(plant, amount, from?)` | 施加伤害；生命值归零时植物背离 `from` 倒下。 |
| `harvest(plant, amount?)` | 至多采集 `amount` 次，返回实际采得的数量。 |
| `on(listener)` | 订阅事件：`activated`、`deactivated`、`damaged`、`felled`、`landed`、`harvested`、`removed`、`regrown`。返回取消订阅的函数。 |
| `saveState()`、`loadState(state)` | 序列化与恢复植物状态。 |

被砍倒的植物作为带有自身网格的实体倒下，以运动学刚体绕根部旋转，因此会阻挡其横躺处的物体。其放置立即移除，远景版本中也一样。

**持久化。** 植物状态以植物而非格子为键，因此区块释放并重新生长后被砍倒的树仍保持倒下。`saveState()` 以纯数据返回全部状态，
包括重新生长的计时；`loadState(state)` 可在格子生长之前或之后恢复它。生成世界的植物以其在规划中的位置标识；`PlacedFoliage` 的
植物以其在 `records` 中的索引、在 `stateKey`（或实体名）下标识，因此除重新排序记录外，存档均保持有效。两个植物集应使用不同名称。

## 尾流与冲击波

接触只在植物旁边时分开植物。快速运动的物体还会推动空气：它经过的植物被推倒、弹回越过直立位置，并在物体离开后逐渐平息；冲击波
只在其前沿传播到植物处时才影响它。两者都是已知时刻的冲量，因此每株植物的响应是在其绘制处、仅根据自冲量起经过的时间计算的阻尼
弹簧：约四分之一秒倒下，再用其三分之一的时间弹回越过直立，两秒内静止。

| 组件 | 字段 | 说明 |
|---|---|---|
| **`WindWake`** | `radius` | 物体推动空气的路径两侧范围，世界单位（默认 2）。 |
| | `strength` | 推力占物体速度的比例：1 使空气与物体同速（默认 1）。 |
| **`WindBurst`** | `strength` | 前沿推力，世界单位/秒（默认 20）。 |
| | `speed` | 前沿向外传播的速度（默认 40）。 |
| | `reach` | 前沿耗尽前传播的距离（默认 30）。 |

`WindWake` 每移动半个半径发出一次经过；`WindBurst` 在其实体获得该组件时触发一次。在代码中，
`emitWindBurst(app, position, { strength, speed, reach })` 无需实体即可发出前沿。最新的八次经过和四个前沿会传给所有读取它们的
材质：Foliage 着色器按 `u_wakeBend`（每单位空气推速对应的倾斜世界单位）使植物倾斜，上限为 `u_wakeMax`；2D **Sway** 模板
（`sprite-sway`）按其自身的 `u_wakeBend` 使精灵尖端沿 x 倾斜。`windLean` 在 CPU 上执行相同计算，供游戏自行倾斜的物体使用。

## 限制

- **仅位置。** 区域假定不旋转、不缩放；跟随地形的位置和等比缩放，不跟随旋转。
- **只有手摆植物可被砍伐。** 散布的 `Foliage` 会被接触分开，但每个格子只是一个网格，没有可碰撞、砍伐或采集的单株植物。需要
  砍伐的森林应使用 `PlacedFoliage` 或 `WorldRules.plants`。
- **倒下是脚本化的，不是模拟的。** 植物绕根部旋转到 `fallAngle`，不会在斜坡上安定或滚动，因此在陡坡上树干可能悬空或插入地面。
  其刚体为运动学刚体：会推动其落下处的物体，但不受推动。
- **碰撞需要 3D 物理模块。** 模块加载后才会添加代理的胶囊（含 `CharacterController3D` 或 3D 刚体的场景会加载它）。没有它时，
  植物仍会倾斜并可被砍倒，但不发生碰撞。胶囊是唯一形状：不贴合宽大的树冠或分叉。
- **倒下中的植物按已砍倒保存。** 仍在倒下的树在存档中记为已砍倒，加载后即消失。
- **网格的远景版本是面片，不是替身。** 它显示指定的纹理矩形，从任何方向看都相同；纹理中没有这样画面的植物会在此显示其纹理。
- **格子在帧预算内生长，** 由近及远，因此远处需要片刻才能填满。
