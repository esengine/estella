材质是**着色器加参数**。支持材质的渲染器——`Sprite`、`SpineAnimation`、`ParticleEmitter`、
`MeshRenderer` 和 `UIVisual`——都暴露一个 `material` 句柄字段;设置它就用你自己的着色器绘制,而非默认。

## 工作原理

你编写一个 `.esshader`,用 `#pragma param` 声明它可调的参数。引擎把它们**反射**进一个
std140 uniform 块,于是 CPU 能按名字设置、并安全地送到 GPU。一个 `Material` 把编译好的
着色器绑定到一组参数值;把它的句柄赋给渲染器的 `material` 字段,就用它来绘制该渲染器。

## 内置着色器模板

你很少需要从空白文件开始。内容浏览器的 **New Material** 子菜单从内置模板创建材质——
同一份清单在代码里是 `BUILTIN_SHADER_TEMPLATES`:

| 模板 | `builtin:` id | 作用 |
|---|---|---|
| **Unlit** | `sprite-unlit` | 纹理 × 顶点色 × `u_tint`,普通默认。 |
| **Lit** | `sprite-lit` | 被场景 2D 灯光照亮;`u_tint` + 可选 `u_normalMap`。 |
| **Sway** | `sprite-sway` | 随风倾斜，底部固定、顶部自由——草、芦苇、悬挂的布。`u_swayStrength` 是倾斜幅度占精灵宽度的比例，天气的 `wind` 会放大它。受光照，可带法线贴图。给角色加 `SwayPusher`，它走过时周围的植物会向外倒(取离相机最近的八个;`u_swayPushStrength` 是倒的幅度)。 |
| **Hit Flash** | `sprite-hit-flash` | 按 `u_flash` 混向 `u_flashColor`——代码里驱动它做受击闪白。 |
| **Outline** | `sprite-outline` | 彩色剪影描边(`u_outlineColor`、`u_outlineWidth`,单位纹素)。 |
| **Dissolve** | `sprite-dissolve` | 噪声烧蚀 + 发光边缘(`u_progress` 0→1)。 |
| **Pixelate** | `sprite-pixelate` | UV 量化到 `u_pixels` 网格。 |
| **UV Scroll** | `sprite-uv-scroll` | 按 `u_scrollSpeed` × 时间滚动纹理。 |
| **Model** | `model` | glTF 材质在 base color 之外说的东西:`u_normalMap`、`u_emissive`(`Map`)、`u_occlusionMap` + `u_occlusionStrength`、`u_alphaCutoff`、`u_metallic` / `u_roughness`(以及 `u_metallicRoughnessMap`),还有[着色层](#着色层)——清漆、绒面、各向异性、半透、薄膜干涉、折射率、透射。模型导入会写出它。 |
| **Toon** | `toon` | 分档受光:每盏灯的光被切成 `u_bands` 个平坦的档(`u_bandSoftness` 让档与档的交界变软),`u_shadeColor` 是灯照不到处的颜色,亮度超过 `u_specThreshold` 画一块平的高光(`u_specColor`,`u_specSize` 是光滑度),再加一圈边缘光(`u_rimColor`、`u_rimWidth`、`u_rimStrength`)。灯的阴影算进它的那一档。用帧里的 16 盏灯,和 Model 一样带着灯的循环。 |
| **Matcap** | `matcap` | 用一张"打好光的球"的图(`u_matcap`)按表面朝向相机的方向查色。不问任何灯、不读阴影,只读一次纹理,所以适合手机。`u_baseBlend` 把底色乘进去。 |

| **Terrain** | `terrain` | 四个纹理图层(草、泥土、雪、岩石),由 [Terrain](/docs/zh-cn/graphics/terrain/) 组件加权并按世界位置平铺。 |
| **Foliage** | `foliage` | 在风里摆动的植物:按顶点颜色里画好的权重做顶点弯曲,双面、半透光,可选镂空纹理。见[植被](/docs/zh-cn/graphics/foliage/)。 |
| **Skin** | `skin` | 按颜色分开的柔和漫反射、偏暖的明暗交界、薄处透光、两层高光和一层绒毛光,不模糊画面。见[皮肤与头发](#皮肤与头发)。 |
| **Hair** | `hair` | 发丝光照:Kajiya-Kay 漫反射、沿流向图错开的两条高光,以及透过发丝的光。见[皮肤与头发](#皮肤与头发)。 |
| **Water** | `water` | 水平的水体:传播的波浪和涟漪、被折射并按水深染色的背后场景、反射与泡沫。见[水](#水)。 |

新建材质是**按 id 引用**其模板的——它存的是 `shader: "builtin:sprite-unlit"`,并**不会**在磁盘上
写出 shader 文件。引擎从内置源码编译该模板(运行时加载器、cook 步骤、编辑器三处以同样方式解析
`builtin:<id>`),所以新材质立即就能绘制,无需额外管理。只有当你把材质**转为独立着色器**(见下文)
或自己**新建着色器**时,才会有真正的 `.esshader` 落到磁盘上。

## 水

**Water** 着色器(`builtin:water`)画一片水体:按实测水深折射,以及反射和泡沫。`WaterBody` 组件说明海洋、湖泊或河流在哪里,`WaterZone` 把它们烘成一个用它画出的水面,用波浪抬起几何体,并让代码能查询水面。全部内容在[水](/docs/zh-cn/graphics/water/)一章。

## 皮肤与头发

两个着色器,给金属/粗糙度这一对参数描述不了的角色部位用。它们都和 Model 着色器一样,从网格自己的纹理取基础颜色,并把 `u_normalMap` 和 `u_ormMap`(红色是遮蔽,绿色是粗糙度)当作**数据**纹理:导入时要把 sRGB **关掉**,否则法线贴图会被颜色曲线扭曲,表面会出现斑块。

**皮肤**(`builtin:skin`)不模糊画面。光进入皮肤又在不远处出来,会让弯曲表面的受光一侧变软,这里按颜色分开做:漫反射光取自比表面自己的法线更软的法线,红色最软(`u_blurRed`、`u_blurGreen`,是法线贴图的 mip 层级),所以毛孔和高光保持清晰。明暗交界线被染暖(`u_sssColor`、`u_sssWrap`),薄的或曲率大的地方会透光(`u_translucency`、`u_thinness`:耳朵、鼻翼、手指),高光是两层(`u_specular`、`u_lobe2`、`u_lobe2Roughness`),另有一层很淡的绒毛光照亮边缘(`u_fuzz`)。打开 `u_subsurface` 还会把它标记给[次表面散射](/docs/zh-cn/graphics/post-processing/#次表面散射)特效,在更大的尺度上扩散剩下的光,代价是会模糊画面。`u_preIntegrate` 让明暗交界线之后的环绕光按颜色分开(红色最远),并在表面急转的地方变宽,所以鼻翼和耳朵边缘会透出光,而平坦的脸颊保持清晰;`u_curvature` 是每个世界单位内多快的转折算作急转。`u_detailMap` 是平铺在表面上的第二张细法线图(`u_detailTile`),用来补烘焙贴图没有足够像素表现的毛孔和皮纹:它按 `u_detailStrength`(0 表示不用)叠在高光读取的锐利法线上,不叠在柔和的漫反射法线上。导入时关闭 sRGB,并把环绕方式设为重复。它对每个像素做三次光照计算,所以适合镜头里的角色皮肤,不适合一群人。

**头发**(`builtin:hair`)把发丝当发丝来打光。`u_lobeGain` 决定灯光画出多少发丝高光(环境反射则只由 `u_specular` 决定)。`u_anisotropy` 大于 0 时,两道发丝高光换成 Principled 着色器的高光:沿发丝方向按这个各向异性(Blender 的定义)拉长的 GGX,`u_specular` 作为镜面系数;从 Blender 导出、带各向异性的发片导入后就是这样设置的。`u_strandDiffuse` 决定漫反射里发丝自己的那部分占多少(0 就是 Principled 着色器的漫反射,发片背向光时会变暗)。`u_hairShadow` 是光沿着射线穿过一层发丝被吸收的密度:大于 0 时,帧会给头发单独拟合一个阴影级联(排在太阳级联的最前面),相隔几毫米的发片才分得开,穿过的头发越厚透过的光越少,和深度阴影图的读法一样。`u_clumpCount` 把一张发片的发丝画成横向若干束:束与束明暗不同(`u_clumpTone`)、高光各自错开(`u_clumpShift`)、束间有一道阴影缝(`u_clumpGap`);0 表示保持贴图原样。`u_flowMap` 说明发丝朝哪个方向(红、绿是贴图上的一个方向),漫反射是 Kajiya-Kay(发丝被光照亮的程度取决于光离它的走向有多远),高光是两条沿发丝的窄高光,由 `u_shiftMap` 把它们错开(`u_shiftAmount`、`u_shiftTile`):一条白的靠近表面,一条带颜色的在下面(`u_secondaryTint`)。`u_roughness` 决定线条有多紧。光会从发丝背面透过来(`u_translucency`),`u_sharpen` 让发片上密布的细发丝在斜着看时不被冲淡,`u_rootDark` 按遮蔽图把发根压暗。`u_alphaCutoff` 按贴图的 alpha 把发片抠出形状,在 MSAA 下由 alpha-to-coverage 柔化边缘,`u_tipSoftness` 增加柔和的外缘:alpha 从裁剪值往下降这么多的范围内,由第二遍混合绘制把发丝尖端渐隐地画出来,和其他混合绘制一起排序,所以发梢不会在覆盖率下出现阶梯(0 表示不用)。发片投进阴影图里的也是这个形状,而不是它所在的矩形。头发模型通常是发片或发带而不是真正的发丝;这个着色器把发丝的明暗给了几何本身给不了的部分。

**眼睛**(`builtin:eye`)用两张贴图和几个数值做出一只眼睛。`u_depthMap` 在虹膜和角膜穹顶上为白色,`u_irisNormalMap` 是这个穹顶的法线(两张都要以关闭 sRGB 的方式导入)。视线在角膜处折射(`u_ior`)再下行到虹膜(`u_irisDepth`),所以眼球转动时虹膜在表面后面移动。虹膜本身由 `u_irisColor` 到 `u_irisColor2` 绘制,带纤维纹理、深色角膜缘(`u_limbal`)和瞳孔(`u_pupilSize`),衬在眼白(`u_scleraColor`)上,眼白的光会绕过明暗交界线(`u_scleraWrap`)。角膜近似镜面(`u_corneaRoughness`、`u_specular`),所以每盏灯和天空都会变成一个眼神光。眼睑会给眼睛投下阴影:`u_lidMap` 是手绘的遮蔽图(眼睛睁开处为白色),`u_lidShadow` 会在表面朝上的地方(从 `u_lidStart` 即与世界上方向的点积起,到正上方)变暗并淡化角膜的反射,在头部直立时这就是上眼睑。网格上画的眼睛贴图会与结果相乘。

两者读的是和所有 Lit 着色器相同的光照核心,所以阴影、基于图像的光照和其他特效都适用。

## 着色层

**Model** shader 是一个金属/粗糙度表面,上面可以叠层。每一层默认关闭,强度为零的层不消耗任何开销,一个什么都不写的材质就是它一直以来的那个普通表面。

| 层 | 参数 | 作用 |
|---|---|---|
| 清漆(Clear coat) | `u_clearcoat`、`u_clearcoatRoughness` | 表面上一层光滑的漆:第二个更锐利的高光,底层被清漆反射走的那部分变暗,并带有自己的环境反射。清漆用表面自身的法线着色,所以法线贴图只会让漆下面变粗糙,不会让漆变粗糙。车漆、清漆木头、湿石头。 |
| 绒面(Sheen) | `u_sheenColor`、`u_sheenRoughness` | 布料在掠射角回弹的柔光(Charlie 瓣),并从底层里扣掉对应能量,不凭空增加亮度。天鹅绒、缎面、毛毡。 |
| 各向异性 | `u_anisotropy`(-1..1)、`u_anisotropyRotation` | 高光沿垂直于纹路的方向被拉长而不是圆的:拉丝金属、纤维、光盘。纹路沿 UV 坐标系按旋转角转过后的方向;环境反射也按同一方向弯折。 |
| 半透(Translucency) | `u_translucency`、`u_translucencyColor`、`u_thickness` | 光散射进薄的表面:受光面越过明暗交界线向背光侧延伸,背后的灯会透出来并带上颜色,越厚越弱。树叶、纸、蜡、灯罩、耳朵边缘的皮肤。 |
| 次表面 | `u_subsurface` | 把表面标记为光会在其中扩散的表面:体积里有[次表面散射](/docs/zh-cn/graphics/post-processing/#次表面散射)效果时,它的受光颜色会沿表面被模糊,红色最远。皮肤、蜡、大理石。 |
| 薄膜干涉 | `u_iridescence`、`u_iridescenceIor`、`u_iridescenceThickness`(nm) | 反射的色相随角度变化:肥皂泡、油膜、甲虫壳、镀膜玻璃。 |
| 折射率 | `u_ior`、`u_specular` | 非金属正对时反射有多强(1.5 是玻璃和大多数塑料,宝石是 2.4),以及反射的总缩放。 |
| 透射(Transmission) | `u_transmission`、`u_attenuationColor`、`u_thickness`、`u_refractionStrength` | 玻璃和水:表面显示它背后的东西,被玻璃折射(越厚折得越多)、带上颜色、并按粗糙度变柔;掠射角处反射更强。 |

这些都由模型导入从同名的 glTF 扩展写出(`KHR_materials_clearcoat`、`_sheen`、`_anisotropy`、`_ior`、`_specular`、`_iridescence`、`_transmission`、`_volume`、`_diffuse_transmission`)——见[模型](/docs/zh-cn/assets/models/)。

在编辑器里,Model 材质把每一层显示为带开关的独立分区:关闭把该层强度设为 0(绒面则是把颜色设为黑),开启给它一个能看出效果的强度,分区里的字段用来调节它。反射率(折射率和镜面缩放)没有开关。

**限制。** 这些是便宜的实时模型,下面说清楚它们止步在哪里:

- **透射只折射不透明场景。** `u_transmission` 大于 0 的材质在场景其余部分之后绘制,读取的是之前刚拍下的画面副本:光线穿过表面厚度后被折弯,在落点处读取副本。所以玻璃不会折射另一块玻璃,薄壳对画面的偏折是固定的量,而不是像透镜那样把画面翻转。它需要引擎能拷贝的场景,也就是有后处理链在运行(任意效果、输出变换,或小于 1 的渲染比例);没有时表面退回 alpha 混合覆盖,背景不会变形。
- **半透是着色项,不是模糊。** 它让光越过明暗交界线向背光侧延伸,并让背后的灯透出来,但从某一点进入的光仍在这一点出去。真正的扩散是次表面散射效果的事,它会模糊被标记表面的整个受光颜色,所以表面上锐利的高光也会被一并变软。
- **不读取层的贴图。** 每一层对整个材质是一个常量(Model shader 已经没有多余的纹理单元);glTF 扩展的贴图在导入时会报告,其系数会保留。
- **绒面和薄膜是拟合。** 绒面的能量损失和薄膜的干涉是解析近似,代替了生产级渲染器烘焙的查找表。
- **不提供:** 头发(Marschner 式的发丝模型)、眼睛、清漆单独的法线贴图、超过一层清漆的分层材质。

### 在你自己的 shader 里

`Lit` shader 可以用同一套光照。`applyLightingSurface(albedo, N, worldPos, V, metallic, roughness, specular, ao, ext)` 就是带层的 `applyLightingPBR`;用 `surfaceExtNone(N)` 起一个 `ext`,再设置你用到的字段:

| 字段 | 含义 |
|---|---|
| `ext.coat` | `x` 强度,`y` 感知粗糙度;`ext.coatN.xyz` 清漆的法线 |
| `ext.sheen` | `rgb` 颜色(黑色为关闭),`a` 感知粗糙度 |
| `ext.aniso` | `xyz` 切线(单位向量,垂直于 `N`),`w` 强度 -1..1(0 为关闭) |
| `ext.scatter` | `rgb` 散射光的颜色,`a` 包裹 0..1;`ext.trans.x` 透过多少,`ext.trans.y` 厚度 0..1 |
| `ext.film` | `x` 强度,`y` 膜的折射率,`z` 厚度(纳米) |
| `ext.misc.x` | 非金属正对时的反射率(折射率 1.5 对应 0.04) |

## 在编辑器里选取与共享着色器

在内容浏览器里选中一个材质,Details 面板会打开它的检视器,顶部(参数上方)是一个 **Shader** 区。
**Shader** 下拉框列出每个内置模板(显示为 *Built-in · Unlit*、*Built-in · Lit* ……)以及项目里
每个 `.esshader`——选一个即可给材质重新绑定着色器。

![材质检视器的 Shader 区与参数列表](@/assets/guides/zh/material-shader.png)

*材质检视器:**Shader** 区及其选择器(这里是 `dissolve.esshader`),下方是从该着色器 `#pragma param` 反射出的**参数**。*

切换会重跑着色器反射:下方的参数列表按新着色器的 `#pragma param` 重建,所以检视器始终与当前绑定的
着色器一致。由于旧着色器的参数不再适用,**切换会清空材质的参数值**——请为新效果重新调参。

- **在多个材质间共享一个着色器。** `.esshader` 是一等资源(徽标 **SHD**)。让多个材质指向*同一个*
  `.esshader` 文件,它们就共享同一份编译后的着色器——改一次源码,所有引用它的材质一起更新。这正是
  选择器把项目着色器和内置模板并列的意义。
- **Convert to Unique Shader(转为独立着色器)。** 当材质还引用着 `builtin:` 模板时,该区会显示一个
  **Convert to Unique Shader** 按钮。它把内置源码复制成材质旁边一个可编辑的 `<material>.esshader`,
  并把材质重新指向它——参数值会保留。想手改内置效果时就用它。
- **New Shader(新建着色器)。** 想从零写着色器,用内容浏览器的 **New Shader** 入口(一个子菜单——
  选一个内置模板作为起点)。它会写出一个独立的 `.esshader`,之后可在任意材质的 Shader 下拉框里选中。

<Aside type="note">
  材质把着色器存为**相对于材质自身**的路径(或一个 `builtin:` id),而不是 `@uuid`。若被引用的
  `.esshader` 被改名或移走,Shader 区会把该引用标记为缺失,你在那里重新选一次即可。
</Aside>

## `.esshader` 格式

一个文件容纳所有 stage 与元数据,用 pragma 分段:

| Pragma | 含义 |
|---|---|
| `#pragma shader "Name"` | 显示名。 |
| `#pragma version 300 es` | 每个 stage 的 GLSL 版本行。 |
| `#pragma domain <D>` | `Unlit`(默认)、`Lit`、`PostProcess`、`UI`。`Lit` 注入光照 uniform + helper。旧拼写 `Unlit2D` / `Lit2D` 仍按这两个域加载。 |
| `#pragma param …` | 反射的材质参数(见下表)。 |
| `#pragma switch NAME [default(on)]` | 材质可控的静态排列开关(一个 `#define`)。 |
| `#pragma coverage PARAM` | 浮点参数 `PARAM` 大于零时,着色器输出的 alpha 就是覆盖率——镂空的 alpha 在阈值附近锐化到约一个像素宽(`cutoutCoverage(alpha, cutoff, fwidth(alpha))`)。不透明物体画进多重采样目标时,它会转成多重采样覆盖率,镂空边缘就有抗锯齿而不是台阶;没有多重采样时就是硬切。任何距离都在阈值处切,与 glTF 的 MASK 定义一致:镂空缩小显示时之所以还保持原来的面积,是因为烘焙时把每级 mip 的 alpha 缩放到与原图在阈值处相同的覆盖率。内置 Model 着色器声明了 `u_alphaCutoff`。 |
| `#pragma feature NAME` | 引擎选择的编译期变体关键字。 |
| `#pragma hairshadow PARAM` | 浮点参数 `PARAM` 大于零时,用这个材质画的网格就是阴影意义上的头发:太阳的级联多出一个只拟合它们的级联,并且着色器在打光前设置 `g_hairShadow` 的话,阴影就按沿光线的密度读,而不是硬比较。参数值就是密度。内置 Hair 着色器声明了 `u_hairShadow`。 |
| `#pragma gbuffer` | `PostProcess` 着色器要读取场景的表面记录(见[G-buffer](/docs/zh-cn/graphics/post-processing/#g-buffer)),在 `u_gbuffer` 处。声明它才会让这一帧画出一份;着色器里没有它的链路永远不付这笔钱。 |
| `#pragma vertex` / `#pragma fragment` … `#pragma end` | Stage 代码体。**2D 域的顶点段可省略**——引擎注入规范顶点段。 |
| `#include "path"` | 文本 include(由宿主解析)。 |

### 只写片元

2D 精灵的世界变换烘焙进批处理顶点,所以所有 2D 着色器共享同一个顶点段。省略
`#pragma vertex`,只写片元;以下 varying 开箱即用:

| Varying | 类型 | 值 |
|---|---|---|
| `v_color` | `vec4` | 每实例色调(精灵的 `color`)。 |
| `v_texCoord` | `vec2` | 纹理 UV。 |
| `v_worldPos` | `highp vec2` | 世界坐标(**仅 Lit 域**)。 |

精灵纹理是 `u_textures[0]`(声明 `uniform sampler2D u_textures[8];`——单元 0–7 归批处理;
纹理*参数*自动绑定在其上方)。

### 用 `#pragma param` 声明参数

```glsl
#pragma param u_tint      color   default(1, 1, 1, 1)
#pragma param u_intensity float   default(1.0) range(0, 4) ui(slider)
#pragma param u_mask      texture default(white)

// … your GLSL fragment code, reading u_tint / u_intensity / u_mask …
```

| 参数类型 | GLSL | 值的形状 | 备注 |
|---|---|---|---|
| `float` / `int` | `float` / `int` | `number` | 标量旋钮;`range(min,max)` + `ui(slider)` 控制检视器。 |
| `vec2` / `vec3` / `vec4` | 同名 | `[x, y, …]` | 向量旋钮。 |
| `color` | `vec4` | `[r, g, b, a]` | RGBA,0..1;检视器里是取色器。 |
| `texture` | `sampler2D` | 纹理句柄 | `default(white \| black \| flatnormal)` 未设置时的回退。着色器把贴图当数值读(法线贴图、打包的粗糙度)时加 `texel(data)`:项目健康检查会指出绑在这里却仍标为 sRGB 的贴图,线性管线会把它当颜色解码。 |

参数存在引擎生成的 std140 块里,并从 `default(…)` 初始化——材质从未设置某参数也能正确绘制。

### 注入的 uniform 与 helper

引擎向每个编译的 `.esshader` 注入以下内容——永远不要自己声明它们:

| 注入项 | 可用范围 | 说明 |
|---|---|---|
| `u_time` | 总是 | `vec4` 帧时钟:`.x` 累计秒,`.y` 帧间隔秒。 |
| `u_viewport` | 总是 | `vec4` 画布:`.xy` 像素尺寸,`.zw` = 1/尺寸(屏幕 UV = `gl_FragCoord.xy * u_viewport.zw`)。 |
| MaterialConstants 块 | 着色器有参数时 | 你的 `#pragma param` 值。 |
| `applyLighting2D(albedo, N, worldPos)` | Lit | 应用场景所有灯光(含阴影),返回受光颜色。 |
| `applyLighting2DAO(albedo, N, worldPos, ao)` | Lit | 同上,但环境光项乘以 `ao`(1 = 无遮蔽)。 |
| `sampleNormal(map, uv)` | Lit | 解包切线空间法线贴图(RGB → [-1,1],归一化)。 |
| `shadowFactor2D(worldPos, target, softness)` | Lit | 朝向目标点的遮挡系数(`applyLighting2D` 内部使用)。 |

`#pragma switch` 选择编译期烘焙进材质的静态着色器排列(通过 `compileShader` 的 `features` 参数)。

## 用代码创建与应用

**只编译一次**着色器(不要每帧),做一个材质,然后把渲染器指向它:

```typescript
import { Material } from 'esengine';

const shader = Material.compileShader(tintShaderSource);
const tintMat = Material.create({
  shader,
  uniforms: { u_tint: [1, 0.6, 0.2, 1], u_intensity: 1.5 },
});
```

```typescript
import { defineSystem, Query, Mut, Sprite } from 'esengine';

const applyMaterial = defineSystem([Query(Mut(Sprite))], (q) => {
  for (const [entity, sprite] of q) {
    sprite.material = tintMat;   // the material handle
  }
});
```

## 运行时更新参数

```typescript
Material.setUniform(tintMat, 'u_intensity', 2.5);
const v = Material.getUniform(tintMat, 'u_intensity');
```

## `Material` API 参考

| 方法 | 说明 |
|---|---|
| `compileShader(esshaderSource, features?)` | 编译一个 `.esshader`(反射 `#pragma param`);返回着色器句柄。 |
| `createShader(vertexSrc, fragmentSrc)` | 编译一对原始 GLSL 顶点/片元(无反射参数)。 |
| `create({ shader, uniforms })` | 构建一个把着色器绑定到参数值的材质。 |
| `setUniform(material, name, value)` | 运行时设置一个反射参数。 |
| `getUniform(material, name)` | 读取一个参数的当前值。 |

### `MaterialOptions`

`Material.create(options)` 接受完整的渲染状态,不只是着色器 + uniform:

| 字段 | 默认 | 说明 |
|---|---|---|
| `shader` | — | `compileShader` / `createShader` 返回的着色器句柄(必填)。 |
| `uniforms` | — | 按名字给出的初始参数值;纹理用 `Material.tex(textureId)`。 |
| `blendMode` | `BlendMode.Normal` | 材质的合成方式(`Normal`、`Additive`、`Multiply` 等)。 |
| `depthTest` | `false` | 对深度缓冲做测试。 |
| `depthWrite` | `true` | 写入深度缓冲。 |
| `cull` | `CullMode.None` | 三角形剔除模式。 |
| `switches` | `{}` | 启用的 `#pragma switch` 名——该材质编译时选定的静态排列。 |

每个状态字段都有运行时 setter——`setBlendMode`、`setDepthTest`、`setDepthWrite`、
`setCull`——而 `Material.createInstance(source)` 构建一个廉价变体:从父材质继承
一切,只存储你之后在它上面设置的差异。

### `CullMode`

| 值 | 含义 |
|---|---|
| `CullMode.None` | 双面都画(2D 默认)。 |
| `CullMode.Back` | 剔除背面。 |
| `CullMode.Front` | 剔除正面。 |

### `ShaderSources`

走原始 `createShader` 路径时,`ShaderSources` 提供现成的 ES 3.0 GLSL,使用批处理
顶点布局(`vec3` position + `vec4` color + `vec2` texCoord,带 `u_projection` /
`u_model` uniform)——顶点与片元配对使用:

| 源 | Stage | 作用 |
|---|---|---|
| `ShaderSources.SPRITE_VERTEX` | 顶点 | 透传位置、颜色和 UV。 |
| `ShaderSources.SPRITE_FRAGMENT` | 片元 | `texture(u_texture, uv) × v_color`。 |
| `ShaderSources.COLOR_VERTEX` | 顶点 | 仅位置 + 颜色(无 UV)。 |
| `ShaderSources.COLOR_FRAGMENT` | 片元 | 平铺顶点色。 |

它们**不是** `.esshader` 模板——没有 `#pragma param` 反射;把它们当
`Material.createShader(vertex, fragment)` 网格的起点。

## 用代码构建材质图

编辑器的材质图不是另一条管线——它是**生成 `.esshader` 的可视化前端**。
`compileMaterialGraph(graph)` 从输出节点遍历节点 DAG,发出与手写等价的着色器源
(GLSL 片元和它的 WGSL 孪生同时生成),所以图材质在两个后端都能跑,而它的
常量/纹理节点会变成普通的反射 `#pragma param`。这意味着图可以完全用代码编写——
图就是普通数据:

```typescript
import { compileMaterialGraph, Material, type MaterialGraph } from 'esengine';

const graph: MaterialGraph = {
  name: 'TintedSprite',
  output: 'out',                     // 输出节点的 id
  nodes: [
    { id: 'tex',  type: 'textureSample', params: { name: 'u_albedo', default: 'white' } },
    { id: 'tint', type: 'constColor',    params: { name: 'u_tint', value: [1, 0.6, 0.2, 1] } },
    { id: 'mul',  type: 'multiply',      inputs: { a: 'tex', b: 'tint' } },
    { id: 'out',  type: 'output',        inputs: { color: 'mul' } },
  ],
};

const shader = Material.compileShader(compileMaterialGraph(graph));
const mat = Material.create({ shader });
Material.setUniform(mat, 'u_tint', [1, 0, 0, 1]);   // 图参数就是普通参数
```

`compileMaterialGraph` 在出现环、缺节点/缺输入、或 `output` 根不是 output 节点时
抛错。

### 节点类型

`GraphNodeType` 覆盖输入、参数和数学(`NODE_SPECS` 保存每种类型的端口和可编辑
字面量——编辑器调色板读的就是这份 schema):

| 节点 | 输出 | 说明 |
|---|---|---|
| `uv` / `screenUV` | `vec2` | 纹理 UV / 画布归一化屏幕 UV(0–1,y 朝上)。 |
| `vertexColor` | `vec4` | 精灵的逐实例色调。 |
| `time` | `float` | 引擎帧时钟,单位秒。 |
| `constFloat` / `constColor` | `float` / `vec4` | 一个反射材质参数(`params: { name, value }`)。 |
| `textureSample` | `vec4` | 在某 UV 采样一个纹理参数(`params: { name, default }`)。 |
| `multiply` / `add` / `lerp` | 拓宽类型 / `vec4` | 算术;标量对向量广播。 |
| `oneMinus` / `saturate` / `sin` | 同输入类型 | `1 − x` / 钳制 0–1 / 正弦。 |
| `smoothstep` | 同输入类型 | `smoothstep(edge0, edge1, x)`——边界是节点字面量。 |
| `noise` | `float` | 基于 UV 的程序化值噪声(`scale` 字面量)。 |
| `panner` | `vec2` | `uv + time × speed`——滚动 UV(`speedX` / `speedY` 字面量)。 |

### 编辑操作

面向工具(或程序化生成图),SDK 导出一组纯函数操作——每个都返回**新**图,
不改动输入:

| 函数 | 作用 |
|---|---|
| `newMaterialGraph()` | 起始图:一个白色 `textureSample` 接到 `output`。 |
| `addNode(g, type, x, y)` | 添加带合理默认参数的节点;返回 `{ graph, id }`。 |
| `connect(g, fromId, toId, toSlot)` | 连一条边;若会成环或槽位未知,**原样返回** `g`。 |
| `disconnect(g, toId, toSlot)` | 清除一个输入连接。 |
| `moveNode(g, id, x, y)` | 仅画布布局——编译器忽略位置。 |
| `removeNode(g, id)` | 移除节点及所有相连的边(`output` 节点不可移除)。 |

## 自定义几何

材质不局限于组件渲染器:**`Geometry`** API(`Geometry.create` 加
`GeometryOptions` 顶点布局,还有 `createQuad` / `createCircle` / `createPolygon`
辅助函数)构建句柄式网格,用 `Draw.drawMeshWithMaterial(geometry, material)`
即时绘制——完整参考见[自定义绘制](/docs/zh-cn/graphics/drawing/)。

## 最佳实践

- 启动时**只编译一次**着色器并复用句柄——绝不在每帧系统里编译。
- 让使用相同着色器 + 参数的渲染器**共享一个材质**,以合批成更少的 draw call。
- **优先用编辑器的材质图(material graph)** 编写;它会生成 `#pragma param` 着色器并让你
  可视化地赋材质。这里的代码 API 用于程序化材质。
- **动画效果用 `setUniform`** 驱动共享材质,而不是重建材质。

<Aside type="note">
  没有反射参数的原始着色器用 `Material.createShader(vertexSrc, fragmentSrc)` 而非
  `compileShader`。`ShapeRenderer` 和 `TilemapLayer` 没有 `material` 字段——只有 `Sprite`、
  `SpineAnimation`、`ParticleEmitter`、`MeshRenderer` 和 `UIVisual` 有。
</Aside>
