材质由着色器、该着色器的一组参数值和渲染状态组成。带 `material` 字段的渲染组件使用所指定的材质绘制，替代其默认着色器。

![材质检视器的 Shader 区与参数列表](@/assets/guides/zh/material-shader.png)

*材质检视器：**Shader** 区及其选择器（此处为 `dissolve.esshader`），下方为从该着色器的 `#pragma param` 反射出的**参数**。*

## 接受材质的渲染组件

| 组件 | 字段 | 参考 |
|---|---|---|
| `Sprite` | `material` | [精灵效果](/docs/zh-cn/graphics/sprites/effects/#材质与光照) |
| `SpineAnimation` | `material` | — |
| `ParticleEmitter` | `material` | [粒子材质](/docs/zh-cn/world/particles/rendering/#粒子材质) |
| `MeshRenderer` | `material` | — |
| `UIVisual` | `material` | [图片](/docs/zh-cn/ui/images/#自定义材质) |

`material` 为 `0` 时使用渲染组件的内置着色器。`ShapeRenderer` 与 `TilemapLayer` 没有 `material` 字段。代码绘制的几何体在每次绘制调用中指定材质（[自定义几何](/docs/zh-cn/graphics/materials/code/#自定义几何)）。

## 材质的构成

着色器是一个 `.esshader` 文件，以 `#pragma param` 声明其可调参数（[`.esshader` 格式](/docs/zh-cn/graphics/materials/esshader/)）。引擎将这些声明反射为 std140 uniform 块，因此 CPU 端可按名称设置参数。材质把一个已编译的着色器绑定到一组参数值与一个渲染状态；将材质句柄赋给渲染组件的 `material` 字段后，该渲染组件即以此材质绘制。

## `.esmaterial` 资源

材质资源是一个 JSON 文件：

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | string | 格式版本，`"1.0"`。 |
| `type` | string | 固定为 `"material"`。 |
| `shader` | string | 内置模板为 `builtin:<id>`；项目 `.esshader` 为**相对于材质**的路径。 |
| `properties` | object | 按名称存放的参数值。 |
| `blendMode`、`depthTest`、`depthWrite`、`cull`、`depthBias` | number / boolean | 渲染状态。缺省字段在加载时取引擎默认值。 |
| `switches` | object | 启用的 `#pragma switch` 名称；加载时据此选择着色器排列。 |
| `instanceOf` | string | 材质实例的父材质。着色器以及实例未设置的渲染状态取自父材质；`shader` 被忽略，`properties` 只包含被覆盖的参数。 |

着色器引用是相对路径而非 `@uuid`。被引用的 `.esshader` 改名或移动后，材质检视器会将该引用标记为缺失，需在检视器中重新选择。

## 内置着色器模板

内置模板在代码中以 `BUILTIN_SHADER_TEMPLATES` 列出。使用模板的材质存储 `shader: "builtin:<id>"`，不在磁盘上写出着色器文件。运行时加载器、cook 步骤与编辑器以相同方式将 `builtin:<id>` 解析为代码内的源码。

### 核心模板

| 模板 | `builtin:` id | 说明 |
|---|---|---|
| **Unlit** | `sprite-unlit` | 纹理 × 顶点色 × `u_tint`。默认模板。 |
| **Lit** | `sprite-lit` | 受场景 2D 灯光照明；`u_tint` 与可选的 `u_normalMap`。 |
| **Lit Particle** | `particle-lit` | 在所处位置受太阳、天空与灯光照明的粒子（雾、烟、尘）；来自背后的光按 `u_translucency` 透过。 |
| **Sway** | `sprite-sway` | 随风倾斜，底部固定、顶部自由：草、芦苇、悬挂的布。`u_swayStrength` 为倾斜量占精灵宽度的比例，天气的 `wind` 对其缩放。受光照，可带法线贴图。角色上的 `SwayPusher` 使其穿过的植物向外倾倒（取离相机最近的八个；`u_swayPushStrength` 为倾倒幅度）。 |
| **Hit Flash** | `sprite-hit-flash` | 按 `u_flash` 向 `u_flashColor` 混合；由代码驱动，用于受击闪烁。 |
| **Outline** | `sprite-outline` | 彩色剪影描边（`u_outlineColor`，`u_outlineWidth` 以纹素计）。 |
| **Dissolve** | `sprite-dissolve` | 噪声烧蚀，带发光边缘（`u_progress` 0→1）。 |
| **Pixelate** | `sprite-pixelate` | 将 UV 量化到 `u_pixels` 网格。 |
| **UV Scroll** | `sprite-uv-scroll` | 按 `u_scrollSpeed` × 时间滚动纹理。 |
| **Model** | `model` | glTF 材质中基础色以外的部分：`u_normalMap`、`u_emissive`（+ `u_emissiveMap`）、`u_occlusionMap` + `u_occlusionStrength`、`u_alphaCutoff`、`u_metallic` / `u_roughness`（+ `u_metallicRoughnessMap`）、潮湿地面，以及[着色层](/docs/zh-cn/graphics/materials/surface-shaders/#着色层)：清漆、绒面、各向异性、半透、薄膜干涉、折射率、透射。由模型导入写出。 |
| **Ground Blend** | `ground-blend` | 用于立在地面中的物体的 Model 着色器：与地面相接处淡出为其后方的画面（[地面融合](/docs/zh-cn/graphics/terrain/overview/#地面融合)）。 |
| **Toon** | `toon` | 分档光照：每盏灯的光被切分为 `u_bands` 个平坦档位（`u_bandSoftness` 柔化档位交界）；`u_shadeColor` 为灯光照不到处的颜色；亮度超过 `u_specThreshold` 时绘制平坦高光 `u_specColor`（`u_specSize` 控制光泽度）；以及边缘光（`u_rimColor`、`u_rimWidth`、`u_rimStrength`）。灯光阴影计入其所在档位。使用帧内的 16 盏灯，并与 Model 一样包含灯光循环。 |
| **Matcap** | `matcap` | 按表面朝向相机的方向，在一张受光球体的图片（`u_matcap`）中查找颜色。不读取灯光与阴影，只读取一次纹理，适用于手机。`u_baseBlend` 将基础色乘入。 |
| **Particle** | `particle` | 用于 `ParticleEmitter`：粒子接近其后方场景时淡出（`u_softness`，世界单位），纹理随粒子年龄侵蚀（`u_erosion`、`u_erosionEdge`）。见[粒子材质](/docs/zh-cn/world/particles/rendering/#粒子材质)。 |
| **Distortion** | `distortion` | 扭曲其后方已绘制的画面：热浪、冲击波、透镜。纹理 alpha 决定扭曲位置与强度（`u_strength`、`u_radial`、`u_dispersion`）。可用于粒子与网格。 |

| 模板 | `builtin:` id | 模块 | 说明 |

| **Terrain Layers** | `terrain-layers` | `esengine/terrain` | 最多八个地形图层（albedo、法线与遮罩数组），由 Terrain 组件加权，按高度混合，在斜坡上投影。 |
| **Terrain Surface Bake** | `terrain-surface-bake` | `esengine/terrain` | Terrain Layers 对一个地面节点的未受光结果，绘制到该节点在运行时虚拟纹理中的页面。 |
| **Planet** | `planet` | `esengine/terrain` | 球面上的地面，来自 Planet 组件的四叉树节点，按四种图层颜色着色。 |

| **Voxel Ground** | `voxel-ground` | `esengine/voxel` | 用于无 UV 地面的 Model 着色器：最多四种材质，按顶点色加权，各自按世界坐标从三个方向投影。 |
| **Foliage** | `foliage` | `esengine/foliage` | 随风摆动的植物：按顶点色中绘制的权重做顶点弯曲，双面、半透光，可选镂空纹理。见[植被](/docs/zh-cn/graphics/foliage/)。 |
| **Strands** | `strands` | `esengine/groom` | 将毛发组的曲线绘制为面向相机的条带，宽度按组的设置从根部到尖端变化，沿发丝方向受光。 |
| **Hair** | `hair` | `esengine/character-shaders` | 发片上的发丝光照。见[头发](/docs/zh-cn/graphics/materials/surface-shaders/#头发)。 |
| **Skin** | `skin` | `esengine/character-shaders` | 按颜色分离的柔和漫反射、偏暖的明暗交界、薄处透光、两层高光与绒毛光，且不模糊画面。见[皮肤](/docs/zh-cn/graphics/materials/surface-shaders/#皮肤)。 |
| **Eye** | `eye` | `esengine/character-shaders` | 角膜折射、虹膜、角膜缘环、瞳孔、巩膜与眼睑阴影。见[眼睛](/docs/zh-cn/graphics/materials/surface-shaders/#眼睛)。 |

## 创建材质与着色器

内容浏览器的创建菜单包含以下条目：

| 条目 | 结果 |
|---|---|
| **新建材质** ▸ *模板* | `New<Template>Material.esmaterial`，引用 `builtin:<id>`，不写出着色器文件。 |
| **新建着色器** ▸ *模板* | `New<Template>Shader.esshader`，为模板源码的副本，可在任意材质的 Shader 选择器中选用。 |
| **新建材质图** | 一个 `.esmatgraph` 材质图（[代码中的材质图](/docs/zh-cn/graphics/materials/code/#代码中的材质图)）。 |
| **新建材质子图** | 一个 `.esmatsub` 图，在其他图中作为节点使用。 |
| **创建材质实例**（材质的右键菜单） | `<材质名> Instance.esmaterial`，`instanceOf` 指向该材质，无覆盖项。 |
## 材质检视器

在内容浏览器中选中材质后，材质在 Details 面板中打开。检视器分为三部分：**着色器**、参数分区与**渲染状态**。

### 着色器

| 控件 | 说明 |
|---|---|
| **着色器**下拉框 | 列出所有内置模板（显示为 *内置 · &lt;名称&gt;*）以及项目中的所有 `.esshader`。选择其一即重新绑定材质。 |
| **转为独立着色器…** | 材质引用 `builtin:` 模板时显示。将模板源码写入材质旁的 `<material>.esshader`，并让材质指向该文件。参数值保留。 |
| 着色器缺失提示 | 被引用的 `.esshader` 不存在时显示。 |

更换着色器会重新执行反射：参数分区按新着色器的 `#pragma param` 重建。材质的参数值与已启用的开关被清空，因为它们属于先前的着色器。

多个材质可以引用同一个 `.esshader`（资源徽标 **SHD**）。它们共享同一份编译后的着色器，对源码的修改作用于所有引用它的材质。

### 参数

带 `group(Name)` 子句的参数按分组各成一个分区（Model 着色器的分组为 Base、UV、Normal、Emissive、Occlusion、Wetness 与 Detail）；无分组的参数显示在**参数**下。字段标签由参数名生成：`u_uvTiling` 显示为 **UV Tiling**。Model 材质的每个[着色层](/docs/zh-cn/graphics/materials/surface-shaders/#在检视器中编辑着色层)为一个分区，标题栏带开关。

### 渲染状态

| 字段 | 取值 |
|---|---|
| **混合模式** | 正常、相加、正片叠底、滤色、预乘 |
| **深度测试** | 开 / 关 |
| **深度写入** | 开 / 关 |
| **剔除** | 无、背面、正面 |

### 材质实例

材质实例（`instanceOf` 另一个材质）在着色器选择器的位置显示 *着色器继承自父材质。*，并在每个参数前显示一个勾选框。勾选的参数由实例设置；未勾选的参数取父材质的值，显示为灰色且不可编辑。勾选后，参数保持当前显示的值直至被修改，即使该值来自父材质。

<Aside type="note">
  材质实例只存储被覆盖的参数与渲染状态。对父材质的修改作用于所有未覆盖该项的实例。
</Aside>
