`Terrain` 将高度场地面绘制为以视点为中心、由同一块面片组成的四叉树：近处网格最细，随距离逐级加倍。地面在每个
(x, z) 位置只有一个高度；洞穴、悬垂和孔洞需使用[体素地形](/docs/zh-cn/world/voxel-terrain/)。

地形是可选模块（`esengine/terrain`）。场景包含 `Terrain` 或脚本导入该模块时，包中才会带上它。

## 组件

为实体添加 `Terrain`。地面位于该实体处；其子实体为四叉树节点，在运行时及编辑器场景视图中创建，并随视点移动而更新。
仅保存组件本身，不向场景烘焙任何几何体。

`extent` 选择地面类型：

| `extent` | 行为 |
|---|---|
| **Area** | 以实体为中心、`sizeX` × `sizeZ` 的地面，来源为高度图、分块集，或（两者皆无时）生成器在该区域世界位置上的一个窗口。同尺寸的两块噪声区域并排放置时彼此衔接；移动区域移动的是窗口，而非地面。支持侵蚀、溅射图、颜色图和遮蔽图。 |
| **Infinite** | 由生成器在任意世界位置给出的地面，没有边缘，围绕视点绘制到 `drawDistance`。相同的生成器、世界、种子和版本，在编辑器、游戏和服务器上得到相同的地面。 |

![Terrain 的 Details：图层列表，以及地面的形状和高度来源](@/assets/guides/zh/details-terrain.png)

*`Terrain` 组件：图层，其后为地面形状及高度来源。*

### 形状

| 字段 | 说明 |
|---|---|
| `extent` | `Area` 或 `Infinite`。 |
| `heightmap` | 仅 Area。按数据读取的图像：读取文件原始字节，不做颜色转换，也不生成 GPU 纹理，按原 PNG 发布。导出时被压缩的高度图会使地形失败并给出提示。将图像指定到此处时，其纹理在导入设置中被标记为 **Data**（见[纹理](/docs/zh-cn/assets/textures/)）：除非另行设置，否则不限制尺寸，设置上限时仍保留 16 位。留空则由噪声生成地面。 |
| `tiles` | 仅 Area。取代 `heightmap` 的 `.esterrain` 文件：视点附近读取分块，其余部分使用粗略总览。见[分块地面](/docs/zh-cn/graphics/terrain/large-worlds/#分块地面)。 |
| `heightmapFormat` | **Grey**：按文件位深读取灰度（或红色）通道——16 位 PNG 为 16 位，8 位 PNG 为 256 级。**Red + green**：8 位图像的红色（高字节）与绿色（低字节）组成 16 位。 |
| `sizeX`、`sizeZ` | 区域尺寸（世界单位）。无限地面中 `sizeX` 为 `frequency` 座山丘分布的跨度，`sizeZ` 不使用。 |
| `height` | 最高地面的世界高度。 |
| `provider`、`world`、`generatorVersion` | 无限地面或无高度图的区域：生成器（`estella:noise` 为引擎自带噪声，或由游戏注册）、传给它的世界名，以及该世界生成时所用的版本。生成器不再列出的版本会使地形失败。 |
| `erosion` | 0–4。雨水侵蚀强度，见[侵蚀](#侵蚀)。0 不改变地面。 |

### 噪声

地面来自 `estella:noise` 时使用。

| 字段 | 说明 |
|---|---|
| `seed` | 噪声种子，不同种子生成不同地面。 |
| `frequency` | 区域内（无限地面为 `sizeX` 内）横跨的山丘数。 |
| `octaves` | 细节层数，1–8。 |
| `persistence` | 每个更细八度保留的高度比例，0–1。越低越平滑。 |
| `ridged` | 0 为起伏丘陵，1 为尖锐山脊。 |
| `resolution` | 仅 Area。噪声场每边的采样数（17–2049）。 |
| `warp` | 0–1。噪声被自身噪声扭曲的程度：形成蜿蜒的山谷和弯折的山脊，而非圆丘。 |

### 图层

| 字段 | 说明 |
|---|---|
| `layers` | 至多八个[地形层](#地形层)文件，顺序即绘制权重的顺序。设置后地面使用 **Terrain Layers** 着色器。留空时绘制四种图层颜色，或 Terrain 着色器材质中的纹理。 |
| `material` | **Terrain** 着色器上的材质；设置了 `layers` 时为 **Terrain Layers** 着色器上的材质。留空使用内置材质。 |
| `splatmap` | 仅 Area。第 1–4 层的 RGBA 权重。留空则按高度与坡度绘制。 |
| `splatmap2` | 仅 Area。第 5–8 层的 RGBA 权重，与 `splatmap` 一同读取。 |
| `colorMap` | 仅 Area。覆盖整个区域、按 alpha 混入地面颜色的纹理（花海、地图区域、焦土）。导入**用途**：颜色。其第一行位于区域 z 最小处，与高度图一致。 |
| `colorMapStrength` | 0–1。颜色图 alpha 为 1 处的混入量。每帧读取，修改不触发重建。 |
| `occlusionMap` | 仅 Area。红色通道表示到达地面的天光比例：为沟壑、洼地和崖脚烘焙的遮蔽，这些尺度超出屏幕空间遮蔽的范围。只减弱环境光，直射阳光交由阴影处理。导入**用途**：数据。 |
| `occlusionStrength` | 0–1。遮蔽图的应用程度。 |
| `rockSlope` | 地面变为岩石的坡度（0 平坦，1 垂直）。 |
| `dirtHeight`、`snowHeight` | 以 `height` 比例表示的高度：草地让位于泥土处、积雪开始处。 |
| `layerColor0`–`3` | 无材质时草、泥土、雪、岩石的颜色。 |

### 细节

| 字段 | 说明 |
|---|---|
| `cellSize` | 近处使用的最细网格单元，世界单位。距离越远单元逐级加倍。 |
| `detail` | 0.25–8。最细单元覆盖范围的倍数。大于 1 时远处更细，三角形更多。 |
| `drawDistance` | 仅 Infinite。地面从视点起的绘制距离。 |
| `virtualTexture` | 将分层表面烘焙为页，见[虚拟纹理](/docs/zh-cn/graphics/terrain/rendering-and-code/#虚拟纹理)。仅适用于有图层的地面。 |
| `virtualTextureFrom` | 从烘焙页绘制的第一个四叉树层级：0 包括最近的地面，1（默认）烘焙除最近一级外的所有层级。 |

### 碰撞

| 字段 | 说明 |
|---|---|
| `collision` | 3D 刚体和角色是否与地面碰撞。 |
| `collisionDistance` | 在每个运动刚体和角色周围构建碰撞分块的半径，世界单位。 |
| `collisionLayer` | 高级。碰撞层，0–15。 |
| `friction` | 高级。地面摩擦。 |

修改 `detail`、`drawDistance` 或图层颜色在下一帧生效；修改其他字段会重建地面。

### 侵蚀

在区域型地面上，`erosion` 模拟水力侵蚀：雨滴沿场向下坡流动，能携带更多泥沙处切削地面，减速处沉积。结果是坡面上的冲沟、
冲沟之间更锐利的山脊和谷底的淤积。取 1 时每个场采样对应一滴雨（上限 600 000 滴）。相同种子得到相同结果。侵蚀同样作用于
高度图的场。水流经过的冲沟处，草地被替换为泥土。大场的侵蚀分摊到多帧执行并显示进度（见
[分帧构建](/docs/zh-cn/graphics/terrain/rendering-and-code/#分帧构建)）。

无限地面没有供水流出的边缘，其侵蚀体现在噪声中：每个八度在其下方八度已陡峭处被衰减。这会在尖锐山脊之间形成平滑山谷，
除噪声本身外不增加开销，也不绘制泥土冲沟。

## 地形层

地形层（`.esterrainlayer`；编辑器中 **New → New Terrain Layer**）以一组纹理描述一种地面材质——草地、小路泥土、沙、岩石。
`Terrain` 在 `layers` 中列出至多八层，由溅射图分配权重（第一张溅射图 RGBA 为第 1–4 层，第二张为第 5–8 层）。没有溅射图时，
前四层按高度和坡度绘制为草、泥土、雪和岩石；[生成世界](/docs/zh-cn/world/generation/)的生物群系可绘制全部八层。

| 字段 | 说明 |
|---|---|
| `albedo` | 颜色纹理，sRGB。留空为白色，由 `tint` 着色。 |
| `normal` | 切线空间法线贴图，绿色朝上（OpenGL 约定）。留空为平面。 |
| `mask` | 红：环境光遮蔽。绿：粗糙度。蓝：高度。留空时：无遮蔽，使用 `roughness`，以反照率亮度作为高度。 |
| `tile` | 纹理重复一次覆盖的世界单位（默认 400，即每米 100 单位下 4 m）。 |
| `tint` | 反照率的 RGB 乘数。 |
| `roughness` | 无遮罩时的粗糙度（默认 0.9）。 |
| `normalStrength` | 法线贴图强度：1 为原样，0 为平面。 |
| `heightBlend` | 可选，0–1。本层自身高度对与其他层交界位置的决定程度：0 仅按绘制权重混合（草地过渡到沙地），1 按图层高度（石块穿出草地）。多层交汇时各层按权重参与。缺省时使用材质的 `u_heightBlend`。 |
| `occlusion` | 可选，0–1。到达本层的天光比例，与遮罩遮蔽相乘。使植被覆盖的地面比裸岩接收更少天光。直接光源不受影响。缺省为 1。 |

**Terrain Layers** 着色器（`builtin:terrain-layers`）绘制分层地面：

- 每层按世界位置采样，近处无可见重复，远处混入更宽的平铺。
- 图层交界处显示遮罩高度更高的一层（石块穿过草地，沙填充石缝）。
- 斜坡上各层还从侧面投影（三平面），悬崖不被拉伸。
- 法线贴图及遮罩中的遮蔽和粗糙度参与光照。
- 每个点由权重最大的四层绘制；锐化后其余层只占混合的极小部分，却会让每个地面像素读取全部八层纹理。

| 参数 | 说明 |
|---|---|
| `u_sharpness`、`u_heightBlend`、`u_blendNoise`、`u_antiTile`、`u_macroVariation`、`u_wetLevel`、`u_wetBand` | 同 [Terrain 材质](#terrain-材质)。 |
| `u_farScale` | 远处混入的更宽平铺的倍率。 |
| `u_triplanarFrom` | 开始侧面投影的坡度。 |
| `u_strataWarp`、`u_strataSpan` | 侧面投影的图层按高度读取，悬崖纹理的岩层保持水平。`u_strataWarp` 为岩层上下起伏的幅度，由宽 `u_strataSpan` 的缓变噪声驱动（默认 0，保持笔直）。 |
| `u_antiTileTurn` | 无重复采样中单元格可旋转的程度。带方向纹理的图层（沙纹）旋转后会显出六边形单元；0 只平移不旋转。 |
| `u_surfaceUp` | 从虚拟纹理绘制的最陡地面（法线向上分量，默认 0.65，约 50°）；更陡的地面实时着色。 |

**纹理要求。** 每层三张正方形、2 的幂、可无缝平铺的纹理。图层按最大图层的尺寸打包为纹理数组，上限 1024（小游戏平台为
512），因此 1024 已足够。法线贴图和遮罩按数据导入（不做色彩管理）。地形构建时打包图层纹理；图层文件或其纹理保存时重新打包。

## Terrain 材质

没有地形层文件时，地面固定为草、泥土、雪和岩石四层，由 **Terrain** 着色器（`builtin:terrain`）绘制。每个点对每层都有权重，
来自溅射图或高度与坡度。纹理按世界位置平铺，图层在地面上连续不断；岩石从三个方向投影。

| 参数 | 说明 |
|---|---|
| `u_layer0`–`3` | 图层纹理：草、泥土、雪、岩石。 |
| `u_tint0`–`3` | 各层颜色乘数。 |
| `u_tile0`–`3` | 各层重复一次覆盖的世界单位。 |
| `u_sharpness` | 接缝处权重较大一层的主导程度：1 为线性混合，越高边缘越硬。 |
| `u_heightBlend` | 接缝随图层起伏（纹理亮度）变化的程度：岩石先从草地缝隙中露出，沙子填满石块间的低处。0 为普通混合。 |
| `u_antiTile` | 每层以旋转后的更宽平铺再次采样、经缓变噪声混入的量，用于隐藏大片区域中的重复。随距离淡出。 |
| `u_macroVariation` | 覆盖所有图层的大尺度、缓变亮度变化。 |
| `u_relief` | 图层起伏（亮度作为高度）参与光照的深度，世界单位。0 为平滑。 |
| `u_wetLevel`、`u_wetBand` | 水线处的湿润地面：低于 `u_wetLevel + u_wetBand`（世界高度）时地面变暗、变得更有光泽，在 `u_wetLevel` 处最强。带宽为 0 时关闭。 |
| `u_roughness` | 干燥地面的粗糙度。 |

其他参数（`u_heightPages`、`u_lodRange0` 等）由 `Terrain` 组件每帧写入，不在材质中编辑。

## 地面融合

以下三种机制用于隐藏物体与地面相接的线，均不要求地面是地形。

### Ground Blend 材质

`builtin:ground-blend` 着色器即 [Model](/docs/zh-cn/graphics/materials/overview/#内置着色器模板) 着色器，保留其全部贴图和参数，用于岩石、路缘石和地基。
表面靠近其后方已渲染的内容时，会淡入场景中该像素的画面，因此接缝融入地面实际绘制的样子（图层、光照与阴影），无需任何烘焙。

| 参数 | 说明 |
|---|---|
| `u_blendDistance` | 距后方表面多高处材质完全不透明，世界单位。按高度而非视线方向度量，相机俯仰时过渡带保持不变。0 为硬边。 |
| `u_blendNoise`、`u_blendNoiseScale` | 边缘的不规则程度及其世界尺度。 |
| `u_layer2`、`u_layer2Tint`、`u_layer2Roughness` | 第二层：泥土、苔藓、湿石。 |
| `u_layer2Tile` | 第二层重复一次的世界长度，从上方投影，跨物体对齐。0 使用网格自身 UV。 |
| `u_layerReach` | 第二层从后方表面向上延伸的高度。 |
| `u_vertexBlend` | 1：顶点颜色红色通道绘制第二层，顶点颜色不再为表面着色。 |

使用该着色器的材质在获取不透明场景副本之后绘制，与水相同；包含此类材质的场景即使没有后处理效果也会获取该副本。

### `RoadDecal`

带有 `Spline` 的实体上的 `RoadDecal` 将实体的 `MeshRenderer` 沿曲线逐行铺在地面上。样条或地面变化时重建。没有地形时按曲线
原样铺设。两侧边缘在 `edgeFade` 范围内淡出，因此应使用混合材质。

| 字段 | 说明 |
|---|---|
| `step` | 沿曲线的行间距，世界单位。越小越贴合地面与弯道。 |
| `across` | 横向单元数（1–32）。越多越贴合拱起或倾斜的地面。 |
| `widthScale` | 各样条点所存宽度的乘数。 |
| `lift` | 离地高度。远处地面绘制得比请求的更粗，远看的道路需要更大的抬升。 |
| `edgeFade` | 每侧边缘淡出范围占半宽的比例。 |
| `tile` | 纹理沿曲线重复一次的长度。 |

### 积雪与湿润表面

`snowCover` [后处理效果](/docs/zh-cn/graphics/post-processing/sky-and-weather/#积雪覆盖)在任何朝天且未被遮挡的表面上铺雪，地形与物体同样适用，无需修改材质。
参数：`u_amount`、`u_snowLine` 与 `u_snowLineBand`（积雪止于的高度）、`u_slopeLimit`、`u_grainScale`。`Snow`
[天气](/docs/zh-cn/graphics/weather/)会添加该效果。`rain` 效果在 `u_intensity` 为 0 且提高 `u_wetness` 时，可得到无降雨的湿润地面。

## 限制

- **每个位置一个高度。** 洞穴、悬垂和孔洞需使用[体素地形](/docs/zh-cn/world/voxel-terrain/)，或与地形一同摆放的网格。
- **仅位置。** 地形跟随实体位置；`heightAt` 和着色器均忽略旋转与缩放。保持实体不旋转、不缩放，用 `sizeX`、`sizeZ` 和
  `height` 设定地面尺寸。
- **无限地面由生成器给出。** 不接受高度图或溅射图，其侵蚀不绘制泥土。
- **绘制精度等于页精度。** 图层权重与高度一同采样，每个单元两个样本；更细的溅射图在近处被平均，远处更粗。
- **Ground Blend 淡入其后方的内容。** 表面后方近处没有内容时（以远处山谷为背景的岩石侧面），没有可隐藏的接缝。紧贴 Ground
  Blend 物体后方的墙同样算作近处。两个 Ground Blend 物体之间不会互相淡入，因为二者都不在对方读取的场景副本中。需要浮点渲染
  目标；不支持时按普通 Model 材质绘制。
- **`snowCover` 是屏幕空间效果。** 它没有深度：不会让边缘变圆，也不会掩埋石块，只覆盖相机所见。
