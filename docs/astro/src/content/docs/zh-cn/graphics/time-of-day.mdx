`TimeOfDay` 根据时角、纬度和太阳赤纬（季节）确定太阳位置，得到正确的昼夜形态：夏季的弧线长而高，冬季的短而低，日出偏东。
它对灯光、天空和雾的作用与[天气](/docs/zh-cn/graphics/weather/)一样，以**场景已编写数值的乘数**表示，因此同一钟点适用于任何项目。

## 组件

为一个实体添加 `TimeOfDay`。

| 字段 | 说明 |
|---|---|
| `hour` | 钟点，0–24（12 为正午；默认 12）。运行时由系统推进；在编辑器中设置以预览某个钟点。 |
| `daySeconds` | 运行时一整天的实际秒数。0（默认）保持钟点不变。 |
| `latitude` | 纬度（度），北为正（默认 40）：决定正午太阳的高度和白昼长度。 |
| `declination` | 季节，−23.5 至 23.5；正值为北半球夏季（默认 15）。 |
| `north` | 世界相对指南针北（+Z）向 +X 旋转的角度（度）：决定日出方向（默认 0）。 |
| `drive` | 钟点驱动的内容：Lights、Sky、Fog、Exposure、Reflections。默认全部五项。 |

*`TimeOfDay` 组件：标出钟点的日照曲线、实时太阳读数和驱动开关。*

## 在编辑器中

Details 以曲线而非数字列表显示一天：根据本组件的纬度和赤纬计算的 24 小时太阳高度（冬季为低而短的弧线，极地夏季太阳不落），
并有一个设置钟点的手柄。也可聚焦表盘后使用方向键：每步 15 分钟，按住 **Shift** 为一小时。曲线旁显示该钟点的太阳高度、日照值
和主光缩放；下方为每个驱动项的开关。编辑器中设置的钟点仅用于预览，只在运行时推进。

## 钟点驱动的内容

| 驱动 | 作用 |
|---|---|
| **Lights** | 主光——跟随全景图太阳或投射阴影的方向光，否则为第一个方向光——对准太阳，并按日照曲线缩放：近地平线时偏暖、偏弱，落到地平线下不久后关闭。太阳落下后，主光对准**月亮**，强度为太阳的百分之几并带蓝色调，因此夜晚有来自月亮的阴影。切换发生在两者都暗的时刻，不会跳变。环境光同步缩放和着色：夜间偏蓝，黄昏偏暖。 |
| **Reflections** | 烘焙的反射探针变暗并降低饱和度，因为它们是在白天天空下烘焙的。 |
| **Sky** | [Sky Atmosphere](/docs/zh-cn/graphics/post-processing/sky-and-weather/#天空大气) 效果模拟阳光在大气中的散射——瑞利散射产生空气的蓝色，米氏散射产生雾霭和太阳周围的眩光——正午的蓝、日落的红和余晖都来自同一计算。它绘制太阳（头顶为白色，地平线处为红色）、月亮、星星，以及由太阳照亮、随风移动的体积云。它从时钟取得太阳位置，因此不会把月光下的主光误认为太阳。 |
| **Fog** | Height Fog 的颜色随一天的光照变化（夜间暗，黄昏橙），其辉光跟随主光。 |
| **Exposure** | 夜间提高 Auto Exposure 的补偿，保持画面可读。没有 Auto Exposure 的场景在其 Colour Grade 上获得补偿。 |

在编辑器中不修改场景灯光——与天气一样，预览钟点不会改变保存的场景——因此跟随太阳的效果（天空、雾）直接获得时钟的太阳位置。
灯光在运行时移动。

## 与天气组合

昼夜与天气缩放相同的灯光，各自基于编写的数值，因此二者可组合：雨天黄昏即黄昏的颜色 × 雨天的强度。天气还会使天空变灰
（`overcast`），随云层增厚遮住太阳、月亮和星星。

## 代码

```ts
import { timeOfDayAt, currentTimeOfDay, TimeOfDay } from 'esengine';

// 北纬 51 度、仲夏 18:30 的太阳。
const evening = timeOfDayAt(18.5, 51, 23);
evening.sunDir;        // 指向太阳的单位向量
evening.daylight;      // 夜间为 0，白天为 1

// 设置钟点，其余由系统完成。
world.insert(clockEntity, TimeOfDay, { hour: 6, daySeconds: 600 });
```

| 函数 | 说明 |
|---|---|
| `timeOfDayAt(hour, latitude?, declination?, north?)` | 某钟点的状态（默认值 40、15、0），包括 `sunDir` 和 `daylight`。 |
| `currentTimeOfDay()` | 当前帧所处的昼夜状态；没有 `TimeOfDay` 时为 `null`。 |
| `hourAt(hour, daySeconds, t)` | 从 `hour` 开始的时钟在 `t` 秒后的钟点。 |

钟点与天气一样来自场景时钟；`seekSceneClock(t)` 移动时钟（见[场景时钟](/docs/zh-cn/graphics/weather/#场景时钟)）。

## 限制

- **烘焙光照只对应一个时刻。** 光照贴图、探针体积和烘焙反射探针都在白天天空下烘焙，因此不来自灯光的光照不随太阳移动。需要
  经历一整天的场景应使用实时太阳和天空——由灯光照亮，或烘焙内容主要来自柔和的天光——其余由上述变暗与着色处理。
- **自发光表面不会自动切换。** 窗户和灯在夜间不会自行点亮；为其使用自发光材质，或根据 `currentTimeOfDay()?.daylight` 打开灯光。
