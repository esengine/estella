`Video` 组件将视频片段解码为一张逐帧刷新的 GPU 纹理，并将该纹理写入同一实体上的渲染组件：`Sprite`、`UIVisual` 或 `MeshRenderer`。在网页上由 `HTMLVideoElement` 解码；在原生与小游戏目标上，由引擎自带、编译为 wasm 的 MPEG-1 解码器解码 cook 生成的副本。纹理契约在所有平台上一致。

## `Video` 组件

在编辑器中，为带 **Sprite** 的实体添加 **Video** 组件并设置其 **Source**。在代码中，将其与渲染组件一同插入：

```typescript
import { defineSystem, Commands, Transform, Sprite, Video } from 'esengine';

const spawnScreen = defineSystem([Commands()], (cmds) => {
  cmds.spawn()
    .insert(Transform, { position: { x: 0, y: 0, z: 0 } })
    .insert(Sprite, { size: { x: 360, y: 360 } })
    .insert(Video, { source: 'assets/clip.mp4', autoplay: true, loop: true, muted: true });
});
```

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `source` | 资源 | `''` | 视频片段。修改后停止当前流并开始播放新片段。 |
| `autoplay` | boolean | `true` | 首帧就绪后立即开始播放。 |
| `loop` | boolean | `true` | 播放结束后从头开始。 |
| `muted` | boolean | `true` | 静音。静音片段可自动播放；非静音播放需要用户手势。 |
| `volume` | number | `1.0` | 音量，0–1（`muted` 时忽略）。 |
| `playbackRate` | number | `1.0` | 播放速度与音高（`1` 为正常）。 |
| `fitSize` | boolean | `true` | 帧到达后将 `Sprite` 调整为视频的原生像素尺寸。仅作用于 `Sprite`。 |
| `enabled` | boolean | `true` | 为 `false` 时停止并释放视频流，不移除组件。 |

`volume`、`muted`、`loop` 与 `playbackRate` 修改后立即作用于正在播放的流。清空 `source`、禁用组件或销毁实体会停止并释放视频流。

### 渲染组件

视频系统将帧纹理写入在实体上找到的第一个渲染组件，顺序如下：

| 渲染组件 | 写入的字段 | 用途 |
|---|---|---|
| `Sprite` | `texture`；设置了 `fitSize` 时还有 `size` | 世界中的视频。 |
| `UIVisual` | `texture`；`visualType` 设为 `Image` | 屏幕 UI 中的视频面板。 |
| `MeshRenderer` | `texture` | 映射到自定义几何体上的片段。 |

带 `Video` 但没有渲染组件的实体会解码但不显示任何内容，控制台对该实体输出一次警告。

### 行为

- 视频**只在运行模式下**解码；编辑场景时不解码。
- 视频插件与音频插件一样属于默认插件集，无需额外添加。
- 帧纹理是**无路径的**（永不淘汰），其句柄在视频流生命周期内保持不变，因此写入一次的句柄始终有效。

<Aside type="note">
  静音片段在所有平台上都能自动播放。浏览器在用户手势之前会阻止非静音的自动播放，因此带声音的播放应由点击或按键触发。
</Aside>

## 多个表面共享一条视频流

帧纹理是普通的纹理句柄，任意数量的精灵都可以使用：读取正在播放的精灵的 `texture`，赋给其他精灵。每个表面通过 Sprite 的 `uvOffset` / `uvScale` 选取帧的一个**区域**（与图集帧相同的约定，`v = 0` 为图像底行）。一次解码供所有表面使用。

```typescript
// 将活动视频纹理镜像到每个瓦片上；每个瓦片采样 1/N 区域。
const shareVideoTexture = defineSystem(
  [Query(Sprite, Video), Query(Mut(Sprite), PuzzlePiece)],
  (preview, pieces) => {
    let texture = 0;
    for (const [, sprite] of preview) { texture = sprite.texture; break; }
    if (!texture) return;                       // 首帧尚未解码
    for (const [, sprite] of pieces) {
      if (sprite.texture !== texture) sprite.texture = texture;   // 每片写入一次
    }
  },
);
```

**video-puzzle** 示例以此方式将一个片段变为一整块可交换的实时拼图瓦片。

## `VideoPlayer`

`VideoPlayer` 资源无需组件即可播放视频源，并返回一个**流句柄**，其 `textureHandle` 可赋给任何精灵或材质：

```typescript
import { defineSystem, Res, VideoPlayer } from 'esengine';

const playIntro = defineSystem([Res(VideoPlayer)], (video) => {
  const stream = video.play('assets/intro.mp4', { loop: false, muted: true });
  stream.onEnded = () => { /* 跳过片头 */ };
  // stream.isReady 后将 stream.textureHandle 赋给某个 Sprite/MeshRenderer
});
```

| `VideoPlayer` 方法 | 说明 |
|---|---|
| `play(source, options?)` | 开始一条视频流并返回其句柄。 |
| `stop(handle)` | 停止并释放一条视频流。 |
| `stopAll()` | 停止所有视频流。 |

`play` 的选项与组件相同，但默认值不同：

| 选项 | 默认值 |
|---|---|
| `autoplay` | `true` |
| `loop` | `false` |
| `muted` | `false` |
| `volume` | `1` |
| `playbackRate` | `1` |

流句柄成员：

| 成员 | 种类 | 说明 |
|---|---|---|
| `play()` / `pause()` / `stop()` | 方法 | 播放控制。 |
| `seek(seconds)` | 方法 | 跳转到指定时间。 |
| `setVolume(v)` / `setMuted(m)` | 方法 | 调整音频。 |
| `setLoop(l)` / `setPlaybackRate(r)` | 方法 | 调整循环与速度。 |
| `textureHandle` | 只读 | 实时帧纹理：首帧前为 `0`，之后无路径（永不淘汰）。 |
| `width` / `height` | 只读 | 原生像素尺寸。 |
| `isReady` | 只读 | 首帧已解码。 |
| `isPlaying` | 只读 | 正在播放。 |
| `currentTime` / `duration` | 只读 | 秒。 |
| `onReady` / `onEnded` / `onError` | 回调 | 生命周期钩子。 |

## 导入设置

选中视频资源后显示循环、静音的预览及其**导入设置**。播放设置（自动播放、循环、静音）属于 `Video` 组件，不属于资源。两项**高级**设置控制 wasm 解码路径的转码：

| 设置 | 范围 | 默认值 | 说明 |
|---|---|---|---|
| **Cook Quality** | `2`–`31` | `4` | MPEG-1 量化器。`2` 接近无损、文件最大；`31` 文件最小。 |
| **Cook Audio Bitrate** | `96` / `128` / `192` kbps | `128` | 分离出的音轨的 AAC 码率。 |

{/* SHOT: video-import-settings | Details panel with an .mp4 video asset selected in the Content Browser: the video preview at the top and the Import Settings with the Advanced group expanded, showing Cook Quality 4 and Cook Audio Bitrate 128 kbps. */}

视频资源包括 `.mp4`、`.m4v`、`.mov` 容器，MPEG-1 `.mpg` / `.mpeg` 源文件，以及 cook 生成的 `.esv` 文件。`.webm` 文件默认归为音频，除非其 `.meta` 类型为 `video`。

## Cook 后的视频

面向 Android、iOS、原生桌面、微信及其他小游戏平台的导出，会将每个随包发布的视频转码为带编解码标记的 **`.esv`**（MPEG-1 程序流）以及一个 **`.m4a`** 音轨文件。这是 wasm 解码器读取的格式；音轨通过音频管线播放，并作为视频的时钟。网页导出原样发布原始文件。

## 平台后端

纹理句柄契约在所有后端上一致，只有解码器不同。

| 平台 | 解码器 | 说明 |
|---|---|---|
| 网页、编辑器运行 | `HTMLVideoElement` | 浏览器支持的任意编解码格式（H.264 `.mp4`、WebM 等）。WebGL2 逐帧零拷贝上传；WebGPU 通过 canvas 回读。 |
| 原生（Android、iOS、桌面） | 引擎自带的 wasm 解码器，以侧模块方式获取 | 播放 cook 生成的 `.esv` + `.m4a`；设备上没有其他视频路径。 |
| 微信 | 引擎自带的 MPEG-1 wasm 解码器（`videodec`，pl_mpeg） | 在所有设备上结果确定；`wx.createVideoDecoder` 在 PC 上缺失、在手机上不可靠。场景使用 `Video` 时自动随包；播放 cook 生成的 `.esv` + `.m4a`。 |
| 其他小游戏平台 | 同一个引擎自带的 wasm 解码器，在所有厂商上均为默认 | 宿主视频解码器在 PC 客户端上缺失，在手机上不可靠。 |

## 使用准则

- 自动播放时保持 `muted: true`；带声音的播放由用户手势触发。
- 通过纹理句柄与 `uvOffset` / `uvScale` 在多个表面间共享一条视频流，而不是用多个 `Video` 组件解码同一片段。
- Sprite 有明确尺寸（固定屏幕）时关闭 `fitSize`。
- 面向原生与小游戏目标时，片段应短小、分辨率适中：软件解码开销与下载体积都随分辨率增长。
