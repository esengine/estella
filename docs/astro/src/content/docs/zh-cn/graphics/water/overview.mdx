水由三部分组成：

| 部分 | 作用 |
|---|---|
| **`WaterBody`** | 声明水的位置：海洋、湖泊、河流、岛屿、排除体积或自定义形状。水体是输入，本身不绘制。 |
| **`WaterZone`** | 将区域内所有水体烘焙为一张场，据此绘制一个由波浪抬起的水面，并用同一数据回答水面查询，因此脚本读到的就是绘制出的内容。 |
| **Water 着色器**（`builtin:water`） | 水面外观：折射、水深、反射、泡沫、焦散。 |

水是可选模块（`esengine/water`）。只有场景包含 `WaterBody` 或脚本导入该模块时，包中才会带上它。

## 水体

为实体添加 `WaterBody`。实体决定水体的位置；水体可绕自身上方向旋转，但不能倾斜。移动水体、编辑其字段、轮廓或样条，或修改
其下方的地形，都会立即重新烘焙水体区域。

| `form` | 形状 |
|---|---|
| **Ocean** | 没有边缘。在地面低于实体高度且与开阔海相连的地方处于实体高度，并延伸到区域之外。 |
| **Lake** | 以实体为中心的 `sizeX` × `sizeZ` 矩形，或 `boundary` 中的轮廓，位于实体高度。 |
| **River** | 沿同一实体上的 `Spline`。见[河流](/docs/zh-cn/graphics/water/rivers-and-shores/#河流)。 |
| **Island** | 将矩形或轮廓内的地形抬升到实体高度，使其露出周围水面。 |
| **Exclusion Volume** | 不含水的盒体（`sizeX` × `sizeY` × `sizeZ`，或高度为 `sizeY` 的轮廓）：其上不绘制水面，其内部任何位置都不在水下。用于海底干燥房间或船舱。 |
| **Custom** | `shapeMesh` 从上方看的形状（喷泉池、任意轮廓的水池），水面位于网格顶部。该网格只作为形状，不被绘制。 |

### 形状

| 字段 | 形态 | 说明 |
|---|---|---|
| `bodyId` | 全部 | 查询在各次运行中使用的稳定名称（实体编号不稳定）。留空时以实体称呼该水体。 |
| `sizeX`、`sizeZ` | Lake、Island、Exclusion | 没有 `boundary` 时的范围。 |
| `sizeY` | Exclusion | 体积高度，以实体为中心。 |
| `boundary` | Lake、Island、Exclusion | 轮廓：水体自身 xz 平面上三个或更多点。留空使用矩形。 |
| `shapeMesh` | Custom | 其俯视三角形即为水面的网格。 |
| `shoreWidth` | Ocean、Lake、River、Island、Custom | 从岸边向内波浪增长到完整高度的距离（0：一直完整到边缘）。对岛屿而言，是其坡面越过轮廓向外延伸到地面的距离。 |
| `bedDepth` | Lake、River | 水切入地形的深度：河流为河道中部的河床，湖泊为轮廓下的湖底。只向下切；0 不改变地面。 |
| `shapeDilation` | Lake、River、Custom | 水越过轮廓向外延伸的距离。用于加宽窄于几个区域纹素的水体（溪流、小池塘），否则它们会变细或断开。 |

排除体积另有 `excludeAllOverlapping`（排除所有重叠水体；默认开启）和 `excludeBodies`（关闭时要排除的水体）。

### 波浪

| 字段 | 形态 | 说明 |
|---|---|---|
| `waveHeight` | Ocean、Lake、Custom（河流保留已存值） | 最高波浪的高度，世界单位。波长、速度和方向由水体区域决定。 |
| `waveAttenuationDepth` | Ocean、Lake、River、Custom | 波浪保持完整高度的水深；更浅处逐渐平息，到边缘处为平面。0 关闭按水深平息（`shoreWidth` 仍然生效）。 |
| `flowSpeed` | River | 河流最宽处的流速，世界单位/秒。 |

### 外观与渲染

| 字段 | 说明 |
|---|---|
| `surfaceLook` | **Zone Material**：使用区域水材质的颜色。**Own**：使用水体自身的 `waterColor`。有自身颜色的水体与其他水体相接时，颜色在交汇处混合。 |
| `waterColor` | 本水体浅水的颜色；深水按材质深水色的方式使其变暗。 |
| `overlapPriority` | 水体重叠处，优先级较高者提供颜色，只在其自身边缘处混合。优先级相同时按点位于各自内部的深度混合。 |
| `waterMaterial` | 本水体在共享水面上的材质实例。留空继承区域材质。 |
| `underwaterMaterial` | 镜头没入水中部分的后处理材质。留空使用内置水下着色器。 |
| `riverToLakeMaterial`、`riverToOceanMaterial` | 仅河流。河流汇入湖泊或开阔海处共享水面上的材质。 |

水面材质共享 Water 着色器的位移约定，在同一几何上相接。水下相关字段见[水面之下](/docs/zh-cn/graphics/water/interaction-and-shader/#水面之下)，
地形塑形字段见[地形塑形](/docs/zh-cn/graphics/water/rivers-and-shores/#地形塑形)。

## 水体区域

`WaterZone` 规定水绘制的范围、分辨率以及所有水体共享的内容。其区域以实体为中心，大小为 `sizeX` × `sizeZ`（只使用 x 和 z）。

| 分组 | 字段 | 说明 |
|---|---|---|
| Region | `sizeX`、`sizeZ` | 烘焙区域。区域外的水不绘制，海洋除外。 |
| Region | `resolution` | 区域长边上的纹素数（32–1024）：岸线与河流的描绘精度。 |
| Look | `material` | 没有覆盖设置的水体使用的默认水面材质。留空使用内置 Water 着色器。 |
| Waves | `waveLength`、`waveSpeed`、`waveDirection` | 最长波浪的波长、速度乘数和方向（度）。见[波浪](#波浪)。 |
| Waves | `surf`、`surfLength`、`surfSpread` | 碎浪相对水体波浪的高度（0：无）、拍岸浪波长，以及来浪波峰的方向扩散（0 为直线波峰，1 为交叉涌浪）。见[拍岸浪](#拍岸浪)。 |
| Mesh | `tileSize`、`extentInTiles` | 基础分块宽度（世界单位，0 由旧的单元设置推导），以及从区域中心到 X、Z 各边缘的分块数。 |
| Mesh | `tessellationFactor` | 每块每边有 2^`tessellationFactor` 个单元（1–6）。 |
| Mesh | `lodScale` | 以分块宽度计的拆分距离（0.5–4）。越大，远处保留的细节越多。 |
| Mesh | `forceCollapseDensityLevel` | 允许合并部分有水的岸线分块的第一个层级。−1 保留岸线轮廓。 |
| Detail | `cellSize`、`cells`、`rings` | 旧版环形网格，仅在 `tileSize` 为 0 时使用。 |
| Ripples | `ripples`、`rippleSize`、`rippleSpeed`、`rippleDamping`、`foamFade` | 见[涟漪](/docs/zh-cn/graphics/water/interaction-and-shader/#涟漪)。 |
| Far Distance | `farDistance`、`farDistanceExtent`、`farDistanceMaterial`、`farMeshWithoutOcean` | 见[水面网格](#水面网格)。 |

### 烘焙

水体区域将区域内的所有水体烘焙为一张网格，每个纹素存储：

- 水面**高度**：湖泊的水位、河流曲线在最近点处的高度、海洋的水位；
- 到最近岸线的有符号**距离**，水上为正：决定水面在何处被裁切、在何处起泡；
- 该处的**波高**：水体的 `waveHeight`，向岸边和随水变浅而平息；
- **流速**（河流）以及水面到地面的**水深**。

两个水体相接处，每个纹素按位于各水体内部的深度对其加权，过渡范围为一个半纹素，因此数值从一个水体连续过渡到另一个：河流在
河口处达到湖泊的水位，流速逝入静水，河岸延续为湖岸，没有接缝。湖泊和河流优先于海洋。没有水体占据的纹素保留最近水面的
高度，因此被岸线裁切的水面边缘不会被拉低。某点属于哪个水体与添加水体的顺序无关。

没有 `WaterZone` 的场景会获得一个覆盖所有湖泊和河流（含岸线余量）的区域，使用组件默认值，每纹素为最细单元的一半（长边 32–1024
纹素）。只有海洋的场景不需要区域。存在多个 `WaterZone` 时使用第一个找到的。

烘焙在 CPU 上进行，不需要渲染器，因此服务器或无头测试也能查询水面。水体、区域或地形变化时整体重做，开销与纹素数 × 水体数成正比。

## 波浪

八道尖峰正弦波（`exp(sin(θ) − 1)`：波峰窄于波谷）围绕风向分布，每道比前一道短，其波长、高度和速度为区域 `waveLength`、
`waveSpeed` 和 `waveDirection` 的比例。所有水体共享这些波浪。局部高度取自场中的值：水体的 `waveHeight` × 岸线保留的比例 ×
天气的波浪乘数。

驱动风的 `Weather` 按水面开阔程度缩放波浪：风浪随风区增长，因此海洋完整接受天气乘数，湖泊相对八个 `waveLength` 越宽接受越多，
河流几乎不受影响。

波浪**位移几何体**：每个顶点按波高抬升，片元着色器用同一公式逐像素计算坡度，因此受光表面与天空下的轮廓一致。波浪在世界 xz
平面上计算，并垂直抬升水面。波长和高度以世界单位计；重力为 9.8 m/s² 换算到世界单位，因此相同物理波长在米制和厘米制项目中
周期相同。

## 拍岸浪

在水与地面相接处，水体区域测量每个纹素沿地面到最近岸线的距离（海洋对海滩与湖泊相同）。在最后四个 `surfLength` 的水域内，
拍岸浪按此距离隆起：朝岸一侧陡峭、背面平缓的波浪，以该波长的深水波速 × `waveSpeed` 向岸推进。

- 拍岸浪随水变浅而增高，在带内侧破碎处泛白，并在波峰后保持一段时间的白色。
- 越过岸线后沿地面上冲：那里的水面绘制在略高于静止高度处，深度测试在地面升起处将其裁切，因此水线沿海滩爬升又回落。
- 碎浪高度为 `surf` × 水体的 `waveHeight`（包含天气波浪）× 水面开阔程度。拍岸浪是来自开阔水域的涌浪，因此湖岸只有轻拍，
  海岸则有碎浪；水流不携带拍岸浪，河流与河口保持平静。
- 波峰是其自身距离场（开阔水域边缘，河流水域视为陆地，并在一个 `surfLength` 内平滑）的等值线，因此从开阔水域笔直而来，只在
  近岸处转向岸线，并笔直越过河口。隆起、破碎和上冲的位置遵循真实岸线。
- 水体区域烘焙每段岸线的陡度：波浪在岩石和悬崖上迸裂起泡，在缓坡海滩上冲成一条细线，且只上冲一小段距离。

`Waters.sample` 包含相同的拍岸浪，因此海滩附近的漂浮物随之起伏。

## 水面网格

水体区域在共享的海洋、河流和湖泊水面上遍历分块四叉树。完全无水的分块被跳过。当前视图中近处分块细、远处分块粗。三角形对角线
交替排列；细边使用相邻粗块的实际顶点，顶点随相机移动逐渐移到父级网格上。`forceCollapseDensityLevel` 为 −1 时，混合的岸线
分块保持细节。最终岸线遵循烘焙的场。

基础分块每边有 `2 ** tessellationFactor` 个单元。`lodScale` 独立于分块尺寸和范围改变拆分距离。只保存了 `cellSize`、`cells`
和 `rings` 的场景保持原有的比例和覆盖范围。

**Water Zone → Mesh → 水面网格视图** 可在 **材质着色**、**波面线框** 和 **基准高度线框** 之间切换。两种线框都显示渲染器提交
的索引三角形，并给出分块数和三角形数。

**Far Distance** 用一张略低于海平面、由八个三角形组成的平面网格，将海洋从分块区域延伸到 `farDistanceExtent`，使海洋到达
地平线。它使用 `farDistanceMaterial` 绘制（留空时使用区域水材质的深水色和天空反射），且只在区域有海洋时绘制，除非开启
`farMeshWithoutOcean`。

## 画质档位

水按项目画质档位允许的开销绘制。这些设置属于每个档位的配置（`project.esproject`、`features.rendering.quality.profiles`），
项目可自行修改。**项目设置 → 渲染 → 档位 · 水** 为 **编辑档位** 下选中的档位编辑这些设置；画质关闭或项目排除了水模块时该组
隐藏。

| 设置 | 低 | 中 | 高 | 说明 |
|---|---|---|---|---|
| `waterWaves` | 3 | 5 | 8 | 从最长起累加的波数：作用于几何、着色和 `Waters.sample`。 |
| `waterRippleCells` | 32 | 64 | 128 | 涟漪网格每边的最大格数；区域的 `ripples` 被限制到该值。0 表示不保留。 |
| `waterDisplacement` | 关 | 开 | 开 | 波浪是否抬升几何。关闭即**轻量水**：位于静止高度的水面，波浪只在着色中体现。 |
| `waterMirror` | 关 | 开 | 开 | 从下方看水面时是否映出其下方的世界（屏幕空间步进）。 |
| `waterReflectionSteps` | 8 | 12 | 20 | 反射步进的步数，水上与水下均适用。步数少时每步更长，到达同样远但精度较低。 |
| `waterCaustics` | 关 | 开 | 开 | 是否在水下物体上绘制焦散，以及从水下看时的光柱。 |
| `waterCausticFieldSize` | 0 | 128 | 256 | 投影波面场每边的采样数。0 使用程序近似。 |
| `waterCausticLayers` | 2 | 3 | 3 | 程序近似（场大小为 0）的噪声层数。 |
| `waterShaftSteps` | 16 | 16 | 24 | 水下每像素沿视线累积光柱的采样数。步点有抖动，步数少时表现为噪点而非条带。 |

代码遵循绘制结果：没有位移时，`Waters.sample` 的水面处于静止状态，漂浮物停在其上；波数减少时两者同时减少。运行画质策略时由
当前档位决定；没有策略时，**小游戏**使用低档的水，其他平台使用高档。轻量水不为波浪做顶点计算，着色仍然流动，远看仍像水。

## 在编辑器中

Details 只显示水体当前形态使用的字段。湖泊的 **Boundary** 行显示点数（或显示为按尺寸的矩形），并可重置为矩形。水体还列出
作用于它的 **水体岛屿** 和 **水体排除体积**，以及它所属的水体区域。**新建水材质** 为水体或区域创建一个 Water 着色器材质并
指定；**编辑材质** 打开已指定的材质。

选中湖泊或河流时，其点显示为视口手柄，编辑方式与多边形碰撞体的顶点相同：

- **湖泊。** 每个轮廓点上一个方块，每条边中点一个圆。拖动点在湖泊平面上移动；拖动边上的圆插入一个点；按下点并原地松开则删除
  它。湖泊至少保留三个点；没有点时，矩形的四个角即为点，移动其中一个会把矩形转换为轮廓。
- **河流。** 在其 `Spline` 上使用相同手柄，并在每个点处有一个横向偏移半个河宽的宽度手柄，拖动它设置该处宽度。河流至少保留
  两个点。最后按下的点在 Details 的 Spline 下编辑（见[样条](/docs/zh-cn/graphics/water/rivers-and-shores/#样条)）。
- 每次操作为一个撤销步骤。拖动过程中点被实时写回，水随之变化。这些手柄是 Gizmo 菜单中的 **Water** 项。

水体区域的范围没有手柄，在 Details 中设置其尺寸。

## 限制

- **水面是水平的。** 水体可绕上方向旋转，不能倾斜；水面每个位置只有一个高度，不存在水上之水。
- **一个水体区域。** 使用第一个找到的 `WaterZone`，以及一个海洋（第一个找到的）。区域外的水不绘制，海洋除外。
- **场分辨率。** 岸线与河流按区域的 `resolution` 描绘：一两个纹素宽的河流，或比一个纹素更细的轮廓细节会丢失，除非用
  `shapeDilation` 加宽。大区域需要较高的 `resolution`。
- **范围。** 每个轴上的分块范围从区域中心量起。使用旧环形参数创建的海洋保留移动窗口。
- **波浪是正弦叠加，** 不是模拟的频谱，只垂直抬升水面，没有水平位移。
- **水面需要场景副本。** 折射使用与玻璃相同的引擎场景副本（必须有后处理链在运行），并需要浮点渲染目标存储深度。没有后处理链
  时，水作为半透明表面绘制在场景之上；没有浮点目标时，各处深度均为 `u_fallbackDepth`，颜色不随深度变化，只有区域烘焙的
  岸线起泡。
- **混合绘制与水。** 一帧同时包含两者时分层绘制（不透明场景；在其上绘制混合物体，作为水折射的画面；恢复不透明场景并绘制水；
  再次绘制混合物体并与水做深度测试）。水下的混合物体透过水面可见，水前的混合物体覆盖在水面上，远离水面处只混合一次。这只在
  两者同时存在的帧中额外产生两次全屏场景复制和一遍混合绘制。没有深度测试或穿过水面的混合绘制会在水面两侧完整绘制；位于水前
  的混合物体还会透过水面再淡淡地出现一次。
