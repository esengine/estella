天气以**场景已编写数值的乘数**表示——太阳为原强度的四分之一、雾浓五倍、画面略灰——再加上少数在任何项目中含义相同的绝对量，
如降雨强度和地面湿度。因此同一预设适用于任何项目，与其雾的单位或太阳亮度无关。

## 户外环境

户外场景的各部分相互依赖：时钟移动太阳，天空绘制投射阴影的云，雾读取这些云使云隙成为光柱，天气则缩放这一切。**创建 → 渲染
→ 户外环境**（Create → Rendering → Outdoor Environment）在一个根节点下创建这套组合：太阳、天光、`TimeOfDay`、`Weather`，以及
带天空、高度雾和中性调色的全局后处理体积，按引擎参考比例每米 100 单位设置。结果是普通实体，任何部分都可编辑或删除。

## 组件

为一个实体添加 `Weather`。

| 字段 | 说明 |
|---|---|
| `preset` | 当前天气：Clear、Mist、Overcast、Rain、Storm、Snow。默认 Clear。 |
| `target` | 正在过渡到的天气；None（默认）表示没有过渡。 |
| `progress` | 过渡进度，0–1（默认 0）。运行时由系统推进；在编辑器中设置以预览部分过渡。 |
| `duration` | 过渡时长，秒（默认 6）。 |
| `sequence` | 自动循环的预设，逗号分隔，例如 `clear,mist,rain,clear`。留空（默认）保持当前天气。 |
| `hold` | 序列中每种天气在下一次过渡前保持的秒数（默认 20）。 |
| `drive` | 天气驱动的内容：Lights、Fog、Rain、Grade、Exposure、Reflections、Sound、Wind。默认全部。 |
| `soundSource` | 带循环 `AudioSource` 的实体，用作雨声。下雨时天气将其 `playing` 置为开启，并将音量设为编写音量 × 降雨强度。 |

过渡有缓入缓出。过渡完成后 `preset` 设为目标，`target` 被清除。

## 在编辑器中

Details 以按钮显示内置天气（项目自定义的预设 id 仍然有效，显示为 **Custom**），以可拖动的值显示过渡进度，并显示循环和驱动开关，
以及对画面当前作用的实时读数：主光缩放、雾缩放、湿度和降雨。雨和雾通过后处理体积作用于画面，面板会提示这一点。

## 天气驱动的内容

| 驱动 | 作用 |
|---|---|
| **Lights** | 方向光按其编写值缩放并着色，环境光按其编写值缩放（天气始终缩放编写的数值，而非自己上一次的结果）。移除天气或关闭 `Lights` 时恢复。只在运行时生效；在编辑器中不修改灯光，因此预览天气不会改变保存的场景。随着天空转阴，方向光阴影变柔（`shadowSoftness` 乘数加宽太阳光源）、变淡（`shadowStrength` × 编写的暗度）。 |
| **Fog** | 缩放 Height Fog 的密度、太阳辉光和携带的体积光，提高天空雾霭，并使雾色趋向天气的颜色。 |
| **Rain** | 按预设强度添加 Rain 效果（场景中没有时），Rain 与屏幕空间反射获得相应的湿度和水洼。场景自行编写了雨时，天气只能使其增强。**Snow** 使用同一驱动：添加 [Snow Cover](/docs/zh-cn/graphics/terrain/overview/#积雪与湿润表面) 效果（场景中没有时），铺在朝天的表面上，并由 Rain 效果的 `snowfall` 绘制飘落的雪花。 |
| **Reflections** | 烘焙的反射探针显示其烘焙时的天空，雨天街道会映出晴天。环境光的 `reflectionScale` 和 `reflectionSaturation` 对烘焙探针显示的内容做乘法和去饱和，天气会降低这两项。 |
| **Wind** | 预设的 `wind` 缩放 Sky Atmosphere 云的漂移和植物摆动（Foliage 材质的 `u_windStrength`、Sway 精灵的 `u_swayWind`）；`waves` 缩放所有水体的波高，绘制结果和水面查询都受影响。 |
| **Grade**、**Exposure** | 缩放 Colour Grade 的饱和度和对比度，提高 Auto Exposure 补偿。 |
| **Sound** | `soundSource` 的音量和播放跟随降雨强度。 |

Sky Atmosphere 效果还将预设的 `overcast` 作为云量和雾霭：云层增厚并连成一片，云后的太阳、月亮和星星以相同的透射率被遮住。

效果在场景的体积混合之后施加，因此雾薄的场景在同样的雨中仍比雾浓的场景更薄。

## 自定义预设

```ts
import { registerWeatherPreset } from 'esengine';

// 预设只列出它改变的项，其余保持中性。
const sandstorm = registerWeatherPreset('sandstorm', {
  sun: 0.5, fogDensity: 10, fogTint: [0.82, 0.62, 0.38], fogTintAmount: 0.85,
  saturation: 0.8, exposure: 0.4,
});
```

预设是部分的 `WeatherState`。标为 × 的字段乘以场景原本的值（`1` 保持不变）；其余为绝对量。

| 字段 | 中性值 | 说明 |
|---|---|---|
| `sun` / `sky` | `1` | × 方向光强度 / × 环境光强度。 |
| `sunTint` | `[1, 1, 1]` | × 方向光颜色。 |
| `shadowSoftness` | `1` | 太阳作为阴影光源的宽度，以太阳为单位：`8` 使阴影柔和八倍。 |
| `shadowStrength` | `1` | × 阴影的浓度。 |
| `fogDensity` / `fogGlow` / `skyFog` | `1` | × 高度雾密度 / × 其太阳辉光与携带的光柱 / × 其天空雾霭（上限为 1）。 |
| `fogTint`、`fogTintAmount` | `[0.7, 0.72, 0.76]`、`0` | 雾趋向的颜色及程度（`0` 保持雾自身的颜色）。 |
| `saturation` / `contrast` | `1` | × 调色的饱和度 / 对比度。 |
| `exposure` | `0` | 加到自动曝光补偿上的档数。 |
| `rain`、`wetness`、`puddles` | `0` | 雨的强度，以及它留下的潮湿与水洼。 |
| `snow` / `snowfall` | `0` | 积雪量 0..1 / 降雪量 0..2。 |
| `ssr` | `1` | × 屏幕空间反射强度。 |
| `reflection` / `reflectionSaturation` | `1` | × 烘焙反射探针显示的内容 / × 其颜色（`0` 为灰色）。 |
| `overcast` | `0` | 天空云量，0 晴朗到 1 全灰，遮住太阳、月亮与星星。 |
| `sound` | `0` | 雨声音量 0..2。 |
| `wind` / `waves` | `1` | × 植物摆动与云的漂移 / × 所有水体的浪高。 |

`registerWeatherPreset(name, preset)` 返回预设的 id。自定义预设在 `sequence` 中按名称引用，在 `preset` 和 `target` 中按返回的
id 引用。再次注册内置名称会重新调整该预设。

## 从代码过渡

组件是数据：写入 `target` 和 `progress: 0`，系统即执行过渡。

```ts
import { Weather, WEATHER_RAIN } from 'esengine';

world.insert(weatherEntity, Weather, { target: WEATHER_RAIN, progress: 0, duration: 10 });
```

## 场景时钟

天气状态取决于其运行开始的时间和已运行的时长，以场景时钟度量：即游戏自身的游玩秒数（暂停时静止，减速时变慢）。任意时刻都可
直接计算而无需播放到那一刻，同一 `t` 在每台机器上得到相同天气，过场动画或回放可以任意移动时钟。

```ts
import { seekSceneClock, sceneClock, weatherAt, WEATHER_CLEAR, WEATHER_NONE } from 'esengine';

seekSceneClock(240);   // 从下一帧起，天气、钟点和云处于四分钟时的状态
sceneClock();          // 时钟已运行的游玩秒数

// 不移动任何东西进行查询：以 `start` 开始的 Weather 在 90 秒后的状态。
weatherAt({ preset: WEATHER_CLEAR, target: WEATHER_NONE, progress: 0, duration: 10, sequence: 'clear,mist,rain', hold: 8 }, 90);
```

| 函数 | 说明 |
|---|---|
| `seekSceneClock(t)` | 将场景时钟移到 `t` 秒，从下一帧起生效。 |
| `sceneClock()` | 时钟已运行的游玩秒数。 |
| `weatherAt(start, t)` | 以 `start` 开始的天气在 `t` 秒后的 `{ preset, target, progress }`。 |
| `blendWeather(from, to, progress)` | 从预设 `from` 过渡到预设 `to`、进度为 `progress`（0..1）时的 `WeatherState`，两端做了缓动。`to` 为 `WEATHER_NONE` 时返回 `from`。 |
| `currentWeather()` | 当前帧所处的 `WeatherState`；没有 `Weather` 组件时为 `null`。 |
| `weatherPresetId(name)` / `weatherPresetNames()` | 按名称查预设 id，以及按 id 顺序列出所有预设名称。 |

直接写入组件（如[从代码过渡](#从代码过渡)）会从写入的值开始一次新的运行，因此脚本的过渡与时钟保持一致。云被放在天空的风
（对天气强度变化积分）本应将其带到的位置。
