import { Aside } from '@astrojs/starlight/components';

控件工厂用 [UI](/docs/zh-cn/guides/ui/) 组件模型(`UINode` + `Interactable` +
`$interaction` [控制器与属性绑定](/docs/zh-cn/guides/ui-controllers/))构建常见控件,免得你逐个手动接线。每个工厂接收一个选项对象,返回一个**句柄(handle)**——
总是带 `entity` 和 `dispose()`,外加读取和驱动它的命令式方法。

交互式控件需要 world 和 UI 事件队列——`world` 来自 `GetWorld()`,`events` 来自 `Res(UIEvents)`,
和 [UI 指南](/docs/zh-cn/guides/ui/)里一样。它们都接受 `parent?`、一个 `node?`
([`UINode`](/docs/zh-cn/guides/ui/#uinode--the-layout-box) 布局)和视觉覆盖。交互式控件
**默认键盘可达**:它们自带 `Focusable`,Tab 能到达、Enter/Space 能点击、方向键能驱动滑块——
用 `focusable: false` 退出。

<Aside type="tip">
  这些是方便的起点,而非封闭集合——一个控件不过是挂了 UI 组件的实体树,所以你能用同样方式组合
  自己的控件。
</Aside>

<Aside type="note">
  需要跨多个元素的 **共享** 状态——页签、单选组、显隐面板、或从数据驱动的自定义按钮状态——
  请用 [UI 控制器](/docs/zh-cn/guides/ui-controllers/):一个具名的"页"状态,加上声明式的每页字段
  绑定,可在编辑器里授权。
</Aside>

## Button 按钮

`createButton(opts)` 生成一个可点击实体(带可选子标签),在各视觉状态间过渡。返回 `ButtonHandle`。
一次点击是在按钮*上*按下再松开——或在它持有键盘焦点时按 Enter/Space。

```typescript
import { createButton } from 'esengine';

const btn = createButton({
  world, events, parent,
  text: 'Play',
  node: { width: px(160), height: px(44) },
  states: {
    normal:  { color: { r: 0.20, g: 0.55, b: 1.0, a: 1 } },
    hover:   { color: { r: 0.30, g: 0.65, b: 1.0, a: 1 } },
    pressed: { color: { r: 0.12, g: 0.45, b: 0.9, a: 1 } },
    disabled:{ color: { r: 0.3, g: 0.3, b: 0.3, a: 1 } },
  },
  onClick: (entity) => { /* … */ },
});
```

| 选项 | 说明 |
|---|---|
| `text` | 标签——字符串或 `TextInit`。省略则无标签。 |
| `states` | 状态名(`normal` / `hover` / `pressed` / `disabled` / `focused`)→ 颜色 / sprite / 缩放覆盖的映射。省略则用当前主题的 control 角色。 |
| `background` | 背景视觉(默认:纯白)。 |
| `fadeDuration` | 颜色 / 缩放状态切换的补间时长(默认 `0` = 瞬切;sprite 交换总是瞬切)。 |
| `disabled` | 初始禁用。 |
| `focusable` / `tabIndex` | 键盘可达性(默认 `true` / `0`)。 |
| `onClick(entity)` | 点击回调。 |

**句柄:** `entity`、`setDisabled(disabled)`、`dispose()`。

之后可用 `setButtonState(world, handle.entity, 'loading')` 切到自定义状态。

## Toggle 开关

`createToggle(opts)` 用一个按钮加一个开/关勾选指示器组合而成。返回 `ToggleHandle`。

```typescript
import { createToggle } from 'esengine';

const toggle = createToggle({
  world, events, parent,
  interactionStates: { normal: { color: /* … */ }, hover: { /* … */ }, pressed: { /* … */ } },
  check: { color: { r: 0.2, g: 0.8, b: 0.4, a: 1 } },   // "开"指示器
  isOn: true,
  onChange: (isOn, entity) => { /* … */ },
});

toggle.setIsOn(false);      // 程序化改变(触发 onChange)
```

| 选项 | 说明 |
|---|---|
| `interactionStates` | 框架视觉状态(类似按钮的 `states`;省略则用主题默认)。 |
| `check` | 开状态指示器:`{ node?, color?, sprite? }`,开时显示(默认主题强调色)。 |
| `isOn` | 初始状态。 |
| `onChange(isOn, entity)` | 切换时触发。 |

**句柄:** `isOn()`、`setIsOn(value)`、`setDisabled(disabled)`、`entity`、`dispose()`。

<Aside type="note">
  状态存在 **`UIToggle` 组件**里;行为系统在点击时翻转它,并且是勾选视觉的唯一写者——
  `setIsOn`、绑定、或编辑器 Inspector 改摆放的 prefab,都会同样地翻转指示器并触发 `change`。
</Aside>

## Slider 滑块

`createSlider(opts)` 构建轨道 + 填充 + 手柄。返回 `SliderHandle`。
输入是内置的:在轨道上任意位置**拖拽**(按下即捕获,直到松开),或聚焦后用**方向键**
(步长为 `step`,连续滑块为量程的 1%)、**Home**/**End**。

```typescript
import { createSlider } from 'esengine';

const slider = createSlider({
  world, events, parent,
  min: 0, max: 100, value: 50, step: 5,
  onChange: (value) => { /* … */ },
});

slider.setValue(75);
```

| 选项 | 说明 |
|---|---|
| `min` / `max` / `value` | 范围与初始值。 |
| `step` | 量化步长(`0` = 连续)。同时是键盘步进量。 |
| `handleWidth` | 手柄宽度(像素,默认 `12`)。 |
| `disabled` / `focusable` / `tabIndex` | 交互性与键盘可达性。 |
| `trackVisual` / `fillVisual` / `handleVisual` | 各部件视觉。 |
| `onChange(value, entity)` | 值改变时触发——无论来自输入、`setValue` 还是任何其他写者。 |

**句柄:** `getValue()`、`setValue(v)`、`dispose()`,以及 `trackEntity` /
`fillEntity` / `handleEntity`。

<Aside type="note">
  状态存在轨道实体上的 **`UISlider` 组件**里;行为系统是视觉的唯一写者。任何写
  `UISlider.value` 的东西——指针、键盘、`setValue`、编辑器 Inspector 里改摆放的
  prefab——都会同样地移动填充与手柄并触发 `change`。
</Aside>

## Progress 进度条

`createProgress(opts)` 是一个非交互的填充条。返回 `ProgressHandle`。

```typescript
import { createProgress } from 'esengine';

const bar = createProgress({
  world, parent,
  direction: 'right',
  fill: { color: { r: 0.2, g: 0.8, b: 0.4, a: 1 } },
  value: 0,
});

bar.setValue(0.6);   // 0..1

// 径向仪表(冷却 / 环形计量)——从 12 点钟方向顺时针扫过的扇形:
const ring = createProgress({ world, parent, radial: true, value: 0.75 });
```

| 选项 | 说明 |
|---|---|
| `value` | 初始进度,`0..1`。 |
| `direction` | 线性填充增长方向:`'right'`(默认)、`'left'`、`'up'`、`'down'`。 |
| `radial` | 用径向仪表替代进度条——顺时针扫过整圆的扇形。忽略 `direction`。 |
| `background` / `fill` | 轨道和填充视觉。 |

**句柄:** `value()`、`setValue(v)`、`dispose()`,以及 `fillEntity`。

<Aside type="note">
  **同一个填充原语。** 进度条就是一个处于 **`Filled`** 模式的
  [`UIVisual`](/docs/guides/ui/)——与滑块填充共用同一个原语,对应 Unity 的
  "血条 = Filled Image"。`setValue()` 写入 `fillAmount`,因此填充是渲染期裁剪、
  **不触发每帧布局**,贴图填充会沿轴**揭示**而非拉伸。`direction` 通过共享的
  `FILL_AXIS` 表解析为 `Filled` 的裁剪轴与锚定边,让进度条、滑块以及其他基于
  Filled 的控件填充行为完全一致。
</Aside>

## Dropdown 下拉

`createDropdown(opts)` 显示当前选择,并弹出一个选项行列表。它对选项类型是泛型的。返回
`DropdownHandle<T>`。

```typescript
import { createDropdown } from 'esengine';

const dd = createDropdown({
  world, events, parent,
  options: ['Low', 'Medium', 'High'],
  selectedIndex: 1,
  onSelect: (index, option) => { /* … */ },
});

// 对象需要一个标签映射:
createDropdown({
  world, events, parent,
  options: resolutions,                       // 例如 { w, h }[]
  optionToLabel: (r) => `${r.w}×${r.h}`,
  onSelect: (i, r) => applyResolution(r),
});
```

| 选项 | 说明 |
|---|---|
| `options` | 可选值列表。 |
| `selectedIndex` | 初始选择。 |
| `optionToLabel(option, i)` | 把非字符串选项映射为显示文本。 |
| `buttonStates` | 主按钮的颜色(选项行走主题角色)。 |
| `optionHeight` | 行高(像素,默认 `32`)。 |
| `disabled` / `focusable` / `tabIndex` | 交互性与键盘可达性。 |
| `onSelect(index, option, entity)` | 选择时触发。 |

**句柄:** `getSelected()`、`getSelectedIndex()`、`setSelectedIndex(i)`、`open()`、
`close()`、`isOpen()`、`dispose()`。

<Aside type="note">
  标签与选择存在 **`UIDropdown` 组件**里;行为系统拥有弹出层(点击开合,**点击其他任意位置
  自动关闭**)、行选择、以及键盘:开合两态方向键都能换选(打开的弹出层高亮选中行),
  **Enter** 确认、**Escape** 取消——摆出来的 prefab 无需代码即完整可用。
  弹出层每次打开都用新鲜的主题角色重建。
</Aside>

## Dialog 对话框

`createDialog(opts)` 是一个模态:一个挡住点击的背景加一个居中面板,打开前隐藏。返回
`DialogHandle`。**把你的内容作为 `panelEntity` 的子实体加进去**——关闭时会在背景根上
设置 `display: none`,整棵子树(包括你的内容)一次性退出布局、渲染和输入。

```typescript
import { createDialog, spawnUIEntity } from 'esengine';

const dialog = createDialog({
  world, events, parent,
  panelNode: { width: px(420), height: px(260) },
});

spawnUIEntity({ world, parent: dialog.panelEntity, text: { content: '确定吗?' } });

dialog.open();
// …之后
dialog.close();
```

| 选项 | 说明 |
|---|---|
| `backdropNode` / `backdropVisual` | 面板后方的全视口遮罩。 |
| `panelNode` / `panelVisual` | 模态面板(默认:400×300,居中)。 |
| `startHidden` | 初始关闭(默认 `true`)。 |
| `closeOnEscape` / `closeOnBackdrop` | 两个标准关闭方式——Escape,以及点击遮罩(不含面板)。都默认 `true`。 |
| `onOpenChange(open)` | 每次开/关都会触发,无论由谁发起。 |

对话框打开期间还会**捕获 Tab 环**:只有打开对话框子树内的可聚焦控件参与轮换
(遮罩本来就挡住了外部的指针聚焦)。

**句柄:** `open()`、`close()`、`isOpen()`、`dispose()`,以及 `entity`(背景根)/ `panelEntity`。

<Aside type="note">
  关闭行为由背景根上的 **`UIDialog` 组件**数据驱动,打开状态就是根的
  `UINode.display`——因此从编辑器 prefab 实例化的对话框无需任何代码就能响应
  Escape / 遮罩点击。
</Aside>

## 列表与集合

对于长的、可滚动的、**数据驱动**的列表——背包、排行榜、聊天记录——`createListView` 构建一个
**虚拟化**列表(或网格):只有视口附近的条目会被挂载,所以一万行的列表也很轻。一次调用就组合了
数据源、布局、条目回收、滚动和裁剪。

```typescript
import { createListView, uiPlugin, arrayDataSource, spawnUIEntity, px } from 'esengine';

const list = createListView<Player>({
  world, host: uiPlugin, parent,
  viewportSize: { x: 320, y: 480 },     // 可见窗口,像素
  data: arrayDataSource(players),        // 任意 DataSource<T>,或裸数组
  layout: { itemHeight: 56 },            // 列表
  item: {
    create: (world, parent) => spawnUIEntity({ world, parent, node: { height: px(56) } }),
    bind: (entity, player, index) => { /* 用 `player` 填这行的 Text / Sprite */ },
  },
});
```

`host` 是驱动虚拟化并路由滚动输入的插件——传你 app 构建时用的 `uiPlugin`。
`item.create` 建一个行实体;`item.bind` 用数据填它。`bind` 每当一行被复用到不同索引时都会跑,
所以把它写成纯粹的"应用这份数据"函数。

**布局**是列、行或网格:

| `layout` | 结果 |
|---|---|
| `{ itemHeight }` | 竖直列表——固定行高,或传 **`(index) => number`** 实现[自适应行高](#自适应行高)。 |
| `{ itemWidth, direction: 'row' }` | 水平列表。 |
| `{ columns, itemSize }` | 网格(*TileView*)。 |

**更新**列表 = 改它的数据源——`ArrayDataSource` 会通知视图,视图在下一帧重新同步:

```typescript
list.data.append([newPlayer]);        // 增
list.data.remove(3);                   // 删索引 3
list.data.update(0, updatedPlayer);    // 改一个
list.data.setItems(freshList);         // 全替换
```

**句柄:** `data`(改它来改列表)· `scrollToIndex(i)` · `refresh()` · `mountedCount()`
(永远不随数据量增长——测试里好用)· `dispose()`,以及 `scroll` 和 `view` 作为通往底层
`ScrollContainer` / `ListView` 的逃生舱。

<Aside type="note">
  滚动开箱即用:视口上的鼠标滚轮、指针**拖拽 + 惯性甩动**(平台层把主触点并入指针流,
  触摸滚动走同一条路径),以及每个可滚动轴的**自动淡出悬浮滚动条**(ScrollContainer 传
  `showScrollbar: false` 关闭)。可用 `dragScroll: false` 关闭,或用 `decelerationRate` 调惯性
  (甩动 1 秒后剩余的速度比例;默认 `0.135`,ScrollRect 标准值)。异构行:用「item 类型 → 模板」
  的映射代替单个 `item`,并给数据源一个 `getItemType(i)`。
</Aside>

### 自适应行高

给 `itemHeight` 传一个**函数**,让每行按内容自适应高度——聊天记录里气泡随换行文本增高就是
典型场景。列表会缓存测量结果,并在数据或视口变化时重排:

```typescript
import { measureText } from 'esengine';

createListView<Message>({
  world, host: uiPlugin, parent,
  viewportSize: { x: 360, y: 480 },
  data: messages,
  layout: {
    itemHeight: (i) => measureText(messages.getItem(i).text, {
      fontSize: 14, maxWidth: 320,
    }).height + 16,                      // 换行文本高度 + 上下内边距
    spacing: 8,
  },
  item: { /* create / bind */ },
});
```

`measureText(text, { fontSize, maxWidth?, bold?, italic?, letterSpacing?, lineHeight? })`
返回 `{ width, lineCount, height }`,用的是**渲染器取字形 advance 的同一套 Canvas2D 度量**,
所以测出的高度和实际渲染一致——不再有裁剪或溢出的行(无 DOM 的环境回退到平均字宽估算)。

### 自由内容滚动

滚动**任意内容**的面板(设置页、长表单)——不虚拟化、无数据源——用 `createScrollView`,
把内容挂到它的 `content` 帧下:

```typescript
import { createScrollView, uiPlugin } from 'esengine';

const panel = createScrollView({
  world, host: uiPlugin, parent,
  viewportSize: { x: 320, y: 480 },
  contentSize:  { x: 320, y: 1200 },
});
// 在 panel.content 下构建内容 …
panel.scrollTo({ x: 0, y: 300 });
```

滚轮、拖拽/触摸和惯性甩动与列表视图完全一致;内容变大后调 `setContentSize()`。

## 文本输入

`createTextInput(opts)` 构建可编辑输入框——背景、光标、占位提示和 IME 管线都齐了——
颜色走主题角色,换主题时会重新解析。返回 `TextInputHandle`(`getValue()` /
`setValue(v)` / `entity` / `dispose()`)。

```typescript
import { createTextInput } from 'esengine';

const name = createTextInput({
  world, events, parent,
  placeholder: '你的名字', maxLength: 20,
  onChange: (value) => { /* 内容被编辑 */ },
  onSubmit: (value) => save(value),   // 回车
});
```

工厂是 `TextInput` **组件**之上的糖——想完全手动控制,把组件直接插到任意 UI 实体上:

```typescript
import { spawnUIEntity, TextInput, px } from 'esengine';

const field = spawnUIEntity({ world, parent, node: { width: px(240), height: px(32) } });
world.insert(field, TextInput, { placeholder: '你的名字', maxLength: 20 });

events.on(field, 'change', () => { /* 内容被编辑 */ });
events.on(field, 'submit', () => save(world.get(field, TextInput).value));  // 回车
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `value` / `placeholder` | `''` | 内容 / 为空时显示的提示。 |
| `maxLength` | `0` | 字符上限(`0` = 不限)。 |
| `multiline` | `false` | 回车插入换行而不是提交。 |
| `password` | `false` | 掩码显示。 |
| `readOnly` | `false` | 可聚焦但不可编辑。 |
| `fontSize` / `fontFamily` | `16` / `Arial` | 文字样式——`color`、`placeholderColor`、`backgroundColor` 和 `padding`(`6`)补全观感。 |
| `renderMode` | `Auto` | 输入文本的字形管线——`Auto`(不缩放时用清晰位图、缩放后转 SDF)、始终 `Bitmap`、或始终 `Sdf`。 |

点击(或 Tab 到)输入框即聚焦;**Escape** 失焦,单行输入框按**回车**触发
`submit`。内容超出框宽时会**裁剪到框内并横向滚动**,让光标随输入始终可见。

<Aside type="note">
  文本输入只在**播放模式**运行,且需要浏览器 DOM(它驱动一个隐藏的原生
  textarea 以支持 IME)——在编辑器编辑态下不生效。
</Aside>

## 数据绑定

控件的值就是普通组件字段,[signal](/docs/zh-cn/guides/ui/) 层可以直接绑——
`bindWidgetValue` 让它**双向**:signal 驱动组件,控件的 `change` 事件回写 signal。

```typescript
import { signal, bindWidgetValue, UISlider, UIToggle } from 'esengine';

const volume = signal(50);
bindWidgetValue(world, events, slider.entity, UISlider, 'value', volume);
const muted = signal(false);
bindWidgetValue(world, events, toggle.entity, UIToggle, 'isOn', muted);

volume.set(80);          // 滑块随之移动
// 拖动滑块 ↦ volume.get() 跟随
```

signal 的等值守卫会打断回环,一个来回一跳即收敛。

## 拖放

给任何可交互的 UI 实体加 `Draggable`,指针拖动就能移动它——有 `UINode` 时移动
其绝对 inset,否则移动 `Transform`:

```typescript
world.insert(entity, Draggable, { dragThreshold: 5, lockY: true });
events.on(entity, 'drag_start', () => { /* 还有 'drag_move' 与 'drag_end' */ });
```

`lockX` / `lockY` 锁轴,`constraintMin` / `constraintMax` 钳制范围;自动插入的
`DragState` 组件暴露实时拖动数据(`isDragging`、`deltaWorld`、`totalDeltaWorld`
等)。没有内置的放置目标(drop target)概念——在你的 `drag_end` 处理器里自行
判定落点。

## 键盘焦点

带 `Focusable` 组件的实体参与键盘焦点:**点击**聚焦,**Tab / Shift+Tab** 轮换
(按 `tabIndex` 升序,跳过禁用控件,到头回绕),**Enter / Space** 激活聚焦的控件
(合成一次 `click`;文本框保留这些键用于编辑),滑块响应**方向键**,**Escape**
或点击空白处清除焦点。控件工厂自动添加 `Focusable`(用 `focusable: false` 退出);
聚焦的控件显示它的 `focused` 交互页(默认主题 hover 色)。`FocusManager` 资源暴露
`focusedEntity` 以及 `focus(entity)` / `blur()` 供编程控制,被聚焦的实体在 UI
事件总线上收到 `focus` / `blur` 事件。

## 安全区(移动端刘海)

给一个全屏、绝对定位的 `UINode` 容器加 `SafeArea`,它的 inset 就会跟随平台
安全区——刘海、圆角、微信胶囊——里面布局的子节点永远不会被硬件遮住。
`applyTop` / `applyBottom` / `applyLeft` / `applyRight`(默认全 `true`)选择
生效的边。

## 主题

控件颜色来自一套共享令牌:`getTheme()` / `setTheme(tokens)`,角色包括
`surface`、`control`、`controlHover`、`primary`、`onPrimary`、`track`、
`backdrop`(内置 `DARK_TOKENS` / `LIGHT_TOKENS`)。`setTheme` 影响之后构建的控件;
**`switchTheme(world, tokens)`** 还会实时重刷屏幕上已有的一切——控件记录了每个颜色
来自哪个主题*角色*(`ThemeStyle` 组件,也随 prefab 持久化),换主题时按角色重新
解析色相并保留各自的 alpha。

## 编辑器预制体

这些控件同时作为编辑器预制体提供,所以 **创建… → UI** 会把现成的 Button、Toggle、Slider、
Dialog、TextInput 等放进场景,你再在 Details 里编辑。存在组件里的行为——滑块的拖拽/方向键、
对话框的 Escape/遮罩关闭——摆出来的 prefab 无需代码即可用。见
[编辑器](/docs/zh-cn/guides/editor/)。
