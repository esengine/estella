description: 帧调试器参考——从视口、运行中的游戏或设备捕获一帧、带合批中断原因的 draw 列表、单个 draw 的详情，以及把帧重放到某个 draw。

**帧调试器**捕获单独一帧，按顺序列出每个 draw call，并说明每一个**为何开始新的批次**（着色器、混合模式、材质、纹理、裁剪矩形不同等）。它是[帧捕获 API](/docs/zh-cn/performance/profiling/frame-capture/) 的编辑器视图。

通过 **Window → Frame Debugger** 打开，或在命令面板中搜索 **Frame Debugger**。它停靠在性能剖析器旁边。
## 捕获一帧

1. 选择**范围（realm）**：**Viewport**（编辑器视图）、**Running game**（Play 期间）或 **Device**（已连接的设备预览）。
2. 单击 **Capture frame**。该帧以一个或多个**通道**列出：每个相机一个相机通道，再加上 UI 在最上层绘制的屏幕浮层通道，各自带有 draw 数。

捕获是一份快照。之后场景发生变化时，面板会给出提示；再次捕获即可查看新的帧。

## draw 列表

每一行是一个 draw call：

| 列 | 内容 |
|---|---|
| **Type** | draw 的类型：精灵、文本、网格、瓦片地图分块、特效… |
| **Break reason** | 该 draw 为何无法并入前一个。 |
| **Drew** | 材质、着色器与纹理。 |
| **Triangles** | 三角形数。 |

列表上方的 **Break reason** 标签按原因筛选行：

| 中断原因 | 原因 | 处理 |
|---|---|---|
| **First draw of its pass** | 每个通道都开始一个批次。 | — |
| **Shader / Material / Blend mode** | 相邻 draw 使用了不同的着色器、材质或混合模式。 | 调整实体顺序使同类 draw 相邻，或共用材质。 |
| **Texture slots** | 前一个 draw 已用满所有纹理槽位。 | 把精灵打包进更少的图集。 |
| **Scissor / Stencil** | 两个 draw 之间 UI 遮罩或裁剪区域发生变化。 | — |
| **Depth / Culling / Render state** | 深度测试、面剔除或自定义状态不同。 | — |
| **Vertex layout / Index gap** | 不同类型的几何无法共享一段缓冲。 | — |

UI 通道中大量出现 **Blend** 与 **Material** 中断，说明不同类型的控件交错排列；应调整兄弟节点顺序或合并材质。

## 查看单个 draw

单击某一行，或用 **Previous draw** / **Next draw** 逐个查看，会显示其详情：材质、着色器、纹理、三角形、实例、层、裁剪与模板，以及它绘制的**实体**（**Select in the Outliner** 选中其中一个）。没有实体的 draw（字形串、gizmo、特效）会标明这一点。

视口可以把帧**重放**到所选 draw，显示到该时刻为止已绘制的内容。无法重放的 draw 会给出提示，而不是显示错误的图像。
