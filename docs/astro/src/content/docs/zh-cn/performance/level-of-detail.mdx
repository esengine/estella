**`LODGroup`** 在网格于屏幕上缩小时改用更便宜的替代网格，并在低于最小尺寸时不再绘制。**`Impostor`** 用一张面向相机的网格图像替代远处的网格。

## LODGroup 组件

`LODGroup` 与 `MeshRenderer` 位于**同一个实体**上。渲染器的网格是第 0 级，即全细节网格；该组列出物体缩小时替代它的网格：

```typescript
world.insert(rock, MeshRenderer, { mesh: 'assets/models/rock-lod0.esmesh', lit: true });
world.insert(rock, LODGroup, {
    lod1: 'assets/models/rock-lod1.esmesh',
    lod2: 'assets/models/rock-lod2.esmesh',
    lod1Size: 0.25,   // 低于屏幕高度的四分之一时绘制 lod1
    lod2Size: 0.11,   // 低于 0.11 时绘制 lod2
    cullSize: 0.02,   // 低于五十分之一时不绘制
    hysteresis: 0.1,
});
```

移除该组件即恢复全细节网格。

![LOD Group 的详情：当前级别、投影尺寸、级别表与三个级别的网格](@/assets/guides/zh/details-lod-group.png)

*编辑器中的 **LOD Group**：当前使用的级别、实体的投影尺寸以及阈值表。*

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `lod1` / `lod2` / `lod3` | 网格 | — | 替代网格，最粗的放在最后。 |
| `lod1Size` | number | `0.5` | 低于该屏幕高度比例时绘制 `lod1`。 |
| `lod2Size` | number | `0.25` | 低于该屏幕高度比例时绘制 `lod2`。 |
| `lod3Size` | number | `0.1` | 低于该屏幕高度比例时绘制 `lod3`。 |
| `cullSize` | number | `0.02` | 低于该屏幕高度比例时不绘制；`0` 表示从不剔除。 |
| `hysteresis` | number | `0.1` | 物体必须超过阈值多少比例，较精细的级别才会恢复（0–1）。 |
| `enabled` | boolean | `true` | 关闭：始终绘制渲染器自身的网格。 |

`LODMember` 只在另一个实体的 `LODGroup` 选中其级别时绘制自身的 `MeshRenderer`，用于以整个实体作为级别的情况（例如毛发的发丝与其面片）。

## 屏幕尺寸阈值

`lod1Size` 等尺寸是物体包围盒覆盖**视口高度**的比例：`1.0` 表示物体恰好一屏高，`0.02` 表示五十分之一屏高。

与距离不同，屏幕比例同时考虑了物体大小、视场角与正交投影，且与分辨率无关，因此同一数值在手机与桌面上都适用。画质档位的 **LOD distance scale** 会乘到测得的尺寸上（[视距与绘制](/docs/zh-cn/performance/quality-levels/settings/#视距与绘制)）。

<Aside type="tip">
选择阈值时，把相机放在主要玩法发生的位置，估计物体覆盖窗口高度的比例。低于约 5% 的物体可以使用最粗的网格。
</Aside>

## 迟滞

单一数值的阈值在相机轻微移动时会来回切换。`hysteresis` 使每个阈值不对称：物体在阈值处切换到较粗的网格，只有在超过阈值该比例之后才切换回来。默认 `0.1` 且 `lod1Size: 0.20` 时：

- 缩小到 **0.20** 以下切换到第 1 级；
- 增大到 **0.22** 以上恢复第 0 级。

`0` 表示单纯的阈值。迟滞同样作用于 `cullSize`。

## 级别选择

- **按相机。** 同一帧中的两个相机（主视图与小地图，或分屏）可以以不同级别绘制同一物体。实体上没有 `currentLOD` 字段。
- **按所有级别包围盒的并集测量**，因此测得的尺寸不随所绘制的级别变化。
- **在视锥剔除之后。** 视锥之外的物体不参与测量。
- **与实例化兼容。** 选择级别只改变 draw 引用的网格，因此处于同一级别的物件仍以一次实例化调用绘制。

## 编辑规则

- 按顺序填写槽位：`lod1`、`lod2`、`lod3`。空槽位会结束级别链，其后的槽位永远不会用到，引擎会给出警告。
- 尺寸必须递减：`lod2Size` 小于 `lod1Size`，依此类推。
- `cullSize: 0` 关闭剔除，该组永远不会不可见。
- 组可以没有替代网格。只设置 `cullSize` 时，物体足够大时绘制渲染器的网格，更小时不绘制，适用于没有更便宜版本的物体，例如草丛。
- 级别可以在导入时用 **Generate LODs** 生成，同时添加 `LODGroup`（[自动生成 LOD](/docs/zh-cn/assets/models/geometry/#自动生成-lod)）。
- 蒙皮组的所有级别必须共享同一套骨骼（关节数相同）。不一致的级别以绑定姿势绘制，引擎会报告。

## Impostor

与 `MeshRenderer` 放在一起的 `Impostor` 在物体覆盖的视图高度小于 `screenSize` 时，用一张面向相机的卡片替代网格。卡片显示从视图方向拍摄的网格图像。

```typescript
world.insert(tree, Impostor, { screenSize: 0.06, frames: 8, resolution: 1024 });
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `screenSize` | number | `0.06` | 低于该屏幕高度比例时由卡片替代网格。 |
| `frames` | number | `8` | 图集每边的图像数（共 `frames × frames` 张），2–16。数量越多，视角环绕时的跳变越小，但每张图分辨率越低。 |
| `resolution` | number | `1024` | 图集边长（像素），128–4096；每张图为 `resolution / frames`。 |
| `enabled` | boolean | `true` | 关闭：始终绘制网格。 |

- **拍摄。** 图像在游戏运行时为每一类拍摄一次：`frames × frames` 个正交相机从上半球的各个方向拍摄网格副本，每张图写入图集中各自的单元格。它们是普通相机，因此在所有后端上图像都包含网格的材质、纹理与场景光照。网格、材质、纹理与颜色都相同的实体共享一个图集；各类依次拍摄，每类一到两帧。
- **绘制。** 每个视图在一个面向它的正方形上绘制与其方向最接近的图像。卡片通过精灵批处理绘制，因此图集能放进一次 draw 纹理槽位的卡片只需一次 draw。画质档位的 **LOD distance scale** 同样作用于 `screenSize`。
- **限制。** 图像保留拍摄时的光照，且处于物体自身的坐标系中：旋转后的物体会像光源随之旋转一样被照亮，因此 Impostor 适合柔和光照或不旋转的物体。视角环绕时图像按步跳变。卡片不投射阴影，从下方看不到。图像在 Play 与构建后的游戏中拍摄，编辑器视口中不拍摄。

## 烘焙静态簇代理

节点编辑工具可以调用 `@estella/pipeline` 中的 `bakeStaticProxy`，合并并简化已划分好的静态表面簇。每个源提供解码后的网格数据、世界矩阵、绘制状态，以及明确的运动与混合分类。烘焙器使用与静态合并相同的几何合并与绘制分组。

```typescript
import { bakeStaticProxy } from '@estella/pipeline';

const proxy = await bakeStaticProxy(sources, {
    origin: [1000, 0, 2000],
    ratio: 0.25,
    maxWorldError: 0.05,
});
```

| 选项 | 说明 |
|---|---|
| `origin` | 簇的局部原点；返回的网格放置在此处。 |
| `ratio` | 目标三角形比例，取值 (0, 1]。误差上限优先，可能保留更多三角形。 |
| `maxWorldError` | 最大简化误差（世界单位），与簇的范围无关。 |
| `pruneDisconnected` | 允许在误差范围内移除较小的不相连部件。默认关闭；需要人工目视检查。 |
| `maxVertices` | 每组简化前的顶点预算。 |

- 结果包含簇局部网格及其原始绘制状态、源 id、简化前后的三角形与字节数、测得的误差以及输入指纹。材质、纹理、着色、层、光照与阴影的差异仍为单独的 draw。
- 由调用方写出网格资源并把绘制标识解析为资源引用；该 API 不修改场景。
- 顶点色与两套 UV 都计入简化误差。在源上设置 `preserveGeometry: true`（自发光或其他高对比度表面）会保留其整个组的几何，同时仍允许合并。
- 移动、变形、公告板、混合、烘焙光照、蒙皮与变形目标表面在 `refused` 中返回，仍由调用方负责。

流式世界对其单元使用相同的分组：在 `StreamedWorld` 上启用 **Far proxies** 后，每个单元都带有一个烘焙的替身，在单元未驻留时显示（[世界流式加载](/docs/zh-cn/world/streaming/)）。代理不烘焙自身的纹理或自发光，更远处也没有更粗的代理链。

## 适用范围

`LODGroup` 改变的是单个物体在不同尺寸下的绘制方式。它不做流式加载：所有级别的网格都常驻，低于 `cullSize` 的物体不绘制但仍存在于世界中。相关系统：

- [世界流式加载](/docs/zh-cn/world/streaming/)按单元加载世界，并使用上述烘焙器生成的远景代理。
- [植被](/docs/zh-cn/graphics/foliage/)：植物的远景版本（`Foliage`、`PlacedFoliage`）。
- [地形](/docs/zh-cn/graphics/terrain/overview/)：地形自身基于距离的四叉树。
- [静态合并](/docs/zh-cn/performance/static-batching/)合并不同网格以减少 draw，但不简化它们。
- [纹理流式加载](/docs/zh-cn/performance/quality-levels/texture-streaming/)按视图所需的尺寸保留纹理。
- [簇 LOD](/docs/zh-cn/assets/models/geometry/#簇-lod)无需 `LODGroup`，按视图绘制高密度静态网格。
