视锥剔除移除相机视野之外的内容。**`Occluder`** 声明视线无法穿过的盒子；渲染器随后不再收集完全藏在其后的物体。

```typescript
world.insert(wall, Occluder, { halfExtents: { x: 400, y: 300, z: 20 } });
```

遮挡剔除改变的是一帧的开销，而不是画面：有无遮挡体时同一帧的像素完全相同。

## 字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `halfExtents` | Vec3 | `{50, 50, 50}` | 盒子的半尺寸（世界单位），以实体位置为中心，并随实体旋转。不应用缩放。 |
| `enabled` | boolean | `true` | 关闭：不使用该盒子。 |

## 放置遮挡盒

遮挡盒是手工放置的，而不是由几何推导。网格的包围盒包住整个网格，因此柱子、拱门或岩石的包围盒在其角落处包含空白区域，站在这些区域中的物体会在可见的情况下被剔除。

<Aside type="caution">
**盒子必须位于几何的实心部分之内。** 盒子太小只是剔除得少；盒子太大则会剔除可见的物体，且没有任何计数器会报告这一点。
</Aside>

- 编辑器在视口中绘制该盒子，因此可以对照其所在的墙调整尺寸。
- 盒子可以放在墙自身的实体上，也可以放在单独的空实体上。由许多网格组成的建筑通常只需要一个大盒子，而不是每个网格一个。

## 剔除的内容

只剔除深度测试本来就会隐藏的 draw。忽略深度的物体会画在其前方的墙之上，因此精灵、UI、文本以及材质关闭了深度测试的任何表面都从不被遮挡体剔除。

遮挡按相机计算：

- 一帧中的每个相机分别测试各自的遮挡体。
- **阴影不参与遮挡剔除。** 对相机不可见的物体仍会投射阴影。
- 包含相机的遮挡体会被忽略。

## 遮挡网格

遮挡体在 CPU 上光栅化到一个网格中，网格边长由画质档位的 **Occlusion grid** 设置决定（默认在所有档位均为 64；[视距与绘制](/docs/zh-cn/performance/quality-levels/settings/#视距与绘制)）。之后每个物体的包围盒与之测试。盒子只隐藏它**完全覆盖**的网格单元，因此：

- 窄于一个网格单元（默认大小下为视图的 1/64）的遮挡体不隐藏任何内容。墙、楼层之间的楼板、建筑与悬崖等大型形状才有效。
- 只被两个盒子共同遮挡、而两盒之间有缝隙的物体仍会被绘制；每个盒子单独测试。

## 计数器

| 计数器 | 含义 |
|---|---|
| `render.cull.occluders` | 该视图使用的遮挡盒数。 |
| `render.cull.occluded` | 被遮挡体剔除的可渲染对象数。 |
| `render.culled` | 所有被剔除的可渲染对象，包括视锥剔除。 |

遮挡体为零表示盒子未被使用（旋转到近裁剪面之外，或尺寸为零）。使用了遮挡体却没有任何对象被遮挡，表示它们不在任何物体之前。

## 相关系统

`Occluder` 决定哪些物体被收集。[世界流式加载](/docs/zh-cn/world/streaming/)决定哪些物体存在，[`LODGroup`](/docs/zh-cn/performance/level-of-detail/) 决定剩余物体的几何开销。三者可以组合使用。
