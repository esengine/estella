---
title: 设备磁盘缓存
description: 热更新资产在设备上的磁盘缓存——支持的平台、性能分析器中的“设备磁盘缓存”区域、受保护与可释放的字节、版本标签、保留版本，以及按预算清理缓存。
---

加载[远端内容](/docs/zh-cn/publishing/hot-update/)的游戏会把校验过的字节写入设备上的**磁盘缓存**，下次启动时更新后的资产无需网络即可加载。每次更新都会留下上一修订版本的文件，因此缓存会随时间增长。性能分析器中的 **设备磁盘缓存** 区域显示已存储的内容和可以删除的内容，并按预算清理缓存，且不会删除游戏可能仍需要的修订版本。

## 平台支持

| 目标 | 磁盘缓存 |
| --- | --- |
| **桌面** | 受管理：可列出、测量和清理。 |
| **小游戏**、**原生（iOS、Android）** | 宿主文件 API 能列出和删除文件时受管理；否则仅存储。 |
| **Web** | 无。下次启动从 CDN 重新获取。 |

该区域报告所连接宿主的状态：

| 状态 | 含义 |
|---|---|
| **受管理** | 下文所有控件均可用。 |
| **仅存储** | 宿主会存储缓存字节，但无法列出或安全删除；不提供用量信息。 |
| **不可用** | 平台没有受管理的磁盘缓存。 |

## 打开该区域

在设备已连接到编辑器的情况下，打开 **性能分析器**，将 **性能数据来源** 设为 **设备**。**设备磁盘缓存** 区域显示在设备控件下方。选择设备时读取一次；目录扫描不会轮询，需点击 **重新扫描** 刷新。

## 概要

概要一行的格式为 *资源 · 受保护 · 可释放 · 索引*：

| 数字 | 含义 |
|---|---|
| **资源** | 磁盘上已缓存资产的字节数。 |
| **受保护** | 游戏可能仍需要的字节：受保护版本的文件，以及所有者未知的文件。 |
| **可释放** | 其余所有字节；清理只能释放这部分。 |
| **索引** | 缓存自身的记录文件，单独计算。 |

## 版本

概要下方，缓存已知的每个版本占一行，列出其修订号、保留原因以及磁盘上缺失的文件数：

| 标签 | 含义 |
| --- | --- |
| **当前版本** | 游戏正在运行的修订版本。 |
| **待提交版本** | 已发现并暂存、但尚未提交的更新。 |
| **回退版本** | 上一个修订版本，保留以便更新失败时回退。 |
| **下次启动 / 保留版本** | 按要求保留的修订版本。 |
| **旧版本** | 未受保护；其文件可释放。 |

所有者未知的文件（缓存开始记录所有者之前写入的文件）在一次校验写入确定其所有者之前一直受保护。存档始终不参与清理。

## 保留版本

对运行中构建的版本，**保留版本** 会预留一个修订版本——例如正在 QA 测试的构建——使当前/回退版本推进时不会释放它。**取消额外保留** 解除预留。保留状态与自动保护分开存储，因此更新不会丢弃已预留的修订版本。

## 按预算清理

1. 以 MiB 为单位设置 **资源预算**（默认 128）。
2. **预览清理** 显示将释放的文件数和字节数，不删除任何内容。
3. **清理未保护资源** 按最近最少使用的顺序删除，直到缓存符合预算，并报告释放的字节数及删除失败的项。

只有未受保护的文件才会被清理。如果受保护文件本身就超出预算，面板会给出提示并保留它们。如果清理释放了空间但未能保存更新后的索引，面板会给出提示；下次扫描时会重新校正索引。
