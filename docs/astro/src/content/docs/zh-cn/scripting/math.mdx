SDK 附带了几个小的数学命名空间——`v2` / `v3`(向量)、`col`(颜色)、`scalar`(数值)
——它们操作的正是你组件里用的那套规范类型(`{x, y}` 向量、0..1 的 `{r, g, b, a}` 颜色)。
每个辅助函数都是**纯函数**:返回新值,绝不修改入参。至于这些数字*意味着*什么——世界
单位、设计像素、物理米制以及 Y 轴向上的坐标系——见
[变换、单位与坐标系](/docs/zh-cn/core-concepts/transforms/)。

## 向量

`v2` 覆盖 2D 向量运算;`v3` 为 3D 提供同样的核心运算。

```typescript
import { v2 } from 'esengine';

// Move a point by a velocity over dt.
const next = v2.add(pos, v2.scale(vel, dt));

// Aim: unit direction from pos to target, then a step of length speed*dt.
const dir  = v2.normalize(v2.sub(target, pos));
const step = v2.scale(dir, speed * dt);

v2.dist(pos, target);                 // distance (for a range check)
v2.fromAngle(Math.PI / 2, 10);        // { x: 0, y: 10 }
v2.rotate({ x: 1, y: 0 }, Math.PI);   // { x: -1, y: 0 }
```

- 四则:`add` / `sub` / `scale` / `mul`(逐分量)/ `neg`。
- 点积/长度:`dot`、`cross`、`len` / `len2`、`dist` / `dist2`。
- 方向:`normalize`、`angle`、`fromAngle`、`rotate`、`perp`(逆时针 90°)。
- 还有:`create`、`clone`、`lerp`、`equals`(带 epsilon 的比较)。

## 颜色

`col` 在 `{r, g, b, a}`(0..1)约定上构造与混合颜色——白色是 `{1, 1, 1, 1}`。命名空间
叫 `col` 是因为裸的 `color` 名字已经是一个 SDK 导出。

```typescript
import { col } from 'esengine';

col.rgb(1, 0, 0);            // opaque red (0..1 channels)
col.from255(255, 128, 0);   // from 0..255 channels
col.fromHex('#ff8800');     // #rgb / #rgba / #rrggbb / #rrggbbaa

col.lerp(red, blue, 0.5);   // blend halfway (e.g. a damage flash)
col.withAlpha(white, 0.3);  // fade
col.multiply(base, tint);   // per-channel tint
```

- 构造:`create`、`rgb`、`from255`、`fromHex`(格式非法时抛错)、`clone`。
- 混合:`lerp`、`withAlpha`、`multiply`、`scaleRgb`;用 `toHex` 序列化。

## 标量

`scalar` 汇集了玩法与数值调校常用的数值辅助:

```typescript
import { scalar } from 'esengine';

scalar.clamp01(hp / maxHp);      // 0..1
scalar.lerp(a, b, 0.25);         // interpolate
scalar.remap(x, 0, 100, 0, 1);   // rescale one range onto another
scalar.smoothstep(0, 1, t);      // eased 0..1 ramp
scalar.deg2rad(90);              // degrees -> radians
```

还有:`clamp`、`inverseLerp`、`rad2deg`、`approximately`、`mod`、`sign`。

## 带种子的随机数

`createRng(seed)` 返回一个带种子的生成器,**在每个宿主上抽出相同的序列**(基于 32 位整数运算的 SFC32),
所以裁定结果的服务器和做预览的客户端能得到一致的数。`hashSeed` 把数字、字符串或列表变成稳定的 32 位哈希:

```typescript
import { createRng } from 'esengine';

const rng = createRng(['loot', levelId]);
rng.float();                     // [0, 1)
rng.int(1, 6);                   // 1..6(含两端),无取模偏差
rng.chance(0.25);                // 25% 概率为 true
rng.pick(items);                 // 随机取一个元素
rng.weighted(items, (i) => i.weight);
rng.shuffle(items);              // 洗牌后的副本
const drops = rng.fork('drops'); // 独立的随机流,不受本流抽取次数影响
```

## 旋转辅助

`Transform.rotation` 是四元数;2D 下只会绕 Z 轴旋转,几个导出就覆盖了
角度 ↔ 四元数的往返:

```typescript
import { quat, quaternionToAngle2D } from 'esengine';
import { normalizeAngle } from 'esengine/ai';

// Angle -> quaternion. NOTE: the factory takes w FIRST — quat(w, x, y, z).
const a = Math.PI / 3;
const rot = quat(Math.cos(a / 2), 0, 0, Math.sin(a / 2));

// Quaternion -> angle (radians), from the z/w components.
const facing = quaternionToAngle2D(rot.z, rot.w);   // Math.PI / 3

// Wrap to (-π, π] — the shortest signed turn from facing toward a target angle.
const delta = normalizeAngle(targetAngle - facing);
```

| 辅助函数 | 说明 |
|---|---|
| `quat(w?, x?, y?, z?)` | 四元数工厂;不传参数得到单位四元数 `{w: 1, x: 0, y: 0, z: 0}`。 |
| `quaternionToAngle2D(rz, rw)` | 由四元数的 `z`/`w` 求 Z 角度(弧度,`2 * atan2(z, w)`)。 |
| `normalizeAngle(a)` | 把任意角度归一到 `(-π, π]`,用于最短转向比较。 |

完整的 3D 旋转用 `q` 命名空间:`create`、`mul`、`axis(axis, rad)`、`normalize`、`conjugate`、`rotate(q, v)`、`fromEuler` / `toEuler`、`rotationTo(from, to)`、`setAngleZ` / `angleZ` 等。

如果需要的是方向*向量*而不是旋转,留在 `v2` 里就好:`fromAngle` / `angle` /
`rotate`。完整的工作示例(炮塔朝向光标)见
[变换、单位与坐标系](/docs/zh-cn/core-concepts/transforms/#2d-旋转)。

<Aside type="tip">
  返回值用的是和组件一样的规范类型,可以直接落回去——例如
  `transform.position = v2.add(transform.position, step)` 或
  `sprite.color = col.withAlpha(sprite.color, a)`,无需转换。因为每次调用都会分配一个
  新对象,在计较分配次数的热点内循环里请把它们提到循环外。
</Aside>
