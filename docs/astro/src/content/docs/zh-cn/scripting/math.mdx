SDK 提供若干小型数学命名空间——`v2` / `v3`（向量）、`col`（颜色）、`scalar`（数值）与 `q`（四元数）——它们作用于组件所用的规范类型：`{x, y}` / `{x, y, z}` 向量、`{w, x, y, z}` 四元数，以及取值 `0..1` 的 `{r, g, b, a}` 颜色。所有辅助函数都是**纯函数**：返回新值，不修改输入。单位与坐标约定见[变换、单位与坐标系](/docs/zh-cn/core-concepts/transforms/)。

结果与组件字段类型相同，可直接赋值，例如 `transform.position = v2.add(transform.position, step)` 或 `sprite.color = col.withAlpha(sprite.color, a)`。每次调用都会分配一个新对象。

## 向量

```typescript
import { v2 } from 'esengine';

// Move a point by a velocity over dt.
const next = v2.add(pos, v2.scale(vel, dt));

// Unit direction from pos to target, then a step of length speed * dt.
const dir  = v2.normalize(v2.sub(target, pos));
const step = v2.scale(dir, speed * dt);

v2.dist(pos, target);                 // distance
v2.fromAngle(Math.PI / 2, 10);        // { x: 0, y: 10 }
v2.rotate({ x: 1, y: 0 }, Math.PI);   // { x: -1, y: 0 }
```

| 分组 | `v2` | `v3` |
|---|---|---|
| 构造 | `create`、`clone` | `create`、`clone` |
| 算术 | `add`、`sub`、`scale`、`mul`（逐分量）、`neg` | `add`、`sub`、`scale`、`mul`、`neg` |
| 积与长度 | `dot`、`cross`、`len`、`len2`、`dist`、`dist2` | `dot`、`cross`、`len`、`len2`、`dist` |
| 方向 | `normalize`、`angle`、`fromAngle`、`rotate`、`perp`（逆时针 90°） | `normalize` |
| 其他 | `lerp`、`equals`（epsilon 比较） | `lerp`、`equals` |

## 颜色

`col` 按 `{r, g, b, a}`（`0..1`）约定创建与混合颜色；白色为 `{1, 1, 1, 1}`。该命名空间名为 `col`，因为 `color` 是另一个 SDK 导出。

```typescript
import { col } from 'esengine';

col.rgb(1, 0, 0);            // opaque red (0..1 channels)
col.from255(255, 128, 0);    // from 0..255 channels
col.fromHex('#ff8800');      // #rgb / #rgba / #rrggbb / #rrggbbaa

col.lerp(red, blue, 0.5);    // halfway blend
col.withAlpha(white, 0.3);   // change alpha
col.multiply(base, tint);    // per-channel multiply
```

| 分组 | 成员 |
|---|---|
| 构造 | `create`、`rgb`、`from255`、`fromHex`（输入格式错误时抛出异常）、`clone` |
| HSV | `fromHsv(h, s, v, a?)`（色相以度计，其余为 `0..1`）、`toHsv` |
| 混合 | `lerp`、`withAlpha`、`multiply`、`scaleRgb` |
| 其他 | `toHex(c, withAlpha = false)`、`equals` |

## 标量

```typescript
import { scalar } from 'esengine';

scalar.clamp01(hp / maxHp);      // 0..1
scalar.lerp(a, b, 0.25);         // interpolate
scalar.remap(x, 0, 100, 0, 1);   // map one range onto another
scalar.smoothstep(0, 1, t);      // smooth 0..1 ramp
scalar.deg2rad(90);              // degrees -> radians
```

成员：`clamp`、`clamp01`、`lerp`、`inverseLerp`、`remap`、`smoothstep`、`deg2rad`、`rad2deg`、`approximately`、`mod`、`sign`。

## 带种子的随机数

`createRng(seed)` 返回一个带种子的生成器，它在**所有宿主上产生相同的序列**（基于 32 位整数运算的 SFC32），因此决定结果的服务器与预览结果的客户端保持一致。`hashSeed` 将数字、字符串或列表转换为稳定的 32 位哈希；`createRng` 接受相同形式的种子。

```typescript
import { createRng } from 'esengine';

const rng = createRng(['loot', levelId]);
rng.float();                     // [0, 1)
rng.int(1, 6);                   // 1..6 inclusive, without modulo bias
rng.chance(0.25);                // true with probability 0.25
rng.pick(items);                 // one element
rng.weighted(items, (i) => i.weight);
rng.shuffle(items);              // a shuffled copy
const drops = rng.fork('drops'); // an independent stream
```

| `Rng` 成员 | 说明 |
|---|---|
| `nextU32()` | 下一个原始 32 位值。 |
| `float()` | `[0, 1)` 内的值。 |
| `int(min, max)` | `[min, max]` 内的整数，无取模偏差。 |
| `chance(p)` | 以概率 `p`（钳制到 `[0, 1]`）返回 `true`。 |
| `pick(items)` | 一个元素。 |
| `weighted(items, weight)` | 按权重选出的一个元素。 |
| `shuffle(items)` | 打乱后的副本。 |
| `fork(label)` | 从本生成器派生的独立生成器；任一方的抽取不影响另一方。 |

## 旋转辅助函数

`Transform.rotation` 是四元数。2D 旋转仅绕 Z 轴：

```typescript
import { quat, quaternionToAngle2D } from 'esengine';
import { normalizeAngle } from 'esengine/ai';

// Angle -> quaternion. The factory takes w FIRST: quat(w, x, y, z).
const a = Math.PI / 3;
const rot = quat(Math.cos(a / 2), 0, 0, Math.sin(a / 2));

// Quaternion -> angle (radians), from the z/w components.
const facing = quaternionToAngle2D(rot.z, rot.w);   // Math.PI / 3

// Wrap to (-π, π]: the shortest signed turn toward a target angle.
const delta = normalizeAngle(targetAngle - facing);
```

| 辅助函数 | 说明 |
|---|---|
| `quat(w?, x?, y?, z?)` | 四元数工厂函数；无参数时返回单位四元数 `{w: 1, x: 0, y: 0, z: 0}`。 |
| `quaternionToAngle2D(rz, rw)` | 由四元数的 `z` / `w` 计算以弧度计的 Z 角（`2 * atan2(z, w)`）。 |
| `normalizeAngle(a)` | 将角度规整到 `(-π, π]`。来自 `esengine/ai`。 |

`q` 命名空间涵盖 3D 旋转：

| 成员 | 说明 |
|---|---|
| `create`、`clone` | 构造。 |
| `mul`、`dot`、`neg`、`scaled`、`normalize`、`conjugate` | 四元数运算。 |
| `axis(axis, rad)` | 绕 `axis` 旋转 `rad` 弧度。 |
| `rotate(q, v)` | 旋转一个向量。 |
| `fromEuler` / `toEuler` | 与以**度**计的欧拉角相互转换。 |
| `rotationTo(from, to)` | 从一个方向到另一个方向的最短旋转。 |
| `setAngleZ(q, deg)` / `angleZ(q)` | 以度设置 Z 角 / 以弧度读取 Z 角。 |

方向向量可通过 `v2.fromAngle`、`v2.angle` 与 `v2.rotate` 生成，无需四元数。完整示例（朝向光标的炮塔）见[变换、单位与坐标系](/docs/zh-cn/core-concepts/transforms/#2d-旋转)。

<Aside type="tip">
  由于每个辅助函数都会分配结果对象，对分配次数敏感的热点内层循环应就地计算，或将辅助函数调用移出循环。
</Aside>
