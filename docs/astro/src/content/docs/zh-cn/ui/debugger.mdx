title: UI 调试器
description: 实时检查 UI 树——拾取元素、录制它收到的事件、检查文本溢出与伪本地化预览、走一遍 Tab 顺序。
---

**UI 调试器**是编辑器里检查 UI 树的面板。细节面板负责改实体的组件,调试器回答的是
*一个控件为什么长这样、为什么这样响应*:布局给了它多大、哪些输入能到达它、文字放不放得下、
Tab 下一步去哪。从命令面板(**UI 调试器**)或窗口菜单打开。编辑时它读**编辑器世界**,
Play 时读**运行中的世界**。

它有四个视图,在顶部切换。

## 元素

左边是可搜索的 **UI 层级**,右边是所选节点的真实组件值——包括**实际布局尺寸**,
也就是布局算出来的结果,而不是你填的值。

- **拾取元素**让你直接在视口或游戏视图里点一个 UI 元素,不用在树里翻。**Esc** 取消;拾取的那一下点击不会传给游戏。
- 数值实时更新。在细节面板里编辑;Play 中的编辑在停止后恢复。

## 事件

录制 UI 在你游玩时实际派发的事件:点**录制事件**,操作游戏,再看列表——**目标节点**、
事件**冒泡**经过的节点,以及是否**已停止传播**或**已阻止默认行为**。可按事件类型或节点筛选。

- 需要游戏在运行:先开始 Play。
- 保留最近 200 条记录,有旧记录被丢弃时会提示。
- 录制不消耗输入;没有记录本身不代表故障。
- UI 冒泡只经过启用的 `Interactable` 祖先,普通布局父节点会被跳过;`blockRaycast` 可以在没有停止标记的情况下结束这次传播。

## 文本

场景里每个 `Text`,把**测量**尺寸和**容器**尺寸、溢出方式并排放,被裁掉或溢出的标签一眼可见。
顶部有**文本**、**溢出**、**待复核**的计数,**只看问题**会隐藏其余行。

**预览**菜单把所有文本重新渲染为**原文**、**重音 + 35%**(字母换成带变音符号的形近字,字符串约长三分之一
——能发现缺这些字形的字体)或**重音 + 100%**(同样处理,长度翻倍——能发现只适配英文的布局)。
预览不会改写场景里的文本。

## 焦点路径

每个 `Focusable` 控件的 Tab 顺序,按 **Tab 索引**排序(同值沿用实体顺序),并说明某个控件为什么被跳过——
已禁用、层级中已隐藏、或位于打开的弹窗之外。Play 时还会显示**当前焦点**,以及它是否是可见(键盘)焦点。
选中某一行只是检查该实体,不会移动焦点。

如果什么都没列出,给控件加上 `Focusable` 再重新读取。
