Estella 的 UI 是基于 ECS 的保留模式 UI，布局由 C++ 内核中的 CSS flexbox 引擎求解。界面由实体与组件构成，编辑器与代码操作同一数据模型；以设计像素布局，在屏幕空间渲染，响应指针、键盘与触摸输入。不存在 `RectTransform`：`UINode` 是以 `px`、`percent` 或 `auto` 定尺寸、由锚点、弹性布局或 `Absolute` 内偏移定位的 flexbox 盒。

<Aside type="caution" title="Sprite 是世界空间渲染组件">
  `Sprite` 经相机在世界空间渲染。屏幕空间图像（图标、按钮、面板、进度条）使用画布下的 `UINode` + `UIVisual`，通过 *创建 → UI → Image* 或将纹理拖放到画布上创建。`UINode` 实体上的 `Sprite` 不会渲染。见[精灵还是 UI 图片](/docs/zh-cn/ui/sprite-or-ui/)。
</Aside>

## 组件模型

| 组件 | 职责 | 章节 |
|---|---|---|
| `Canvas` | 界面的根：设计分辨率，以及它如何适配真实屏幕。 | [画布](/docs/zh-cn/ui/canvas/) |
| `UINode` | 盒子：尺寸、外边距、锚点、内偏移、显示、透明度。每个 UI 元素都有一个。 | [布局](/docs/zh-cn/ui/layout/) |
| `FlexContainer` | 排列一个节点的子节点——行或列、对齐、间距、内边距、换行。 | [布局](/docs/zh-cn/ui/layout/) |
| `UIVisual` | 盒子画什么：纯色、图片、九宫格边框、平铺图案、填充条。 | [图片](/docs/zh-cn/ui/images/) |
| `Text` | 文字：字体、字号、颜色、对齐、换行、描边、阴影、富文本。 | [文本](/docs/zh-cn/ui/text/) |
| `UIMask` | 把子节点裁到它的框或它的形状。 | [遮罩与显隐](/docs/zh-cn/ui/masks/) |
| `UIScroll` | 把一个被裁切的节点变成滚动区域。 | [列表与滚动](/docs/zh-cn/ui/lists/) |
| `Interactable` | 让节点可以被悬停和点击；引擎写入 `UIInteraction` 并发出 `UIEvents`。 | [交互](/docs/zh-cn/ui/interaction/) |
| `UIController` + `UIGear` | 命名的状态（分页、按钮状态、界面）以及每个状态要设置的字段——不用写代码。 | [控制器](/docs/zh-cn/ui/controllers/) |

*创建 → UI* 下的编辑器预设：**Canvas**；**Text**（`UINode` + `Text`）；**Image**（`UINode` + `Image` 模式的 `UIVisual`）；**Container**（`UINode`）；以及控件预制体（Button、Toggle、Slider、Progress、Dialog、Dropdown、TextInput、ListView、ScrollView 等）。

## 分层架构

各层依赖其前一层：

1. **画布** —— 界面根节点与设计分辨率。→ [画布](/docs/zh-cn/ui/canvas/)
2. **布局** —— 由弹性盒引擎求解的 `UINode` 盒子；`FlexContainer` 排列子节点，锚点和 `Absolute` 内偏移摆放覆盖层。→ [布局](/docs/zh-cn/ui/layout/)
3. **显示与文本** —— `UIVisual` 渲染盒，`Text` 渲染字形，`UIMask` 裁切。→ [图片](/docs/zh-cn/ui/images/)、[文本](/docs/zh-cn/ui/text/)、[遮罩与显隐](/docs/zh-cn/ui/masks/)
4. **交互** —— `Interactable` 让盒子可被命中；引擎把指针状态写进 `UIInteraction` 并发出冒泡的 `UIEvents`；拖放和键盘焦点建立在其上。→ [交互](/docs/zh-cn/ui/interaction/)
5. **控件** —— `createButton`、`createSlider` 等工厂及编辑器控件预制体组合以上各层；`createListView` 提供虚拟化列表。→ [控件](/docs/zh-cn/ui/widgets/)、[列表与滚动](/docs/zh-cn/ui/lists/)
6. **状态** —— 控制器以无代码方式切换命名页面；信号将游戏状态同步到 UI；主题统一控件外观。→ [控制器](/docs/zh-cn/ui/controllers/)、[数据绑定](/docs/zh-cn/ui/data-binding/)、[主题](/docs/zh-cn/ui/theming/)

## 创作方式

编辑器与代码写入同一组组件，编辑器没有独立的数据格式。

- **编辑器**：UI 工作区（画布框选、UI 控件面板）、*创建 → UI*、在大纲中编辑层级、在细节面板中编辑字段与使用锚点选择器、按设计分辨率与设备预设预览。见[第一个界面](/docs/zh-cn/ui/first-screen/)。
- **代码**：在启动系统中使用 `spawnUIEntity` 与控件工厂（[第一个界面 → 等价代码](/docs/zh-cn/ui/first-screen/)）。

## 准则

- 屏幕空间图像使用 `UIVisual`；`Sprite` 仅用于世界空间。
- 优先使用弹性布局（`FlexContainer`、`flexGrow`）；`Absolute` 内偏移仅用于覆盖层与角标。
- 使用锚点与 `percent` / `auto` 尺寸实现宽高比无关；`px` 用于有意固定的尺寸。
- 可缩放的带框元素使用 `NineSlice`。
- 将 `UIInteraction` 与 `UIEvents` 视为游戏逻辑的只读输入。
- 使用控件工厂与预制体以保持交互状态的一致性。
