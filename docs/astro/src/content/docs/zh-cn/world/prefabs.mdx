**预制体**是以 `.esprefab` 资源保存的实体树。它在编辑器中创作一次，即可在场景中或在运行时通过 **`Prefabs`** 资源实例化任意次。资源是唯一的数据来源；每个实例可在其上叠加自己的值（覆盖）。

## 创建预制体

*世界大纲 → 右键实体 → 创建预制体* 将该实体及其整个子树写入 `assets/prefabs/<Name>.esprefab`，以实体名命名。原实体保留在场景中不变，不会被替换为实例。

放置实例：将 `.esprefab` 从内容浏览器拖入场景，或从 *+ 添加 → 创建实体…* 的 **Prefabs** 分类中创建。

如果子树引用了选区之外的实体，编辑器会先询问*暴露外部引用？*。这些引用在预制体中保持**未绑定**，由每个实例在检视器中绑定到场景实体。

## 预制体模式

双击 `.esprefab`，或在实例上选择*编辑预制体*，即进入**预制体模式**。预制体作为独立的实体树在视口、大纲与细节面板中打开，四周以强调色边框标出，顶部显示**正在编辑预制体**横幅。实体与组件的编辑方式与场景相同。**保存预制体**写入资源，所有场景中的所有实例随之更新。**返回场景**回到原场景。

![编辑器处于预制体模式，单独编辑 Coin 预制体](@/assets/guides/zh/prefab-mode.png)

*预制体模式：带**保存预制体**与**返回场景**的**正在编辑预制体**横幅；预制体作为独立的实体树打开。*

- **UI 预制体**在按项目参考分辨率创建的宿主画布中打开，因此百分比尺寸可以正常解析，布局、选中轮廓与 gizmo 的表现与场景中一致。宿主不属于预制体：不出现在大纲中，也不会被保存。
- **预制体模式不支持：**就地编辑嵌套预制体，以及编辑基础预制体不是扁平结构的变体。
- **编辑预制体时禁用：**播放与*另存为*。

## 实例与覆盖

放入场景的实例与其源保持链接。修改实例上的字段即创建一个**覆盖**：叠加在预制体值之上的逐实例值。编辑器以下列方式标记覆盖：

| 标记 | 位置 |
|---|---|
| 根节点名称以强调色显示 | 大纲中的实例根节点 |
| 字段上的 ↺ *重置为默认值* 按钮 | 细节面板 |
| 组件标题上的琥珀色圆点 | 细节面板 |
| 仅显示被覆盖字段的过滤器 | 细节面板 |

字段上的 ↺ 将该字段恢复为预制体的值。
预制体变化时，打开场景中的实例立即更新。这适用于从预制体模式保存、从另一个实例*应用到预制体*、磁盘上的改写（版本控制拉取或其他工具），以及从其来源的 2D 骨骼重新烘焙。每个实例保留其覆盖以及场景中挂在其内部的实体。预制体中仍存在的实体保持身份不变，因此选中状态与其他实体对它的引用依然有效。场景不会被标记为已修改，因为场景文件只存储覆盖。

## 预制体操作

在大纲中右键实例，或使用细节面板顶部的预制体栏，可执行：

| 操作 | 效果 |
|---|---|
| **编辑预制体** | 在预制体模式中打开源。 |
| **选中预制体源** | 在内容浏览器中定位 `.esprefab`。 |
| **应用到预制体** | 将本实例的覆盖写入源，改变所有实例的基础值。 |
| **还原为预制体** | 丢弃本实例的覆盖，并与源重新同步。 |
| **创建变体** | 保存一个继承基础预制体并包含本实例覆盖的新 `.esprefab`。 |
| **解包预制体** | 脱离子树：其实体成为不带预制体链接的普通场景实体。可撤销。 |

*应用到预制体*是唯一会改写共享资源的操作。它先显示逐项差异（*将改动应用到预制体？*）：修改为琥珀色，新增为绿色，删除为红色，结构性改动标为破坏性。
<Aside type="caution">
  删除 `.esprefab` 不会删除其实例。编辑器列出引用它的文档，并将文件移入回收站（可用撤销恢复）。剩余实例将无法解析，并在其场景下次加载时被丢弃。需要保留实体时，先执行**解包预制体**。
</Aside>

当某实例覆盖过的组件在预制体中被重命名或移除时，这些覆盖不再匹配，在场景加载时被丢弃并给出通知。检视器标记受影响的实例并提供**修复**；保存场景即持久化清理后的状态。

预制体可以嵌套：预制体可以包含其他预制体的实例，覆盖沿嵌套层级生效。

## 虚拟实例

**虚拟**实例在编辑器中完整显示与编辑，但运行中的场景只创建其根节点，在实例被打开时才构建其余部分。适用于由多个页面组成的界面，只有打开的页面需要其实体。

- 通过细节面板预制体栏中的**虚拟**，或大纲右键菜单中的*设为虚拟（按需加载）*切换。
- 运行时通过 [`UIPages`](/docs/zh-cn/ui/overview/) 打开：`registerDeferred(entity)` 将虚拟实例注册为以其根节点命名的页面。
- 增加、移除或重新挂接实体的实例总是完整创建，不作为虚拟实例。
- 页面地址参数 `?expand-virtual` 在启动时完整创建所有虚拟实例，供需要全部节点的测试工具使用。标记为同一页面另一种布局的实例除外，否则多种布局会并列出现。
- 以这种方式维护多种布局的游戏可使用导出的 `deferredEntities` 与 `deferredRecord`。

![细节面板顶部的预制体栏，含编辑、选中、应用、还原与虚拟按钮](@/assets/guides/zh/prefab-virtual-toggle.png)

![预制体实例的大纲右键菜单，含设为虚拟（按需加载）](@/assets/guides/zh/outliner-prefab-menu.png)

## 运行时实例化

`instantiate` 在首次使用时加载预制体资源（及其依赖）并生成实例。该调用为异步，兑现为生成的实体树；`root` 为新的根实体。

```typescript
import { defineSystem, Res, Prefabs } from 'esengine';

const spawnEnemy = defineSystem([Res(Prefabs)], async (prefabs) => {
  const { root } = await prefabs.instantiate('assets/prefabs/enemy.esprefab');
});
```

### 父级与子实体

`parent` 在生成时将实例放到已有实体之下，使其变换在第一帧即正确解析。返回的 `entities` 映射用于访问生成的子实体。

```typescript
const { root, entities } = await prefabs.instantiate('assets/prefabs/turret.esprefab', {
  parent: mountPointEntity,
});
// root      → the instance root
// entities  → Map<number, Entity> of every spawned entity, root included
```

### 逐实例覆盖

`overrides` 只修改本实例的值，不编辑资源——例如以不同生命值或着色生成同一种敌人。覆盖指明组件与属性，除非指定其他实体，否则作用于预制体的**根**。

```typescript
const { root } = await prefabs.instantiate('assets/prefabs/enemy.esprefab', {
  overrides: [
    { type: 'property', componentType: 'Health', propertyName: 'value', value: 250 },
  ],
});
```

要作用于子实体，将 `prefabEntityId` 设为该实体在 `.esprefab` 中的字符串 id（编辑器保存的预制体为 UUID）。不带 `prefabEntityId` 的覆盖作用于根。与预制体中任何实体都不匹配的 id 会**抛出错误**，错误信息列出根 id 与现有的 id。

<Aside type="caution" title="prefabEntityId: '0'">
  `'0'` 是引入稳定 id 之前所有预制体的根 id，出现在较早的示例代码中。此后由编辑器保存的预制体使用 UUID，因此 `prefabEntityId: '0'` 的覆盖会抛出错误。作用于根时省略该字段即可。
</Aside>

| 覆盖 `type` | 使用的字段 |
|---|---|
| `'property'` | `componentType`、`propertyName`、`value` |
| `'name'` | `value`（字符串） |
| `'visibility'` | `value`（布尔值） |
| `'parent'` | `value`（新父级的 `prefabEntityId`，或 `null`） |
| `'component_added'`、`'component_replaced'` | `componentData`（`{ type, data }`） |
| `'component_removed'` | `componentType` |
| `'metadata_set'` | `metadataKey`、`value` |
| `'metadata_removed'` | `metadataKey` |

### 预备生成

在 `prefabs.instantiate(path, options)` 或已准备预制体的 `spawn(options)` 中传入 `{ owner: entity }`，生成的整棵实体树就归该实体所在的场景。
异步加载期间实体若转移到另一个场景，实例会归入新场景。`parent` 控制根节点挂载的位置。时间轴生成轨道会用播放器实体作为 `owner`。

`prepare(path)` 加载预制体及其实体所用的全部资源（网格、材质、纹理），并持有它们直到释放。从结果生成是同步的：实体在请求它们的那一行即已存在。

```typescript
const bullet = await prefabs.prepare('assets/prefabs/bullet.esprefab');
const { root } = bullet.spawn({ parent: gunEntity });   // synchronous
// …
bullet.release();                                         // a spawn after release throws
```

`spawn` 接受 `parent` 与 `scene`，不接受覆盖。

## `instantiate` 参考

| 选项 | 类型 | 说明 |
|---|---|---|
| `parent` | Entity | 将实例放到该实体之下。 |
| `overrides` | override[] | 逐实例修改。 |
| `baseUrl` | string | 解析预制体资源所用的基础 URL。 |
| `scene` | boolean | 默认 `true`：生成的实体由生成完成时的活动场景收养，并随该场景移除。`false` 使其不属于任何场景，用于需要比生成它的区域存活更久的实体。 |

| 结果字段 | 说明 |
|---|---|
| `root` | 实例根 `Entity`。 |
| `entities` | 所有生成实体的 `Map<number, Entity>`，包括根。 |

应通过 `entities` 访问子实体，而不是按索引遍历层级。
