瓦片碰撞是瓦片上的数据：在 `.estileset` 中创作的形状与修饰（[碰撞形状](/docs/zh-cn/world/tilemaps/tilesets/#碰撞形状)）、从 Tiled 导入的数据，或在[碰撞层](#碰撞层)上以内置碰撞笔刷绘制的数据。场景运行时由这些数据生成静态碰撞体。

## 碰撞体生成

| 瓦片碰撞 | 生成的碰撞体 |
|---|---|
| 普通实心矩形（无修饰） | 与相邻矩形贪心合并为大块静态碰撞体。 |
| 圆形、多边形、斜坡或半砖；单向；触发器；物理材质覆盖 | 每个瓦片一个碰撞体。 |

- 瓦片翻转标志会重定向碰撞几何，使其与渲染出的瓦片一致。
- 单向瓦片只在一侧实心；触发器瓦片产生重叠事件，无接触响应。

<Aside type="note">
  瓦片碰撞体只存在于播放模式。它们在场景运行时生成，从不属于编辑世界，也不会被序列化。[可破坏瓦片地图](/docs/zh-cn/world/tilemaps/code/#可破坏瓦片地图)将这一生成改为只针对露在外面的瓦片。
</Aside>

### 碰撞覆盖层

视口中的**显示标记 → 瓦片碰撞**（亦可用**显示瓦片碰撞**命令）将所选图层的完整碰撞绘制为覆盖层。覆盖层显示的形状与播放时生成的形状相同。
## 来自 Tiled 的碰撞

在 Tiled 瓦片碰撞编辑器中绘制的形状（矩形、椭圆、多边形）导入到同一模型。整格矩形保持为可合并的实心矩形；其他形状每个瓦片生成一个碰撞体。瓦片属性应用相同的修饰：

| Tiled 瓦片属性 | 类型 | 效果 |
|---|---|---|
| `oneway` | bool `true` | 顶部实心的单向碰撞。 |
| `sensor` | bool `true` | 触发器。 |
| `friction` / `restitution` / `density` | number | 物理材质覆盖。 |
| `collision` | bool `true` | 普通实心矩形（旧写法）。 |

Tiled 对象层也可生成碰撞体；见[碰撞对象组](/docs/zh-cn/world/tilemaps/tiled/#碰撞对象组)。

## 碰撞层

**碰撞层**是不渲染任何内容的 `TilemapLayer`，在其背后的任意画面上绘制碰撞格。它为美术是一张背景图而非瓦片的关卡提供墙、地板与斜坡。

碰撞层是普通的瓦片图层，其瓦片集引用是哨兵值 `builtin:collision` 而非 `.estileset`。因此它使用标准的绘制工具、分块存储、翻转与矩形合并。其格子保存在图层的分块数据中；碰撞体与其他瓦片碰撞一样在播放时生成。

**新建碰撞层**（命令面板，或图层选择器菜单中的**新建碰撞层**）创建碰撞层，选中实心笔刷与笔刷工具，并打开以碰撞笔刷代替瓦片集的瓦片调色板。新图层复制所选瓦片图层的网格——格子尺寸、原点偏移、位置与朝向——未选中时取场景中第一个瓦片图层；场景中没有瓦片图层时使用 32 × 32 px 网格。

![碰撞笔刷调色板——实心、斜坡、半砖、单向与触发器笔刷，以及逐层的摩擦力与弹性字段](@/assets/guides/zh/collision-palette.png)

*碰撞调色板：**实心**、斜坡、半砖、**单向 ↑** 与**触发器**，以及作用于整层的**摩擦力**与**弹性**字段。*

| 按键 | 笔刷 | 格子 | 用途 |
|---|---|---|---|
| `1` | **实心** | 整格矩形 | 墙、地板、天花板。贪心合并为大块碰撞体。 |
| `2` / `3` | **斜坡 ◢** / **斜坡 ◣** | 三角形 | 向右 / 向左升的斜坡（方形格子上为 45°）。 |
| `4`–`7` | **半砖**（下、上、左、右） | 半格矩形 | 台沿、矮墙、薄地板。 |
| `8` | **单向 ↑** | 上方实心的矩形 | 可上跳穿过的平台。翻转格子可改变朝向（天花板、墙）。 |
| `9` | **触发器** | 触发器矩形 | 产生重叠事件的非实心区域；见[标记与触发区](/docs/zh-cn/gameplay/markers/)。 |

选中碰撞层时，数字键用于选择笔刷。

### 图层物理材质

调色板的**摩擦力**与**弹性**字段为图层的所有格子设置同一份物理材质；字段留空时使用引擎默认值。材质以查询参数的形式保存在图层的瓦片集引用中，例如 `builtin:collision?friction=0.1&restitution=0.2`；`density` 以同样形式生效，但调色板中没有对应字段。

设置材质后，实心格子携带该材质，不再贪心合并：图层的每个格子各自生成碰撞体。

## 碰撞查询

玩法代码直接读取解析后的碰撞数据，无需物理射线检测。这些函数适用于所有图层（包括碰撞层），从 `esengine/tilemap` 导出。

| 函数 | 返回 |
|---|---|
| `tileCollisionAt(layer, x, y)` | 瓦片解析后的形状与修饰，或 `null`。 |
| `isTileSolid(layer, x, y)` | 任何非触发器碰撞均为 `true`。单向瓦片视为实心；需区别处理时检查结果的 `.oneWay`。 |
| `tileCollisionAtWorld(layer, worldX, worldY, originX?, originY?, rotation?)` | 以世界像素寻址的 `tileCollisionAt`。 |
