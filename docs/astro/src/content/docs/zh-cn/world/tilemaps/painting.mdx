选中带 `TilemapLayer` 的实体即启用**瓦片地图模式**：绘制工具出现在视口工具栏，**瓦片调色板**在底部停靠区内容浏览器旁打开。也可通过活动栏中的图标进入瓦片地图模式。瓦片直接在视口中绘制，光标下显示图章预览。

## 绘制工具

| 工具 | 按键 | 行为 |
|---|---|---|
| 笔刷 | `B` | 绘制当前图章；拖动可连续绘制。`Alt`+单击从图层拾取图章。 |
| 橡皮擦 | `E` | 清除瓦片。 |
| 矩形 | `U` | 以图章图案填充拖出的矩形。`Shift` 约束为正方形；`Alt` 只绘制边框。 |
| 椭圆 | `O` | 填充拖出包围盒的内切椭圆。`Shift` 约束为正圆；`Alt` 绘制圆环。 |
| 直线 | `L` | 沿直线铺设图章。`Shift` 约束为水平、垂直或 45°。 |
| 填充 | `G` | 泛洪填充相连的同类瓦片区域。 |
| 选择 | `M` | 框选。`mod`+`C` / `mod`+`X` 复制 / 剪切区域，`Delete` 清空，`mod`+`V` 作为笔刷粘贴。从选区内部拖动可移动整块（单个撤销步骤；`Esc` 取消）。 |
| 取色器 | `I` | 从图层上的瓦片拾取图章。 |
| 地形 | `T` | 地形笔刷：绘制地形并重新解析相邻瓦片（[地形](/docs/zh-cn/world/tilemaps/tilesets/#地形)）。 |

选中瓦片图层时，工具按键随时可选择工具。以下按键在绘制工具激活时生效：

| 按键 | 操作 |
|---|---|
| `H` / `V` | 水平 / 垂直翻转图章。 |
| `R` | 将图章顺时针旋转 90°。 |
| `D` | 切换随机模式。 |
| `Q` / `Esc` | 退出绘制并回到选择工具。 |
| `W` | 退出绘制并回到移动工具。 |
| `1`–`9` | 在[碰撞层](/docs/zh-cn/world/tilemaps/collision/#碰撞层)上：选择调色板中对应位置的碰撞笔刷。 |

## 瓦片调色板

![瓦片调色板特写——瓦片集选择器、图块 / 地形 / 图章标签、用于取图章的图集，以及当前画刷](@/assets/guides/zh/tilemap-tools.png)

*瓦片调色板：顶部为瓦片集选择器与**图块 / 地形 / 图章**标签，中间为图集，另有带翻转、旋转、**随机**与**存为图章**的**当前画刷**。*

| 标签 | 内容 |
|---|---|
| **图块** | 当前瓦片集的图集。单击瓦片，或拖过多个瓦片将一整块作为多瓦片图章。方向键移动选择；`Shift`+方向键将选择扩展为图章。 |
| **地形** | 瓦片集的地形（或地形颜色），供地形工具使用。 |
| **图章** | 项目中已保存的图章。单击图章将其设为笔刷；`×` 删除。 |

- 当前画刷下方的**存为图章**将笔刷加入项目的图章库。相同图案只保存一次。图章库保存在 `assets/editor/tile-stamps.json` 中，随项目一起迁移。
- **随机**（`D`）使每个绘制的格子从图章中随机取一个瓦片，而非重复图案。取样按瓦片集编辑器属性模式中每个瓦片的**概率**加权（默认 `1`；`0` 表示排除该瓦片）。

## 图层

场景中有多个瓦片图层时，视口工具栏中的图层选择器用于切换当前图层。其菜单提供：

| 项目 | 作用 |
|---|---|
| 逐图层控件 | 显示 / 隐藏、锁定、不透明度、重命名、复制、删除、上移 / 下移（绘制顺序）。 |
| **新建图层** | 以当前瓦片集创建图层。 |
| **新建碰撞层** | 创建[碰撞层](/docs/zh-cn/world/tilemaps/collision/#碰撞层)。 |
| **批量替换图块…** | 打开图块替换对话框。 |
| **高亮缺少匹配规则的单元** | 标记由回退规则解析的格子。 |

### 批量替换图块

**批量替换图块…** 在当前选区内或整个图层中，将某个瓦片 id 的所有出现替换为另一个。受影响的格子先在视口中预览并在对话框中计数，再由**替换**作为单个撤销步骤提交。对话框打开期间图层发生变化时，替换会被拒绝，直到重新计算预览。

### 缺失的地形规则

**高亮缺少匹配规则的单元**以橙色标记地形组合在瓦片集中没有精确对应瓦片、由回退规则解析的每个格子；菜单显示使用回退规则的格子数。`examples/tilemap-workflows` 包含一个 48 × 32 的图层，其边、角与 Wang 规则特意不完整，用于此用途。
