**`.estileset`** 是引擎的瓦片集资源。它引用一张图集纹理，并存储逐瓦片数据：碰撞形状与修饰、动画帧、地形归属以及自定义键值属性。使用该瓦片集的每个图层都会在编辑器视口与运行时应用这些数据，无需代码。

## 创建瓦片集

**内容浏览器 → 右键纹理 → 创建瓦片集** 打开*新建瓦片集*对话框，将纹理切分为网格：

| 字段 | 说明 |
|---|---|
| **瓦片宽** / **瓦片高** | 瓦片尺寸（像素）。 |
| **边距** | 第一个瓦片之前的边框（像素）。 |
| **间距** | 瓦片之间的间隙（像素）。 |

对话框显示所得的列 × 行数与瓦片数，并在纹理无法被整除时给出警告（最后一行或一列会被截断）。双击 `.estileset` 可在**瓦片集编辑器**中打开。

## 瓦片集编辑器模式

| 模式 | 编辑内容 |
|---|---|
| **碰撞** | 逐瓦片的碰撞形状与修饰。 |
| **地形** | 地形集以及每个瓦片的地形数据。 |
| **动画** | 瓦片的动画帧。 |
| **属性** | 瓦片的自定义键值属性与随机笔刷的 `probability`。 |

## 碰撞形状

![瓦片集编辑器的碰撞模式——形状标签、修饰、斜坡预设，以及图集上的碰撞覆盖](@/assets/guides/zh/tileset-collision.png)

*碰撞模式：形状标签（**矩形 / 多边形 / 圆形**）、修饰（**单向**、**触发器**、摩擦 / 弹性 / 密度）与斜坡预设。覆盖层标出每个瓦片的碰撞体。*

| 形状 | 创作方式 |
|---|---|
| **矩形** | 整格矩形。单击或拖过瓦片进行绘制；再次绘制则清除。 |
| **圆形** | 适配格子的圆形。拖动绘制；从已有圆形的瓦片开始拖动则清除。圆形编辑器可移动圆心并调整半径。 |
| **多边形** | 在顶点编辑器中自由绘制多边形：单击添加顶点，拖动顶点移动，单击顶点删除。达到三个及以上顶点时生效。 |

多边形模式提供**预设**，单击瓦片即可盖上常用形状（拖动可连续盖一排）：**斜坡 ◢**（向右升）、**斜坡 ◣**（向左升），以及**半砖**（下、上、左、右）。

修饰叠加在所绘形状之上：

| 修饰 | 效果 |
|---|---|
| **单向** | 一侧实心、另一侧可穿过：顶部实心（可上跳穿过的平台）、底部实心（天花板）、左侧实心或右侧实心。 |
| **触发器** | 非实心触发：产生重叠事件，无接触响应。 |
| **摩擦** / **弹性** / **密度** | 瓦片碰撞体的物理材质覆盖。 |

这些形状如何生成碰撞体见[瓦片碰撞](/docs/zh-cn/world/tilemaps/collision/)。

## 瓦片动画

![瓦片集编辑器的动画模式——某个瓦片的帧条带与逐帧时长](@/assets/guides/zh/tileset-animation.png)

*动画模式：所选瓦片（#34）、带逐帧时长（毫秒）的帧，以及循环预览。*

在**动画**模式中，单击要设置动画的瓦片，再单击图集中的瓦片将其追加为帧。工具栏下方的帧条带提供：

- 循环播放的实时预览；
- 每帧的时长字段（毫秒），以及将所有帧设为同一时长的**统一**；
- 拖动以重排帧、移除帧，或**清除动画**。

带动画的瓦片在图集中带有 ▶ 标记。帧保存在 `.estileset` 中；使用该瓦片集的每个图层都会在编辑器视口与运行时播放。由代码构建的图层使用 [`setTileAnimation`](/docs/zh-cn/world/tilemaps/code/#瓦片动画)。

## 地形

![瓦片集编辑器的地形模式——带 Grass / Sand / Water 颜色的角 Wang 集](@/assets/guides/zh/tileset-terrain.png)

*带角 Wang 集的地形模式：地形颜色 Grass、Sand 与 Water，以及为每个瓦片角指定的颜色。*

地形集使地形工具（`T`）绘制的是地形而非具体瓦片：解析器选择边或角与相邻瓦片匹配的瓦片。地形集在**地形**模式中创建，采用以下三种模型之一：

| 模型 | 瓦片声明的内容 | 典型规模 |
|---|---|---|
| **边（4 位）** | 四条边中哪些属于该地形。 | 16 个瓦片 |
| **角（blob）** | 哪些边和角属于该地形。 | 47 个瓦片 |
| **角（Wang）** | 四个角各自的地形颜色。 | 一个集中包含多种地形 |

**边**与**角（blob）**是单地形模型：笔刷绘制地形并修正相邻瓦片的过渡。

**角（Wang）**是多地形模型。地形集持有一组**颜色**（例如草、沙、水），每个瓦片为每个角指定一种颜色。笔刷在**半格角网格**上绘制颜色：在四个瓦片之间单击会按角的精确匹配重新解析这四个瓦片，无精确匹配时回退到最接近的瓦片，从而在地形之间形成平滑边界。

- 瓦片集编辑器负责添加、重命名、改色与删除颜色。
- 瓦片的每个四分之一区域是对应角的点击目标。单击或拖动绘制当前颜色；鼠标右键擦除。
- 瓦片调色板的**地形**标签列出可用于绘制的颜色。

地形工具根据地形集的模型选择解析方式。`examples/tilemap-demo`（`wang-map` 场景，使用 `wang.estileset`）以角 Wang 集混合草、沙与水。缺失的组合可通过[高亮缺少匹配规则的单元](/docs/zh-cn/world/tilemaps/painting/#缺失的地形规则)定位。

## 瓦片属性

在**属性**模式中单击瓦片可编辑两类数据：

| 数据 | 说明 |
|---|---|
| **概率** | 瓦片在随机笔刷中的权重。默认 `1`；`0` 表示排除该瓦片。 |
| 自定义属性 | 字符串键值对。使用该瓦片集的图层会接收这些属性；玩法代码通过 `getTileProperty` 读取（[代码中的瓦片地图](/docs/zh-cn/world/tilemaps/code/#tilemaps-api-参考)）。 |

自定义属性 `hardness` 设置瓦片在[可破坏瓦片地图](/docs/zh-cn/world/tilemaps/code/#可破坏瓦片地图)中被摧毁前可承受的伤害。
