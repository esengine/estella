[Terrain](/docs/zh-cn/graphics/terrain/overview/) 每个位置只有一个高度，因此无法表示洞穴、悬垂结构或孔洞。`VoxelTerrain`
在三维网格的每个点上存储有符号距离，因此可以表示。它适用于地面本身会发生变化的游戏：采矿、生存、可破坏的世界。它与 `Terrain`
并存而不替代它，并且是可选模块（`esengine/voxel`），不使用它的游戏不会包含它。

## 添加体积地形

给实体添加 `VoxelTerrain`。实体的位置决定体积的位置；旋转和缩放不起作用。使用默认设置时，地面为带隧道的丘陵，土壤覆盖在岩石上，岩石中有矿脉。

| 字段 | 默认 | 说明 |
|---|---|---|
| `cellSize` | `1` | 格子边长，世界单位：地面能表现的最小细节。边长减半，格子数变为八倍。 |
| `chunkCells` | `24` | 每个块每边的格子数，8–64。块越小，每次编辑重建得越少，绘制的网格越多。 |
| `minY`、`maxY` | `-48`、`48` | 体积从实体向下、向上延伸的距离。两端封闭：挖不穿底，也建不过顶。 |
| `seed` | `1` | 默认地面的种子。存档保存的是对该种子所生成地面的改动。 |
| `surfaceHeight` | `8` | 地面的平均高度，从实体算起。 |
| `hillHeight`、`hillScale` | `14`、`60` | 丘陵起伏的高度和宽度。 |
| `caveWidth`、`caveScale` | `2.5`、`36` | 隧道的宽度和间距。`caveWidth` 为 `0` 时没有隧道。 |
| `soilDepth` | `5` | 到达岩石之前的土壤深度。 |
| `oreAmount` | `0.06` | 岩石中矿的比例，0–1。 |
| `drawDistance` | `96` | 离视点多远以内绘制地面。 |
| `castShadows` | `true` | 地面是否投射阴影。 |
| `collision` | `true` | 3D 刚体和角色是否与地面碰撞。 |
| `collisionDistance` | `32` | 在每个运动刚体和角色周围构建碰撞的范围。 |
| `collisionLayer` | `0` | 地面所在的碰撞层，0–15。 |
| `friction` | `0.6` | 表面摩擦。 |
| `color0`..`color3`、`map0`..`map3` | — | 每种材质的颜色和贴图。贴图按世界位置从三个方向投射，因为提取出的表面没有 UV。 |
| `tile` | `8` | 贴图在世界中一次重复的长度。 |
| `material` | 无 | 使用 `builtin:voxel-ground` 着色器的材质，用于替换默认材质。 |

四种材质为 `VoxelMaterial.Topsoil`、`Soil`、`Rock` 和 `Ore`。

## 编辑

所有编辑都通过 `VoxelTerrains` 资源进行，位置使用世界坐标。

```ts
import { VoxelTerrain, VoxelTerrainsRes, VoxelMaterial } from 'esengine/voxel';

const voxels = app.getResource(VoxelTerrainsRes);

// 玩家看着的地方。
const hit = voxels.raycast(eye, forward, 8);
if (hit) {
    const dug = voxels.carve(hit.entity, { kind: 'sphere', center: hit.point, radius: 1.5 }, {
        keep: (material) => material === VoxelMaterial.Ore && !hasPick,
    });
    inventory.add('stone', dug.removed[VoxelMaterial.Rock]);
}
```

`carve` 返回每种材质被移除的体积，单位为立方世界单位，即矿工能带走的量。

| 形状 | 字段 |
|---|---|
| `sphere` | `center`、`radius` |
| `box` | `center`、`halfExtents` |
| `capsule` | `from`、`to`、`radius`。一次调用即可挖出一条隧道。 |

| 方法 | 说明 |
|---|---|
| `carve(entity, shape, options)` | 移除一个形状。 |
| `fill(entity, shape, material, options)` | 用某种材质填充一个形状。 |
| `edit(entity, shape, op, options)` | 通用形式：`op` 为 `'subtract'`、`'add'` 或 `'paint'`。`'paint'` 改变形状内的材质（`options.material`），不改变外形。 |
| `raycast(origin, direction, maxDistance)` | 射线最先碰到任意体积的位置：点、法线、材质和实体。 |
| `distanceAt(entity, at)`、`materialAt(entity, at)` | 某位置的有符号距离或材质。小于零为实心。 |
| `onEdit(listener)` | 接收每次产生变化的编辑，用于同步导航网格或游戏状态。返回一个移除该监听的函数。 |
| `collisionReadyAt(entity, x, z)` | 该位置的地面碰撞是否已构建；放置物体前应等待它。 |
| `status(entity)` | 绘制的块数和三角形数、持有和编辑过的块数，以及上次重建的开销。 |

编辑选项：

| 选项 | 说明 |
|---|---|
| `smooth` | 形状边缘融入相邻部分的距离，世界单位。`0` 保持锐利。 |
| `keep` | 关于材质的判定函数：返回 `true` 的材质不能被这次编辑改变。 |
| `material` | `add` 填充和 `paint` 涂改所用的材质。默认为 `0`。 |

只有编辑波及的块及其碰撞会重建。新网格就绪前旧网格保持不变，每帧至少重建一个块。原本压在被移除地面上的刚体会被唤醒并下落。

## 自定义地面

`setSource` 用一个关于位置的函数替换默认地面。对相同位置必须返回相同结果，因为未改动的块会被释放，之后再重新请求。

```ts
voxels.setSource(entity, (x, y, z, out) => {
    out.distance = y - Math.sin(x * 0.1) * 4;  // 小于零是实心；靠近表面时应大致等于真实距离
    out.material = VoxelMaterial.Rock;
});
```

`heightVoxelSource` 可把任意高度场转为体积，因此 `heightVoxelSource((x, z) => terrains.heightAt(x, z))` 会把 Terrain 自身的地面转为体积。

## 存档

存档只包含编辑过的块，为普通 JSON，因此其大小取决于玩家的改动量，而不是世界的大小。

```ts
const whole = voxels.serialize(entity);                // 所有编辑过的块
const delta = voxels.serialize(entity, true);          // 只有上次这样调用之后改动的块
voxels.restore(entity, whole);                         // 恢复：其余部分回到生成源的样子
voxels.restore(entity, delta, true);                   // 把这些块叠加到现有内容上
```

种子或生成源必须与存档时相同。来自其他网格（`cellSize` 或 `chunkCells` 不同）的存档会被拒绝且不做任何改动：`restore` 返回 `false`。
无法读取的块保持不变，并给出警告。

## 限制

- **没有细节层级。** `drawDistance` 以内的块都以全精度绘制。默认地面在 `drawDistance` 为 96、`cellSize` 为 1 时约有 170 个块、
  24 万个三角形，因此远景开销高于 [Terrain](/docs/zh-cn/graphics/terrain/overview/)。
- **编辑器中没有笔刷。** 编辑场景时会绘制体积，但改动只能在运行时由代码完成。
- **不能在 Terrain 上开洞。** 两者是相互独立的地面。要挖掘 Terrain 的形状，用 `heightVoxelSource` 生成体积并改为绘制该体积。
- **编辑过的块保留在内存中，** 默认 24 格时每块约 35 KB，在游戏运行期间一直保留。
- **导航不会自动更新。** 使用 `onEdit` 重建游戏所需的部分。
- **没有法线贴图，每个体积最多四种材质。** 自定义 `material` 必须使用 Voxel Ground 着色器，否则表示各位置材质的顶点色会被当作染色。
- **未在移动设备上测量。** 在桌面上，一次波及三个块且带碰撞的编辑约占帧时间 4 ms，最多 8 ms。首次编辑尚未生成的地面时还需生成它：每块约 3 ms。
