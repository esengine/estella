# Space Frigate · 深空护卫舰

一艘在气态巨行星外巡航的护卫舰。画面里没有一张手绘贴图，也没有一个外部建模软件做的模型：舰体、装甲分块、掉漆、舷窗和引擎都是模型配方（`.esmodel`）里的步骤，星云、行星和星空由脚本与着色器生成。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `S` | 车钟升、降一档：停、1/4、1/2、3/4、全速。设定后保持，不用按住 |
| `A` / `D`（或左右方向键） | 舵一次一档：左右各 10°、20°、30°。打过去就保持，舰一直转，能转满一圈 |
| `Q` / `E`（或上下方向键） | 俯仰一次一档：下压、上仰各两档。同样是保持的角速度，能翻过垂直再转回来 |
| `X` | 舵和俯仰都回中。回中后舰保持当时的姿态，不会自己改平 |
| `T` / `R` | 锁定下一个目标 / 释放目标 |
| `F` | 开关采矿光束（要先锁定目标；过热会自己停） |
| `V` | 自动接近已锁定的目标 |
| `B` | 自动对准下一个航点 |
| 鼠标左键拖动（触屏是手指拖动） | 环绕舰体；瞄准视角里就是移动准星 |
| 滚轮 | 拉近拉远 |
| `1` – `6` | 跳到六个预设机位 |
| `G` | 开关火炮瞄准视角：镜头抬到舰体上方平视，炮塔跟着准星转 |
| `C` | 开关自动开火：锁定目标后炮塔自己算提前量、自己打 |
| 空格 | 开关自动巡航镜头；在瞄准视角里是开火：按一下打一座已就绪的炮塔，连按两下齐射，按住连续射击 |
| 鼠标单击（瞄准视角里） | 同空格开火；点操船台上的按钮仍是按按钮 |
| 屏幕右侧的 `FIRE` / `SALVO` / `AUTO` | 给没有键盘的手：按住 `FIRE` 连续射击，`SALVO` 齐射，`AUTO` 开关自动开火 |
| `M` | 开关背景音乐 |

画面底部中间的操船台上，车钟、舵条、俯仰阶梯和这些功能都有对应的按钮，点一下和按键等效。舰体始终在原点，只改姿态；“航行”是周围的小行星按舰首方向反向移动。

不碰任何按键时，镜头在六个机位之间自动巡航：四个远景，两个贴近舰桥和前甲板的近景。

## 配方做了什么

舰体的配方在 `assets/models/frigate.esmodel`，由 `tools/generate.py` 写出。它分三段：

1. **粗模**：放样出的舰体和上层建筑、三层舰桥、侧舷装甲带、引擎舱、舰尾的隔热板和四个带加强肋的钟形喷口、尾鳍、带炮盾和炮口制退器的炮塔、桅杆。这一段就是最终画出来的网格，约六千七百个三角形。喷口是一条从轴线出发又回到轴线的 `lathe` 轮廓，所以内腔是真的空腔：轮廓的端点若不在轴线上，`lathe` 会在那里补一个圆盘把口封住。
2. **细节**：`panels` 把每个面切成大小不一的装甲板，板间留缝、板面带倒角，再在每块板上切一层更小的分块；然后加舷窗、甲板机械、管线和航行灯。这一段只进贴图，不进网格。
3. **做旧**：一组 `texel: true` 的 `stain`，在烘焙时逐像素求值：粗糙度云斑、大面积褪色、边缘磨白（`where: "edges"` 加 `fray`）、棱角掉漆露出金属、两层刮痕、细小凹坑、缝隙积灰（`where: "cavity"`）、引擎周围的烟熏。

做旧之前还有一层标识：舰首两舷和前甲板的舷号“27”、侧舷装甲带上的舰名、舰桥窗的窗棂，都是 `stain` 的 `line` 从正侧面、正上方或正前方投到表面上的笔画（`tools/generate.py` 里的 `STROKES` 是一套只有几个字的笔画字），所以掉漆和积灰会盖在它们上面。舷窗和舰桥窗的灯光另有两层明暗与冷暖的变化，不是一片同色。

`normalBake` 把细节和做旧烘成法线、底色、金属粗糙度、环境遮蔽和自发光五张贴图。舷窗、航行灯和引擎喉部靠 `glow` 写进自发光贴图，由泛光接住。材质上还有一层薄清漆（`coat`），让涂装在粗糙的底色之上有一道锐利的高光；炮塔、桅杆和引擎罩是枪灰色金属，喷口是带蓝色和古铜色热变色的钢。

## 其余部分

- **星云**：`tools/generate.py` 用分形噪声算出一张全景高动态范围图，导入成环境，既是背景也是环境光。
- **星空**：后处理里的 `starfield` 效果，星点按像素大小画，叠加在星云之上，任何分辨率下都是点；恒星圆盘也由它按主光方向画出。
- **行星**：带状云纹贴图同样由脚本生成；外面套一层自定义着色器画的大气辉光（`assets/materials/atmosphere.esshader`）。行星对舰体的反光是一盏不投影的暖色平行光，另有一盏冷色轮廓光勾出背光面。
- **小行星带**：三种石块同样是模型配方（球体加三层位移造型，逐像素做旧，减到两千四百个三角形），在场景里散布四十多块。近处的四十块随航速向舰尾漂移并循环，远近不同的视差就是速度感的来源。
- **星门**：航点上有一座真的星门（`assets/models/gate.esmodel`，同样由 `tools/generate.py` 写出）：半径一百七十个单位的环体、六个带发射器的节点、一座有舷窗和桅杆的控制塔，分块和做旧的做法与舰体相同。门内的能量膜是一张方片加一个自定义着色器（`assets/materials/gatefield.esshader`）。`src/main.ts` 每帧把它放在界面所说的航点上；抵达之后它留在原处随航速后退，舰体从环里穿过去，下一座在新的航点出现。
- **操船与姿态喷口**：舵和俯仰下的都是角速度指令，不是角度：打过去就一直转，回中就停在当时的姿态，不会自己改平，所以能转满一圈，也能翻过垂直再转回来。转动要靠推力建立——舰首和舰尾各有上下左右四个姿态喷口（配方里的 `jet`），偏航角加速度最多 0.14 rad/s²、俯仰 0.11 rad/s²，从静止到满舵的转速大约两秒；转速稳定后喷口熄火（太空里匀速转动不耗推力），回中时另一侧的喷口点火把转动刹住。喷流用的是主机尾焰那个模型和着色器（`plume-jet.esmaterial`）。自动驾驶对准航点或目标时也是通过同一套喷口。计算在 `src/helm.ts`。
- **炮塔**：五座双联炮塔——前甲板 A、B，上层建筑两侧的 P、S，舰腹倒装的 V。炮塔座和炮管是两个独立的模型配方（`turret.esmodel`、`guns.esmodel`），各自分块、做旧、烘焙，所以炮塔能回转、炮管能俯仰，舰体上只留固定的炮座。锁定目标后炮塔自己转过去跟着它，采矿光束从一座正对着目标的炮塔炮口出来；进了瞄准视角（`G`），炮塔改为跟着准星。每座炮塔每秒最多转 38°、俯仰 26°，射界各不相同：A、B 打不到正后方，P、S 只管自己那一舷，V 能转一整圈；俯仰从 -8° 到 68°，所以准星压得太低时甲板上的炮塔够不着，只有舰腹那座能打。有死角的炮塔绕远路转，不会穿过自己打不到的方向。瞄准界面是一条带刻度的准星线，每座炮塔当前指向的位置各有一个小标记，转动时落在准星后面、到位后叠上去；准星下面一排是五座炮塔的状态和装填进度（`READY`、`TRAIN`、`LOAD`、`MASKED`）。炮弹打中石块会削掉它，削完就碎；大石块打不动。自动开火（`C`）只打已锁定的目标：火控按目标相对本舰的速度和炮弹飞行时间算出提前量，炮塔瞄的是那个提前点；它没有手动准，每发炮弹在一个散布角里偏出去，目标越远、横向越快散布越大，锁定保持得越久（六秒内）散布越小，界面上的 `SOLUTION` 就是这个进度。目标转到所有炮塔的射界或俯仰限位之外就停火，提示 `TARGET MASKED  TURN THE SHIP`，等舰转过来再打。求解、限位、回转、提前量和散布的计算在 `src/gunSolution.ts`，不依赖引擎，由 `sdk/tests/space-frigate-gunnery.test.ts` 检查；操船的在 `src/helm.ts`，由 `sdk/tests/space-frigate-helm.test.ts` 检查。
- **碎石与灯**：舰体周围一百五十块指甲盖到拳头大的碎石（还是那三种石块模型）随航速掠过并循环，贴近镜头时就是速度感；它们绕开舰体，不会穿模。桅顶和龙骨的频闪灯、舰首的两盏白灯按各自的节拍闪，左红右绿的航行灯常亮，都是一个小球加一个自定义着色器（`assets/materials/flare.esshader`）再配一盏小点光。穿过星门的那一刻，一圈光波从门心扩散到门框（能量膜着色器 `gatefield.esshader` 的 `u_front` 和 `u_burst`），同时一盏大范围的点光把舰体照亮一下再衰减。
- **尾焰**：同一个旋转体网格画两遍，外面是宽而暗的外焰，里面是细而亮、带明暗节点的焰芯，共用一个自定义着色器（`assets/materials/plume.esshader`）；强度和长度由 `src/main.ts` 按油门驱动。
- **声音**：八个声音都是声音配方（`assets/audio/*.essound`），在设备上合成，没有录音：随油门变化的引擎低鸣、车钟与舵令的提示音、进出自动驾驶的提示音、采矿光束、岩石破碎、过热告警和抵达航点。引擎和光束是放在舰上的空间声源，镜头拉远就轻。背景音乐是一份音乐配方（`drift.esmusic`），用的十二个钢琴采样在 `assets/audio/piano/`，许可见其中的 `LICENSE.txt`。安装在 `src/audio.ts`，混音规则在 `src/soundMix.ts`。
- **镜头**：`src/flight.ts` 里的机位表和插值是纯函数，只由经过的时间决定，无头逐帧步进时每一帧都能复现。

## 运行

在编辑器里打开本目录的 `project.esproject`，或从仓库根目录导出后用无头浏览器出图：

```bash
node pipeline/bin/estella.mjs export examples/space-frigate --out output/space-frigate/web --no-aot
```

```bash
node examples/space-frigate/tools/capture.mjs 0.5,10,19,28,39,48
```

截图写到 `output/space-frigate/frames/`，第一个参数是要截的时间点（秒），第二个参数可选，是画面尺寸（如 `1920x1080`）。

## 重新生成资产

所有资产都由一个脚本确定性地生成（需要 Python 的 `numpy` 与 `Pillow`，以及已构建的开发包）：

```bash
python3 examples/space-frigate/tools/generate.py
```

舰体贴图默认烘成 4096。烘焙会用上所有核心，并把探测结果存在工程的 `.esengine/cache/model-bake/` 里：十核的机器上第一次约一分钟，之后只改做旧的颜色、图案或材质时约二十秒；调试时加 `--size 1024` 更快。只重做一部分用 `--only`，取值是 `sky`、`planet`、`grain`、`models`、`materials`、`scene`，可用逗号连写；只重烘某几个模型再加 `--models`，例如 `--only models --models rock-a,rock-b,rock-c`。
